# 复盘模板与自检清单

## 这一篇怎么用

**不要通读这篇笔记。** 它不是用来读的，是用来复制粘贴的。

你在 [拍摄训练法：突破平台期](06-拍摄训练法：突破平台期.md) 里会看到一个判断：平台期的本质是"拍摄量够了，但判断量不够"。这一篇就是把"判断"这件事固化成表单——**因为判断力不会自己长出来，它是被结构化的提问逼出来的。**

用法：每次需要复盘时，新建一条笔记，从下面复制对应的模板，填完。填的过程比填完的结果重要。

> **提示**　Obsidian 用法建议
>
> 把下面的模板存成 Obsidian 的 Template（模板插件），或者直接把这篇笔记设为收藏，每次 `Ctrl+C` / `Ctrl+V`。
> 可以把复盘集中在同一个文件夹里，每篇用「日期－地点」命名。

## 模板一：单张照片复盘（核心工具，用得最多）

用于你觉得"还不错"或者"说不上哪不对"的照片。**一次拍摄只对 3–5 张用这个模板**，多了会变成敷衍。

```markdown
## 照片复盘 · {{date}}

（在这里放入本次要复盘的照片）

**基本信息**：镜头 / 光圈 / 快门 / ISO / 时间 / 地点

---

### 一、光线
- 光从哪个方向来？（顺光 / 侧光 / 逆光 / 顶光 / 散射）
- 光是硬还是软？
- 高光和阴影的分布，是在帮这张照片，还是在碍事？
- **如果我换一个时间来，这张会更好吗？**

### 二、构图
- 观众的眼睛第一眼落在哪？是我想让他落的地方吗？
- 有没有无意义的线条、形状在抢视线？
- **画面四条边上有没有多余的东西？**（这是最常见的问题）
- 如果裁掉 20%，会更好还是更差？

### 三、主体与叙事
- 这张照片在讲什么？用一句话说出来。
- 如果去掉标题和说明，陌生人能看懂吗？
- 有没有"决定性"的成分——一个动作、一个表情、一种关系？
- **如果只能留画面里的一个元素，是哪个？其余的在为它加分还是减分？**

### 四、技术执行
- 曝光、对焦、噪点，是在服务前三点，还是在破坏它们？
- 有没有技术缺陷严重到毁掉这张照片？

---

### 结论（必填，不许写"还行"）
- 这张照片最强的一点是：
- 最弱的一点是：
- **如果重拍一次，我会改的那一件事是**：
- 评级：⭐ / ⭐⭐ / ⭐⭐⭐ / ⭐⭐⭐⭐ / ⭐⭐⭐⭐⭐
```

### 用这个模板的四条纪律

这四条来自成体系的摄影自评方法，每一条都在对抗一种具体的自我欺骗：

| 纪律 | 对抗的是什么 | 怎么做 |
|---|---|---|
| **隔一天再看** | 拍摄现场的兴奋感会让你高估自己的照片 | 拍完当天只做导入和粗筛，**不修图、不评级**，第二天再开始 |
| **参照对比** | 你只跟自己比，永远看不出差距 | 把你的照片和何藩/薇薇安·迈尔的同题材作品并排放在屏幕上（见 [资源清单](13-资源清单.md)），差距会立刻现形 |
| **缩略图测试** | 你在 100% 放大时看到的细节，观众永远看不到 | 把照片缩到手机屏幕大小甚至更小，**能不能在一瞥之间抓住重点**——这才是观众真实的观看状态 |
| **反向提问** | "加什么能更好"是加法思维，会让照片越来越乱 | 永远问"**去掉什么会更好**" |

## 模板二：一次拍摄复盘（每次外拍后）

```markdown
## 外拍复盘 · {{date}} · [地点]

**时长**：__ 小时　**张数**：__ 张　**镜头**：____
**本次的训练目标**（出发前定的）：____________
**天气/光线**：____________

### 数字
- 导入：__ 张
- 粗筛后留下：__ 张（技术合格率 __%）
- 精选后留下：__ 张
- 值得精修的：__ 张

### 三个问题
1. **今天最好的一张是哪张？为什么它比第二好的强？**
   （答不出这个问题，说明你今天的收获是零）

2. **今天最大的一次失败是什么？**（错过的瞬间 / 参数设错 / 犹豫了没按下去 / 构图当时没看到边缘的杂物）
   → 它是技术问题、判断问题，还是心理问题？

3. **下次来这个地方，我会做的一件不同的事是**：

### 训练目标达成了吗
- [ ] 达成
- [ ] 部分达成，因为：
- [ ] 没达成，因为：

### 拍摄点档案更新
（如果发现了值得再来的地点，按 [题材作战地图](09-题材作战地图.md) 的模板记录）
```

> **注意**　关于"张数"
>
> 请如实记录，不要美化。**如果你连续几次都是"拍了 300 张，值得精修的 2 张"，那问题不在于选片太严，而在于你在现场没有思考，靠数量碰运气。**
> 健康的状态是：随着训练推进，**拍摄张数应该下降，合格率应该上升**。

## 模板三：「100 选 5」精选流程（这是你最该补的能力）

出自 [拍摄训练法：突破平台期](06-拍摄训练法：突破平台期.md) 的训练五。请把它当成一个有固定步骤的操作，而不是"随便挑挑"。

### 操作步骤

**第 1 步 · 粗筛（在 Lightroom 里，快，不要犹豫）**
- 只看技术：脱焦、糊、曝光崩溃、构图明显失败 → 打 `X`（排除）
- 目标：**刷掉 60–70%**。刷不掉这么多，说明你的标准太松
- 这一步不许放大看，不许犹豫，一张不超过 3 秒

**第 2 步 · 精选（隔一天做）**
- 剩下的里面选 15 张打旗标
- 再从 15 张里选 5 张打 5 星

**第 3 步 · 强制去重（关键的一步）**
- 检查这 5 张：**有没有两张是同一个想法的不同版本？**（同一个场景连拍的、构图雷同只是时机差一点的）
- 如果有 → **只能留一张**，另一张必须换成一个完全不同的瞬间或构图
- 理由：5 张构图雷同的照片，暴露的是"你今天只有一个想法"

**第 4 步 · 删除的勇气**
- 把你最舍不得删的第 6、第 7 张也删掉
- 逼自己面对"到底哪张最强"这个问题

### 自检
- [ ] 我的 5 张里，没有两张是同一个想法
- [ ] 每一张我都能说出它为什么在这里
- [ ] 如果只能给别人看 1 张，我知道是哪张

## 模板四：每周复盘（工作日晚上，20 分钟）

```markdown
## 周复盘 · 第 __ 周（{{date}}）

### 本周计划 vs 实际
| 项目 | 计划 | 实际 | 备注 |
|---|---|---|---|
| 外拍次数 | | | |
| 后期练习（小时） | | | |
| 看片/读书 | | | |
| 本周主题（52周挑战） | | | |

### 本周最好的一张
（在这里放入本周选出的照片）
为什么：

### 本周学到的一件具体的事
（必须具体到能写成一句操作指令，比如"逆光时用点测光对着人脸，而不是相信评价测光"。
写不出具体的，说明这周是在重复而不是在学习。）

### 下周要改的一件事
```

> **说明**　为什么只要"一件事"
>
> 每周改一件事，六个月是 26 件。每周想改十件事，六个月是零件。

## 模板五：每月复盘（月末，1 小时）

```markdown
## 月复盘 · 第 __ 月

### 一、数字
- 本月外拍 __ 次，共 __ 张
- 进入 5 星的 __ 张
- 后期精修完成 __ 张
- 本月新增拍摄点 __ 个

### 二、本月交付物是否完成
（对照 [六个月周历](11-六个月周历.md) 里本月的交付物）
- [ ] 
- [ ] 

### 三、三张对比
把本月最好的一张，和**上个月最好的一张**、**六个月前的一张**并排放。
- 有没有可见的进步？体现在哪个维度？（光线 / 构图 / 后期 / 瞬间）
- 如果看不出进步，是这个月练错了方向，还是练的强度不够？

### 四、风格线索（这一条累积到第6个月会很值钱）
翻一遍本月的 5 星照片，找共同点：
- 我反复被什么样的**光**吸引？
- 我反复用什么样的**构图**？
- 我的后期反复往哪个**色调**走？
- 我反复拍什么**题材**？

> 风格不是设计出来的，是从你反复被打动的东西里长出来的。
> 这一栏连续填六个月，第六个月你会看到答案。

### 五、下个月的一个调整
```

## 清单 A：出门前检查（拍摄前）

- [ ] 电池充满 + 备用电池
- [ ] 存储卡已清空/格式化，容量足够
- [ ] 镜头前后镜片擦干净（前一天做，不要在现场做）
- [ ] 相机设置归位（MR 档位，见 [相机设置：一次性配置清单](03-相机设置：一次性配置清单.md)）
- [ ] **明确今天的训练目标**（一句话，比如"今天只找侧光"、"今天只拍框架构图"）
- [ ] 查过今天的日出/日落时间（巧摄 App，见 [光线手册](07-光线手册.md)）
- [ ] 如果拍夜景：三脚架、快装板
- [ ] 电动车电量够往返

> **重点**　最重要的一条是"明确今天的训练目标"
>
> **没有目标的外拍，等于把随手拍这件事重复了一遍。** 这正是你卡在平台期的原因。

## 清单 B：修完一张片子的自检（后期）

对应 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md)。每张精修完的照片都过一遍。

- [ ] **暗部**：直方图左侧有没有堆积贴边？（贴边 = 死黑丢细节）
- [ ] **高光**：右侧有没有溢出贴边？**三通道同时溢出 = 真过曝；单通道溢出 = 偏色**（这个区分决定你该拉高光还是该动白平衡/HSL，详见 [直方图与影调：读图能力专项](05-直方图与影调：读图能力专项.md)）
- [ ] **肤色**：不蜡黄也不失血色，高光区皮肤没有死白
- [ ] **锐化**：放大到 100%，边缘有没有白边/黑边光晕？
- [ ] **饱和度**：有没有塑料感、色彩断层？
- [ ] **Before/After 对比**：重点看肤色、边缘、色彩过渡是否自然
- [ ] **缩略图测试**：缩小到手机大小，还成立吗？
- [ ] **一致性**：和这组里其他照片的调子统一吗？（作品集的关键）

---

## 清单 C：构图坏习惯自查

对应 [构图进阶训练](08-构图进阶训练.md)。这些是业余摄影最常见的构图问题，拍完扫一遍：

- [ ] 主体离画面边缘太近，显得局促
- [ ] 地平线歪了（除非是故意的）
- [ ] 背景有电线杆/树枝从主体头顶"长"出来
- [ ] 前景有杂物却没起到前景的作用
- [ ] 什么都想拍进去，结果没有主体
- [ ] 无意义的居中（居中要有理由，比如对称）
- [ ] 边缘元素被切掉一半，看起来像失误而非设计
- [ ] 引导线指向了空处，而不是主体
- [ ] 画面里有两个东西在抢主角

## 六个月里程碑自测

不看笔记，直接回答。答不上来就回去补对应的那一篇。

### 第 1 个月末
- [ ] 我能说出 RAW 和 JPEG 的本质区别，以及为什么 RAW 调白平衡不损失画质
- [ ] 我能看着直方图说出这张照片的影调性格，而不只是"过没过曝"
- [ ] 我知道曝光、对比度、高光、阴影、白色、黑色这六个滑块各自影响哪段亮度

### 第 2 个月末
- [ ] 我能区分"整体过曝"和"单通道偏色"
- [ ] 我能用曲线做出比对比度滑块更精细的反差控制
- [ ] 我知道自己所在城市今天的日落时间，不用查

### 第 3 个月末
- [ ] 我有至少 5 个记录在案的拍摄点档案
- [ ] 我能在举起相机之前，就预判这个焦段的构图大概长什么样
- [ ] 我能对一张自己的照片说出具体的、可操作的批评

### 第 4 个月末
- [ ] 我修的照片有了可辨识的一致调子（不是套的同一个预设，是同一套判断）
- [ ] 我完成过至少一次主动向陌生人请求拍摄
- [ ] 我的拍摄张数在下降，合格率在上升

### 第 5 个月末
- [ ] 我能从一次拍摄的 200 张里，果断选出 5 张且说清理由
- [ ] 我知道自己反复被什么样的光和构图吸引（月复盘第四栏累积的答案）

### 第 6 个月末
- [ ] 我有一组 20–30 张、调子统一、能拿得出手的作品
- [ ] 我有一个还在持续的长期项目（52 周挑战 / 《一年 12 次》 / 某个单一主题）
- [ ] 我能向别人讲清楚我的照片在拍什么
