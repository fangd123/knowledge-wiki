# W1 开机周：逐日执行清单

> **重点**　这一周和后面 23 周不是一回事
>
> W1 **不是训练周，是装机周**。它唯一的目标是把六个月要用的那套系统装好、跑通一遍：相机设置、照片管理、备份、复盘习惯、三个长期项目的开关。
> **这周拍得好不好完全不重要。** 周三和周六拍的那些静物，唯一的用途是给周四的流程演练提供素材——它们大概率会很平庸，那是正常的，不要为此沮丧，更不要因此把时间花在"再拍好一点"上。
> 从 W2 起才开始真正的训练。→[24 周作战卡：每周只看一张卡](16-24_周作战卡：每周只看一张卡.md)

**本周总时间预算：约 7 小时**（周一 1.5h／周二 1.25h／周三 1h／周四 45min／周五 45min／周六 3h／周日 2h）。这是这六个月里工作日投入最重的一周，因为它是一次性的。

---

## 三条本周专属的纪律

**1. 不要出远门拍。** 地基没打之前出去拍，只是在增加待处理的废片。周六在家和楼下就够了。

**2. 只核对两类配件。** 40.5mm 遮光罩 + 相机内胆包与三脚架绑带。**摄影包的决定推迟到 M2 末（W8）**，那时你才有真实数据判断需不需要。→[携行与相机包](15-携行与相机包.md)

**3. 不读理论书。** 这周的资源只有 B 站泰罗的几集视频，还是快进看。读书比装机舒服得多，那正是它这周的危险之处。

## 周日晚（今晚，开工前）· 15 分钟

> 这一格是"预备动作"，做完这周才启动得起来。

- [ ] **核对遮光罩和携行配件**（拼多多搜索词直接抄）：
  - `相机内胆包 加厚 防震 微单 24` — 认准**内部尺寸约 24×16×13cm**，要**上开盖不要侧拉链**，隔板必须是**魔术贴可调**，底部要有独立缓冲层，详情页不给内部尺寸的直接划走
  - `三脚架绑带 背包外挂 尼龙`
  - `遮光罩 40.5mm` — 狗头和福伦达 135/4 同口径，一个罩两支通用
- [ ] **手机日历建两个重复提醒**（这一步只要 3 分钟，但它是整套计划的"发条"）：
  - 每周四 21:00 —— 「选片 + 周复盘」，**这一条永远不许关**
  - 每月家庭拍摄前一天 —— 「15 分钟准备清单」→[人像的解法：家人与陌生人](10-人像的解法：家人与陌生人.md)
- [ ] **在 Obsidian 里建两个空文件夹**：分别收纳复盘和拍摄点档案，复盘笔记按「日期－地点」命名。

## 周一晚 · 90 分钟 · 相机设置（本周唯一超时的一晚）

> **提示**　[相机设置：一次性配置清单](03-相机设置：一次性配置清单.md) 末尾有六项完成确认
>
> 在机身上逐项验证，再给对应项目打勾。

### 第 1 步 · 画质与存储（5 分钟）

- [ ] RAW 格式：**非压缩 RAW**（机身支持的话）
- [ ] 色彩空间：**sRGB**
- [ ] **关闭同时存 JPEG**，只存 RAW

> 为什么关 JPEG：你的目标是养成"每张都过一遍后期"的习惯。机内 JPEG 是偷懒的入口。

### 第 2 步 · 对焦（10 分钟）

- [ ] 默认 **AF-C**（静物/摆拍时手动切 AF-S）
- [ ] 对焦区域：日常**广域**，特写用**灵活点**
- [ ] **人眼 AF 绑到 AF-ON / 中央键**，按住启用、松开恢复
- [ ] 给 16-50 狗头开 **DMF**（先 AF 粗定位，再手动微调）

> 记住能力边界：**能自动对焦的只有唯卓仕 25/1.7 和 16-50 狗头**；135/4 + LM-EA7 能用对焦框但**人眼 AF 无效**；两支手动 50 这一整步都不生效。

### 第 3 步 · 手动头生命线（10 分钟，五支里有三支靠它）

- [ ] **无镜头释放快门：打开** ← **这一项不开，装手动头时你连快门都按不下去**
- [ ] 峰值对焦：等级 **低（Low）**，颜色选**红或黄**（别选接近肤色的）
- [ ] **对焦放大绑到 C2**（机背自定义键）
- [ ] SteadyShot 手动输入焦距：两支 50 输 **50**，福伦达输 **135**（换镜头记得改）

### 第 4 步 · 曝光辅助（10 分钟）

- [ ] 斑马纹：日常 **70–100**，拍人像大光圈时调到**接近 100**专盯皮肤高光
- [ ] **把直方图加进 DISP 取景显示循环** ← 这一项是 W2 直方图专项的前提
- [ ] DRO：**关闭**
- [ ] 测光：默认**多重测光**，逆光/高反差时切**点测光**

### 第 5 步 · 自定义按键（10 分钟）

| 按键 | 绑什么 |
|---|---|
| C1（机顶） | 对焦区域模式切换 |
| C2（机背） | **对焦放大** |
| AF-ON / 中央键 | 人眼 AF（按住启用） |
| 方向键 左 | 驱动模式（单张/连拍） |
| 方向键 右 | ISO |
| 方向键 下 | 峰值开关/等级 |
| 方向键 上 | 直方图/显示切换 |
| Fn | 保留默认，塞曝光补偿、白平衡 |

### 第 6 步 · MR 两档（15 分钟）

**MR1 扫街快速反应档**：A 档｜f/5.6–8｜**最低快门锁 1/125s**｜Auto ISO 上限 3200｜AF-C + 广域｜单张或低速连拍｜斑马纹 70

**MR2 三脚架夜景档**：A 档（熟练后转 M）｜f/8–11｜ISO 固定 100–200｜AF-S 或 MF + 对焦放大｜单张 + **2 秒自拍定时代替快门线**｜直方图常驻

### 第 7 步 · 验收（5 分钟，别跳）

- [ ] **把每个自定义键按一遍**，确认弹出来的是你绑的功能，不是你以为的功能
- [ ] 装上一支手动 50，确认**快门按得下去**（验证第 3 步）
- [ ] 拍一张，回放**切出直方图**（验证第 4 步）
- [ ] 转到 MR1、MR2 各拍一张，确认参数真的切换了

> 最常见的 W1 坑就是这一步没做——到周六出门才发现某个键根本没绑上。

## 周二晚 · 75 分钟 · Lightroom 地基

> 后期能力练得再好，管理一团糟照样低效甚至丢照片。这 75 分钟买的是未来六个月的秩序。

### 目录（15 分钟）

- [ ] LrC 目录（`.lrcat`）建在**内置硬盘**上，**不要建在移动硬盘，选择桌面以外、容易找到和备份的位置**
- [ ] RAW 原片可以放移动硬盘，但**目录文件必须在本机**
- [ ] LrC 设置里把"退出时备份目录"改成 **每周一次**

> 从来不备份 `.lrcat` 是新手最惨的坑：硬盘一坏，RAW 可能还在，但**所有星级、旗标、修图历史一次性全丢**，等于半年白筛。

### 文件夹命名（10 分钟）

- [ ] 定一套命名规范，例如先建年份文件夹，里面的每次拍摄用 `YYYY-MM-DD_静物练习` 这样的名称。
- [ ] **年份文件夹 + 日期_主题**，日期在前，排序自动就是时间轴

### 导入预设（15 分钟）

- [ ] 建一个导入预设：不转 DNG、**加版权元数据**（姓名 + 年份）、构建**标准预览**
- [ ] 存储卡**先原封不动拷一份到硬盘**，再导入 LrC——这一步是习惯，不是软件设置

### 导出预设（15 分钟，建两套，一次设置管六个月）

- [ ] **社交**：sRGB / 长边 2400px / 质量 90% / 加锐化"屏幕-标准"
- [ ] **存档**：sRGB 或原色彩空间 / 原始尺寸 / 高质量

### 筛选约定（10 分钟，写在这一页上）

| 标记 | 含义 |
|---|---|
| `X` 排除 | 技术废片：脱焦、糊、曝光崩溃、构图明显失败 |
| 1 星 | 留着但不修 |
| **3 星** | **值得修**（只精修 3 星以上） |
| 4–5 星 | 精品，进作品集候选池 |

- [ ] 第 1 份（工作盘）：______
- [ ] 第 2 份（不同介质，比如移动硬盘）：______
- [ ] 第 3 份（异地或云端）：______

## 周三晚 · 60 分钟 · 第一次拍摄

> **这不是练习，是给周四的流程演练供素材。** 拍平庸没关系，拍不出来才是问题。

- [ ] 挑**一个**静物（一件旧物最好——正好是本周主题词）
- [ ] 放在窗边，**主体侧对窗户约 45°**，不要正对也不要背对
- [ ] 用**唯卓仕 25/1.7 或七工匠 50/1.8**（**焦段纪律只管外拍**，室内静物不受"锁 16mm"约束；135/4 最近对焦 4 米，在家根本对不上焦）
- [ ] 拍 10 张，**每张只改一个变量**：白纸远近 → 白纸角度 → 机位高低 → 拉不拉薄窗帘
- [ ] 拍的时候顺手验证周一的设置：**峰值亮了吗？直方图切得出来吗？斑马纹在高光处闪吗？**

## 周五晚 · 45 分钟 · 器材体检与遗留项

> 这一格是 [总纲：六个月摄影提升计划](01-总纲：六个月摄影提升计划.md) 里"本周就该做的六件事"里剩下的部分，都是十分钟量级的小事，但每一件都会在某个月突然变得很重要。

### 福伦达 135/4 体检（15 分钟，六十年的老镜头，先验货）

- [ ] **手电筒穿透检查**：用手机手电筒从后往前照穿镜片
  - 像蒙了层白纱、光晕发散 → **起雾**
  - 蛛网状、放射状白丝 → **霉**
  - 边缘出现彩虹纹或气泡状分层 → **胶合分离**
- [ ] **无穷远校验**：整串接上机身 → 对焦环拧到 **∞** → 对着 100 米外的楼顶/天线 → 开峰值和对焦放大看清不清楚
  - 清楚 → 正常
  - 怎么都糊、或要往回退一点才清楚 → 转接叠厚了超过无穷远，仍可用，只是 ∞ 那端要靠手感找
- [ ] **验完把 LM-EA7 从机身上卸下来收好** ← 它**关机也偷电**，装着放一周电池就空了

### 音频链路（20 分钟）

- [ ] LARK M2 接收器切到**立体声模式**（一拖二时永远选立体声——**混掉了后期神仙也分不开**）
- [ ] A6300 录音电平改**手动**，峰值控制在 **-12dB 到 -6dB**（削顶是永久失真）
- [ ] ⭐ **实测 Action 2 走 USB-C 接 LARK M2**（前置触屏模块上那个 USB-C 口）——要用手上的设备**确认兼容性**，十分钟的事，**别等正式拍摄当天才发现不认**

### 其他（10 分钟）

- [ ] 去唯卓仕官网查 25/1.7 有没有针对 A6300 这类老机身的固件更新
- [ ] 备用电池充满（实拍常掉到 250–350 张，一块不够用）

## 周六 · 3 小时 · 静物 20 张（不出门）

> 静物是本月的主力题材，因为它是**唯一一个能让你完全控制光线**的题材。你要先在可控环境里理解光，才能在不可控环境里认出光。

**出发前（就算是在家）也要写下今天的训练目标**：

> 今天的训练目标：____________（比如"只用一扇窗的光，把同一个物体拍出三种不同的情绪"）

三组任务，各拍 6–7 张：

- [ ] **A · 同一物体三种光**：上午柔和窗光 / 中午硬光（拉开窗帘让直射光进来）/ 傍晚低角度光
- [ ] **B · 美食一组**：晚饭就是素材，靠窗、避开头顶灯直射、白纸补阴影
- [ ] **C · 主题词「一件旧物」**：家里的老物件，静物 + 情感叙事，只交一张

> 别追求 20 张都好。**20 张里有 2 张让你自己觉得"这张有点意思"，这周就成了。**

- [ ] **拍摄点档案**：新建一篇，表头抄这个 ——

| 位置 | 最佳时段 | 最佳季节 | 适合题材 | 机位备注 |

### 与家人练三条手机拍摄规则（15 分钟）

可以当面演示，也可以发一条简短的语音。参考说法：

> "我在做一个六个月的摄影计划，想请你帮个忙——你平时拍孩子的照片，能不能改三个小习惯，然后原图发我，我统一修好再发回来给你。
> 第一，拍之前看一眼光从哪来，让孩子面向窗户或者侧对窗户，别背对窗户，背对着拍出来是黑的。
> 第二，蹲下来，手机降到孩子眼睛的高度——这一条最管用，大人站着往下拍是儿童照片最常见的毛病。
> 第三，多拍几张，别只拍一张，孩子表情是流动的，连着拍五张总有一张对的。
> 记得发**原图**，不要发微信压缩过的。"

> 这件事的价值有三层：你获得了源源不断、而且你**真正在乎**的练习素材；把不同设备不同时间的照片统一成一个调子，**正是"个人风格"的核心训练**；以及——分工合作时，"我在处理你拍的照片"是一件具体的、持续的、双向的事。

**过关自检（不看笔记直接回答）**：能不能说出 RAW 和 JPEG 的本质区别，以及**为什么 RAW 调白平衡不损失画质**？
