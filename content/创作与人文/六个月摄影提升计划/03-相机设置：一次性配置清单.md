# 相机设置：一次性配置清单

> 这些设置花你30分钟做一次，能省掉未来六个月里无数次手忙脚乱——尤其是用手动头时错过合焦、忘了看直方图、按键找半天找不到功能。照着做一遍，之后基本不用再碰，只有 MR 档需要偶尔微调。配合 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 一起看，很多设置是专门为了配合那两支手动头存在的。

**关于菜单路径的说明**：A6300 菜单层级比较深，我记不准每一项的精确页码位置，所以下面只写**功能名称和大致所在的菜单分类**（比如"对焦辅助""曝光/色彩""拍摄设置"这几个大类）。找的时候直接在机身菜单里用功能名搜索，或者按分类翻，比死记页码靠谱。

---

## 第一步：画质与存储设置

**怎么做**：
- RAW格式：选**非压缩RAW**（如果机身支持）或至少确认是标准RAW，避免用"RAW+JPEG"里的压缩选项影响后期空间。如果只有"压缩RAW"和"RAW+JPEG"可选，压缩RAW也能用，但要知道它是有损压缩。
- 色彩空间：选 **sRGB**（除非你确认自己的后期流程和最终输出全程走 Adobe RGB，否则 sRGB 兼容性更好，微信、大部分网站默认按 sRGB 显示）。
- 是否同时存JPEG：**建议关闭，只存RAW**。

**为什么**：
- 压缩RAW虽然文件小，但在暗部大幅提亮时更容易出现色阶断层，非压缩RAW给你的后期空间更大。
- 如果目标是练习 RAW 后期，JPEG 直出的"参考图"用途有限，反而占存储空间、拖慢导入速度。你的目标是养成"每张都过一遍后期"的习惯，而不是依赖机内JPEG偷懒，这个态度上的转变可以参考 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md)。

---

## 第二步：对焦设置

**怎么做**：
- 对焦模式：日常挂 **AF-C（连续自动对焦）** 作为默认，静物/人像摆拍时切到 **AF-S（单次自动对焦）**。
- 对焦区域模式：日常扫街用**广域**或**区域**，人像特写用**中间/自由点**配合人眼AF。
- 人眼AF：在自定义键菜单里找"眼部对焦"（Eye AF）相关功能，绑定到一个自定义键上（建议见下方按键分配表），按住时启用，松开恢复正常对焦——这样你可以按需触发，不用一直锁在人眼模式。
- DMF（直接手动对焦）：给 **16-50 狗头**挂上，用它的价值是——先让AF帮你粗定位，再手动微调，兼顾速度和精度。

> **注意**　这一节对哪几支镜头有效
>
> - **唯卓仕 25/1.7** ⭐ 和 **16-50 狗头**：完整支持本节所有设置，包括人眼AF。**这两支是你的自动对焦阵容。**
> - **福伦达 135/4 + LM-EA7**：AF-S / AF-C、对焦框选择能用，但**人眼AF 无效**（转接环限制）。用「灵活点」手动把对焦框挪到眼睛上。
> - **Kamlan 50/1.1、七工匠 50/1.8**：纯手动，本节全部不生效，看第三步。
>
> 见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md)。

**为什么**：
- AF-C适合你走动扫街时主体随时可能移动的场景；AF-S在你已经站定构图、主体不动时更稳，不会因为你手抖或前景遮挡而重新对焦跑焦。
- 人眼AF对你想拍的人像题材（尤其是拍孩子）几乎是决定成片率的关键功能——而它**只在狗头上可用**，这正是 [人像的解法：家人与陌生人](10-人像的解法：家人与陌生人.md) 里把狗头定为家庭挂机头的原因。
- DMF 对狗头意义很大：AF先帮你对上大致位置，你再微调，比纯手动效率高，比纯AF在近距离时更精准。

## 第三步：手动头专用设置（三支定焦的生命线）

**你五支镜头里有三支是纯手动**（Kamlan 50/1.1、七工匠 50/1.8、福伦达 135/4），所以这一节不是"进阶选项"，是**日常使用的前提**。这几项不设好，这三支镜头基本没法用，务必都做一遍。

**怎么做**：
1. **峰值对焦（Focus Peaking）**：在"对焦辅助"相关菜单里找到 Peaking Level 和 Peaking Color。灵敏度设**低（Low）**——灵敏度太高会到处提示假合焦，反而误导你；颜色选一个跟你常拍场景反差大的（比如拍人像多选红色或黄色，别选跟肤色接近的颜色）。
2. **对焦放大（Focus Magnifier）绑定按键**：把"对焦放大"功能绑定到一个你顺手的自定义键（建议见下方按键分配表），按一下放大到画面中心或对焦点位置，方便你在合焦前精确判断。
3. **无镜头释放快门**：在"拍摄设置"相关菜单里找到类似"无镜头快门释放"（Release w/o Lens）的选项，**必须打开**——手动头没有电子触点，机身默认可能因为"检测不到镜头"而拒绝释放快门，不开这个你可能根本按不下快门。
4. **SteadyShot 手动输入焦距**：在防抖/SteadyShot相关菜单里找到手动输入焦距的选项——两支 50 输入 **50**，福伦达输入 **135**（换镜头记得改）。机身读不到这三支镜头的电子焦距信息，得手动告诉它。

5. **⚠️ 用完 LM-EA7 就把它从机身上卸下来**：Techart LM-EA7 在**相机关机状态下仍会缓慢耗电**。这不是设置项，是使用习惯——不卸下来，你会遇到"明明充满电放了一周，拿出来就没电了"。见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 的 LM-EA7 五个坑。

**为什么**：
这几项对应的正是 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 里的手动头合焦现实——Kamlan 全开时景深只有 1-2 厘米，手持合焦成功率本来就只有 30%-60%，**峰值调低 + 对焦放大**是把命中率拉起来的两个关键动作；无镜头释放快门不开，你连快门都按不下去。

**关于福伦达 135/4 的一个特殊操作**：接了 LM-EA7 之后，**把镜头自己的对焦环拧到 ∞ 然后就别再碰它**——转接环马达的 4.5mm 行程正好覆盖 4 米到无穷远，也就是这支镜头的全部原生对焦范围。想拍更近（2–4 米）时，才把对焦环拧到最近端。这套用法的推导过程见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md)。

## 第四步：曝光辅助

**怎么做**：
- 斑马纹（Zebra）：在曝光/显示相关菜单里找到 Zebra 设置，日常设 **70-100** 提示接近过曝的区域；拍人像大光圈时，把数值调到**接近100**，专门盯皮肤高光别死白。
- 直方图显示：在显示设置或者DISP按键循环里，把**直方图**加入到取景显示循环中，拍摄时随时能切出来看，不要只用肉眼看液晶屏亮度判断曝光。
- DRO（动态范围优化）：**建议关闭**，或最多用最低档。
- 测光模式：日常用**多重测光（评价测光）**，逆光或者高反差场景（比如夜景霓虹灯、逆光人像）切到**点测光**，测在你要保留细节的关键区域上（通常是高光或人脸）。

**为什么**：
- 斑马纹是比"看液晶屏亮不亮"靠谱得多的曝光判断方式，尤其是户外强光下液晶屏本身就看不准。
- 如果还不熟悉直方图，这一步先把直方图调出来养成"随时看一眼"的习惯，看懂它是下一阶段的事，专门在 [直方图与影调：读图能力专项](05-直方图与影调：读图能力专项.md) 里练。
- DRO会在机内对JPEG做动态范围压缩处理，你现在主拍RAW+后期，这个功能对你意义不大，还可能干扰你对真实曝光/直方图的判断，不如关掉自己在后期做。
- 点测光配合斑马纹，是前面提到的"弱光欠曝保高光"策略的具体执行工具。

## 第五步：自定义按键布局建议

A6300 有9个自定义键，下面这张表按你的四个主力题材（扫街人文、风光夜景、日常静物美食、人像）来分配，尽量让手指不用离开取景状态就能操作最常用的功能。

| 按键位置 | 绑定功能 | 理由 |
|---|---|---|
| C1（机顶自定义键） | 对焦区域模式切换 | 扫街时经常要在"广域"和"中间点"之间切换，放在最顺手的位置 |
| C2（机背自定义键） | 对焦放大（Focus Magnifier） | 手动头合焦的核心操作，必须一键触发，不能藏在菜单里 |
| AF-ON / 中央键 | 人眼AF（按住启用） | 拍人像/抓拍陌生人时随时按需触发，不常驻，避免干扰其他题材 |
| 方向键左 | 驱动模式切换（单张/连拍） | 从静物慢拍切到扫街抓拍时快速换驱动模式 |
| 方向键右 | ISO快捷调整 | 弱光下需要频繁手动权衡ISO和快门，放在最快能到的位置 |
| 方向键下 | 峰值对焦开关/等级切换 | 用手动头时随时切换峰值灵敏度或临时关闭（避免干扰构图判断） |
| 方向键上 | 直方图/取景显示切换（DISP功能相关） | 快速切出直方图核对曝光，尤其夜景慢门时 |
| Fn（功能菜单键） | 保留默认，常用曝光补偿/白平衡等放进去 | 作为综合功能面板，放你偶尔需要但不必单键常驻的项目 |
| C3或其他可自定义键（如有） | 静音快门/电子快门开关 | 扫街抓拍想安静时随手切，注意开静音快门RAW会降到12bit（见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md)），按需使用 |

**为什么这么分**：扫街和抓拍需要的是"眼睛不离取景器"就能改的参数（对焦区域、驱动模式、人眼AF），所以放在最靠近快门指法的位置；手动头合焦相关的（对焦放大、峰值）单独占两个键，因为这是你现在最容易失败的环节；曝光判断相关的（直方图、ISO）放在拇指方便到达的方向键上，因为夜景和弱光场景你会频繁用到。

## 第六步：MR 两档预设

机身拨盘上有两个 MR 档位，可以各存一套完整参数组合，切换模式转盘就能秒切，不用现场一项项调。建议这样分配：

### MR1：扫街快速反应档

| 项目 | 设置 |
|---|---|
| 拍摄模式 | 光圈优先（A档） |
| 光圈 | f/5.6-f/8（保证一定景深容错） |
| 快门 | 由光圈优先自动，但设置最低快门限制在1/125s左右，避免自动降到过慢 |
| ISO | Auto，上限设到3200左右 |
| 对焦模式 | AF-C + 广域 |
| 驱动模式 | 单张或低速连拍 |
| 镜头 | **唯卓仕 25/1.7 优先**，或 16-50 狗头。这一档的核心是"快速反应"，三支手动定焦不满足前提 |
| 其他 | 人眼AF按需触发，斑马纹70开启 |

### MR2：三脚架夜景/慢门档

| 项目 | 设置 |
|---|---|
| 拍摄模式 | 光圈优先（A档）或手动（M档，熟练后切） |
| 光圈 | f/8-f/11（兼顾锐度和景深） |
| 快门 | 视场景，慢门可到数秒（配合三脚架和快门线/自拍定时避免震动） |
| ISO | 固定100-200，靠慢门而不是高ISO获得曝光 |
| 对焦模式 | 切到 AF-S 或 MF，配合对焦放大精确对焦到关键位置（如城市灯光的边缘、建筑轮廓） |
| 驱动模式 | 单张，开启2秒自拍定时代替快门线，减少按快门瞬间的震动 |
| 镜头 | 狗头广角端为主。**三脚架上手动头反而是优势**——不赶时间、可以慢慢用对焦放大精确合焦，两支 50 在这一档完全可用 |
| 其他 | 长曝光降噪按需开启（会拉长成片等待时间，赶时间连续拍摄时可以关闭）；直方图务必调出来实时核对 |

**为什么分这两档**：你的主拍方向里扫街人文需要的是"随时能拍、参数别拖后腿"的响应速度，夜景则完全相反，需要"慢下来、用三脚架、精确控制每一个参数"。把这两种截然不同的工作模式固化成两个物理档位，你不用在现场临时纠结该怎么调，直接转拨盘进入对应状态。

## 出门前检查清单

打印出来贴在包上，或者存在手机备忘录里，出门前过一遍：

- [ ] 电池：机身内一块 + 备用电池已充满，随身携带
- [ ] 存储卡：已插卡，卡内空间充足，卡是UHS-I U3规格
- [ ] 镜头：今天要拍的题材已经想清楚，挂上对应的镜头（参考 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 分工表）
- [ ] 镜头清洁：镜片、传感器无明显灰尘，随身带一块擦镜布
- [ ] 三脚架：夜景/静物拍摄计划时确认已带
- [ ] 转接环：用手动头当天，确认对应转接环已装好、没松动
- [ ] 设置归位：确认拨盘不在上次用完忘记切回的模式，MR档位对应今天的拍摄类型
- [ ] SteadyShot焦距：换用手动头时，确认已手动输入对应焦距
- [ ] 直方图显示：确认取景循环里能调出直方图
- [ ] 存储空间：卡里旧照片已经备份并清理，留足空间
