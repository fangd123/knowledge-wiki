# 携行与相机包

> 关联：器材分工见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) · 骑行与安全见 [题材作战地图](09-题材作战地图.md) · 每月挂机头见 [六个月周历](11-六个月周历.md) · 视频配件见 [四机分工：两台手机、相机与 Action 2 怎么分工拍 Vlog](14-四机分工：两台手机、相机与_Action_2_怎么分工拍_Vlog.md)

## 一句话总结

**你需要的包比你以为的小得多。** 因为 [六个月周历](11-六个月周历.md) 里"每月锁死一支挂机头"这条纪律，六个月里"带两支以上镜头出门"的场景几乎不存在——真正的携行需求是**一机一镜 + 一块电池**，加上第 3 个月起多一根三脚架。

所以结论是：**现在（M1）只买一个内胆包和一根三脚架绑带，塞进普通双肩包。大包推迟到 M2 末，跟三脚架一起决定，而且很可能根本不需要。**

这一篇的存在意义是：**别在 M1 就买一个为"五支镜头全带"设计的包**——那个场景在这六个月里一次都不会发生。

---

## 一、每次出门到底带什么

把 [题材作战地图](09-题材作战地图.md) 的题材表和 [六个月周历](11-六个月周历.md) 的挂机排布对起来，实际会出现的组合只有七种：

| 组合 | 场景 | 带什么 | 出现在 | 体积档位 |
|---|---|---|---|---|
| **A 通勤轻装** | 下班顺路，5km 内 | 机身 + 当月挂机头 + 1 块电池 | 全程，尤其 M2 夏季 19:00 后 | 极小 |
| **B 周末扫街** | 5–15km | 机身 + 挂机头 + 电池 + 备卡 | M4 主场 | 小 |
| **C 夜景蓝调** | 蹲守 | 机身 + 挂机头 + **三脚架** + 快装板 | **M3 起** | 小 + 一根杆 |
| **D 晴天长焦人像** | 户外 4–15m | 机身 + **135/4 转接链**（+ 阴天备 Kamlan） | **M5** | **决定尺寸的那一档** |
| **E 静物美食** | 在家 | 不用包 | M1、每周三晚 | — |
| **F 视频** | 四机分工 | 机身 + 16-50 + 手机 + Action 2 + LARK M2 一拖二 + 小脚架 | 按需 | 小件多，要配件仓 |
| **G 家庭纪实** | 随行李携带 | 机身 + 唯卓仕 25/1.7 + 电池，**塞进行李** | 家庭拍摄时 | 内胆场景 |

### 三条从表里读出来的结论

**1. 两支手动 50 永远不会同时进包。** [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 里写死了："它们是重复的，带一支出门就够了。"

**2. 只有 M5 会带两支镜头**（135/4 晴天 / Kamlan 阴天，出门前天气不定时才两支都塞）。其余月份都是一机一镜。

**3. 组合 G 决定了内胆包优于任何摄影包。** 如果旅途中也要拍家人，你需要"把相机塞进行李箱/双肩包"，不是"背一个摄影包"。[六个月周历](11-六个月周历.md) 建议家庭拍摄时挂唯卓仕 25/1.7，不受当月训练镜头约束——那是全套器材里最小的一支（168g），一个内胆包绰绰有余。

> **重点**　六个月里体积需求最大的一天，是 M5 的某个晴天
>
> 不是"所有镜头全带"那天，因为那天不存在。

## 二、尺寸怎么算出来的

这是全篇唯一需要算的地方，算完就不用再纠结了。

**福伦达 135/4 转接链**（[器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 里的数据）：

```
Super-Dynarex 135/4 本体   约 95mm
  + ROOLAD DKL-M 转接环     约 25mm
  + Techart LM-EA7          约 25mm
  ────────────────────────────────
  镜头段总长                约 150mm
  + A6300 机身厚度          约 50mm
  ════════════════════════════════
  整套横放所需长度          约 200mm
  整套竖放（镜头朝下）所需净高  约 200–210mm
```

机身宽度约 120mm。所以：

| 摆法 | 需要的仓内尺寸 |
|---|---|
| 竖放（镜头朝下） | 净高 ≥ **210mm** |
| 横放（镜头轴线水平） | 净长 ≥ **210mm** × 净宽 ≥ **130mm** |

**关键推论**：一个**内部约 24×16×13cm** 的内胆包，横放刚好装得下这套最长的组合，也就是说——**一个内胆包能覆盖 M1 到 M5 的全部挂机组合**，只有三脚架装不下。

这就是为什么大包在这六个月里是可选项而不是必需品。

> **注意**　别信估算，自己量一次
>
> 上面的数字是按公开规格推的。ROOLAD 是通用转接环，厚度有批次差异。
> **动手做一次**：机身接上 135/4 全链，用卷尺量总长，加 15mm 余量，这个数字才是你的筛选下限。量完把结果写回这一页。
>
> 实测总长：______ mm（待填）

## 三、买什么：分两步走

### 第一步 · 现在就买（M1）

[六个月周历](11-六个月周历.md) 的 M1 明写"别买器材""本月不要出远门拍"，W1 是"不出门，在家拍静物 20 张"。所以现在只买这两样小件，不违背那条纪律：

**① 相机内胆包，内部尺寸约 24×16×13cm**

一件东西同时解决四个场景：

- 塞进你现有的通勤双肩包 → 组合 A/B，M1–M2 零额外成本
- 单独拎着 → 周三晚室内静物、周末在家拍美食
- 扔进行李箱 → **组合 G，旅途中拍家人**
- M5 横放装下 135 转接链 → 组合 D

**② 三脚架外挂绑带**

两根尼龙扣带，把三脚架捆在现有背包侧面。M3 的夜景线开始时先用这个顶着，别为了挂一根杆去买一个新包。

### 第二步 · M2 末的决策点（按需决定）

到 M2 结束时（[六个月周历](11-六个月周历.md) W8 之后），你会有真实数据来判断：现有通勤包背着骑车稳不稳、外挂三脚架晃不晃、蓝调蹲守时东西够不够放。

**触发买大包的三个信号**，出现任意两个就买：

1. **W7 蓝调蹲守**（日落前 30 分钟拍到天全黑）时，三脚架 + 换镜头 + 天冷加衣，东西没地方放
2. 骑电动车时包体左右甩，或外挂三脚架磕腿
3. **M4 W16 蹲 2 小时以上**、**M5 W19 反复回同一地点**——蹲守型拍摄需要能放水、能久背，这是大包唯一不可替代的场景

**如果三个都没出现，就不买。** 省下的钱按 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 的采购表，直接进 CPL 或 ND。

## 四、真要买大包时的硬指标

四条筛选器，不满足直接划走，其余都是加分项：

| 指标 | 数值 | 为什么 |
|---|---|---|
| **相机仓净高** | **≥ 210mm** | M5 的 135 转接链，见第二节 |
| **侧面三脚架绑带 + 底部托兜** | 必须有 | M3 起夜景线的刚需 |
| **自带防雨罩** | 必须有 | [题材作战地图](09-题材作战地图.md) "防雨"那条，别再另买塑料袋 |
| **胸前扣带** | 必须有 | 骑电动车防止包体左右甩，这条比想象中重要 |

**强烈建议的两个设计**（能兼得最好，二选一也行）：

- **侧开门**：不脱包就能侧身抽出相机。正好对上 [题材作战地图](09-题材作战地图.md) 里"电动车随停随拍、不用找停车位"的机动性优势
- **背板开口**（贴背那面开）：背着时别人打不开，对应"临时停车防盗"那条

**容量**：15–20L，自重最好 < 1kg。**上下分仓**（上仓放外套/水/充电宝，下仓放器材）在 W7 蹲两小时那晚会体现价值。

## 五、拼多多怎么检索

### 搜索词

**现在要买的两样**（把尺寸数字写进搜索词，能过滤掉一大半标题党）：

```
相机内胆包 加厚 防震 微单 24
三脚架绑带 背包外挂 尼龙
```

**M2 末如果要买大包**，按从精确到宽泛的顺序试：

```
微单摄影包 双肩 侧开 三脚架
双肩摄影包 防盗 背部开口 防雨罩
相机双肩包 索尼 微单 15L
```

补充关键词按需追加：`胸扣`、`分仓`、`快取`、`轻量`。

### 内胆包的四个核对点

小件的坑和大包不一样，这四条是专门针对内胆的：

1. **隔板必须是魔术贴可调，不能是固定缝死的**。缝死的只能按它的格子放，M3 换七工匠、M5 换 135 链时会直接卡死
2. **要"上开盖"，不要"侧拉链"**。上开盖能从上方直接抓相机；侧拉链塞进大包之后基本打不开
3. **底部要有独立缓冲层**。最常见的偷工是四壁有棉、底部没有——而底部正是放下背包时受冲击的地方，[题材作战地图](09-题材作战地图.md) 里"电动车颠簸防抖动"防的就是这个
4. **详情页必须给内部尺寸**。只给外部尺寸的直接划走，基本是通用件贴牌

### 大包的四步核对

1. **只看内部尺寸**，不看外部尺寸
2. **在评价区用关键词搜索**（拼多多评价区可以搜词）：依次搜 `尺寸`、`长焦`、`三脚架`、`隔板`、`防雨罩`。真实买家晒的内部图比主图有用十倍
3. **拿卷尺量一次自己的 135 全链**（见第二节），得出筛选下限
4. **优先选支持七天无理由 + 退货包运费的链接**。包这类东西尺寸不合的概率不低

### 品牌

- **内胆包**：品牌不重要，这个价位都是同一批代工。看评价区实拍图的隔板厚度就行
- **便宜档大包**：卡登 CADEN、宝罗 BAROL、赛富图 Safrotto、吉尼佛 JENOVA、锐玛 EIRMAI。做工够用，隔板偏薄
- **加钱档**：乐摄宝 Lowepro、天霸 Tenba、曼富图 Manfrotto。**只在"百亿补贴"频道买这几个牌子**，普通链接正品率不稳
- **避开**：标"仿国家地理""同款 NG"的帆布包。造型好看，但隔板薄、无防震、下雨吸水，和"防抖动 + 防雨"两条要求直接冲突

## 六、用肩带快挂缩短取机时间

搜 **相机快挂扣 / 肩带快挂**（Peak Design Capture 的国产同类）。夹在双肩包肩带上，相机直接挂在胸前。

这解决的是双肩包唯一的结构性缺点——**取机慢**。对 [题材作战地图](09-题材作战地图.md) 里"电动车随停随拍"那条机动性优势，快挂能省下取机的时间：停下车，两秒钟就能拍。

配合 [六个月周历](11-六个月周历.md) M4 的扫街月尤其明显——那个月练的是决定性瞬间，取机速度就是命中率。

## 七、骑行携行的三条纪律

摘自 [题材作战地图](09-题材作战地图.md)，放在这里便于出门前对照：

- **防抖动**：镜头之间必须有软隔板分开，避免颠簸中互相磕碰。手动老头（Kamlan、七工匠、福伦达）没有电子部件，但镜片组和镀膜怕震
- **防雨**：包内常备防水罩，突然下雨第一时间罩住，别等淋湿了才想起来
- **防盗**：临时停车拍摄时，**包不要放在车筐里无人看管**。福伦达 135/4 是六十年前的镜头，丢了买不回同一支

> **提示**　出门前的两秒检查
>
> 电池装了吗（[器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md)：实拍常掉到 250–350 张，必须带第二块）· 卡在机身里吗 · 防雨罩在包里吗
>
> 另外：**LM-EA7 在相机关机状态下仍会缓慢耗电**。M5 用完 135/4 那套，回家把转接环从机身上卸下来。
