# 四机分工：两台手机、相机与 Action 2 怎么分工拍 Vlog

> 关联：[总纲：六个月摄影提升计划](01-总纲：六个月摄影提升计划.md) · 器材底子见 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) · 后期流程见 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md) · 题材分工见 [题材作战地图](09-题材作战地图.md) · 人像难题见 [人像的解法：家人与陌生人](10-人像的解法：家人与陌生人.md) · 采购清单汇总见 [资源清单](13-资源清单.md)

## 一句话结论

**这套方案用四台设备分工，不是"手机 vs 相机"的二选一。** 简单说：

1. **一加13T 负责日常记录、需要即时分享的内容、以及走动式 vlog 口播**——屏幕能自拍监看，主摄 4K60 够用，拍完直接能发朋友圈/小红书。**它的定位是"快"，不是"好"**：不用调色、当天就要发的东西给它。
2. **红米 K90 才是你真正的视频主力机**——因为它**支持 LOG 录制而 13T 不支持**，而且相机里能一键下载官方还原 LUT。凡是打算认真调色、要进作品集的视频，用 K90 拍。它另外还补上了超广角和第二机位两个洞。详见第二节之二。
3. **DJI Action 2（含前置触屏模块）负责运动/穿戴/超广角自拍这类手机和相机都够不到的第一视角**——磁吸挂身上、贴脸自拍、骑电动车、贴身跟拍孩子跑动，155°超广角能装下手机装不下的环境信息。**有了前屏之后，它是四台设备里唯一"超广角 + 能自拍监看"的一台**，走动式自拍 vlog 的白天首选。但它有两个硬伤要提前认清：**发热自动关机**和**续航短**，别指望它长时间连续录制；另外**装上前屏模块就不防水了**。
4. **A6300 负责静态摄影和"有设计感的空镜"**——光学质感、浅景深、可换镜头带来的视角控制，这三样是手机和运动相机的计算摄影都模拟不出来的，加上它作为静态照片主力机的定位没有变。

下文把四台设备各自的能力边界、麦克风怎么接、以及具体场景该用哪台，都摆清楚。

## 一、A6300 为什么不适合 vlog：障碍表

| 障碍 | 实拍中的具体表现 | 有没有绕过办法 |
|---|---|---|
| **屏幕不能翻到自拍角度** | A6300 是可上下俯仰的翻转屏，但**翻不到面向镜头前方**——市面上专门有卖"反光镜自拍支架"（挂热靴上把翻起的屏幕反射到镜头前）这种配件，本身就是这个缺陷催生的产物。也就是说自拍/vlog 监看时你看不到自己的取景框，全靠蒙 | 加装反光镜自拍支架，但增加了一层配件、构图仍然别扭；根本上不如直接换设备 |
| **4K 卷帘快门极严重** | 4K 读出速度约 34ms，同代机型里数一数二严重。手持走动/平移拍 4K，画面里的直线（建筑边缘、地平线）会明显扭曲甚至呈"果冻"状，被多篇评测称为"几乎不可用" | 固定机位拍 4K 没问题；一旦要走动/平移，一律降到 1080p（这条在 [器材手册：A6300 与五支镜头](02-器材手册：A6300_与五支镜头.md) 里已经写过） |
| **无机身防抖（IBIS）** | 手持走路拍视频，画面抖动全靠镜头自身 OSS（**只有 16-50 狗头有，三支定焦全都没有**），达不到手机电子防抖 + 云台那种"稳如平台"的效果 | 上三脚架/独脚架，或后期在 PR/达芬奇里做数字稳定（会裁切画面），治标不治本 |
| **视频对焦只有人脸检测，没有人眼AF** | 人眼 AF 只在拍照模式生效，录视频时只能识别人脸大致位置，对焦精度和跟踪能力明显弱于拍照模式，跟手机的视频级人脸/主体跟踪不是一个量级 | 固定景深、手动预对焦，或用小光圈增加景深冗余 |
| **单次录制限制约 30 分钟 + 4K 发热自动关机** | 官方对非专业机身设有 30 分钟录制上限（欧盟税法历史遗留规定）；实测 4K 录制约 20 分钟左右机身就可能报温度过高，部分情况能撑到 29:59 触发上限，也有更早就自动关机的情况 | 备多块电池交替降温、用外部散热配件，但本质上不适合长时间连续录制的 vlog 场景 |
| **无耳机监听口** | 有标准 3.5mm 麦克风输入口（可接外部麦克风，也兼容 Sony XLR-K1M/K2M 转接器），**但没有耳机孔**，录制时无法实时监听收音质量 | 用带自监听功能的麦克风，或录完立即回放检查 |
| **电池续航短（NP-FW50）** | 官方标定约 LCD 400 张/EVF 350 张（针对拍照场景），4K 视频连续录制这种高负载场景实测续航会明显低于这个数字（视频场景的具体分钟数厂商未公布，建议自己实测一次记下来） | 备用电池 |

**能绕过的**（S-Log2/S-Log3 支持、固定机位 4K）不是问题；**绕不过的**（屏幕角度、卷帘快门、IBIS）才是这篇笔记建议你把日常 vlog 交给手机/Action 2 的真正原因。A6300 支持 S-Log2/S-Log3（原生 ISO 800，S-Log3 官方标称约 14 档宽容度），这本是拍视频的加分项，但前提是你得先能稳定、能自拍监看、能收好音——这些前置条件它都缺。

### 它的强项

- **主摄底子不小**（1/1.56 英寸），配 OIS，白天/日常光线下色彩鲜活、细节清晰，评测普遍认为"够用甚至出彩"。
- **视频规格账面上超过 A6300**：4K60、杜比视界HDR、双镜头都能录4K，这几项 A6300 完全没有（A6300 4K 只到 30fps，没有 HDR/杜比视界）。
- **屏幕能直接自拍监看**——这是手机对付 vlog 最朴素也最关键的优势，A6300 做不到（Action 2 裸机也做不到，见下节）。
- **机身防抖体系更完整**：主摄 OIS+EIS 双重叠加，走路手持的稳定性天然比无 IBIS 的 A6300 好一截。
- **小屏轻量**（185g），揣兜里就能随手掏出来拍，适合骑行途中停车拍摄，也方便随手记录。

### 它的短板

- **没有超广角**，这是13T 最大的争议点（下面单独展开）。
- **长焦无 OIS**，只靠电子防抖，手持长焦端视频稳定性会打折扣。
- **前摄美颜算法偏保守**，细节处理被评测认为不如主打自拍的机型。
- **夜景暗部**：主摄白天表现好，但评测反馈暗部噪点涂抹感明显，夜景是"够用不出彩"的水平。
- **不支持 LOG 录制**，这是它和红米 K90 最大的分野：13T 拍的视频只能小幅调整，没法做真正的调色。

### 没有超广角，对 vlog 自拍意味着什么

这条必须单独说清楚，因为它直接影响你能不能"边走边拍自己+环境"这种最常见的 vlog 镜头。

手机自拍 vlog 的取景范围，本质上取决于**手臂长度 + 镜头视角**两个变量——手臂能伸多远是固定的（大约50-70cm），所以镜头视角越广，画面里能装下的"自己+背景环境"就越多。这就是为什么几乎所有主打 vlog 的手机（包括同价位不少竞品）都把超广角作为前摄或后摄自拍的标配：没有超广角，手臂伸到最长，画面里往往也只有你的半张脸+肩膀，背景环境被死死裁掉，"记录我在哪里、周围是什么样"这个 vlog 最基本的功能会被削弱。

13T 用主摄（24mm 等效）自拍，取景范围比广角机型窄，实际影响是：

- **边走边说的自拍口播镜头**：能拍到人，但环境信息会明显变少，尤其是在狭窄街道、室内等空间受限的场景。
- **补救办法**：用前摄（也是24mm左右，视角同样不算广）而不是转后摄自拍；实在需要更广的取景，靠"手机稳定器+延长杆"物理拉远拍摄距离，用空间换视角；或者干脆调整拍法——多用"手持平移展示环境+定点口播"分开拍，而不是硬求一镜到底的广角自拍。
- **这正是 Action 2 该接手的场景**——它的 155° 超广角天生就是为这种"自己+环境"的贴脸自拍设计的，13T 拍不出来的画面，交给 Action 2 反而是它的强项，详见下一节。

### 它补上的第一个窟窿：超广角

前面第二节讲过，**一加 13T 最大的短板就是没有超广角**——自拍时手臂伸到最长，画面里也只有半张脸加肩膀，"记录我在哪、周围什么样"这个 vlog 最基本的功能被削掉了大半。

**K90 有超广角，这个洞就补上了。**

但要认清它的水位，而且限制比想象中更硬：

1. **800 万像素**，光线足的户外够用，进室内或天色转暗，噪点和涂抹感很明显。
2. ⚠️ **超广角录像只有 1080p@30fps**——这条更要命。它没法和主摄的 4K 素材剪在一起而不露怯，也不支持 LOG。

所以超广角的定位要往下调：**它是"应急广角"，不是"vlog 主力"。**

- **白天户外，只需要一两个交代环境的镜头** → K90 超广角，够用
- **需要广角且要画质/要能调色** → 换 Action 2（155°，f/2.8，4K 可用）
- **绝大多数场合** → 用主摄，13T 或 K90 都行

### 它补上的第二个窟窿：LOG —— 这条比超广角重要得多

**K90 的专业模式支持 LOG 视频录制，一加 13T 不支持。** 这一条决定了两台手机的主次关系。

**LOG 之于视频，就是 RAW 之于照片。**

这个类比不是打比方，是同一件事：直出的视频，是手机已经按自己的审美把对比度、饱和度、锐度全部"烤"进画面的成品，你后期再想改，改的是已经被压扁的数据。LOG 则刻意把画面拍成**灰扑扑、低对比、看起来很难看**的样子——因为它在用有限的位深，尽可能多地保留高光和暗部的信息，把"好不好看"这个决定权交还给你。

这正是 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md) 整篇笔记的核心命题，只不过换到了视频上。

**而且 K90 给了你一个"标准答案"：相机设置的"专业视频功能介绍"页里可以一键下载官方的「Mi-LOG 转 Rec.709」还原 LUT。**

这个 LUT 的意义，比它听起来大得多：

| | 照片流程 | 视频流程 |
|---|---|---|
| 原始素材 | RAW | LOG |
| **标准化的第一步** | 相机配置文件 / 校准 | **官方还原 LUT** |
| 之后才轮到 | 你的调色 | 你的调色 |

**你现在最缺的正是"标准化的第一步"。** 如果习惯"套滤镜看效果"——问题不在于用滤镜，在于你是在**一个不确定的起点上**套滤镜，所以只能靠试。官方 LUT 给了你一个确定的、正确的起点：先用它把画面还原成正常的 Rec.709，**这时候画面是"准"的，然后你再往上加自己的风格**。

这套"先归位，再表达"的顺序，是从"碰运气"走向"主动判断"的分水岭。视频这边有官方 LUT 帮你把第一步做对，照片那边你得自己练——但两边是同一套思维。

> **注意**　LOG 是把双刃剑，三条纪律必须守住
>
> 1. **拍了 LOG 就必须调色。** 不调色的 LOG 素材比直出还难看——灰、闷、没对比。**没打算后期的片子，就用普通模式拍。**
> 2. **曝光要准，宁可稍过，绝不欠曝。** K90 的 LOG 是 **10bit**（见下节），余量充足，断层风险比 8bit 低得多。但纪律不变：色阶断层最大的来源是**欠曝之后在后期硬拉暗部**，10bit 只是余量大，不是免疫。
> 3. **LOG 只有 1x 主摄和 2.5x 长焦能用**，超广角没有。所以想要"能调色的广角"，还是得靠 Action 2。

### LOG 素材的实际规格：4K60 / HEVC / 10bit

相机设置里找不到色深开关是正常的——**色深不是用户可调项**，跟着 LOG 和编码格式自动走。

K90 专业模式开 LOG、4K60 拍出来的文件，实测元数据：

```
Writing hardware : REDMI K90
com.xiaomi.record_log : 1          ← LOG 确认开启

Video
Format           : HEVC
Format profile   : Main 10@L6.2@Main    ← 10bit profile
Bit depth        : 10 bits              ← ✅ 确认
Width × Height   : 3840 × 2160
Frame rate       : 60.000 FPS
Bit rate         : 129 Mb/s
Chroma           : 4:2:0
Color range      : Full
Color primaries  : BT.2020
Frame rate mode  : Variable
Audio            : AAC LC 320 kb/s / 48 kHz / 2ch
```

**4K + 60fps + LOG + 10bit 可以同时成立**，后期余量充足，不用担心 8bit 那种色阶断层。

**编码格式决定色深上限**：H.264 在手机上基本等于 8bit，10bit 必须走 H.265/HEVC。K90 默认输出的就是 HEVC，设置无需改动。小米体系里这一项一般在「相机设置 → 视频设置 → 高效视频编码」附近（具体路径以你机器上的 HyperOS 版本为准，未实机核对）。

> **提示**　怎么验别的视频文件
>
> - **MediaInfo**（图形界面）：拖进去看 Video 轨的 `Bit depth`
> - **ffprobe**：`ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,pix_fmt -of default=nw=1 文件.mp4` → `yuv420p` = 8bit，`yuv420p10le` = 10bit

### 这份规格带来的三个实操要点

#### ① 码率 129 Mb/s ≈ 1 GB／分钟

2.9 秒的样片就 45.9 MB。换算下来：

| 时长 | 大致文件体积 |
|---|---|
| 1 分钟 | 约 1 GB |
| 10 分钟 | 约 10 GB |
| 1 小时 | 约 58 GB |

**这直接决定了 LOG 的使用方式：它是"有意识地拍"的模式，不是"一直开着录"的模式。** 想随手记录就用普通模式，码率只有它的零头。家庭拍摄之前务必先清空手机和硬盘空间。

#### ② `Color range: Full` —— 最容易踩的后期坑

大多数视频是 Limited（16–235），而这个文件是 **Full（0–255）**。如果剪辑软件按 Limited 去解读 Full range 的文件，结果是**黑的更黑、白的更白**：暗部细节被压死、高光被削掉，而你会以为是自己拍砸了。

**症状**：素材导进去，LOG 本该灰扑扑的，却显得对比度过高、暗部一团黑。

**解法**：达芬奇里媒体池右键素材 → Clip Attributes → **Data Levels 设成 Full**；Premiere 里对应解读素材时的色彩范围设置。**先把这一步做对，再套官方 Mi-LOG → Rec.709 的 LUT**，否则 LUT 是套在错误的数据上，怎么调都不对。

这件事本身就是「**先归位，再表达**」最好的例子——顺序错了，后面全白费。另外注意色域是 **BT.2020**，别在套 LUT 之外再做一次色域转换，会重复转换。

#### ③ 变帧率（VFR）

样片标称 60fps，但 `Frame rate mode: Variable`（实测区间 52.57–69.93 FPS）。VFR 在剪辑里是出名的麻烦，典型症状是**音画不同步且越到后面偏得越多**，Premiere 尤其明显，达芬奇容忍度好些但也不保险。

**但这段只有 2.9 秒，这个波动很可能只是短样本的测量噪声。** 录一段两三分钟的再看一次 `Frame rate mode`：

- 仍是 Variable → 剪之前先用 HandBrake 或 Shutter Encoder 转成固定帧率（CFR）
- 变成 Constant → 忽略这条

> **提示**　不管答案是几 bit，操作纪律是同一条
>
> **曝光要准，宁可稍微过一点点，绝对不要欠曝。**
> 色阶断层（banding）最大的来源不是位深本身，是**欠曝之后在后期把暗部硬拉回来**。8bit 会更早暴露这个问题，10bit 只是余量大一些，不是免疫。
> 换句话说：**这个问题的答案会改变你的容错空间，但不会改变你该怎么拍。** 查清楚了更好，查不清楚也不耽误你现在就开始用 LOG。

### 它补上的第三个窟窿：第二机位

这一条比超广角更重要，而且几乎没人一开始会想到。

**vlog 之所以看起来"业余"，很大一部分原因是全程只有一个机位。** 一镜到底、角度不变、剪辑时只能靠跳剪，观众三分钟就疲劳了。而解决办法不是买更好的相机，是**再来一个角度**。

有两台手机时，可以先试这个双机位方案：

| 机位 | 设备 | 摆法 |
|---|---|---|
| **A 机位（主）** | 一加 13T | 手持或三脚架，正面口播，画质最好的那一路 |
| **B 机位（辅）** | 红米 K90 | 固定在桌上/三脚架上，侧面 45° 或稍远的全景，全程不动 |

剪辑时在 A 和 B 之间切，画面立刻就"有制作感"了。**这是零成本的观感提升**，比换任何一台设备都划算。

延伸用法：
- **拍孩子**：一台固定拍全景（记录"当时那个房间是什么样"），一台手持追细节。做长期家庭纪实时，固定机位那一路的价值会随时间越来越大。
- **拍美食/静物过程**：一台俯拍，一台侧拍，一次拍完两个角度，不用重来一遍。
- **7100mAh 的意义**：K90 电池大，特别适合当那台"一直开着不管它"的固定机位。

> **注意**　双机位的唯一麻烦：两台手机的色彩不一样
>
> 一加和红米的调色风格不同，同一个场景拍出来，白平衡和饱和度会有肉眼可见的差异。剪在一起会"跳"。
>
> **这恰好是你这六个月要练的核心能力。** 处理办法：两台都尽量用**专业模式手动锁定白平衡和曝光**，后期进同一个 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md) 的流程统一调色。
> 换个角度看——**这是个绝佳的练习题**：如果你能把两台不同品牌手机拍的素材调成一致，你就已经掌握了"统一不同来源照片的调子"这项技能，而这正是 [人像的解法：家人与陌生人](10-人像的解法：家人与陌生人.md) 里"由家人拍摄、统一后期"那套方案的技术前提。

### 它还能干的第四件事：坏天气和脏活

K90 是 **IP68 + IP69**，防护等级明显高于一般手机。下雨天、水边、灰尘大的工地/市集，**用 K90 上，别拿 13T 冒险**。备用机的另一层价值就是"可以不心疼"。

## 三、DJI Action 2 能做什么

先说清楚一件事：Action 2 发布于 2021 年 10 月（国行 2022 年 2 月同步上市），到现在大疆已经出到 Action 3、4、5 Pro 好几代新品，Action 2 大概率处于官方渠道下架清仓或已停售的阶段（**具体停产时间未查证**），目前购买多半要走二手/闲鱼渠道。这不影响它能不能用，但意味着一旦硬件损坏，配件和官方维修的可获得性会逐年变差，心里要有数。

### 核心规格表

| 项目 | 规格 | 备注 |
|---|---|---|
| 传感器 | 1/1.7 英寸 | 和大疆口袋灵眸 Pocket 2 同规格底 |
| 镜头 | f/2.8，**155° 超广角视场角** | 适合需要超广角的场景，比13T的24mm主摄视角宽得多 |
| 照片分辨率 | 最大 4000×3000（约1200万像素），支持 RAW DNG | |
| 视频最高规格 | **4K 120fps**；1080P 最高240fps（8倍慢动作） | |
| 色深/色彩模式 | **仅8bit，不支持10bit**；色彩模式有"标准（Normal）"和"D-Cinelike" | 后期宽容度明显低于A6300的RAW，这条要认清，别对它抱和相机同等的后期期待 |
| 数码变焦 | 拍照/视频最高4倍；60fps以上视频只能2倍 | |
| ISO 范围 | 100-6400 | |
| 电子快门 | 30s 到 1/8000s | |
| 裸机尺寸/重量 | 39×39×22.3mm，56g | 比一节5号电池还小 |
| 防水 | **裸机不装任何模块，原生防水10米**，配合防水壳可下潜到60米 | 这是手机和A6300都做不到的能力 |

### 电子防抖：三种模式怎么选

| 模式 | 支持规格 | 特点 |
|---|---|---|
| **RockSteady**（标准电子增稳） | 支持到 4K/120fps | 靠裁切画面边缘做增稳，稳定性强、可用分辨率最高，代价是会损失一部分155°的原始视场角 |
| **HorizonSteady**（水平锁定） | 最高只到 2.7K/60fps | 能把画面死死锁在水平线上（哪怕机身翻转），但视场角进一步收窄，且分辨率明显低于RockSteady，**拍不了4K** |
| **HorizonBalancing**（后续固件更新新增） | 支持到 4K/60fps，水平修正范围 ±45° | 是前两者的折中：4K可用、视场角比HorizonSteady宽，代价是水平修正幅度有限（不像HorizonSteady理论上能修平任意角度的倾斜） |

想要4K高帧率画质，用RockSteady；想要"哪怕机身歪着也绝对水平"的效果（比如骑车颠簸路段），用HorizonSteady但要接受降到2.7K；日常骑行/走动，HorizonBalancing是更均衡的默认选择。

### 模块化设计：磁吸主机 + 两个可选模块

这是 Action 2 和一般运动相机最大的不同——机身本体极小，靠磁吸吸附不同功能模块来扩展能力：

| 模块 | 作用 | 关键数据 |
|---|---|---|
| **裸机（Camera Unit）** | 最小可用形态 | 实验室工况续航约70分钟（1080p/30fps、关闭防抖），实际4K+防抖开启的发热环境下远达不到这个数字 |
| **前置触屏模块（Front Touchscreen Module）** | 磁吸吸附在主机底部，增加一块OLED前屏，**可以自拍监看构图**；同时内置microSD卡槽和麦克风阵列（3-4麦，不同资料表述略有出入） | 叠加后续航提升到约160分钟（同样是实验室工况）；这个模块本身**不防水**，下水需要额外配防水壳 |
| **续航模块（Power Module）** | 磁吸吸附，无屏幕，纯粹加电池+microSD卡槽，支持通过USB-C外接麦克风 | 叠加后续航约180分钟（1080p/30fps、关闭防抖的实验室工况） |

**对vlog来说最关键的一条判断**：能不能自拍监看，完全取决于你有没有装前置触屏模块。裸机主屏是朝机身背面的1.76英寸屏，自拍时你看不到取景框，和A6300翻不了自拍角度是同一个问题；装上前置触屏模块之后，才有真正意义上能看到自己的"自拍屏"。

> **提示**　用前置触屏监看自拍
>
> 装上它之后，**Action 2 是你四台设备里唯一一台"超广角 + 能自拍监看"的设备**。这一条同时补上了两个缺口：一加 13T 没有超广角（第二节）、A6300 屏幕翻不到镜头前方（第一节）。
>
> 三条连带结论，都要记住：
>
> 1. **续航从约 70 分钟提到约 160 分钟**（实验室工况）。但实际开 4K + 防抖仍然只有十几分钟，发热才是真正的天花板，见第八节。
> 2. ⚠️ **装上前屏模块之后就不防水了。** 裸机原生防水 10 米，模块本身不防水。**下水、大雨、水边拍摄时要么另配防水壳，要么把前屏模块卸下来用裸机**——这时候你就又回到"盲拍"状态，取舍要提前想好。
> 3. 模块自带 **microSD 卡槽 + 麦克风阵列 + USB-C 口**。那个 USB-C 口就是 LARK M2 接进 Action 2 的物理通道，见第五节。

### 磁吸配件生态

大疆围绕 Action 2 做了一整套磁吸配件：磁吸挂绳/项链（挂脖子上做第一视角穿戴拍摄）、磁吸头戴支架、磁吸球头转接座、各类磁吸背夹。这套生态的核心卖点就是"随身穿戴、无脚架也能固定机位"，是它相对手机和相机最有辨识度的使用方式——挂在胸口拍骑行第一视角、别在衣领拍低角度跟拍孩子，这些都是手机举着拍不出来的效果。

> **提示**　磁吸配件的两种用法
>
> 装好前屏模块、固定好磁吸配件，就可以试拍：
> - **骑电动车第一视角**（对应 [题材作战地图](09-题材作战地图.md) 的"电动车半径"）：磁吸挂胸口，HorizonBalancing 模式，白天出门
> - **贴身跟拍孩子**：别在衣领做低机位，这是第九节说的"孩子眼里的世界"那个视角
> - **纪律**：分段短镜头，别指望连续录制，理由见第八节

## 五、你的麦克风：猛玛 LARK M2 一拖二

**好消息：这支麦克风把 vlog 里最难的那一半问题直接解决了。** 它的规格远超你目前的使用需求，接下来六个月里音频这条线你基本不用再操心，只需要把几个开关设对。

### 5.1 核心规格

| 项目 | 参数 | 对你意味着什么 |
|---|---|---|
| 配置 | **一拖二**：2 个发射器（TX）+ 1 个接收器（RX） | 可以同时收两个人的声音，或者一个夹自己、一个放环境 |
| 音质 | **24bit / 48kHz**，信噪比 70dB，最大声压 115dB | 这是正经的广播级规格，不是"手机配件"水平 |
| 接收器输出 | **3.5mm TRS** | ⭐ **正好是 A6300 麦克风口的标准，直插即用，不需要任何转接** |
| 传输 | 2.4GHz，视距最远约 300 米 | 远超任何实际使用距离 |
| 续航 | 接收器内置 145mAh，约 **9 小时**；USB-C 充电约 1.5 小时 | 一整天外拍不用管它 |
| 声道模式 | 机身按键可切 **单声道 / 立体声** | 这是最重要的一个设置，见 5.3 |

### 5.2 各设备怎么接

> **提示**　先看接收器的输出接口
>
> 手机可走 USB-C 音频输出，或使用支持麦克风输入的 3.5mm→USB-C 转接头。Action 2 的兼容性要单独试录。

| 设备 | 怎么接 | 注意 |
|---|---|---|
| **A6300** | 接收器 3.5mm TRS → 机身麦克风口，**零转接、即插即用** | A6300 **没有耳机孔，无法实时监听**。解决办法：看接收器自己屏幕上的电平条，并且**每拍完一段立刻回放确认** |
| **一加 13T** | ✅ 走 USB-C（USB-C 输出或带解码芯片的转接头） | 录一段并回放，确认声音来自领夹麦 |
| **红米 K90** | ✅ 同上走 USB-C | ⭐ K90 支持**耳机回授监听**——这是四台设备里唯一能实时监听录音的一台。**重要的录音场合优先用 K90**，你能当场听出问题，而不是回家才发现 |
| **Action 2** | ✅ 走 USB-C（前置触屏模块上的 USB-C 口） | ⚠️ 这条路径**仍未实测**。运动相机的 USB-C 音频输入兼容性历来不稳。**找一个晚上花十分钟测通一次**，别等到骑行或正式拍摄时现场才发现不认 |

> **提示**　TRS / TRRS 的坑
>
> 3.5mm 插头分两种标准：**TRS**（两道黑环，相机标准）和 **TRRS**（三道黑环，手机耳机标准）。两者插反是"插上没声音/只有一边有声"最常见的原因。
> **LARK M2 的相机接收器输出的就是 TRS，和 A6300 完全匹配。** 转到 USB-C 时要确认转接头带音频芯片并支持麦克风输入，纯物理转接头不能完成这项转换。

### 5.3 三个必须设对的开关

**① 用立体声模式，不要用单声道模式**

一拖二状态下：
- **单声道（Mono）**：两个发射器的声音混在一起，出来是一路信号。**混了就分不开了。**
- **立体声（Stereo）**：TX1 走左声道，TX2 走右声道。后期在剪辑软件里可以**把两个人的声音分别调音量、分别降噪**。

如果只夹了一个发射器，两种模式差别不大；但只要两个都在用，**永远选立体声**。这个决定是不可逆的——录的时候混掉了，后期神仙也分不开。

**② A6300 的录音电平改成手动**

机身默认是自动录音电平（AGC），它会在你不说话的时候把底噪拉高、说话的时候压下去，听起来会"呼吸"。改成手动，峰值控制在电平表的 **-12dB 到 -6dB** 之间——留出余量比顶格更安全，数字音频一旦削顶（clipping）就永久失真，救不回来。

**③ 发射器夹在胸口往上一拳的位置**

夹太低（腰部）会收到衣物摩擦声，夹太高（领口正下方）会有喷麦。**距离嘴巴 15–20cm、略微偏向一侧**是最稳的位置。

**④ 户外一律套防风毛套**

出门前检查毛套：**它只有装上去才有用，忘在包里等于没有。** 风噪是不可逆的——后期降噪能压掉一部分，但会同时吃掉人声的高频，听起来发闷。

把它加进出门前的检查动作：**发射器夹好 → 摸一下有没有毛套 → 看一眼接收器电平**。骑电动车、江边、天台、任何有风的场合，一次都别省。

### 5.4 一个你可能没想到的用法

LARK M2 是一拖二——**这意味着你可以把一个发射器交给另一位家人**。

家庭聚会时，两位家人各夹一个发射器，用手机录一段**日常对话**，吃饭或散步时都可以。声音能唤起照片以外的记忆，也能留下孩子长大过程中声音的变化。

这几乎不占用你任何拍摄精力——按下录音，放在口袋里，之后剪进《一年 12 次》的视频版里。配合 [人像的解法：家人与陌生人](10-人像的解法：家人与陌生人.md) 那套固定格式项目，你会拿到一份别人复制不了的东西。

## 六、把手机（和Action 2）当正式拍摄设备的三条纪律

手机/运动相机能不能算"正式摄影设备"，不取决于它的传感器有多大，取决于你有没有把它纳入和相机一样的工作流程。随手拍和正式拍摄的区别不在设备，在纪律：

**① 照片拍 DNG，视频拍 LOG，都不要直出**

**视频用 K90 的 LOG**（13T 没有这个功能），拍完第一步先套官方「Mi-LOG 转 Rec.709」还原 LUT 归位，再做自己的调色。照片这边——

**四台设备全部能出 RAW。** 一加 13T 和红米 K90 的专业模式都支持 RAW，Action 2 照片模式明确支持 RAW DNG，A6300 本来就是 RAW 主力。

这意味着**"统一个人风格"这件事在技术上已经没有障碍了**——四台设备的照片都能进同一个 LrC 目录、走同一套流程。

务必用 RAW，不要直出：直出 JPEG 是厂商已经按自己的审美"调好味"的成品，跟相机 JPEG 一样，后期空间很小；RAW/DNG 才能让你用同一套流程（曝光、白平衡、影调曲线）去处理，各设备拍的片子风格才可能统一，而不是"一批浓郁鲜艳、一批寡淡还原、一批广角畸变没修"几种画风打架。

**注意一个代价**：手机 RAW 文件大得多（单张几十 MB），而且**手机相册里看 RAW 通常没有"直出"好看**——因为你看到的是没经过厂商算法的原始数据。这不是拍坏了，这是正常的。习惯这一点，本身就是从"看效果"走向"看数据"的一步。

**② 锁定主摄 1x 当"定焦"练，别无意识切镜头**

没有超广角反而是件好事——它逼着你老老实实用主摄的 24mm 视角。日常拍摄时刻意锁定 1x（或用长焦2x 当第二支"定焦"），当成你手上除了 A6300 那几支镜头、Action 2 的155°广角之外的第五支"镜头"来使用，而不是每次都在几个焦段之间乱切、每张构图都靠数字变焦凑合。焦段固定，你才会被逼着用脚步和身体去构图，这和练手动头合焦是同一个道理——限制越死，基本功长得越快。

**③ 手机片/运动相机素材也要进同一个 LrC 目录，走同一套筛选评级流程**

这条最容易被忽略，却是决定这些素材是"素材"还是"作品"的关键。具体做法：

- 拍完导出 DNG（或至少导出高质量素材），导入 LrC，和相机 RAW 放进同一个"时间+主题"命名的文件夹或建立统一目录结构
- 走 [后期路线：从套滤镜到主动判断](04-后期路线：从套滤镜到主动判断.md) 里写的两遍筛选法：粗筛删废片，精筛打星级
- 精修时用同一套预设起点、同一套后期判断逻辑；Action 2 的8bit素材宽容度有限，重点校正它常见的边缘畸变和8bit断层问题，不要用对待A6300 14bit RAW的力度硬拉
- 只有这样，四台设备拍的东西才会形成统一的个人风格，而不是"相机拍的是作品，手机和运动相机拍的是随手拍"几套互不相干的东西——这对你想建立个人风格、攒作品集这两个目标都很关键

## 七、Vlog 的真实瓶颈是音频和稳定，不是画质

新手最容易搞反优先级：纠结"要不要上更好的相机才能拍好 vlog"，而真正让 vlog 看起来业余的，几乎永远是这两件事——**收音发虚/有杂音**、**画面手持抖动**。画质在手机竖屏刷这种实际观看场景下，观众的容错度远比你想象得高；糊了一点没人在意，但杂音、忽大忽小的人声、抖得晃眼的画面，三秒劝退。

### 按拍摄用途配齐器材

前置触屏模块、USB-C 音频通道、防风毛套和磁吸配件各有用途。要让两台手机同时架起来，还要核对**手机夹的数量**。

> **提示**　双机位要的是"两个支撑点"，不是"两个手机三脚架"
>
> 若有**手机小三脚架（含一个手机夹）**和**相机三脚架**，支撑点就够了，再给相机三脚架配一个手机夹即可。手机夹底部是标准 1/4"-20 螺孔，和相机三脚架的云台/快装板完全通用，拧上就用，不需要任何转接件。
>
> **而且相机三脚架当 B 机位比手机小三脚架更好**：高度能调到人眼水平（小三脚架只能放桌上，B 机位永远是仰拍）、更稳（B 机位歪了你当场发现不了，因为你在看 A 机位）、能退远到两三米外那个没有桌子的位置。
>
> **两个不等价的地方**：① M3 夜景月 A6300 长期占着三脚架，会和 B 机位抢——但那些场合本来也不拍双机位 vlog，撞上了就手机用小的、A6300 用大的；② 桌面美食俯拍，大三脚架架在桌上笨重，**取决于你的三脚架有没有中轴横置/反装**，没有的话小三脚架正好留着干这个。

### 手机/Action2 vs 相机的画质差距，在实际观看场景下能感知吗

坦率地说：**在手机竖屏刷视频这个场景下，大概率感知不到。** 观众通过流媒体压缩后的手机屏幕看视频，分辨率、色深这些参数级差距会被压缩算法和小屏幕抹平大半；真正能被一眼看出来的，是运镜稳不稳、人声清不清楚、剪辑节奏顺不顺。这也是为什么职业 vlogger 里相当一部分主力设备就是手机/运动相机+稳定器+领夹麦——不是他们买不起相机，是这套组合的"产出效率/画质"性价比在 vlog 这个内容形式下就是更高。

## 八、Action 2 的坑

这些是官方参数表不会主动告诉你、但会实实在在影响你拍摄体验的问题，如实写出来，别买了之后才发现。

### 发热与自动关机

这是 Action 2 口碑最差的一点。室内环境下，4K60 录制约7分钟左右就可能触发过热关机，2.7K60 约15分钟；极端情况下 4K120 室内录制约3分钟就会过热，4K30 也可能撑不过6分钟就自动关机。室外有自然风、气流通畅时表现明显更好，评测中有反馈能录到电池耗尽也不触发过热。

**缓解办法**：室内/闷热环境下别指望一镜到底，分段短镜头拍摄，中间留出散热时间；夏天户外反而是它的舒适区，比闷热无风的室内更合适；别用密闭的手机壳式配件把机身整个包裹住闷住散热。

### 续航短，且和发热经常同时触发

第三节表格里"70/160/180分钟"都是**实验室工况**（1080p/30fps、关闭防抖）测出来的数字。实际开着RockSteady或HorizonSteady录4K，实测续航经常只有5-20分钟左右就把电量耗尽——很多时候电量耗尽和过热关机是前后脚发生的，两个限制叠加着一起拖累实际可用时长。

**缓解办法**：你的前置触屏模块已经把标称续航从约 70 分钟提到约 160 分钟，**但那是实验室工况**——实际开 4K + 防抖仍然只有十几分钟。**别因为装了模块就以为续航问题解决了**，真正的天花板是发热，加电池解决不了过热关机。随身带充电宝，Action 2 支持 USB-C 直充边充边用；别指望"一次充满能拍一整天"，这不现实。

### 小传感器，弱光表现明显偏弱

1/1.7英寸的传感器，在暗光/夜晚场景下噪点和涂抹感会比A6300甚至一加13T都要明显。它的强项是白天光线充足的运动/穿戴场景，不是弱光vlog的合适选择。

**缓解办法**：夜景/室内暗光的vlog镜头交给一加13T或A6300，Action 2 专心留给白天、光线充足的运动和穿戴视角。

### 超广角边缘畸变

155°的镜头视场角虽然带来了"能装下自己+环境"的优势，但代价是画面边缘（尤其贴脸自拍、主体靠近镜头边缘时）会有明显的桶形畸变和拉伸变形。

**缓解办法**：自拍/贴脸镜头时尽量让主体（脸）靠近画面中心区域，别让脸出现在画面最边缘；后期部分软件（包括大疆自家的Mimo App）自带畸变校正选项，可以开启做基础矫正。

## 九、家庭纪实怎么分工

家庭纪实可以按照片、日常动态和第一人称视角来分工。

和家人相处时，设备切换的时间成本要压到最低。建议这样分工：**A6300 负责拍"作品级"的照片**——用50/1.8或50/1.1拍孩子的特写、拍一家人坐在一起的画面，慢慢构图，事后精修，这是留给多年后翻相册看的东西。**一加13T 负责录日常动态影像和声音**——一句日常对话、笑出声的瞬间、一起散步的样子，这些东西的价值不在画质，在"声音和动作本身"，这恰恰是照片给不了、相机也不该硬拗视频功能去凑的部分。

**Action 2 补的是前两者都够不到的那个视角**：磁吸挂在自己身上或放在贴近地面的低机位，跟着孩子满地跑，拍到的是相机举在手里、手机拿在手上都拍不出来的第一人称视角和声音——孩子跑起来时你看到的世界是什么样，比你居高临下拿着手机拍下来的画面，更接近孩子自己的视角。这是四台设备里唯一能做到这一点的。

但不要指望它能长时间连续记录——上一节写的发热和续航限制是真实的，室内环境下几分钟就可能自动关机，别把它当成"挂着录一整个下午"的监控设备来用。更现实的用法是：挑几个你判断"值得从这个角度录下来"的片段，短镜头分段拍，拍完及时导出、及时给它降温。三类设备各司其职，不用纠结"该用哪个拍孩子"——相机是你决定"这一幕值得慢下来、认真构图"的时刻，手机是你想留住"这一秒正在发生的样子"的时刻，Action 2 是你想要"孩子眼里的世界长什么样"的时刻。和家人相处时，别让设备选择占用你本该专心陪伴的注意力。
