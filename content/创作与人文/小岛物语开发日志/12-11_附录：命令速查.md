# 11 附录：命令速查

以下命令都在项目根目录 `cozy-island/` 下、用 PowerShell 执行。

## 11.1 两种启动方式

| 方式 | 命令前缀 | `user://` 指向 | 适用 |
|---|---|---|---|
| 正式安装的 Godot | `& '<本地路径>'` | 真实用户目录 `%APPDATA%\Godot\app_userdata\小岛物语\` | 平时玩、验收 |
| 工作区启动器 | `python tools/run_godot.py [--record=<log>]` | `.tools/test-profile/`（隔离） | 受限沙箱（Codex）；`--record` 会把输出存到 `test-results/` |

下文用 `godot` 代指第一种的完整路径；换成 `python tools/run_godot.py` 效果相同，只是用户目录不同（区别见 [06](07-06_测试与验收.md#两个重要的认识)）。

准备同版本引擎（下载到 `.tools/`，核对 SHA-256）：

```powershell
python tools/fetch_godot.py
```

## 11.2 运行游戏

```powershell
godot --path .                 # 正常游玩
```

## 11.3 验收四件套

```powershell
godot --headless --path . --import                       # ① 导入资源，应退出 0
godot --headless --path . --quit-after 120               # ② 冒烟：输出 READY: 小岛物语 | 64x44 | 70 props | 6 NPCs | day 1
godot --headless --path . -s tests/run_tests.gd          # ③ 逻辑测试：输出 ALL TESTS PASSED
godot --path . -- --screenshot-test "--shot-dir=$PWD\test-results\screens"   # ④ 截图（不能 headless，29 张）
```

注意：

- 改了素材、音频或 JSON 以后，先跑 ① 再跑其他命令；
- 截图需要真实窗口，不加 `--headless`。截图时窗口被最小化会自动恢复；
- 不要和另一个进程同时导入同一个工程。

## 11.4 专项命令

```powershell
# 截图模式 + 故障注入：01 之后主动最小化一次，检查能否恢复
godot --path . -- --screenshot-test --screenshot-minimize-test "--shot-dir=$PWD\test-results\screens_min"

# 导出 7 个角色的动物语 beep（22050 Hz 16-bit 单声道 WAV），导出后直接退出
godot --headless --path . -- "--dump-voice=$PWD\test-results\voices"

# 真实联网的 TTS 冒烟测试（只请求一次）；第二条用不可达代理验证超时路径，预期退出码 1
godot --headless --path . -s tools/voice_online_smoke.gd
godot --headless --path . -s tools/voice_online_smoke.gd -- --proxy=127.0.0.1:1 --timeout=1

# 自动驾驶演示（实时运行，不录制）
godot --path . -- --demo

# 录制演示视频 → test-results/demo/cozy_island_demo.mp4（需要 ffmpeg）
python tools/record_demo.py
python tools/record_demo.py --size 1280x720 --out <path.mp4>
```

## 11.5 重建前的准备：用到的模型和推理框架

游戏运行时不调用任何 AI 模型，AI 只用在离线生成素材和配音上。生成好的图片、语音、音乐都已经在仓库里，只有想重新生成时才需要准备下面这些。

### 总览

| 环节 | 模型 / 工具 | 推理框架 | 运行位置 | 产出 |
|---|---|---|---|---|
| 静态精灵（角色、建筑、物件） | **Z-Image Turbo**（6B，`int8_convrot` 量化）+ 文本编码器 Qwen3 4B + VAE `ae` | ComfyUI v0.41.0 + PyTorch 2.14.1（CUDA 13.0） | 107 服务器的 RTX 3090，端口 8189 | 33 张静态精灵 |
| 走路帧 | **FLUX.2 klein 4B**（以选定立绘为参考图改图）+ 同一个 Qwen3 4B + VAE `flux2-vae` | 同上 | 同上 | 7 个角色共 35 帧 |
| 抠图、对齐、校色、地面距离场 | 不用模型，numpy + Pillow 写的规则算法 | 本机 Python | 本机 | `assets/sprites/`、地面距离场 |
| 居民配音 | 微软中文神经网络语音（声音名形如 `zh-CN-XiaoyiNeural`，6 位居民各用一种） | 云端服务，通过 `<语音服务地址>` 的 `/v1/audio/speech` 接口调用 | 云端 | 282 条离线语音 |
| 背景音乐 | 不用 AI 模型：Python 手写和弦与旋律 → MIDI | FluidSynth 2.6.1 + GeneralUser GS 2.0.3 音色库渲染，ffmpeg 做响度和编码 | 本机 | 4 首时段 BGM |

两个出图模型都是 Apache-2.0 许可，可以商用。比较过但最后没有采用的方案：走路帧比较过 Qwen-Image-2.1 改图和 MiniMax H3 首尾帧视频（见 03 美术管线），BGM 比较过 ACE-Step 1.5 文生音乐（见 05 音频设计）。

### ComfyUI 服务

- **版本**：ComfyUI v0.41.0 原版。Python 环境里是 torch 2.14.1+cu130 和 comfy-kitchen 0.2.37（`int8_convrot` 量化权重由它计算）。显卡 RTX 3090 24 GB，驱动 595.99.02。
- **节点**：两个工作流只用 ComfyUI 内置节点，不需要装自定义节点。
  - Z-Image：`UNETLoader`、`CLIPLoader`（type `lumina2`）、`VAELoader`、`ModelSamplingAuraFlow`、`KSampler` 等；
  - klein：`LoadImage`、`VAEEncode`、`CLIPLoader`（type `flux2`）、`ReferenceLatent`、`CFGGuider`、`Flux2Scheduler`、`EmptyFlux2LatentImage`、`SamplerCustomAdvanced` 等。
- **启动参数**（107 上的 `~/llm/bin/comfy_cuda.sh`）：`--listen 0.0.0.0 --port 8189 --bf16-vae --reserve-vram 1.5`。
- **速度**（3090）：模型加载好以后，Z-Image Turbo int8 约 5 秒一张，klein 4 步约 4–6.5 秒一张；第一张要加上模型加载时间，约 9–14 秒。

### 模型文件

都来自 ModelScope 上 Comfy-Org 打包好的仓库。下载后按类型放进 ComfyUI 的模型目录，或者像 107 一样用 `extra_model_paths.yaml` 映射：

| 文件 | 放到 ComfyUI 的 | 大小 | 来源（ModelScope 仓库内路径） | 用于 |
|---|---|---|---|---|
| `z_image_turbo_int8_convrot.safetensors` | `models/diffusion_models/` | 6.2 GB | `Comfy-Org/z_image_turbo`：`split_files/diffusion_models/` | 静态精灵 |
| `qwen_3_4b.safetensors` | `models/text_encoders/` | 8.0 GB | `Comfy-Org/z_image_turbo`：`split_files/text_encoders/` | 两个模型共用 |
| `ae.safetensors` | `models/vae/` | 335 MB | `Comfy-Org/z_image_turbo`：`split_files/vae/` | 静态精灵 |
| `flux-2-klein-4b.safetensors` | `models/diffusion_models/` | 7.8 GB | `Comfy-Org/flux2-klein-4B`：`split_files/diffusion_models/` | 走路帧 |
| `flux2-vae.safetensors` | `models/vae/` | 336 MB | `Comfy-Org/flux2-klein-4B`：`split_files/vae/` | 走路帧 |

合计约 22.7 GB。24 GB 显存的 N 卡就够用。3090 这类没有 FP8 硬件的卡用 `int8_convrot` 最快；也可以换成同一仓库里的 `z_image_turbo_bf16.safetensors`，但更慢，而且要把脚本里的文件名一起改掉。

### 换一台机器生成

1. 按上面两张表准备 ComfyUI 和模型文件，确认浏览器能打开 `http://<地址>:<端口>`。
2. 改两个脚本开头的服务地址：`tools/gen_assets.py` 和 `tools/gen_walk_frames.py` 里的 `COMFY = "http://<内部服务器>:8189"`。
3. 换显卡、换量化版本或换 ComfyUI 版本以后，同一个种子出来的图会不一样。已有的选图记录（`_raw/selected.json`、`_raw/walk/selected.json`）只对应原环境生成的原图，重新生成后要重新挑图。

### 配音接口

- 接口地址在 `data/voices.json` 的 `endpoint`，每位居民的声音、语速、音高、风格也在这个文件里。
- `tools/gen_voice.py` 用 Python 标准库发请求，会读 `HTTPS_PROXY` 环境变量。workers.dev 在国内网络通常要走代理，例如先执行 `$env:HTTPS_PROXY = 'http://127.0.0.1:7897'`。
- 游戏里的在线配音（含 `{time}` / `{day}` 的动态台词）先读 `voices.json` 的 `proxy`；留空时按 `HTTPS_PROXY` → `https_proxy` → `ALL_PROXY` → `all_proxy` 的顺序找代理。

### 本机 Python 依赖

在 Python 3.13 上测试过：

```powershell
pip install numpy pillow imageio-ffmpeg
```

numpy 和 Pillow 用于抠图、走路帧处理和地面距离场；imageio-ffmpeg 自带 ffmpeg，用于配音后处理和音乐编码。FluidSynth 和音色库的准备见下面 11.6 的“音乐”。

## 11.6 重建素材和数据

所有产物都已经生成并放在仓库里，**正常运行不需要重建**。下面的命令用于修改内容后重新生成；每次重建后都要再跑一次 `--import`。

### 美术

```powershell
# 在 107 服务器的 ComfyUI（Z-Image Turbo）生成原图 → _raw/<id>_<seed>.png（已存在则跳过）
python tools/gen_assets.py [asset_id ...] [--variants 2] [--seed-base 1000]

# 拼候选对比图，方便挑选
python tools/contact_sheet.py <out.png> [前缀 ...]

# 挑选结果写入 _raw/selected.json 后，抠图 → assets/sprites/*.png + 两张检查图
python tools/process_assets.py
```

### 走路帧

```powershell
# 用 107 上的 FLUX.2 klein 4B 生成候选 → _raw/walk/<角色>_<pose>_s<seed>.png
python tools/gen_walk_frames.py [角色 ...] [--seeds 3,4,5,6] [--poses stepL,pass,stepR]
python tools/gen_walk_frames.py [角色 ...] --mirror    # 先翻转原图再改图，得到另一只脚在前的帧

# 挑选结果写入 _raw/walk/selected.json 后，对齐、校色 → assets/sprites/walk/（35 张 + walk_frames.json）
python tools/process_walk.py
```

### 地图和地面

```powershell
python tools/build_data.py        # 重建 map.json 和地面距离场（会覆盖手工改过的地图；不动台词和物品）
python tools/terrain_fields.py    # 只手工改了 map.json 时，用它重新烘焙距离场
```

### 字体

```powershell
godot --headless --path . -s tools/bake_font.gd   # 换了源字体后重建 default_font.res
```

### 语音

```powershell
# 改了 data/voices.json 的声音参数或改了台词后重跑；只会请求缓存里没有的句子
python tools/gen_voice.py
python tools/gen_voice.py --limit 5    # 开发探测：最多处理 5 句，不改 manifest
```

报告输出到 `test-results/voice_report.json`，原始 MP3 缓存在 `_raw/voice_cache/`。

### 音乐

需要先准备（都放在不进版本控制的 `.tools/`）：

- FluidSynth 2.6.1：`.tools/fluidsynth/fluidsynth-v2.6.1-win10-x64-cpp11/bin/fluidsynth.exe`；
- GeneralUser GS v2.0.3 音色库：`.tools/soundfonts/GeneralUser-GS.sf2`；
- `pip install numpy imageio-ffmpeg`。

```powershell
python tools/compose_bgm.py                    # 重新作曲、渲染全部四首
python tools/compose_bgm.py --only night       # 只重渲染夜曲，但仍检查全部四首
python tools/compose_bgm.py --fluidsynth=<exe> --soundfont=<sf2> --ffmpeg=<exe>   # 指定工具路径
```

报告输出到 `test-results/bgm_report.json`。

换成其他曲目（比如 AI 生成的）时，只改 `data/music.json`：

```json
"morning": {
  "file": "res://assets/audio/music/your_candidate.ogg",
  "gain_db": 0,
  "loop_mode": "crossfade",
  "loop_crossfade": 3.0
}
```

## 11.7 常见调整

| 想改什么 | 改哪里 | 之后要做 |
|---|---|---|
| 某位居民的台词 | `data/npcs.json` | `python tools/gen_voice.py` → `--import` |
| 某位居民的声音 | `data/voices.json` | 同上 |
| 物品售价、喜好 | `data/items.json`、`data/npcs.json` | 直接重启 |
| 背景音乐、交叉淡化时长、对话压低量 | `data/music.json` | `--import`（换文件时）→ 重启 |
| 换一张素材 | `_raw/selected.json` | `python tools/process_assets.py` → `--import` |
| 换一帧走路图 | `_raw/walk/selected.json` | `python tools/process_walk.py` → `--import` |
| 地图布局 | `data/map.json`（或 `build_data.py`） | `python tools/terrain_fields.py` → `--import` |
| 演示视频的台词 | `scripts/demo_director.gd` 里的 `forced` 设置 | `python tools/record_demo.py` |
