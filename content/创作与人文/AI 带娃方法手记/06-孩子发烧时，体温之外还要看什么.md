# 孩子发烧时，体温之外还要看什么

半夜换人照顾发热的孩子，只交代一个体温，接手的人很难知道接下来做什么。我更想先听到几句普通话：醒来能不能像平时那样回应？呼吸费不费力？喝得进去吗，尿比平时少吗？体温和测量方式也要记，但有些变化，看一眼孩子就该行动。

## 先看现在是否需要求助

**孩子难以唤醒、反应明显变差、呼吸费力或发绀，出现抽搐，或有其他明显危急表现，应立即寻求急救。** 不足三个月婴儿发热，或任何年龄孩子发热同时整体状态很差，需要及时医疗评估。[AAP 发热就医提示](https://www.healthychildren.org/English/health-issues/conditions/fever/pages/When-to-Call-the-Pediatrician.aspx)

若出现抽搐，把孩子放到安全位置，移开周围硬物，让头偏向一侧，记下开始时间。嘴里不塞东西，不灌水灌药，不用力按住肢体。发作超过五分钟或呼吸异常，立即呼叫急救；第一次发作也需要及时就医评估。[AAP 热性惊厥急救说明](https://www.healthychildren.org/English/health-issues/conditions/fever/Pages/Febrile-Seizures.aspx)

明显尿少、持续无法进食饮水、反复呕吐、退热后仍表现很差，或病情加重，也要及时求助。低龄孩子发热持续不缓解，尽早联系医生，不靠一张居家表格延长等待。

## 把温度和孩子的样子写在同一行

医生问“精神怎么样”，家长有时很难找到准确的词。我觉得不用勉强自己说术语。“醒来会看人，抱起来能安静一会儿”“现在比平时难叫醒”，表达的已经是两种很不同的状态。拿不准某处是不是痛，可以说什么时候开始、碰到哪里会哭，请医生检查。

| 要记的时间 | 同一行再写些什么 |
| --- | --- |
| 测温时 | 读数、测量部位和方式，当时的反应、呼吸、喝奶或饮水情况与尿量 |
| 给药时 | 药品名称、浓度、实际按医嘱给的量、给药人，随后是否舒服一些 |
| 出现新表现时 | 实际看到什么、持续多久、能否正常回应，什么时候联系了医生 |
| 就诊后 | 医生交代观察什么、何时复查、什么变化要提前回来 |

测温和给药各记各的时刻。遇到异常高的读数，及时复核并求助。反复发热时把恢复的时段也留出来，接触史、接种等按先后记，因果交给医生评估。需要记录异常动作时，先保护孩子、及时求助，有另一位成人且安全才考虑为医生留资料。

## 退热以后，处方上的问题仍要问清

退热护理的目的是减轻不适。衣被适当，保持环境舒适，按孩子出生后的月数和需要，在孩子清醒、能安全吞咽时提供奶或水，留意休息、精神和呼吸。用药按体重、说明书或医嘱，使用配套量具，给过就记，换班时指给下一位看。[AAP 发热护理说明](https://www.healthychildren.org/English/health-issues/conditions/fever/Pages/Fever-Without-Fear.aspx)

拿到处方，我会当场问清药名、剂型、浓度和用途，请医生或药师按孩子当前体重确认用法。再问一句：“症状好转后，这种药怎么处理？漏服或时间与睡眠冲突，找谁确认？”体温恢复后，仍按原来的医疗安排用药和复查，需要调整先联系开药的人。

夜里能轮班，就让一个人陪孩子，另一个人联系医生、找量具或准备出门。交接时说清最后一次用药和下一步安排，往往比一起围着温度计更能帮上忙。
