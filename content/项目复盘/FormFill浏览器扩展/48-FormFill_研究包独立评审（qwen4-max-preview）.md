# FormFill 研究包独立评审（qwen4-max-preview）

评审日期：2026-11-17，Asia/Singapore。受父会话委派，对 `research/2026-11-16-formfill-audit` 研究包做独立批判性复核。本文件是唯一输出；未改既有报告/业务源码/凭据/环境，未部署、注册、联系、发帖、购买，不执行 Plane log。

**总体判断：研究包值得保留，不需重做。** 证据纪律好：官方宣称/本地实测/第三方估计/假设分栏，users≠下载、visits≠UV、月量留"待采样"等边界全部落实。我逐项抽查报告数字与证据 JSON、源码的一致性（见文末），**未发现编造数据或口径混用**。需修正的是：报告间建议冲突、把假设写成现行决策的措辞、¥699 实验的价值单元缺口、排期与自估复杂度矛盾。策略意见均为待验证假设。

## 一、按严重度排序的发现

### F1（高｜内部矛盾）首页定位分叉，假设被写成现行决策

README §2 与 website-audit 推荐通用主句"把已有资料，填进网页表单"；product-strategy §6 与 pricing-positioning §7 却写"**现在的首页主句**：把已有公司资料，填进合作伙伴的网页表单"。后者把自称"尚无访谈证明频率和预算"的假设客群当成已定文案；addendum 的意图观察还警告"供应商登记"类词混入找登记入口的人，与首屏收窄建议有张力，未调和。置信度高（原文比对）。影响：首屏承诺决定访客预期与 SEO 主簇，未验证即收窄会同时损失通用试用者并吸引错误意图。

**建议**：首屏保留通用版（与真实能力一致）；"合作伙伴登记"降为候选试点场景，只进用例页与招募文案，验证后再决定是否升级。把"现在的首页主句"改为"试点验证成立后的候选主句"。验证：试点访谈该场景真实频率；两种主句在招募中的理解差异（小样本观察）。

### F2（高｜内部矛盾）预览/撤销优先级前后冲突

website-audit P2-01 写"先验证用户需求，再做预览/跳过/撤销"；feature-comparison §5 却把 A2 预览/A3 撤销列为"补洞，免费基础"、收敛顺序"先 A0–A3"，product-strategy §3 列 P1，pricing §3 归免费可靠性改进。置信度高。旁证支持后者：FastFiller 公开宣称填前审核+撤销（宣称级）；本项目源码无预览阶段（messaging.ts 仅 fieldId/value，background.ts 模型返回直接写入）；Filler 帖评论关心猜测标记。对已被免费竞品当基础能力、直接关系误填风险的功能，"先验证需求"论证不足，且无预览会抬高试点观察错误的成本。

**建议**：统一为 A0 隐私修复→A1 真实安装→A2 预览+已有值保护→A3 有限 DOM 撤销，作为面向真实业务用户开放前的免费基础；P2-01 改写为"已并入 A2/A3"。把"单主体合成资料技术试验"与"真实业务数据发布"分两道门：前者门 1 后可开始，后者须 A2/A3 完成。验证：实现后跑合成验收，不需先访谈。

### F3（高｜实验设计缺口）¥699 适配的价值单元未定义，前置能力与收入假设错位

pricing §4 范围清晰（一资料模板、一网页表单、≤20 字段、60 分钟指导、14 天缺陷修正），但**客户买"一个表单"的重复价值从哪来**未写明：(a) 同一表单反复填不同记录——需要 A4 记录选择+防串填，而当前整本 Excel 转 Markdown 上下文（源码核实），A4 排在 A0–A3 之后，首发验证又是单企业 docx；(b) 同一资料填多个不同表单——价值单元应是"一套资料×N 表单"，靠 B2 映射复用（高复杂度、排位最后）摊薄成本。报告未区分 (a)/(b)，报价范围、功能路径与"复用成立"判据脱节；若需求是 (a)，交付时产品没有记录隔离，14 天修正的风险敞口被低估。置信度：条文高、缺口判断中高（分析性）。

**建议**：报价前书面固定价值单元二选一：(a) 则 **A4 是 ¥699 收款硬前置**，验收含两条相似记录防串填测试；(b) 则报价单写明"每表单一次交付"，B2 是内部降本目标而非客户承诺。保留"范围内无法交付不收款"，增设内部交付工时止损线。验证：访谈分开问"同一网页填过几份不同资料"与"同一份资料填进几个不同网页"的频率。

### F4（中高｜计划可行性）0–30 天窗口与自估复杂度矛盾

product-strategy §8 的 0–30 天要完成发布前修复+有效安装+中英演示+"基础复核与记录隔离"+5–8 用户+首篇指南；feature-comparison 自估 A0 中、A2/A3/A4 中–高、B1/B2 高，verification.json 承认无工时基线。若"基础复核"含 A2/A4，单人 30 天明显超载。虽声明"不是排期承诺"，结果清单式呈现仍会被当承诺，诱发赶工跳过验收或把"没做完"误读为"方向不行"。置信度：文本高、工程量中。

**建议**：30/60/90 改为依赖图+阶段门槛（见第五节），时间窗仅作复盘节奏；门 1/2 完成后用实际工时回填估算。

### F5（中｜论证缺口）切入点缺少与替代形态的对照

product-strategy §2 等的选择理由是"与资料入口一致、字段叫法有差异、可观察复用"——是能力匹配理由，不是需求证据（报告自认）。同批研究的反证未被用于对照：Excel Paste Filler/XL2Web/Classic 已覆盖"结构化表格→固定表单"，Formly 已宣称多人选记录（均宣称级）。"合作伙伴登记"里最可能高频的子形态（同页多记录、表头整齐）恰是规则工具主场；AI 增量价值集中在字段叫法漂移+非结构化叙述的子形态。报告未拆开比较就定了场景名。置信度中高。

**建议**：改写为两条并列可证伪假设：H-A 同一业务网页×多条记录（第一问"现有 CSV 导入/规则工具为何不够"，够用则诚实推荐规则工具）；H-B 同一资料×多个异构表单。以五问（上月次数/字段数/耗时/现有替代/审批人）定优先级。仍是假设排序，非新结论。

### F6（中｜渠道错位）中文客群与英文渠道桥接不完整

pricing §1 首批获客列中文运营社区/Gitee，§4 只测人民币市场；但全部可执行草稿与社区量化以 Reddit/HN 为中心，V2EX/少数派仅是未审查候选——中文渠道研究深度与英文不对称，执行会自然偏向证据多的英文社区，把人民币产品推向美元反馈人群。且 Gitee 仓库公开可达性未确认（API 404/页面 403），而它是所有草稿的唯一安装入口。置信度高（覆盖比对）。

**建议**：试点启动前补两件事：① 未登录实测 Gitee 仓库与 README 可达性（发布门槛，不可达先补 Release 包/镜像）；② 对 1–2 个中文候选渠道做与 Reddit 同级的当日规则核查。英文社区保留为技术反馈渠道，不承担人民币买家验证。

### F7（中低｜定价参数）¥199/年无成本依据，建议撤下现价

product-strategy §5 表格"可从 ¥199/年试一轮；当前不售卖"，已声明非竞品/汇率推导、无维护工时数据。问题在呈现：无锚点的具体数字进策略表格，易被当已定低价，并与 ¥699 并排诱发错误锚定（一年维护 199 vs 一次适配 699，交付不同但读者会混）。置信度高。

**建议**：撤下 ¥199 现价，改"待维护工时实测后定价；历史假设 ¥199 仅存档"，触发条件不变。¥699 保留报价假设标签，按 F3 补价值单元后才报价。

### F8–F10（低｜措辞与证据链，合并）

- **F8**：README 开头"自带模型接口、Office 输入有实际用途"易被读成"有差异"，正文反证（Formly 格式更多、FastFiller 免费 MIT/BYOK）更强；建议补半句"二者均非独有，差异需实测建立"。
- **F9**：strategy-source-snapshots.json 的 HN 指南条目只有 error 元数据无正文；正文证据实在 community-live-hn-general-guidelines.html。结论不受影响（我已另行在线核实），但引用处应改指后者。
- **F10**：pricing §2"默认选中 500 credits/月、$14.99/月"依赖 worker 核对的 aria-pressed，该属性未随快照存档；competitors §3.2 措辞更谨慎。建议统一为谨慎版："500↔$14.99 对应关系报价前再核实"。不影响"不能换算单次成本"结论。

## 二、未验证问题（阻塞排序，非错误）

1. 目标任务真实频率与形态（阻塞 F3/F5 与定价）：5–8 人五问访谈，H-A/H-B 分开记录。
2. Gitee 匿名可达性（阻塞安装路径与全部草稿）：未登录打开仓库/README。
3. 真实扩展 E2E（阻塞"可试用"与录屏）：干净环境构建→配置→合成资料填公开样例表单；注意 llm-retry.ts:191 附加非标准 `thinking` 参数（源码核实），首测应含开/关两种。
4. A0 修复后否定测试（阻塞真实用户开放）：未同意/未触发/无关表单/关闭学习不采集；textarea 初始文本与密码结构不入摘要。
5. 竞品最小核实（加固"补洞"论据与比较页）：安装 FastFiller 与 Excel Paste Filler 各一次，仅验证审核/撤销与智能表头匹配是否如宣称存在。
6. 中文渠道当日规则（阻塞中文招募）。
7. 关键词量（不阻塞首批页面，阻塞扩张）：按 seo-keywords §5 采样，此前不推断任何量。

## 三、核验通过、值得保留的结论

1. **隐私缺陷定性准确**：settings.ts 默认学习开+未同意；content.ts:23 `<all_urls>`、:385 submit 捕获只查开关、:393 整页提取；background.ts:75-77 历史样本入模型请求；locales:76 "不会上传/never uploaded" 与之矛盾；privacy-evidence.json 三项合成复现与源码一致。"本地采集/入摘要/网络发送"三层区分正确，不夸大为已上传密码。
2. **能力边界与源码一致**：四格式（.doc 抛转换错误）、50,000 字符截断、10MB、全 sheet 转 Markdown、仅 fieldId/value、HTTPS+Key 必填、无预览/撤销/行选择/来源结构、open Shadow DOM 支持/iframe 不支持。"未实现"与"未知"区分严格。
3. **市场数字与证据 JSON 逐条一致**：13 行 CWS（FillApp 2,000、Formly 34、formfill.cc 13、Text Blaze 800,000、Simplify 500,000 等）、4 条月 visits（仅 Simplify/Magical 同 Semrush 2026-10 全设备可比）、论坛 26,231/2,148/447、FastFiller 5 stars/39 次 ZIP 下载、HN 各帖分数均对上；缓存差异保留不当增长；无 users 当下载、visits 当 UV、大平台当市场规模的混用。
4. **本地审计数据一致**：390/360/320px 文档宽 432、英文 Demo 仅识别邮箱、Lighthouse 100/100/100/91 且标注本地模拟。
5. **两项外部声明本日窄核查为真**：Google 官方更新记录确认 FAQ 富结果 2026-05-07 停用（05-08 公告、06-15 移除文档）与 2026-03 删除 JS 旧说法；HN 现行指南含帖子禁生成文本、评论禁生成/AI 编辑文本。seo-keywords/community-launches 的引用与处理正确。
6. **MIT 边界正确**（LICENSE 本地核实）：不禁止收费、不能追溯收回、付费墙可被合法绕过、服务价值来自交付与支持。**品牌冲突处理正确**：formfill.cc/formfillai.cc 按外部主体处理，不认领其数据。**社区方法论**（官方 API 优先、作者自述与读者反馈分栏、低互动≠失败）与 **40 词 CSV 全"待采样"**（本地核实）均保留。**"先修信任与安装再谈增长"、不暗加遥测、广告后置**的总优先级保留。

## 四、对父会话六点拟统一决策的回应

1. 通用首屏+登记降候选、对照"同页×多记录"——**同意**（即 F1/F5）。补充：对照访谈第一问必须是"现有规则/CSV 工具为何不够"，两形态频率分开记录。
2. 隐私/安装/预览/已有值保护/有限撤销排优先级，技术试验与真实发布分开，多记录先有选记录——**同意**（F2/F3 前置）。补充：技术试验也只用合成资料（采集缺陷未修前真实资料有本地留存风险）。
3. 映射复用只依赖可靠来源标识+主体隔离+稳定目标定位，完整 Word 来源追溯作增量实验——**同意**，是对 B1/B2 依赖的合理简化（结构化表格只需列级来源）。补充：B2 仍需稳定 fieldId 替代方案（当前临时 ID 不可持久，源码核实），该成本不消失；建议先在"同站同结构+换记录"最窄条件验证。
4. 服务交付是可选收入验证非规模化软件结论；¥699 条件成立才试价；¥199 撤价留档——**同意**（F7）。补充：¥699 试价前按 F3 书面固定价值单元与硬前置，设工时止损线；"≥2 互不关联客户实付+复用+贡献为正"保留为继续/停止判据，不是 PMF 声明。
5. 阶段验收门槛、30/60/90 仅复盘——**同意**（F4）。
6. 中英市场分开、主渠道随客群、英语页按需——**同意**（F6 后半）。补充：中文渠道规则核查与 Gitee 匿名可达实测须列为试点启动前置，否则会因中文证据空白事实上滑向英文社区。

**反对点：无根本性反对。** 唯一坚持的补充：把"多记录先有选记录"**绑定为 ¥699 收款硬前置**并书面固定价值单元——否则统一决策执行时仍可能在 (a) 形态下裸交付。

## 五、修订执行计划（依赖+门槛，无日历承诺）

1. **门 1 发布基础**：A0 隐私修复（四类否定测试+摘要最小化）→ A1 真实安装（先核实 Gitee 匿名可达，不可达补 Release/镜像）+支持入口+四格式文案+Demo/移动布局修复。退出：干净环境安装→配置→合成首次填表可复现，专项复测全过。
2. **门 2 可信录入**：A2 预览/编辑/跳过/保留非空值 → A3 有限 DOM 撤销（限已验证控件，声明不撤回服务器副作用）。退出：合成验收含"旧结果不写错对象""手动修改不被回滚"。
3. **试点观察**：门 1 后可用合成资料做技术试验，真实业务数据须门 2 后；5–8 人五问访谈+失败归因+第二次真实任务回访；同步核查中文渠道规则。产出频率/形态数据→定价值单元与主定位是否收窄。
4. **门 3 能力补齐（按试点二选一）**：H-A 成立→A4 记录选择+主体隔离（¥699 硬前置）；H-B 成立→最小 B1（xlsx 列级+文本段落来源）+B2 窄原型。另一支缓行。
5. **门 4 付费实验**：价值单元/范围/工时止损线书面化后向 3–5 位已观察需求者报 ¥699；记录报价/试用/验收/实付/退款/拒因；≥2 互不关联实付+复用+贡献为正→继续，否则缩范围或停。¥199 不在本轮出现。
6. **内容与社区（挂门 1–3 产出按余力）**：中文核心页+配置指南+一篇真实任务指南（合成资料可下载）；英文页仅海外试点启动时做；Reddit/HN 门 1 后由作者按现行规则手写技术反馈帖；比较页等竞品最小实测后做；SEO 采样到位前不扩页。
7. **复盘**：每 28 天看漏斗（相关访问→获取→配置成功→首次正确任务→复用→实付），自愿回访+聚合数据，不加扩展遥测。
