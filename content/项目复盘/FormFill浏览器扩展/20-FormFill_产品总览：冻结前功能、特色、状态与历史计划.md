# FormFill 产品总览：冻结前功能、特色、状态与历史计划

更新日期：2026-11-18（项目于同日冻结）。本文记录 FormFill 冻结前的功能、技术证据与历史计划，面向档案使用者、潜在合作者与未来重新评估者。事实以代码与 docs/execution/ 的证据文件为准；本文不宣称未验证的能力。

> **最终状态：已停止产品化并冻结。** 不再扩功能、上架、部署、推广、做 SEO、收费或招募用户。源码与资料保留为技术档案及可复用资产。完整的决定、验证边界、可复用资产和交接索引见[产品收尾与交接报告](22-FormFill_产品收尾与交接报告.md)。

英文用户文档见 README.md。

## 1. 产品是什么

FormFill 是一个浏览器扩展（Chrome / Edge，Manifest V3，WXT + React + TypeScript；既有文档声明 MIT，但冻结时仓库根目录未发现 `LICENSE`，再分发前须核对托管平台许可与版权主体并补齐，见[收尾报告](22-FormFill_产品收尾与交接报告.md#3-冻结时的技术状态)），把用户的自然语言描述或导入的文件（Excel / Word / 文本 / Markdown）转换成网页表单的填写建议，**先预览、用户确认后才写入页面，可撤销，不自动提交**。模型服务由用户自备（BYOK）：数据直接发送到用户配置的接口，不经过开发者服务器。

配套一个静态官网（website/，Vite + React 多页构建），承担介绍、本地模拟 Demo、安装/Excel 指南与隐私政策。

- 定位（首页主句）："把已有资料，填进网页表单"。首要候选客群：已有模型 API 能力、反复把文字和 Office 资料录入各种现有网页表单的用户。
- 冻结前场景假设：经[产品原点与场景方向重估](54-FormFill_产品原点与场景方向重估.md)，原计划以 M01 第一优先验证“多平台 B2B 供应商的企业主档→供应商注册/入库/更新中的纯主体信息表单字段”，第二优先验证无导入/API 的老后台同页多记录。附件上传、CA 认证、资格预审文件、编标与递交均在黑名单；“老”不等于 IE/ActiveX 兼容。该顺序是尚未完成市场验证的研究假设；冻结时，目标类型平台的技术可达与频率、付费均未检验（合格目标类型复现样本为 0）。
- 最终状态：**技术样机，已停止产品化并冻结**。`package.json` 版本仍为 0.1.0，但归档代码包含 `0.2.0 (Unreleased)` 中的未发布行为；0.2.0 从未发布，冻结后也不会发布。项目未上架任何商店、无生产域名；档案已公开镜像于 <https://github.com/fangd123/formfill>，克隆后自行构建加载即复现（原 Gitee 归档地址已移除链接）。
- 界面语言：中英文地位对等（冻结前记录为 143 个双语 key，历史 i18n 测试覆盖对等与 Chrome key 合法性；本轮未重跑）。中文新用户默认火山方舟（豆包），其他语言默认 OpenAI。
- 支持与反馈：[GitHub Issues](https://github.com/fangd123/formfill/issues)（扩展内按钮直达）。

## 2. 功能清单（归档实现；“通过测试”均指冻结前历史结果，真实环境边界见 §5）

### 填写主流程

| 能力 | 说明 | 对应工作项 |
|---|---|---|
| 扫描 → 建议 → 预览 → 应用 → 撤销 | 生成期间不写页；预览逐项可编辑、可勾选；应用前校验页面未变化（scanToken+表单签名），变化整体拒写；撤销只恢复本次写入且未被用户改动的字段（单选按组恢复）；每次应用替换撤销快照 | F03/F04 |
| 已有值保护 | 已有值的字段默认不勾选，勾选后才覆盖；单选按组判定；下拉的空值占位项（"请选择"）不算已有值 | F03 + W05 浏览器轮修复 |
| 受保护字段拒填 | 密码、隐藏、禁用、只读及隐藏祖先中的控件不进入摘要也不被写入，扫描与写入共用保护判定；标签/附近文本排除控件内容、脚本与不可见内容 | F01/F03 |
| 控件范围 | 标准 input（text/email/tel/date 等）、textarea、select、checkbox、radio，含 form 外控件；不支持 Shadow DOM 内控件与 iframe 内表单（内容脚本无 allFrames）；部分站点与浏览器内部页不支持 | 基线 + F03 |
| 不自动提交 | 用户检查页面后自行提交；无提交监听 | F01 |

### 文件与 Excel

| 能力 | 说明 | 对应工作项 |
|---|---|---|
| 四种格式 | .xlsx / .docx / .txt / .md，最大 10 MB；旧 .doc 建议转 .docx；解析内容每次最多发送 30,000 字符（附截断说明） | W01 口径统一 |
| Excel 单记录选择 | 选工作表、表头行、一条记录；只有选中记录发送给模型，其他行保留本地；切换工作表重置选择 | F05 |
| 保真策略 | 日期按 UTC 显示 YYYY-MM-DD；文本前导零保留（Excel 中已存成数值的无法恢复）；真实运行验证 007 与 2026-01-15 原样写入 | F05 + W05 |
| 映射复用 | 填写成功后经确认保存"Excel 列 → 表单字段"映射：只存结构（来源、表单签名、列名/索引、定位器），不存值与 Key，上限 20 条；换记录免调用模型，仍走预览→应用→可撤销；表单签名变化自动停用；可逐条删除 | F06 |

### 模型接入与可靠性

| 能力 | 说明 | 对应工作项 |
|---|---|---|
| 13 个服务商选项 | 国际：OpenAI、OpenRouter、Gemini、Claude（兼容层）；国内：火山方舟、阿里云百炼、DeepSeek、智谱、Moonshot、硅基流动、腾讯混元；本地：Ollama；自定义：任意 OpenAI 兼容 API。各服务商 Key/模型/Base URL 独立保存，切换恢复 | 基线 |
| 测试连接与排障 | Base URL 双层校验（非法地址不发请求）；401/403→查 Key、404→查地址与模型 ID、超时→附配置秒数、网络失败→查网络/本地服务，本地化可执行提示 | F02 |
| 可取消生成 | 每标签页 AbortController；新请求中止旧生成；取消打断请求与重试退避且不写页、不出迟到预览 | F02 |
| 重试与输出校验 | 429/5xx/网络/超时/非法 JSON 最多重试两次；400/401/403/404 立即返回；模型输出统一 {"instructions":[...]}，非法指令丢弃计数 | 基线 |
| 思考参数 | 服务商专属 thinking 开关（预设支持且显式选择才发）；独立的 OpenAI 兼容标准 reasoning_effort（低/中/高，显式选择才发，不受预设门控，两者可共存）；默认均不发送 | W05 轮新增，设置 v6 |
| 超时 | 默认 120 秒，可调 | 基线 |

### 隐私边界

- 数据直传用户配置的接口，无开发者服务器；Key 仅本地存储；无统计、无广告、不出售数据。
- **自动学习已暂停**：不采集提交、不发送历史值；v5 迁移强制关闭旧标记（现存储 v6），旧记录仅本地查看/清除（查看时清理 90 天/50 条上限）。
- 首次填写前提示数据传输范围；表单摘要与文件内容作为不可信数据隔离并要求模型忽略其中指令（不构成防注入的绝对保证）。
- 权限：storage + activeTab + `<all_urls>` 内容脚本；未申请 tabs/scripting。不宣称 activeTab 限制了内容脚本匹配范围。

## 3. 特色与差异化（如实口径）

调研结论（research/2026-11-16-formfill-audit/）明确：**BYOK、开源、Office 输入都不是独家优势**，已有同类覆盖相近卖点。FormFill 的差异化是组合与体验，不是单点独占：

1. **受控写入的完整闭环**：预览可编辑 + 已有值默认保护 + 受保护字段拒填 + 页面变化拒写 + 有限撤销。2026-11-16 的公开竞品观察把多数低价同类描述为“直接填”，出错靠用户自己发现；该判断是历史调研口径，本轮未复核。
2. **国内服务商一等公民**：7 个国内预设 + 中文默认豆包；冻结前曾计划主要经 Edge 商店触达国内用户，但上架未发生。
3. **Excel 单记录主体隔离 + 免模型映射复用**：只发送选中记录（隐私+成本），第二条记录起不再调用模型（快、零成本、可预期）；2026-11-17 历史浏览器探针记录换记录复用约 2.5 秒，本轮未重跑。
4. **中英文地位对等**：不是机翻界面；冻结前历史测试覆盖双语 key 对等与 Chrome key 合法性，本轮未重跑。
5. **隐私行为与文案一致**：学习采集路径已删除而非仅改说明，有合成数据复现证据。

市场参照（2026-11-16 读取公开商店页面时记录的 users；不是下载或活跃，本轮未复核）：Text Blaze 800,000、Simplify 500,000（含求职平台）、FillApp 2,000、Formly 34。直接同类规模有限，大平台数值不能当通用填表市场规模。
