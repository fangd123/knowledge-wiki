## 二、发现（severity / 位置 / 建议）

### A1（中，文案不一致——建议提交前顺手改）
`website/src/App.tsx` Demo 段 section-heading（约 233 行）残留内部备忘文案："借鉴同类工具站的产品界面演示做法……当前使用本地模拟解析器，**后续可接后端模型接口**。"
问题：前半句是写给开发者的设计说明，不应出现在产品页（原审计 P1-06 同类问题）；后半句"可接后端"与本项刚确立的"Demo 纯本地、不上传"承诺存在张力——读者无法区分"以后可能上传"与"现在不上传"。
建议：改为面向用户的一句话，如"演示在浏览器内用本地规则模拟字段匹配，不上传任何输入；扩展的真实填写由你配置的模型服务完成。"删除"借鉴同类工具站"与"后续可接后端"表述。

### A2（低，无效锚点）
`SiteChrome.tsx` SiteFooter"返回顶部" `href="#top"` 为两页共用；首页有 `id="top"`（App.tsx:173），privacy 页无该锚点，点击无效。建议给 PrivacyPolicy 顶部容器加 `id="top"`，或 sub 页脚该项改回首页链接。

### A3（低，备注）版本号口径
PrivacyPolicy.tsx 与 docs 政策均写"适用于计划发布的 0.2.0 版本"，而 package.json 为 0.1.0。口径一致、非错误；发布 0.2.0 时需同步 bump package.json 并复核政策描述仍与代码一致。建议列入发布 checklist。

### A4（低，可延后）OG/favicon 缺失
index.html 与 privacy.html 均无 og:title/og:image/favicon。canonical/sitemap 等域名决定是既定决策不算问题；OG 影响分享卡片观感，可在 W04 或域名确定后补，不阻塞。

### A5（备注，范围归属）
本 diff 混入了 W03/W04 提前量：Demo 竞态保护（runIdRef、切示例/清空重置）与 styles.css 响应式修补（minmax(0,1fr)、overflow-wrap、移动导航）。质量无问题，但 W03/W04 验收时不要将这部分重复计为已完成，剩余断点截图与可访问性回归仍需独立做。w03-home-390.png 已存在，建议在执行记录中注明归属。

### 非问题澄清（避免误报）

- tabs.create 无 tabs 权限：MV3 合法用法，仅读取 tab 敏感字段才需权限。
- README 的 Ollama "API key optional" 与 providers `requiresApiKey:false` 一致；新基线支持 http://localhost，旧评审"仅 HTTPS"结论不适用于本工作区。
- 隐私页链接 `/privacy.html` 为站内绝对路径，多页构建下有效；外链均 `rel="noopener noreferrer"`。
