# 小岛物语（Cozy Island）— 设计文档 v1

2D 俯视角慢生活游戏，玩法参考《动物森友会》。目标：可运行、可玩、有氛围的垂直切片（vertical slice），而不是完整游戏。

## 0. 技术约束

- 引擎：Godot **4.7.2 stable**，GDScript，渲染器用 `gl_compatibility`（2D 足够，兼容性最好）。
  - 可执行文件：`%LOCALAPPDATA%\Programs\Godot\Godot_v4.7.2-stable_win64_console.exe`
- 全程命令行开发：不依赖编辑器 GUI。场景可以用 `.tscn` 文本写，也可以在 `_ready()` 里用代码搭（推荐：主场景 `.tscn` 很薄，世界由代码按数据生成）。
- 视口 1280×720，`stretch_mode = canvas_items`，`aspect = expand`。像素以外的平滑美术，纹理过滤用 linear。
- 中文字体：`assets/fonts/ZCOOLKuaiLe-Regular.ttf`（OFL，Google Fonts），设为项目默认主题字体。
- 所有可调内容（NPC、台词、物品、地图布局）放在 `data/*.json`，代码只读数据。
- 存档：`user://save.json`。

## 1. 核心体验

玩家在一座小岛上散步、捡东西、和 6 位动物居民聊天、把东西卖给商店换铃钱。每位居民性格鲜明，有自己的口头禅和台词，台词随时间段、好感度、天数变化。

## 2. 操作（只用鼠标）

| 操作 | 行为 |
|---|---|
| 左键点地面 | 主角寻路走过去；点击处出现一个缩放淡出的圆圈标记 |
| 左键按住拖动 | 主角持续朝鼠标方向走（按住时每 0.15 s 重新寻路到鼠标位置） |
| 左键点 NPC | 走到 NPC 旁边（距离 < 56 px）后自动开始对话；NPC 停下并转向主角 |
| 左键点可拾取物（地上的贝壳/树枝/花、果树） | 走过去后拾取；果树摇一下掉落苹果（每棵树每天 1 次，掉 1–3 个） |
| 鼠标悬停 NPC/物品 | 光标变手型，NPC 头顶显示名字牌，物品轻微高亮 |
| 对话中左键 | 打字机未完成 → 立即显示完整句；已完成 → 下一句 |
| 右键 / Esc | 关闭打开的面板（背包/商店） |
| 鼠标滚轮 | 相机缩放 0.8–1.6 |

不可达的点击（水里、房子里）→ 走到最近的可达格子。

## 3. 世界

- 网格：`CELL = 32 px`，地图 **64 × 44 格**（2048 × 1408 px）。
- 地形由 `data/map.json` 的 ASCII 网格定义，字符：`~` 海、`.` 沙滩、`,` 草地、`=` 土路、`r` 河（不可走）、`b` 桥（可走）。
  一座有机形状的岛：外圈海，沙滩环带，中间草地，一条小河从北往南流过并有 2 座桥，土路连接广场、商店和各家。
- 地面渲染：**不用瓦片贴图**，用一个 shader 渲染整片地面：把地形网格写成小图（每格 1 像素，linear 过滤），shader 里按地形加噪声做出有机的边界：
  - 草地：两三种绿色的低频噪声斑块 + 细碎的小草点；
  - 沙滩：暖米色 + 细颗粒噪声；
  - 土路：浅棕，边缘柔和；
  - 海/河：动画水面（缓慢流动的色带 + 闪光），靠岸处有白色泡沫线随时间起伏。
- 物件（`data/map.json` 里的 objects 列表，带格坐标）：
  - 6 栋房子（5 位居民 + 玩家自己的家），1 家商店，树（普通/果树/松树/椰子树）、灌木、石头、花丛、路灯、邮筒、告示牌、栅栏。
  - 每个物件有占地 footprint（格），A* 中标为不可走；房子的门口格可走（门口是 NPC 的“回家点”）。
- **Y 排序**：所有物件和角色放在同一个 `y_sort_enabled` 的 Node2D 下，sprite 的原点在脚底/树根，保证前后遮挡正确。
- 物件根据 sprite 高度自动缩放到合适的游戏尺寸（见 §7 素材表的“游戏内高度”）。
- 树等高物件：主角走到其后方时，该物件半透明（alpha 0.55）。
- 散落的可拾取物：每天开始时在沙滩随机刷 6 个贝壳、草地刷 4 根树枝、花丛附近可摘花（每丛每天 1 朵）。

## 4. 寻路

- `AStarGrid2D`，对角移动 `DIAGONAL_MODE_ONLY_IF_NO_OBSTACLES`，启发式 octile。
- 得到路径后做一次**视线平滑**（string pulling：能直线到达的中间点去掉），角色沿平滑后的折线以恒定速度移动（玩家 150 px/s，NPC 60 px/s）。
- NPC 之间、NPC 与玩家之间不互相阻挡（避免卡死）。

## 5. 角色表现

- 每个角色只有一张正面立绘（AI 生成），没有逐帧动画 → **程序化动画**：
  - 走路：sprite 上下弹跳（`abs(sin)`，振幅 4 px，频率随速度）+ 左右轻微摇摆旋转（±4°）+ 落地时轻微压扁（scale.y 0.94）；
  - 朝向：向左走时 `flip_h`；
  - 待机：缓慢呼吸缩放（scale.y 1.0↔1.02，2 s 周期）；
  - 脚下一个半透明椭圆阴影。
- 说话时 NPC 头顶冒小气泡图标（“…” / “♪” / “!”），根据当前台词的情绪标记。
- NPC 行为状态机：`IDLE`（2–5 s）→ `WANDER`（在家附近半径 7 格内随机找可达格走过去）→ 循环；晚上 22:00–6:00 回家门口并隐藏（“睡觉”），对话请求时显示“（屋里静悄悄的……）”。
- 鼠标悬停时名字牌：圆角小牌子，NPC 主题色底色。

## 6. 对话系统（重点）

### 6.1 数据：`data/npcs.json`

每位居民：
```json
{
  "id": "cat", "name": "橘子", "species": "猫", "personality": "元气",
  "sprite": "npc_cat", "home": "house_red", "color": "#f4a64a",
  "voice_pitch": 1.35, "catchphrase": "喵呜",
  "lines": {
    "greeting": { "morning": [...], "afternoon": [...], "evening": [...], "night": [...] },
    "first_meet": [...],
    "chat": { "1": [...], "2": [...], "3": [...] },
    "gift_like": [...], "gift_normal": [...],
    "goodbye": [...]
  },
  "likes": ["item_apple"]
}
```
- 台词是**数组**，每条可以是字符串，或多句对话的数组（一段对话），每句可带情绪前缀：`"!:"` 惊讶、`"♪:"` 开心、`"…:"` 无语/犹豫、`"?:"` 疑问。
- 占位符：`{player}` 玩家名、`{cp}` 口头禅、`{time}` 当前时刻、`{day}` 第几天、`{other:<id>}` 另一位居民名字。
- `chat` 按好感度等级（1 陌生 / 2 熟悉 / 3 好朋友）分池；可以抽当前等级及以下的台词，优先抽当前等级。
- 每次对话从当前池里随机抽，**避免和上一次重复**。

### 6.2 对话流程

1. 走到 NPC 旁 → NPC 转身、停下；
2. 当天第一次对话：说 `first_meet`（仅第一次见面）或 `greeting[时段]`；
3. 弹出选项：**「聊聊天」/「送礼物」/「再见」**；
   - 聊聊天：`chat` 一段；当天第一次聊天好感 +1；
   - 送礼物：打开背包选择物品 → 如果在 `likes` 里说 `gift_like` 并好感 +3，否则 `gift_normal` 并好感 +1；每天每人限 1 次礼物；
   - 再见：`goodbye` 一句后关闭。
4. 好感度阈值：等级 1 = 0–9，等级 2 = 10–24，等级 3 = 25+。升级时对话框后追加一句系统提示“（和{name}变得更熟了！）”。
5. 店主（狸叔）的选项换成：**「卖东西」/「聊聊天」/「再见」**，卖东西打开商店面板。

### 6.3 对话框 UI

- 屏幕下方居中，宽 900，圆角 24 的奶油色气泡框（#fff8e7，描边 #8b6b4a 3 px），阴影。
- 左上角凸出一个 NPC 主题色的名字牌（圆角，略微倾斜 -3°）。
- 左侧 140×140 圆角框里显示 NPC 立绘头像（裁剪上半身）。
- 文字 26 px，深棕色，打字机效果 40 字/秒；句子显示完后右下角一个上下跳动的 ▼。
- **动物语（animalese）音效**：每打出一个非标点字符播放一个短促的“哔”声，音高 = `voice_pitch` × 随机 ±8%，用 `AudioStreamGenerator` 或预生成的 `AudioStreamWAV` 合成（正弦+轻微方波，40 ms，带包络），不要外部音频文件。
- 选项：对话框上方右侧竖排的圆角按钮，悬停变色。
- 对话期间玩家不能移动，相机轻微拉近到 1.15 倍并以两人中点为中心（Tween 0.3 s）。

## 7. 素材（AI 生成，已在 `_raw/`，处理后进 `assets/sprites/`）

选图清单：`_raw/selected.json`（key = 输出名，value = 原图）。注意 `house_player` 是 `house_blue` 的另一张变体。

原图背景**不是纯色**：是浅粉或浅绿底，带轻微渐变，物体下方有一块同色系的深色椭圆投影，个别图上还散落着小草点或光晕（路灯）。所有物体都有一圈深棕色粗描边，可以利用这一点。抠图要求：
1. 背景色取四条边像素的中位数；
2. 从四边做 flood fill，容差按颜色距离来；投影是同色相、更深的背景色，也要判为背景（可以用“色相接近背景，且饱和度和亮度在一定范围内”这类规则）；
3. 去掉孤立的小前景块（散落的草点），只保留面积够大的连通区域；
4. 边缘 1–2 px 羽化，并去掉色溢（把边缘像素里残留的粉色/绿色压掉）；
5. 裁剪到不透明区域的包围盒，留 8 px 边距，长边缩到 ≤ 512 px。
6. 物体内部的白色或浅色区域（兔子、鸭子、栅栏）不能被吃掉。
抠图脚本放 `tools/process_assets.py`。另外输出一张棋盘格底的对比图 `_raw/cutout_check.png`，供设计方验收。

| 素材 | 游戏内高度（px） | 原点 |
|---|---|---|
| player / npc_* | 72 | 脚底中心 |
| house_* / shop | 150 | 底边中心 |
| tree / tree_fruit / tree_pine / palm | 120 / 120 / 140 / 130 | 底边中心 |
| bush / rock | 40 / 36 | 底边中心 |
| flower_* | 30 | 底边中心 |
| sign / mailbox / lamp / fence | 44 / 44 / 80 / 36 | 底边中心 |
| item_*（地上） | 24 | 中心 |
| item_*（UI 图标） | 48 | 中心 |

## 8. 物品、背包、商店

- `data/items.json`：`item_apple` 苹果 100 铃钱、`item_shell` 贝壳 60、`item_branch` 树枝 5、`item_flower` 郁金香 80、`item_coconut` 椰子 250。
- 背包 20 格，屏幕右下角背包按钮（或按 Tab）打开网格面板，格子显示图标和数量。
- 拾取时物品图标从地上飞到背包按钮并弹出一个“+1 贝壳”提示。
- 商店面板：列出背包物品、单价、“卖 1 个”和“全部卖掉”按钮；卖出时铃钱数字滚动增长。

## 9. HUD 与时间

- 左上角：圆角面板显示「第 N 天  上午 9:20」和铃钱数（带图标）。
- 游戏时间：1 现实秒 = 1 游戏分钟；新游戏从第 1 天 8:00 开始；24:00 进入下一天（刷新可拾取物、果树、每日好感上限）。
- 昼夜：`CanvasModulate` 按时间插值颜色（清晨偏粉、白天白、黄昏橙、夜晚深蓝 #5a6aa0）；夜晚路灯和房屋窗户亮起（路灯处加 `PointLight2D` 或简单的加法混合光晕 sprite）。
- 进入游戏时屏幕中央淡入标题“小岛物语”，2 s 后淡出。

## 10. 居民设定（台词由实现方按此扩写，每人每个池 ≥ 4 条，chat 每级 ≥ 5 条）

| id | 名字 | 物种 | 性格 | 口头禅 | 家 | 主题色 | 喜欢 | 说话风格 |
|---|---|---|---|---|---|---|---|---|
| cat | 橘子 | 橘猫 | 元气 | 喵呜 | house_red | #f4a64a | item_apple | 句尾爱加感叹号，热爱做饭和晨跑，总想拉玩家一起运动 |
| dog | 阿福 | 柴犬 | 慵懒 | 汪～ | house_yellow | #e0b36a | item_coconut | 慢吞吞，三句不离吃和睡，偶尔冒出朴素的人生哲理 |
| rabbit | 棉花 | 白兔 | 温柔 | 呼呼 | house_green | #8fc98f | item_flower | 说话轻柔，照顾花园，会提醒玩家注意休息，懂花语 |
| bear | 老熊 | 棕熊 | 暴躁（外冷内热） | 哼 | house_blue | #8a6a4f | item_shell | 嘴上嫌弃，其实很关心人；爱钓鱼，讲年轻时的航海故事 |
| duck | 嘎嘎 | 鸭子 | 自恋文艺 | 嘎 | house_purple | #b98ad6 | item_flower | 自称岛上第一诗人，经常即兴念两句打油诗 |
| raccoon | 狸叔 | 浣熊 | 商人 | 嗯哼 | shop | #5f8f5a | — | 精明但厚道，收购东西时报价，会介绍岛上的事和其他居民 |

台词里要有居民之间的互相提及（例如橘子提到老熊早上又去钓鱼了），让岛有“活着”的感觉。

## 11. 验收标准（测试由设计方执行）

1. `godot --headless --path . --import` 无报错；`godot --headless --path . --quit-after 120` 运行 2 秒无脚本错误。
2. 自动化测试脚本 `tests/run_tests.gd`（`godot --headless --path . -s tests/run_tests.gd`）覆盖：寻路（地图上任意两个可走格可达、路径不穿过障碍）、对话数据完整性（每个 NPC 每个池非空、占位符可解析）、好感度升级、存档读写、商店结算。全部通过时退出码 0。
3. 截图模式：`godot --path . -- --screenshot-test` 启动后自动执行一组脚本化动作（点击移动、点击 NPC、推进对话、打开背包、打开商店、切到夜晚），每步截图到 `user://screens/`（或 `--shot-dir=<路径>`），然后退出。设计方据此做视觉验收。
4. 实际游玩：鼠标点击移动流畅不卡墙；6 位 NPC 都能对话且风格各异；Y 排序正确；中文显示正常。
