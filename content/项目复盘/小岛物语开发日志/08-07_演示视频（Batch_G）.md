# 07 演示视频（Batch G）

## 7.1 需求

> 你帮我录一个游戏的视频，展现这个游戏的基本玩法，时长不超过 1 分钟。

这时 Codex 额度用完了，用户说“codex 没有额度了，你得自己上了”，所以 Batch G 是项目里唯一一批由 Claude 自己实现的。

## 7.2 方案选择

| 方案 | 问题 |
|---|---|
| 运行游戏 + 屏幕录制软件 | 需要人操作；机器卡顿会掉帧；不可复现 |
| 截图模式拼成视频 | 只有离散的截图，没有连贯动作和声音 |
| **自动驾驶 + Godot Movie Maker** | 采用。`--write-movie` 逐帧离线渲染，不受机器性能影响，同样的输入每次产出同样的视频 |

做法：

1. 写一个“导演”脚本 `scripts/demo_director.gd`，用 `-- --demo` 启动时接管游戏，按分镜依次操作；
2. Godot 以 `--write-movie … --fixed-fps 30` 录制画面和声音；
3. `tools/record_demo.py` 负责启动、录制、ffmpeg 编码和自检。

```powershell
python tools/record_demo.py            # 默认 1920x1080 → test-results/demo/cozy_island_demo.mp4
python tools/record_demo.py --size 1280x720 --out <path.mp4>
```

## 7.3 分镜

目标是在一分钟内展示完核心循环：走路、采集、背包、聊天、送礼、卖东西、昼夜变化。

| 时间 | 镜头 | 展示什么 |
|---:|---|---|
| 0 s | 标题“小岛物语”淡入淡出 | 开场 |
| 2.0 s | 点地面，主角走过去 | 鼠标点击移动、逐帧走路 |
| 4.9 s | 摇果树、捡苹果 | 果树掉落、拾取飞入背包 |
| 6.9 s | 摘郁金香 | 花丛采集 |
| 8.3 s | 捡贝壳 | 沙滩拾取 |
| 10.0 s | 打开背包 | 背包界面 |
| 11.9 s | 初见橘子，聊天 | 初见台词、多句对话、TTS 配音、选项 |
| 23.3 s | 送苹果 | 喜欢的礼物（好感 +3） |
| 33.8 s | 狸叔的小店卖贝壳 | 商店、铃钱滚动（+60） |
| 47.4 s | 18:00 → 22:15 延时 | 暮色、路灯和窗户的暖光、BGM 早晨 → 傍晚 → 夜晚、居民回家、镜头拉远 |
| 55.8 s | 画面和声音一起淡出 | 结尾 |
| 57.3 s | 结束 | |

## 7.4 导演脚本的设计

### 所有操作都走真实鼠标事件

导演不直接调用 `world` 的内部函数，而是和截图模式一样，发送真实的鼠标移动、按下、松开事件。这样视频里展示的就是玩家真实能做的操作，不存在“演示专用”的捷径。

### 可复现、可控时长

- 全新的第 1 天 8:20 开始，不读写存档；
- 随机种子固定为 842；
- 语音只用离线片段，结束时断言 TTS 网络请求为 0；
- 用默认音量，不用本机 `settings.cfg` 里的滑块位置；
- `IslandDialogue.forced` 固定几句较短的台词（如橘子的初见、聊天、收礼、告别），控制总时长。正常游戏里这个字典是空的；
- 橘子、棉花、狸叔在演示中原地不动，方便导演找到他们；其余居民照常闲逛，画面更有生气。

### 画一个鼠标指针

Movie Maker 只录渲染出来的画面，不录操作系统的光标。观众看不到指针就不知道在点哪里，所以导演在最上层 CanvasLayer 自己画一个箭头：带阴影和描边，移动时平滑滑动，按下时有回弹，点击处有波纹。

## 7.5 录制和编码

`tools/record_demo.py` 的流程：

1. 临时写入 `override.cfg`：MJPEG 质量、窗口尺寸；录完还原；
2. 启动 Godot：`--write-movie <avi> --fixed-fps 30 -- --demo`；
3. ffmpeg 编码 H.264 CRF 18 + AAC 192k；
4. 两遍 loudnorm（线性增益）到 -16 LUFS / -1.5 dBTP；
5. 自检：时长 ≤ 60 秒、分辨率正确、有音轨。

成品：**57.4 秒，1920×1080，48 MB，-15.8 LUFS。** 输出在 `test-results/demo/cozy_island_demo.mp4`（不进版本控制，随时可以重新生成）。

## 7.6 踩到的坑

| 坑 | 现象 | 解决 |
|---|---|---|
| 窗口尺寸覆盖优先级 | `--resolution 1920x1080` 不生效 | `project.godot` 的 `window_*_override` 比 `--resolution` 优先。只能录制时临时写 `override.cfg`，录完还原 |
| 系统光标录不进去 | 视频里看不到指针 | 自己画指针 |
| 拉伸模式下点歪 | 1080p 下注入的点击位置偏移 | `canvas_items` 拉伸时，世界坐标转窗口坐标要乘 `get_tree().root.get_final_transform()` |
| 点不中花丛 | 点击花丛中心没反应 | 物件按纹理 alpha 判定点击，花丛中心可能是透明的。导演在物件纹理里搜索不透明像素作为点击点 |

## 7.7 测试

`tests/run_tests.gd` 新增 `_test_demo_isolation`：确认演示模式不改动存档、只用离线语音、固定台词生效。之后全套测试通过（约 1.56 万条断言）。

## 7.8 可以改进的地方

- 没有字幕或文字说明。第一次看的人未必知道“送苹果好感 +3”这种机制；
- 只展示了正面走路，没有背面（游戏本身就没有背面帧）；
- 延时段很快，看不太清居民回家的过程。
