## 使用规则：来源层级与证据边界

## 1. 成本结构

### 1.1 折旧、经济寿命与回本期

三者不是同一个量：会计折旧是成本分配政策；经济寿命取决于未来净现金流与替代用途；回本期取决于现金流路径。把“购置价÷月租”叫作市场隐含折旧年限，会遗漏出租率、运维、电费、税费、融资与残值。

各云厂商折旧年限及变更金额仍待逐项对应可定位的财报段落，暂不形成“当前行业 GAAP 均值”。建立可比表时应逐公司记录：财年、资产类别、变更生效日、受影响资产范围、折旧影响额。服务器总体年限不一定就是某代 GPU 的剩余寿命。

### 1.2 每卡每小时：一个可复算而非市场报价的例子

假设设备资本额为 30,000 美元/卡、直线摊销、残值为零；每卡分摊后的**设施总功率**为 1.7 kW，综合电能单价为 0.09 美元/kWh。这里的资本额、功率和电价均是情景输入，不认证为某款 GPU 的当前采购价、行业均值或真实电费账单。

$$c_K=\frac{30,000}{8,760Y},\qquad c_E=1.7\times0.09=0.153\ \text{美元/卡时}.$$

| 摊销年数 $Y$ | 资本摊销/日历卡时 | 电费/日历卡时 | 两者之比 |
|---:|---:|---:|---:|
| 3 | 1.142 美元 | 0.153 美元 | 7.46 |
| 5 | 0.685 美元 | 0.153 美元 | 4.48 |
| 6 | 0.571 美元 | 0.153 美元 | 3.73 |

这里的比值不能证明全行业固定成本占八成。若只有 $u$ 比例的日历卡时可收费，固定成本每收费卡时变为 $c_K/u$；电费须按负载、空闲与关机的功率分别积分，而不是无条件把同一常数除以 $u$。本例未纳入主机、网络、机房、人员和资本机会成本。

### 1.3 完整成本的最小核算框架

$$C_{\mathrm{period}}=C_{\mathrm{capital}}+C_{\mathrm{facility}}+C_{\mathrm{network}}
+C_{\mathrm{energy}}+C_{\mathrm{staff}}+C_{\mathrm{software}}+C_{\mathrm{risk}}.$$

按可销售、满足质量和延迟要求的产出分摊，才得到交付单位成本。资本项可以使用会计摊销或资本回收现金流，但应避免把购置额、折旧和本金偿还重复相加。短期接单使用增量成本与机会成本；长期投资需要覆盖全部经济成本。

“电力占 TCO 的 10%–20%”“固定成本约 80%”等区间尚缺统一样本与原始模型，不作为行业统计。各项比例还必须使用同一分母、同一期限；不同报告的上下限不能拼成成本饼图。

### 1.4 NVIDIA 财务读数及其口径

【公司披露】[NVIDIA FY2026 财务发布](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-fourth-quarter-and-fiscal-2026)，发布于 2026-02-25，第四季度截至 2026-01-25：

| 期间 | 合并营业收入 | GAAP 合并毛利率 |
|---|---:|---:|
| FY2026 第四季度 | 681.27 亿美元 | 75.0% |
| FY2026 全年 | 2,159.38 亿美元 | 71.1% |

这不是数据中心分部毛利率，也不是某款 GPU 的毛利率。毛利还没有扣除全部研发、销售管理等费用，更不是扣除正常资本回报后的纯经济租金。以 NVIDIA 数据中心收入除以几家客户 CapEx，也不能得到“上游利润捕获率”：分子分母包含不同客户、产品和期间，并且收入不是利润。

## 2. 部署规模、利用率与缓存：哪些量已经披露

### 2.1 DeepSeek V3/R1：2025 年的有边界生产台账

【厂商自述】[DeepSeek Day-6 推理系统概览](https://raw.githubusercontent.com/deepseek-ai/open-infra-index/main/202502OpenSourceWeek/day_6_one_more_thing_deepseekV3R1_inference_system_overview.md)明确统计窗口为 UTC+8 2025-02-27 12:00 至 02-28 12:00，覆盖网页、App 与 API 请求，硬件为 H800。

| 指标 | 官方披露 | 正确解释 |
|---|---|---|
| Prefill 部署单元 | 4 节点；路由专家 EP32，MLA/共享专家 DP32 | 此系统的一种生产配置 |
| Decode 部署单元 | 18 节点；路由专家 EP144，MLA/共享专家 DP144 | 不能单凭卡数确定经济 MES |
| 平均/峰值节点占用 | 226.75 / 278；每节点 8 卡 | 均值/峰值约 81.6%，不是 MFU 或付费利用率 |
| 输入量 | 608B Token，其中 342B 命中磁盘 KV 缓存，披露比例 56.3% | 输入包括命中 Token，不是都重新执行完整 Prefill |
| 输出量 | 168B Token | 不应把总输入输出混为统一计算工作量 |
| 每节点平均阶段吞吐 | 输入约 73.7k Token/s，输出约 14.8k Token/s | 输入含缓存命中；两阶段使用不同资源组 |
| 输出速度 | 平均 20–22 Token/s | 不等于集群总吞吐 |
| 调度 | 夜间减少推理节点，资源转给研究与训练 | 说明存在跨用途复用，不给出全日 GPU 算术利用率 |

报告以**假设**的 2 美元/GPU·小时计算日租赁成本：

$$226.75\times8\times24\times2=87,072\ \text{美元/日}.$$

它又假设所有请求按 R1 价格计费，得到理论日收入 562,027 美元，并明确实际收入**显著更低**：V3 更便宜、网页/App 免费、存在夜间折扣。报告所谓 545% 是 $(R-C)/C$ 的假设成本利润率，不是 $(R-C)/R$ 毛利率，更非实际公司净利。用表中已四舍五入的 Token 数复算收入会有小差异。

将上述假设成本除以 776B 总 Token 得到约 0.1122 美元/百万混合 Token，只是**这个流量组合的账面摊销算式**。它不是百万输出 Token 成本，也不适合与另一个缓存比例和输入输出比例不同的系统直接比较。

### 2.2 为什么百卡配置不是行业 MES

要分开记录：模型装载的可行下限、某部署满足 SLO 的配置、经济最小有效规模、客户最低起租批量。它们分别受权重/状态容量、流量与并行策略、长期单位成本曲线、商务条款影响。

2026 年 DeepInfer 推荐的 64 卡 Prefill + 64 卡 Decode 高效配置见第 10 节。这一可行部署点不能单独证明百卡级规模就是全行业 MES，更不能直接推出完全竞争或排除自然垄断。

要估计 MES，至少需要在多个规模上保持模型、量化、上下文分布、到达率形态、尾延迟与可用性可比，核算完整长期成本。单次引擎吞吐对比即使能复现，也只回答技术效率的一部分。

### 2.3 利用率与命中率的分母

| 名称 | 需要写明的分母 |
|---|---|
| 上架率 | 可用机柜位、已建 IT 功率，还是规划容量 |
| 分配利用率 | 已分配 GPU 时间 / 可分配 GPU 时间 |
| 设备忙碌率 | 指标采样期间有内核活动的时间，而非有效 FLOP 占比 |
| MFU | 同精度、同稀疏口径下有效模型 FLOP / 硬件峰值 FLOP |
| 商业利用率 | 付费卡时、已售容量、确认收入中的哪一种 |
| 缓存命中率 | 请求数、输入 Token 数、可复用块数，还是节省的计算量 |

缓存命中受到共享前缀、流量规模、复用间隔、TTL、容量和路由共同影响。56.3% 是上面特定一天的输入 Token 比例；不能移植成 2026 年模型的命中率，也不能从缓存保留 72 小时推导出命中率为 96%。

## 3. 定价结构：有来源的牌价不等于成本

### 3.1 DeepSeek 当前快照

【官方文档】[Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/)的 2026-11-15 快照中，`deepseek-flash` 对应 `DeepSeek-V4.1-Flash-1017`，支持非思考及思考模式，默认思考。下表单位均为**美元/百万 Token**：

| 计费类别 | 闲时 | 高峰 |
|---|---:|---:|
| 缓存命中输入 | 0.003 | 0.006 |
| 缓存未命中输入 | 0.15 | 0.30 |
| 输出 | 0.60 | 1.20 |

该快照的高峰为 UTC 周一至周五 01:00–04:00、06:00–10:00，中国法定节假日除外；其他时间为闲时。价格和路由别名均可能更新，应以实际结算时的版本为准。

**2026-11-17 复核快照**：同一 [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/) 页面当日重读，`deepseek-flash` 仍对应 `DeepSeek-V4.1-Flash-1017`，上表闲时/高峰六项价格与高峰时段定义均无变化；旧别名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍被接受，由 1017 版模型承接并按 Flash 价计费（对应旧模型已退役）。页面同日新增披露 `deepseek-v4-pro`（`DeepSeek-V4-Pro-0813`，不支持视觉输入），单位同为美元/百万 Token：

| 计费类别 | 闲时 | 高峰 |
|---|---:|---:|
| 缓存命中输入 | 0.022 | 0.044 |
| 缓存未命中输入 | 0.66 | 1.32 |
| 输出 | 1.98 | 3.96 |

该 Pro 行是 11-17 页面披露的新增条目，不覆盖 11-15 Flash 快照；两模型的并发上限、功能矩阵不同，牌价差异不能直接读成成本差异。

闲时未命中输入与输出牌价为 1:4，但这不证明单位边际成本恰好 1:4。价格还反映容量、需求、竞争与产品设计。比较供应商前，须固定模型修订、量化、隐藏思考 Token、输入输出组合、缓存命中、工具费、SLO 和退款规则。

### 3.2 OpenRouter：无推理加价不等于无平台收入

【官方文档】[OpenRouter FAQ](https://openrouter.ai/docs/faq)，2026-11-15—16 审校快照：

- 底层供应商推理价按价透传；购买 credits 收 5.5% 手续费，最低 0.80 美元；加密支付费率为 5%。
- BYOK 免费额度按**目录推理成本**计，不按请求次数计。按量付费方案每月有 25,000 美元无 BYOK 费用额度；企业方案另议。
- 超出额度的 BYOK 部分按相同模型/供应商在 OpenRouter 的目录成本收 5% 费用。
- `:floor` 优先按价格排序供应商，是路由功能，不是可以锁定无风险利润的金融套利。

这些条款可以核实收费机制，却不能仅凭“零 Token 加价”推断公司无毛利、无其他收入，或断言它绝无包销、容量采购及其他资产负债安排。

### 3.3 折扣维度与跨商比价

批处理、缓存、承诺用量、保留容量、速度档位和区域都可以形成不同菜单。未见公开阶梯价不能推出大客户没有协议折扣；低牌价也不能证明低成本。大云与专门推理商可能销售不同的可用性、网络、合规与弹性服务。

构造时间序列时，应分别保存标价、实际净价和固定任务质量下成本。模型更新、免费额度、模型组合变化与美元汇率变化都可能造成平均支出变化，而不是同一产品提价或降价。

## 4. 技术可复现性与性能计量

### 4.1 硬件基线与端到端测量

【官方文档】[NVIDIA H100 规格](https://www.nvidia.com/en-us/data-center/h100/)给出 H100 SXM 的 80 GB HBM、3.35 TB/s 带宽，BF16/FP16 Tensor Core **dense 峰值** 989 TFLOPS；结构化稀疏口径数值不同。峰值不是端到端实测吞吐，不能与另一代芯片 FP4 稀疏峰值直接组成“性能提升倍数”。

基本 Roofline 上界为：

$$P_{\mathrm{attained}}\le\min\{P_{\mathrm{peak}},B_{\mathrm{mem}}I\}.$$

这里 $I$ 是与所测内存层次一致的算术强度。通信、负载不平衡、调度与尾延迟还会进一步降低端到端表现。MoE 的激活参数不是整批权重读取量；稀疏注意力访问更少位置也不意味着必须保留的 KV 按同样比例减少。

### 4.2 不拼接加速倍率

FP8、投机解码、连续批处理、稀疏注意力和缓存可能作用于同一瓶颈，收益不能无条件相乘。独立性能声明至少要保留硬件、模型版本、输入输出长度、精度、并发、吞吐指标与延迟/质量约束。

MLPerf 的[推理规则](https://github.com/mlcommons/inference_policies/blob/master/inference_rules.adoc)和[训练规则](https://github.com/mlcommons/training_policies/blob/master/training_rules.adoc)是测试口径的参考，不使任意厂商宣传图自动成为合规结果。跨期软件进步需要相同任务、硬件与质量约束的端到端比较，不能由多个不同实验的倍率相乘得到行业提升率。

### 4.3 开源边界

公开论文、公开权重、算子开源、引擎开源、控制面开源以及完整生产可复现，是不同层次。DeepSeek 的[Open Infra 索引](https://github.com/deepseek-ai/open-infra-index)确有 FlashMLA、DeepEP、DeepGEMM、EPLB、3FS 等组件入口；但组件发布并不消除调度、数据、工程与运营能力的全部差异。模型与软件还须分别核对许可证，不能给整个依赖栈一个未经逐项核验的“全部自由商用”标签。

### 5.2 指数方法已公开到哪一层

【官方文档】[Ornn OCPI 方法论](https://data.ornn.com/methodology)公开了一小时窗口、按 GPU 数量加权的分布、缩尾及加权均值计算；缩尾百分位参数和部分准入门槛不向一般公众完整公开。因此“没有任何加权公式公开”不成立；反过来也不能把发布方的抗操纵设计说明当作独立审计结论。

【官方文档】[Silicon Data 指数公告](https://docs.silicondata.com/products/gpu-index-announcements)记录了 2025-12-04 生效的方法变更：移除 divisor 调整、改变定价模型/覆盖与权重、加入回看机制，并重述自 2024-09-01 起的历史。发布方估计 H100 指数受影响约 −6% 至 −4%，A100 约 +35% 至 +40%；还提示 2025-03-01 扩大覆盖可能造成跳变。

这些是**方法变化的估计影响**，不是相应日期的真实租金涨跌。做收益率与波动率分析必须保留指数版本。公告另记载 B200 指数于 2025-12-04 生效、H200 于 2026-07-15 生效、B300 于 2026-09-14 生效；新指数回溯历史的起点不等于首次发布日。

### 5.3 金融解释的边界

不可储存使普通现货库存的 cash-and-carry 复制不可用，不意味着无套利原则失效。现金结算合同对冲的是指数风险，不自动授予实际 GPU 容量。未来要买算力的企业，面对涨价风险通常采用多头套保；收入随价格下跌受损的卖方通常采用空头。

一份实物交付远期不因没有交易所清算就必然“不属于衍生品”；须按合同结构及适用法域分类。也没有理论要求先发生行业崩盘，企业才会管理未来价格风险。详见[期限结构与远期定价理论](不可储存算力的期限结构与远期定价理论.md)。

## 7. 类比行业：保留机制，不移植数值定律

| 类比 | 可用于提出什么问题 | 不应直接移植什么 |
|---|---|---|
| DRAM、光伏制造 | 投资时滞、技术进步、扩产与价格预期的反馈 | 固定 3–4 年周期、必然同幅度暴跌 |
| 集装箱航运 | 长期运力与短期需求、地域瓶颈、现货/长约并存 | 某一指数跌幅就是全球所有航线跌幅 |
| 电力 | 非储存交付、容量约束、地点与时段风险 | 任意电力风险溢价方向都适用于 GPU |
| 大宗商品价格评估 | 规格分层、样本审查、估价与合同引用 | 必然先有价格评估机构才有成交或期货 |

历史价格类比必须先核对指数名称、单位、覆盖与版本，尤其不能把不同航运指数拼成一条序列。类比的价值是生成可检验假设，不是给算力行业预设阶段及崩盘日期。

## 8. 地理对照：先统一对象，再讨论约束

### 8.1 可比记录应包含什么

跨中国、美国及东南亚比较至少固定：卡型/显存、节点与互联、交付区域、购买日期、合同期限、最低数量、是否含税/电/运维、网络与数据驻留、可中断性、SLA、账期和汇率。相同 GPU 名称不是相同经济产品。

数据中心托管空置率、GPU 设备闲置率、模型推理有效利用率是三个市场的指标。不同年份、不同机构的区域读数须分别注明样本与分母，不能直接排成统一的发展次序。跨城市比较还须核对实际距离、网络路径、互联需求与业务类型。

已定位的区域读数示例（2026-11-17 补核）：JLL《North America Data Center Report Midyear 2026》（2026-08-11）披露北美数据中心空置率连续第三年约 1%（分母为存量托管容量），并预计至 2028 年接近零。该读数只覆盖北美托管市场，不能移植为中国或东南亚的空置率，也不能读成 GPU 利用率；中国及东南亚的同口径分区序列仍待核，详见第 6.1 节复核表。

### 8.2 电力的量纲与队列

- kW/MW/GW 是功率；kWh/MWh/TWh 是电量；美元/MW-day 容量费不是美元/MWh 电能价。
- PUE 是设施总能耗与 IT 能耗之比。IT 包括 CPU、网络、存储等，不能把 GPU 板卡功率直接当作全部 IT 功率。
- 1,000 卡若组成 125 台八卡节点，每台假设 10 kW，则 IT 功率为 1.25 MW；PUE=1.2 时设施功率为 1.5 MW，不是 10–15 MW。这是算术例子，不是实测机房。
- 发电/储能项目的并网队列不能写成数据中心负荷队列。“1,300 GW 排队”必须回到原报告的项目类别、统计日、去重及退出规则，不能作为数据中心已承诺需求。
- 申请量除以当期已通电量不是同一批项目的转化率。申请可能重复、跨期并发生撤回，应使用队列 cohort 跟踪。

政策要求需注明文件、适用区域、设施类别、生效/考核年份和指标定义。“所有新建枢纽强制 80% 绿电”不能脱离这些条件泛化；年度绿电属性匹配也不等于每小时物理电力均来自可再生能源。

### 8.3 地域溢价不是天然的准实验

出口约束、软件生态、性能、供给弹性、服务质量与需求组成可以同时变化。因此 H100 与国产卡的价格反向，或国内外 B300 报价存在倍数差，不足以把全部价差识别成管辖权租金或 CUDA 租金。

异地服务可能受时延、互联、数据法规与可靠性约束，但不是所有推理都必须贴近用户；批任务与交互任务的相关市场边界不同。法律限制须依当时适用条款及最终用途判定，不能把某地固定标成永久合规的转口通道。

## 9. 国内现货样本：记录结构而非未经核验的认证

### 9.1 样本范围与授权边界

相关第三方日度评估和匿名从业者报价处于用户指定的排除范围，没有核验其原始数据库、采样方法、成交凭证和独立性，不列为已核“一手成交实证”。这不判定这些报价虚假，也不改变被排除目录中的原材料。

若后续单独授权研究该组样本，最低记录格式如下：

| 字段 | 要求 |
|---|---|
| 标识 | 来源文档、采集时间、原始记录 ID、可引用范围 |
| 数据类型 | 挂牌、询价、可执行报价、已签合同、已交割，或评估机构价格 |
| 产品 | 卡型/显存、节点数、互联、地区、SLA、最低起租量 |
| 价格 | 币种、税、包月小时、是否含电/运维/网络、预付款、取消权 |
| 证据 | 成交量、合同或回单、去重与异常处理、匿名化方式 |
| 可比性 | 同一供应商/同一规格的复测；不同供应商截面不得伪装为时间序列 |

### 9.2 可以复算的换算，不等于价格认证

设一台八卡服务器**假设**月租 75,000 元，统一使用 730 小时/月，则：

$$p=\frac{75,000}{8\times730}\approx12.84\ \text{元/卡时}.$$

这只能检验除法正确；不能证明实际成交，也不能把 730 小时自动用于按实际日历月结算的合同。按需费率与必须购买整月容量的费率还包含不同的闲置风险和灵活性。

不同地区的两笔报价不能直接组成同一产品的时间变化；购置额除以毛月租不代表经济寿命；少量中介样本也不代表整个行业结构。样本能够支持的结论应与其覆盖和识别设计相匹配。

### 9.3 调度次数不等于交易量

评估调度数据须知道一次调度包含多少卡、持续多久、是否覆盖全部任务、是否只统计跨域调度。不能用次数直接除以目录卡数，宣称全平台利用率或交易量接近零；制度选择还须比较调度、采购与风险管理的实际效果。

| Engram | GPU 版本可将表分片存于主机内存并通过 RDMA 取回；NPU 尚不支持这项 CPU 卸载 | 不应对所有硬件统一扣除这部分设备内存 |
| SWA 有界重放 | 重放最近 128 个 Token 构造近似 SWA 状态；SWA 状态不进入持久 KV 缓存 | 不能改写成所有 KV 都保留 72 小时，或没有精度/传输与重放代价 |
| DSpark | 每次草拟 5 个 Token，按预估接受率选择验证长度 | 不应写成固定一次生成并接受 8–12 个 Token |

Q&A 的 DSpark 表使用 Open-PerfectBlend、EP64/DP64 条件，动态验证相对固定 5 的生产工作点收益约 4%–7%；16 序列/rank 的表中收益为 −1.5%，96 序列/rank 为 +11%。这是带配置的比较，不是投机解码在所有线上流量的固定增益。

155 万亿的单一总量未附审计口径，不能擅自判作 155 万亿新计算 Token，也不能直接与 2025 年的 776B 混合 Token 相除解释为硬件效率增幅。“96% 命中率”“80%–95% 毛利”“自建普遍贵 5–15 倍”在已核文档中没有依据，不能由 38 美元/卡时反推补齐。

### 10.3 Kimi 许可的精确边界

【官方文档】[Kimi K3.1-Pro LICENSE](https://huggingface.co/moonshotai/Kimi-K3.1-Pro/raw/main/LICENSE)规定：被许可方**或任一关联方**经营 MaaS，且被许可方与关联方在任意连续 12 个月内的**合并总收入超过** 2,000 万美元，商业使用前须另行签协议。

门槛不是“只有 MaaS 收入达到 2,000 万”，也不是大于等于；许可未事先给出统一授权费。MaaS 定义排除嵌入特定终端产品功能/执行框架以及单纯转发别人托管模型的请求。第 2、3 条对定义内的内部使用、通过官方产品或认证推理伙伴访问设例外；第 3 条另有超过 1 亿月活或 2,000 万美元月收入产品的显著署名要求。

公开权重不等于满足 OSI 开源定义。实际部署应读完整许可、核对关联方与对外服务方式，不把摘要当法律意见。

### 10.4 从架构证据到经济结论还缺什么

较低激活参数和较小 KV 可以降低部分计算/存储负担，但端到端成本仍需并行效率、功率、设备价格、存储、冗余、人员、利用率与质量约束。模型卡不能代替经营台账，API 牌价不能反推出物理成本；开源追平也不意味着原厂利润自动归零。相关条件见[内生沉没成本、开源溢出与定价机制](大模型层的内生沉没成本、开源溢出与定价机制.md)。

## 11. 仍需补齐的数据与后续验证

| 需要回答的问题 | 最小可执行补证 |
|---|---|
| 工程降本有多少传到客户净价 | 同质量任务成本、实际净价、替代供应商、容量紧张程度及合同调价窗口 |
| 降价怎样改变需求与利用率 | 区分新增任务采用与既有任务使用强度，记录批处理、缓存、排队及付费负载变化 |
| 投资反馈如何穿过交付时滞 | 同项目预期、订单/取消、验收与可售容量、量价现金流和再投/退出的连续记录 |
| 2026 年租金是否反转，幅度多少 | 获取同型号/区域/期限连续原始序列，固定指数版本，拆开方法变更与真实价格变化 |
| 目前是否有活跃算力期货 | 2026-11-17 已核查至 NYMEX 再延期（附条件至 2027-01-08，见 04 台账 §1.8）；仍需批准、挂牌与逐日成交/持仓证据，而非沿用旧公告 |
| 大云与小云谁成本更低 | 同模型/SLO 的完整成本和实际净价，区分采购、融资、利用率与捆绑服务 |
| 是否存在百卡行业 MES | 多规模长期单位成本曲线与真实市场边界；不能用装载卡数或最低起租量替代 |
| 155 万亿与 38 美元如何对账 | 同期命中/未命中输入、输出、思考 Token、GPU 时数、免费/付费流量与现金收入 |
| 2026Q3 财务与融资转向 | 各公司原始财报/电话会、债券与贷款文件，逐项注明期间和口径 |
| 地域价差来自何种租金 | 可比硬件、网络、服务、期限与政策冲击样本；不能只用两地报价倍数 |
| 效率提高是否引发算力反弹 | 同任务成功率、每任务资源、任务数和总资源使用量，控制外生需求与供给变化 |

所有待核条目在完成补证前都不承担理论“实证验证”功能。数据没有验证一个机制，并不表示机制不存在；同样，机制听起来合理，也不能给缺乏出处的数字提升证据等级。
