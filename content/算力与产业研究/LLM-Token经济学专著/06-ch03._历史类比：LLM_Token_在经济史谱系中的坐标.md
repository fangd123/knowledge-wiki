# ch03. 历史类比：LLM Token 在经济史谱系中的坐标

> 历史类比用于提出机制和核查问题，不用于证明行业终局。下面保留八类参照，但分别说明能够迁移的制度经验与不能迁移的物理假设。

**伴读定位：**在 [ch04](07-ch04._概念坐标系：异构服务的四项交易坐标.md)、[ch16 核心方法](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md#16.0%20核心方法阅读入口)和 [ch02](05-ch02._研究命题：异构服务的计量、契约与制度比较.md)之后按需阅读。本章提供可检验的机制与反例，不是主线中从服务走向货币或金融化的历史证明。

## 3.1 为什么历史参照系至关重要

商品市场提醒我们重视品级、交付和基准；电力市场提醒我们区分即时服务与容量；里程与积分提醒我们审查兑付合同。多个参照比单一“AI 石油”标签更有用。

最关键的边界是：**文本 token 是计量单位，推理是服务，服务券是请求权，加密代币是另一类资产**。只凭数字化或按量收费，无法确定其货币性质。

## 3.2 八种典型价值载体多维对照矩阵

| 参照物 | 可借鉴的机制 | 与计算服务的关键差异 |
|---|---|---|
| 比特币 | 可编程转移、网络接受度与价格风险 | 不承诺兑换特定发行人的推理服务 |
| 黄金 | 规格、保管、兑付与市场流动性 | 实物可以储存；工业需求不形成固定价格底线 |
| 原油 | 品级、地区基差、现货与远期 | 可交割实物与模型任务结果的同质性不同 |
| 天然气 / BTU | 对质量调整后的数量进行计量 | 热能可物理标定，智能任务效用依赖任务和评价者 |
| 电力 / kWh | 即时供需、地点与容量权利 | 电能具有明确物理量纲，可按能量守恒核算；token 不提供同样的统一物理换算 |
| 航空里程 | 私营兑付规则、合作伙伴和奖励 | 兑换、转让、到期由具体计划决定 |
| 平台点券 / 余额 | 预付履约与封闭激励 | 法币面额固定不等于实际购买力固定 |
| 排放配额 / 碳信用 | 权利登记、验证和制度性需求 | 配额与信用彼此不同，且无通用兑换关系 |

数字账本也有通信、共识与合规成本，不能称“纳秒级无摩擦结算”。封闭积分同样有信用、消费者保护和运营风险。

## 3.3 比特币、黄金与服务券：不同价值来源与请求权

比特币的非主权网络属性、黄金的实物及金融需求、服务券的发行人兑付承诺是三种不同的价值来源。黄金有工业用途并不保证价格不会大幅下跌；推理需要算力，也不保证交付结果有商业价值。

一张可兑换计算服务的凭证依赖供应商持续服务、合同执行和使用条件。它比“已经拥有一份可独立保管的黄金”更接近未来服务请求权。把二者都称为有物理成本，不足以推导同样的价格底线或储藏能力。

生产成本与价格也不能倒置：沉没成本不保证需求；当需求不足时，商品价格可以低于部分生产者成本。计算价格下降是否引发足够大的新增需求，取决于需求弹性，不是必然指数扩张。

## 3.4 原油与工业金属：品级、交割与价格治理

Brent 油田在 1970 年代发现并开始生产，Brent 期货于 **1988 年**推出；WTI 期货则于 **1983 年**推出。各油种的供给、现货网络和合约发展有不同时间线。[EIA 的 Brent 历史](https://www.eia.gov/TodayinEnergy/detail.php?id=30292)、[ICE 的基准演进](https://www.ice.com/evolution-of-brent-its-markets-and-why-its-ecosystem-is-relied-upon-by-commercial-participants)。

品级、交割地点、时间、可替代品牌和价差规则有助于形成流动性。但标准化、现货交易和金融工具常相互促进，并不是所有市场都依次经历同一路径。将 LLM 市场精确定位成“相当于原油 1900 年”没有可检验依据。

工业金属合约的质量应引用具体标准、版本和注册品牌要求。现货称呼、国家标准与废铜分类不属于同一分类体系，比较 LME、SHFE 与 COMEX 须查具体合约，不能只比较一个铜纯度数字。

价格评估机构发布的是按方法论评估的参考价格；其影响力来自数据质量、治理、合同采用与监管要求，并非报价天然拥有“法定公信力”。

## 3.5 天然气（BTU）：能量计量与质量调整的边界

BTU 是热量单位，不是货币单位。天然气按能量计量能够修正不同成分、温压与热值造成的体积差异，具体高/低位热值及测量口径仍须约定。

计算服务可借鉴这种“先调整质量再比较价格”的思路，但不存在已知的、与任务无关的智能热值。代码审查、翻译和图像理解不能自然合并成一个绝对智能标尺。

可实施的做法是固定任务篮子和验收规则，测量成功率、延迟、总成本及不确定性。所谓 SIU 只能作为公开方法下的操作性指数，不能写成公认的物理单位。详见 [ch16](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md)。

## 3.6 电力网络（kWh）：基础设施市场化与容量远期启示

电力制度最有价值的启示是区分：

- **能量**：一定期间实际消费多少；
- **功率/容量**：特定时段能否获得可用能力；
- **可靠性与地点**：网络拥塞、备用和供给条件。

同理，模型 token 余额、每分钟限额与有 SLA 的预留吞吐不能混为一项。按量价格锁定也不等于保证高峰服务可用。

部分电力市场有 LMP 或容量市场，其他市场采用不同安排；不能把某一区域制度称为全世界统一模式。GPU 租赁和模型服务也不必复制电网拆分结构。

## 3.7 航空里程与积分体系：闭环私营凭证的运行机理与边界

里程类比适用于奖励来源、兑换规则和发行人信用。不同计划可能允许收费转让、家庭合并或伙伴兑换，不能概括为“法律普遍禁止一切转让”。提高兑换所需里程意味着里程购买力下降，不宜称为里程本身“通缩”。

专家贡献换服务额度能否形成有效循环，取决于专家对额度的实际需求和机会成本。高质量贡献者可能只愿接受现金；凭证供给与服务消费必须能匹配，平台不能靠持续增发奖励掩盖亏损。

## 3.8 平台点券（Q币 / Steam 余额）：规模化闭环生态的合规与商业边界

平台点券说明封闭服务权益可以被广泛使用，但不能由知名平台的存在推导新项目当然合法，也不能在缺少独立披露时写出 Q币年流转“百亿级”等数量结论。

历史资料须准确归属：2009 年相关通知由**文化部、商务部**发布，其对象是网络游戏虚拟货币，并区分发行企业与交易服务企业；不能概括成央行发布的“全面禁止跨平台交易、所有退款均禁止”三条通则。[2009 年通知原文](https://zwgk.mct.gov.cn/zfxxgkml/zcfg/gfxwj/202012/t20201204_906151.html)。

该历史文本也不能替代 2026 年对计算服务、预付消费或加密资产的现行判断。不得把“不可提现”写成免牌照、免税或免除消费者退款义务的充分条件，见 [ch06](09-ch06._服务契约的四组约束：计量、权利、漂移与归责.md)。

## 3.9 排放配额与碳信用：制度性权利与验证机制

两类通常以吨二氧化碳当量计量的单位，来源与权利不同：

- **排放配额 allowance**：总量控制制度下的排放许可，通常以吨二氧化碳当量为单位；
- **碳信用 credit**：按特定方法学核证的减排或移除单位，涉及额外性、持久性、泄漏与重复计算风险。

EU ETS 配额不能与 Verra 等项目碳信用不加限定地混用。一个单位的登记和转移，也不证明其环境效果无争议。

可以迁移的经验是登记、注销、独立验证与质量差异管理；不能迁移的结论是“有规则就必然形成成熟金融市场”。

## 3.10 综合定位研判：LLM Token 的经济学生态全貌

严谨的定位是：**推理是可交易的计算服务；token 是一种服务用量记录；预付券是对服务提供方的合同权益；在特殊网络中，权益可能取得受限交换功能。**

商品化意味着规格与交易规则更清晰，不等于其法律上必属商品，也不等于成为商品货币。

## 3.11 从历史参照提取待验机制

类比提出两类待验机制：可审计的任务成本比较能否改善采购，明确交付与赔付的服务合约能否降低争议和履约风险。先与现有评测、账单工具和容量合同比较，只有存在未被解决的问题时才需要新产品。

独立性、代表性样本和市场采用是长期建设任务。运营路由与编制指数可能存在利益冲突，应披露分离机制、样本选择和修订政策，而不是仅宣称中立。

## 3.12 本章小结

历史参照给出“品级—交付—验证—违约”的检查清单，是否新建制度则由客户反事实决定。技术报告核验可以先使用内部验收表和普通服务合同；公共指数与可转让凭证只有在新增用途得到验证时才有必要。
