# ch12. 联合压力测试：五类冲击、损益传导与决策触发器

> 本章接 [ch10 的收入与产能边界](13-ch10._市场边界：从客户任务到可获得收入的测算.md)，检查候选方案对哪些输入敏感。五类冲击可以同时发生；压力测试寻找脆弱依赖，不验证客户需求，也不给方案估计成功概率。

## 12.1 方法论：稳健性需要可观察的损益

Shell 与 Pierre Wack 对情景规划的推广有重要影响，但并非凭此创立了所有情景方法。对本书的实际启示是：比较多种可解释路径，识别可逆行动与脆弱依赖，而不把单一预测当成确定未来。

“无悔”只能指在已考虑情景中相对稳健，不能保证任何未来均盈利。企业仍需现金流、客户采用和责任约束。

## 12.2 五类非互斥压力因素

| 代码 | 压力因素 | 需要改变的模型输入 |
|---|---|---|
| A | 部分任务的开放权重供给与效率提高 | 同质量任务成本、替代供应、客户价格 |
| B | 前沿服务集中与容量波动 | 价差、限流、供应商集中和切换成本 |
| C | 支付、数据或 Agent 责任规则收紧 | 交付范围、治理费用、准入与赔付 |
| D | 机器自动付款与链上交易采用扩大 | 独立付费客户、结算费用、真实服务量 |
| E | 融资收紧与客户预算下降 | 获客、续费、坏账、融资及供应商信用 |

本章不为这五类重叠因素分配概率或计算概率加权排名。每个测试应写明哪些因素共同变化、哪些保持不变，以及为什么采用该变化幅度。

若确需概率模型，应另行定义互斥终端状态或明确联合分布，并说明概率来源、条件关系和更新方法。不能只把重叠冲击的分数相乘或相加。

## 12.3 各类冲击的传导

### 情景 A：任务成本下降与供给增加

应用可能节约采购成本，但竞争可能同步压低终端售价；更便宜的 token 也可能增加调用与核验用量。路由价值可能增加，也可能因模型差异缩小而降低。模型能力接近不意味着 tokenizer、SLA 和许可完全相同。

价格对冲需求可能减弱，特定时段保供仍可能有价值。服务券是否贬值，取决于固定法币还是固定服务承诺。

### 情景 B：前沿集中与容量波动

供应商集中可能提高迁移、采购与容量保障的价值，也可能使第三方无法获得足够供应或有效对冲。不能只给“风险管理产品”打满分而忽略它承担的尾部损失。

去中心化供给是否受益取决于能否提供同类质量与容量；“替代需求上升”不等于替代能力存在。

### 情景 C：监管或责任要求提高

影响取决于规则对象。数据、劳动报酬、执业和消费者要求可能同时影响业务交付与激励安排；企业治理软件可能受益，但适配和审计成本也会上升。

应逐项模拟实际业务变化：停止某类资金托管、增加人工核验、调整数据地域、使用适用的支付服务商或缩小客户范围。

### 情景 D：自动付款采用扩大

协议服务与账户治理可能获得新需求，但不能因此推断算力储备代币兑付问题已经解决。链上交易量需剔除补贴、自交易与重复转移，并与独立客户实际服务购买匹配。

传统账单系统也可支持自动化和净额结算；采用扩大不必使一种支付轨道成为唯一入口。

### 情景 E：资本与客户预算收缩

客户减少实验预算，供应商可能重组或提高预付要求。轻资产服务虽减少硬件暴露，仍可能受流失、坏账、增长停滞和专家固定成本冲击。

降本产品可能较受关注，但客户采购周期也可能变长，不能据此保证“逆周期自造血”。

## 12.4 对同一候选组合做联合压力测试

星级只表达序数偏好，不能直接解释为财务收益并计算风险方差。测试输出应使用可解释的成本、交付、现金与损失指标。

有真实基线时输入测量值；只有教学假设时显式标注，不能把模拟输出反过来当成经营证据。对同一候选组合同时改变相关参数：

| 联合压力 | 试验内容 | 观察输出 |
|---|---|---|
| A + E | 采购价格下降，客户售价和用量也下降 | 贡献毛利、固定费用覆盖与现金消耗 |
| B + C | 供应集中、限流，同时增加合规与复核要求 | 验收率、交付时长、客户流失与赔付 |
| D + C | 自动交易增长，同时收紧授权和资金规则 | 单笔总处理成本、失败及争议率 |
| B + E | 供应方信用恶化，客户预算冻结 | 预付款损失、替代供应成本和现金跑道 |

情景变动幅度应由历史、合同或管理层明确假设给出。例如“售价下降20%、获客延长一倍”若仅为压力输入，必须标示假设，不能称预测。

在技术报告核验案例中，可同时压低客户价格、提高疑难报告比例并减少专家可用工时，再观察验收成本、时限和现金需求。若组合失败，应找出需要减少的服务承诺或组件，而不是给整个“核验行业”贴上失败标签。

## 12.5 动态战略组合与触发器

可将预算分为经营验证、受控扩展与研究储备，比例由现金约束、验证成本和可回撤程度确定。压力暴露越不可控，越应优先缩小承诺与试验规模，而非机械扩大某个“防御赛道”。

触发器应使用与客户直接相关的指标：

- 固定任务集上，替代模型在质量非劣约束下的总成本优势持续超过迁移费用，才扩大切换。
- 拟用金融合约已实际可交易，价差、深度、基差和保证金满足内部要求，才考虑套保；公告日期不满足该条件。
- 出现适用的新规则，先映射受影响资金、数据与责任流程，再调整业务；不自动将一切改为积分或私有部署。
- 客户回款和复购恶化时，按现金跑道及停止阈值缩减投入；“回收期必须小于六个月”应由商业模式决定。

Arena 分数、榜单名次或输出单价的单个阈值，不能单独“确认”宏观情景。各基准分数的含义与置信区间不同。
