# 附录 A. 核心术语与经济学概念对照表

> 本附录维护概念定义与跨章用语；具体价格、协议版本、法律和交易状态以 [附录 C](02-附录_C._核心文献、行业规范与实证数据源汇编.md)及相应章节的来源时点为准。连续阅读路线见 [ch01](04-ch01._核心摘要.md)。

## 一、首先区分的四个对象

| 对象 | 定义 | 不应混同的对象 |
|---|---|---|
| 文本 token（词元） | 分词器或模型处理的离散符号 | 可储存的 GPU、电力或货币 |
| 服务用量 | 在具体模型、方向和规则下计量的消费数量 | 已验收业务结果 |
| 预付服务权益 | 对发行方未来服务的合同请求权 | 无信用风险的现货商品 |
| 支付资产 | 被接受用于付款的存款、稳定币或其他资产 | 因名称相同而与文本 token 等价 |

“USD/百万 token”中的美元是货币记账单位，token 是数量分母。按量计费不构成商品本位制。

## 二、英文缩略语与技术协议

### A2A（Agent-to-Agent Protocol）

跨系统 Agent 发现与任务协作协议。A2A x402 是支付扩展，不能把所有 A2A 消息都当作付款，也不能将其与 AP2 视为同一个协议。

### ACP

存在同名缩写：Virtuals 的 **Agent Commerce Protocol**侧重 Agent 任务协作与托管；Stripe/OpenAI 语境的 **Agentic Commerce Protocol**用于智能体商业交互。引用时须写明组织、全名与版本。

### AP2（Agent Payments Protocol）

用于 Agent 受托购买的开放协议框架，包含可验证授权与交易证据。签名可以帮助核对授权内容，但不自动确定法律主体资格、代理责任或商业争议结论。

### ARR（Annual Recurring Revenue）与 Run-rate

ARR 是按企业明确定义年化的经常性收入指标；Run-rate 是将近期期间的业务速率年化。两者均不等于已确认全年收入、净利润或现金流，披露时需说明期间、收入范围与计算方式。

### BPE（Byte-Pair Encoding）

一类常见的子词构造与编码方法；并非所有 tokenizer 完全相同。词表、预处理和聊天模板会影响计数，不能用固定“每汉字 token 数”替代实际测量。

### BTU / MMBtu

英热单位及百万英热单位，是热量单位。天然气热值和温压口径须约定；它不是货币单位，也不证明存在与任务无关的“智能热值”。

### CED 与 Engram

在 DeepSeek-V4.1-Flash 官方模型卡中，CED 指 Causal Encoder-Decoder 架构，Engram 是条件记忆组件。版本参数与来源见 [ch16](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md)及 [附录 C](02-附录_C._核心文献、行业规范与实证数据源汇编.md)。架构与基准数字是发行方自述，不能直接换算为所有部署的成本或利润。

### CFTC

美国商品期货交易委员会。一般公开征询、具体合约申报、自我认证、延长审查与正式上市具有不同意义。具体文件的日期与状态见 [附录 C](02-附录_C._核心文献、行业规范与实证数据源汇编.md)。

### ClusterMAX 与 MLPerf

ClusterMAX 是 SemiAnalysis 的云 GPU 集群评级体系；MLPerf 是 MLCommons 维护的规定工作负载基准。评级、训练性能、推理性能与实际租赁价格不应混用，也不能单独证明客户任务总成本。

### dTAO（Dynamic TAO）

Bittensor 的动态子网代币机制，涉及子网资产、流动性池与激励分配。具体排放规则随版本变化，代币价格和奖励不等于外部客户服务收入。

### ERC-8004 与 ERC-8183

ERC-8004 涉及 Agent 身份、声誉与验证登记；ERC-8183 定义带托管预算、服务提交和评估者验收的任务机制，不是未来收益权证券化标准。观察时点的草案状态见 [ch05](08-ch05._生态地图：全球计算经济与支付结算全景透视.md)，不能把草案、实现和生产采用视为同一状态。

### GMV（Gross Merchandise Value）

按确定边界统计的商品或服务交易总额。需注明是否实际成交、退款、自交易、重复流转和受影响交易。GMV 与平台收入之比取决于商业模式，不存在统一的百倍或千倍定律。

### GPU 算力合约与交割方式

以具体算力指标或资源为参考的合约，须分别核查标的、期限、规模、现金结算或交付方式及交易状态。代码与公告不能替代可用容量或流动性。ICE–Ornn 与 CME–Silicon Data 的已核验历史文件及未决状态集中在 [ch05](08-ch05._生态地图：全球计算经济与支付结算全景透视.md)与 [附录 C](02-附录_C._核心文献、行业规范与实证数据源汇编.md)。

### IOSCO PRA Principles

2012年文件准确名称为 **Principles for Oil Price Reporting Agencies**，涉及石油价格评估机构的方法、治理和审计等；2013年的 **Principles for Financial Benchmarks** 是另一套更广的基准原则。原则、当地监管要求和具体指数方法不能等同，也不存在一条对所有市场都机械适用的唯一数据瀑布。

### KV Cache、MLA、DSA、KDA 与 CSA2

KV cache 是重复利用历史注意力状态的工程机制；MLA 为潜在注意力，DSA、KDA和CSA2是不同架构中的稀疏或混合注意力方案。模型、层数、精度、上下文和实现决定占用，不能共享固定压缩率。

全局 KV 指标不等于整机所有状态，也不包含所有工作区与运行开销。压缩改善资源使用，不意味着长上下文的全部成本或商业加价依据已经消失；具体模型示例见 [ch16](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md)。

### Mooncake、3FS、DeepInfer 与 TileLang

分别属于缓存服务架构、分布式存储、推理系统和算子编程/编译等不同层次的技术。缓存从 HBM 分层到主机或存储可降低重复计算，但也引入传输、存储和调度成本。

DeepInfer 的生产配置与收入折算示例见 [ch16](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md)，不能把收入当利润或把缓存留存当命中保证。公开模型权重和部分代码不意味着线上缓存管理、负载均衡及全部运维能力均可完全复制。

### LMP（Locational Marginal Price）

部分电力市场采用的节点边际价格，可反映边际发电、损耗与拥塞成本。并非所有电力市场都采用同一节点制度，也不能将GPU地点价差机械写成电力LMP。

### MiCA 与 GENIUS Act

分别涉及欧盟加密资产市场与美国支付稳定币框架。不同资产分类、法域、生效日期与实施规则必须逐项核对；不能把所有服务券称为法币稳定币，也不能将某一框架的储备要求复制到全部产品。

### MPP 与 SPT

MPP（Machine Payments Protocol）由 Tempo 与 Stripe 联合发布，处理机器支付协调，Stripe实现包含稳定币及卡等方式。SPT（Shared Payment Token）是受限付款凭证。协议、凭证、结算资产和支付服务商牌照是四个不同对象。

### MTL / VASP

MTL通常指美国州层面的资金转移许可；VASP是虚拟资产服务商的监管概念，不是全球通用牌照。是否需要许可取决于具体活动、资产、客户、法域和适用例外。

### OCPI 与 Silicon Data 指数

Ornn OCPI 与 Silicon Data 发布的是不同方法下的算力价格指标；需要核对硬件、地域、报价或成交、时点、样本和权重。不能将其统称由去中心化遥测直接证明的同一价格，也不能将GPU指数直接当token成本。

### OpenRouter

多模型 API 聚合与治理平台。token 价差、充值费与 BYOK 费用是不同收费项，价格透明不等于零总费用，模型覆盖不等于全球份额。版本化费用快照集中在 [ch05](08-ch05._生态地图：全球计算经济与支付结算全景透视.md)。

### PD 分离（Prefill-Decode Disaggregation）

把预填充与解码部署在不同资源上的方法。其收益取决于工作负载、网络、批量与调度；预填充不必永远算力受限，解码也不必在所有部署都只受显存带宽限制。

### PPP 与任务有效成本比

货币 PPP 是跨经济体商品篮子购买力比较。本书“Task PPP”借用固定任务篮子思想，实际比较同一任务与验收约束下不同模型及处理政策的总成本，不是可交割货币汇率。公式及适用条件见 [ch16](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md)。

### PRA（Price Reporting Agency）

价格评估机构依据方法论采集、判断并发布参考价。独立性、利益冲突、样本代表性和可审计性影响可信度；不能仅凭PRA名称假设所有机构及关联方绝不参与其他业务，也不能称其报价天然具有法定效力。

### Prompt Caching

复用共同前缀计算或状态的机制。命中条件、保留期、写入费、读取费和存储费用由具体产品决定。缓存留存不是命中保证，命中也不必对应同一折扣。

### TPM / RPM

每分钟token/请求速率限制。限额是上界，不是持续可用吞吐下界；预留服务要按合同的资源定义、并发、质量和SLA另外评估。

### x402 与 Pay-per-crawl

x402是可扩展机器支付交互协议；Pay-per-crawl是Cloudflare内容访问收费产品，两者不是同一个产品。支付授权、网络确认、商业履约及版权许可也是不同环节。

## 三、经济学与产品机制

### 制度比较与总成本

在给定任务、质量、履约和风险约束下，将候选组织、合同、激励或支付安排与现有替代品比较。生产交付成本与狭义交易费用分别记录，再无重复地汇总；客户收益、供应商利润与行业福利另行区分。研究主轴见 [ch02](05-ch02._研究命题：异构服务的计量、契约与制度比较.md)。

### 六组可组合方案

业务交付、运行治理、风险产品、权利形式、供给组织与支出功能的六组候选方案，分别对应 [ch08](11-ch08._六组可组合方案：客户问题、交付责任与单位经济.md) 的一至六。它们不是同层互斥分类，不能直接做统一赛道排名或相加市场规模。

### 闭环工作经济体与可选积分

“闭环工作经济体”描述平台内贡献奖励与服务消费相连接的一种设想。垂直核验服务本身不要求闭环，可用现金支付专家。采用积分时，它是发行方权益承诺，须处理履约、退款、奖励成本与数据权利；闭环不自动证明自给自足或免除监管。

### 处理政策与任务队列

处理政策包括模型选择、提示词、工具、缓存、重试、人工兜底与放弃规则。任务队列是按预先规定范围纳入比较的全部任务，不只包含最终成功者。不同政策可以比较，但任务、验收与成本边界须相同或可校准。

### 证据门与试验优先级

证据门是特定用途在采用或扩量前应满足的条件，不是从软件走向指数再走向金融化的阶段。试验优先级依据客户问题、可取得的基线、权利、成本与可回撤程度形成，不等于商业成功率；按 [ch13](16-ch13._决策框架：预先登记评价标准、采用与停止条件.md) → [ch15](18-ch15._试验设计与证据记录：按预设标准采用、调整或停止.md) → [ch14](17-ch14._综合判断：有条件的试验优先级与可放弃方案.md) 阅读。

### 能力漂移

模型版本、数据、提示词、工具和服务配置变化导致任务表现变化。应以版本、替代规则和持续评测管理；它增加长期合同难度，但不意味着所有服务远期无法订立。

### 内生沉没成本

Sutton分析企业可通过研发、广告等前置投入竞争时市场规模与集中度的关系，其结论有需求与竞争假设。不能从高研发支出直接推出自然垄断、永恒寡头或进入窗口关闭。

### 算力本位与双轨安排

若仅指“按计算用量计费、以法币或支付资产结算”，它是服务定价安排，不是金本位式货币制度。若指发行可兑换算力的货币，则必须说明兑付主体、储备、可转让性和接受范围。

### 数字算力仓单

对明确容量或服务权益签发可验证凭证的构想。未来推理并非已经存入仓库的实体商品；上游授权、服务可交付性、期限与违约责任不能因账本存在而省略。

### 缓存亲和与迁移摩擦

已有缓存和状态可能提高留在同一供应商的经济性。它不是所有会话都不得中途切换的规律；应比较余下工作流的质量、总成本、重建状态费用与故障风险。

### 现金结算、实物交割与容量保障

现金结算按指数差额支付；实物或服务交付按合同提供约定资源；容量保障需要对应时段的可用能力。三者不能互相替代。

### 有效任务成本

固定队列与处理政策下，全量调用、失败、核验、返工和运维成本除以最终验收任务数，并同时报告验收率与重大错误。简单的每次成本除以单次成功率，仅在明确重试与成本假设下可作为特例使用。

### 沪伦比值与跨模型迁移

商品跨市比较需处理币种、期限、品级、税与运输；模型迁移需处理质量、数据、提示词、缓存与工程费用。借鉴比较方法不意味着模型间存在同一可交割资产或无风险套利。
