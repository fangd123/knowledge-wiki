# 从铜到 token：算力经济的政治经济学解剖

副标题：商品标准化、稀缺收益与信用风险的制度边界

> **导读**：电力、GPU-hour、模型服务与业务结果处于同一价值链的不同层级。政治经济学帮助辨认生产资料、所有权、收入索取权和控制权的分布；成本、竞争与金融模型进一步解释这些权利如何影响价格、投资和风险承担。本篇的主线是：**技术决定可行用途，制度与合同界定谁能获得收益、谁承担损失，竞争与需求决定这些权利实际值多少钱**。

## 0. 核心问题与分析层次

本文研究三个问题：哪些服务能形成可比商品，哪些权利支持持续收益，技术与融资如何传递风险。沿着下面的链条，计量和质量条件不断变化：

```text
电能与接入容量 → 硬件时段服务 → 模型调用 → 智能体任务 → 可验收业务结果
```

算力是模型服务的重要投入，但并非每家 Token 卖方都有相同净算力敞口。自持硬件、固定租约、浮动租约和按调用分成对应不同风险；未来采购怕涨价通常买入套保，未来出售怕降价通常卖出套保。

三类命题需要分开：**马克思理论内部的概念解释**、**现代经济学的条件性推导**、**当代市场的经验事实**。前两者不能相互充当经验验证，第三类必须有独立资料和可比口径。

将这种分工落实到一个项目，可以先列权利与责任，再估计现金流：

| 主体 | 主要控制权或索取权 | 需要追踪的风险与决策 |
|---|---|---|
| 设备所有者 | 设备处置、租金和残值 | 购置、技术替代、出租与退出 |
| 承租运营商 | 合同期内的调度与客户服务 | 固定付款、闲置、运维和履约 |
| 模型权利人 | 授权、模型供给与商业条款 | 研发回收、替代模型与许可收益 |
| 终端客户 | 约定质量和容量的服务请求权 | 业务价值、切换、需求变化与供应中断 |
| 债权人 | 约定偿付、担保和违约处置权 | 偿债现金流、抵押覆盖与优先级 |

同一项设备投资，在自持、固定租约或按量采购下，会产生不同的净敞口和投资激励。本文在这些制度约束下讨论收益分配；研发投入和定价的行为假设见[产业组织专章的理论接口](大模型层的内生沉没成本、开源溢出与定价机制.md)。

## 1. 从现货交换到未来收入索取权

### 1.1 商品、服务与支付

《资本论》的使用价值、价值、货币及信用讨论，可以用来分析服务怎样被计量、出售和资本化。即时服务也可以成为商品，不必凝结为可放进仓库的物品。现实“现货”合同仍可延期付款、分批交付，不必所有权和货币在同一时点同时易手。

延期付款形成信用关系；长期租约形成对未来服务的请求权；债券和股权则形成不同优先级的未来收入索取权。它们有联系，但不构成任何行业都必须依次经历的线性阶梯。

### 1.2 远期交割价与证券现值分别计量

债券或股权的价值可由风险调整后的未来现金流贴现分析；远期在签约时通常选择一个使初始价值为零的交割价格。不能将远期报价直接写成“未来现货价格的贴现预期”。

现金结算远期的一次到期支付为 $S_T-K$。若 $M$ 是随机折现因子，其零初值价格为 $K=\mathbb E[MS_T]/\mathbb E[M]$。真实测度预期与风险补偿的关系见[期限结构专章](不可储存算力的期限结构与远期定价理论.md)。交易工具的法律与现金流性质，比泛称“纸质复本”更适合直接用于风险计算。

### 1.3 流通费用与社会价值

马克思区分生产过程在流通领域的延续与纯粹流通费用；运输、必要保管、营销、账务和投机储存不能一律归成同一类。现代福利分析又会问，验证、对账、清算是否减少违约、交易成本和资源浪费。理论中的“不创造新价值”并不等于没有社会效用，也不推出相关企业只能获得很低回报。

产业套保者和投机者的分类按风险目的，不是不可变的社会身份。套保可能降低企业现金流风险，投机可能提供流动性，也可能放大压力；是否有益须考察行为、制度和市场状态，不能仅由参与者比例判定。

## 2. 算力商品与铜的六项差异

### 2.1 不可储存的时段服务

昨日空闲 GPU 时间不能搬到今日。购买设备、保留未来容量和存储计算结果是不同选择。不可储存破坏的是以现货服务做 cash-and-carry 的复制路径，不是否定全部无套利约束，也不否定期货存在；成熟的电力衍生品提供了反例。

### 2.2 多维质量与相关市场

型号、显存、互联、网络、地域、独占性、期限和 SLA 都影响资源可替代性。标准化可以通过单型号、单区域等细分规格，也可以通过明确的质量调整构造指数；两条路线各有流动性和代表性取舍。按型号分别定义并非“绕过抽象化”，而是一种具体的标准化。

相同 GPU 在不同服务包的价差不能直接解释为套利或租金。相关市场取决于客户实际替代选项：低时延交互、批处理、同步训练可能有不同地理范围，不能把全部推理统一缩成都市圈。

### 2.3 无形损耗与资产寿命

更便宜或更适用的新设备会压低旧设备的潜在收益，这是技术陈旧的重要机制。但供给限制、需求扩张、软件兼容和替代用途可能维持甚至提高旧设备收益。

应区分物理寿命、经济寿命、会计折旧年限和投资回收期。会计折旧是资产成本在预计受益期内的分配，不是每日市场估价；不同公司的估计可能因设备组合、使用方式和维护策略不同。不能从毛租金回本三年就证明会计折旧必须三年，更不能由年限变更单独认定盈利质量存在问题。

### 2.4 供给响应需要多个要素

芯片、HBM、封装、机房、并网、软件与资金都可能限制服务供给，而且可以同时约束。芯片交付不等于可运营容量，公告建设 MW 不等于可售 MW。不同项目工期不同，不能从某一建设周期推导全行业必然每两年崩盘。

### 2.5 交割与现金结算

实物服务交割可以约定账户权限、资源、时段、验收与违约赔偿；现金结算则按参考指数计算支付。后者以规则、基准治理、清算和现金支付形成纪律，不需要实物仓单。它的风险是参考指数代表性、操纵、基差和信用，而不是“实体经济的最后一根锚链已经断了”。

### 2.6 信用与所有权的分层

设备所有者、租赁承租者、模型供应商、最终客户和债权人承担不同风险。按量采购可转移部分空置风险，固定价长约可转移部分价格风险；风险转移不等于风险消失。分析金融化应记录合同现金流、抵押、优先级和违约处理，而不是只看 GPU 数量或融资总额。

## 3. 能否形成衍生品：五项设计条件

| 条件 | 实际要解决的问题 |
|---|---|
| 标的定义清楚 | 型号、地域、交付期、计量与 SLA 是否可裁定 |
| 基准可持续 | 数据源、版本切换、停牌和缺失数据怎样处理 |
| 真实风险需求 | 产业采购/销售风险与结算指数是否足够相关 |
| 结算可执行 | 现金支付或服务交割、清算、违约与争议机制 |
| 治理与流动性 | 利益冲突、操纵、集中持仓、参与准入和交易成本 |

可储存、稳定成本地板、集中现货撮合都不是所有衍生品的必要条件。电力可以出现负价；运费指数型合约也可以现金结算；OTC 成交和评估价可以形成参考基准。质量复杂会增加成本，却不构成原则上不可解决的否决项。

模型升级或下架需要合同终止、替代型号、版本冻结或指数重构规则。预留吞吐也不能免除这些问题：“每秒 1,000 Token”必须指定模型、长度分布、输入/输出组合及延迟，否则并不比 Token 单价更同质。

工具选择取决于稳定计量、独立验证、实际敞口相关性和相对于既有合同的增量价值。满足这些条件的硬件时段、容量预留或模型服务都有进一步标准化的可能；越难验证、基差越大、交易成本越高，新增风险市场的用途越受限。应与不套保、直接长约和内部调度比较，而不是事先把金融化边界固定在某一计量层。

## 4. 利润、劳动与稀缺收益

### 4.1 成本结构与利润的两种分析口径

马克思的 $p'=m/(c+v)$ 是其理论中的利润率表达。由推理瞬间几乎无人操作就令全行业 $v=0$，忽略了研发、数据、运维、销售和服务劳动，也忽略部门间利润分配及理论自身的反作用因素。它不能作为现代推理公司利润必为零的定量证明。

现代自由进入模型中的“零经济利润”则是扣除正常资本机会成本后的概念，依赖同质服务、可进入、可复制技术等假设；不等于会计净利率、毛利率或股东现金回报为零。两个框架不能靠共用“零利润”三个字相互验证。

### 4.2 权重可复制，推理仍消耗资源

模型权重可低成本复制但仍有研发与分发投入；推理每次执行需要资源，缓存也需存储和读取。把研发总成本除以预计有效服务量是成本分摊方法，不是市场价格恒等式。分母增加可以摊薄成本，但未来实际服务量受到商业寿命和需求限制。

研发回收、服务边际成本、容量稀缺和客户支付意愿共同影响价格。不能由权重低复制成本断言价值规律已被数学上证伪，也不能用“地租”替代全部成本分析。

### 4.3 把“地租”作为有边界的类比

以下机制值得研究，但需区分：

- **稀缺性收益**：优质并网容量、特定供给、许可和交付时段的供给暂时受限。
- **差异化与知识产权收益**：模型质量、软件、品牌及独占数据影响客户替代选择。
- **成本优势收益**：更有效的系统、较低购置成本、优质区位或更高负载因子。
- **关系与转换成本**：集成、责任、合规、缓存和采购流程使切换有成本。

它们可以类比绝对或级差地租，但不与马克思土地所有权范畴完全等同。NVIDIA 毛利率不是纯经济租金；PJM 的容量价格不是数据中心电能价格；不同国家不同规格服务器的报价倍数也不是法律壁垒收益的干净估计。

### 4.4 开放和许可如何改变收益可占有性

可用的替代权重可以降低进入成本、增加买方议价能力；许可、运营能力、质量、分发和责任仍可能维持差异。模型权重可得、获准商业使用和能够稳定交付，是三个不同条件，技术与许可案例集中见[数据附录第 10 节](算力与_token_经济：数据附录（2026-11-15—16_快照）.md)。

如果开放使可替代服务增多而其他条件相近，原供应商能够保留的价差可能收缩，客户和进入者受益；如果开放扩大生态、需求或互补业务，研发者也可能通过这些渠道回收投入。**预期可占有收益的变化会影响下一轮研发、托管进入和合作选择**，但其方向不能从“开放”标签单独推出。

## 5. 技术降价、需求增长与收益分配

总资源需求可以分为：

$$K=a\,q\,N,$$

其中 $a$ 为每 Token 资源耗费，$q$ 为每任务词元量，$N$ 为任务数。效率提高降低 $a$，新应用和思考预算可能提高 $qN$；只有后者足够增长，总资源消耗才增加。

需求增长包含两个不同反应：更多任务达到采用门槛，以及已采用任务使用更长上下文、更多调用或更高思考预算。有效任务成本下降可能推动两者，但质量、集成费用和责任约束会限制采用；新增任务又会通过批处理、缓存复用或拥堵反馈到交付成本。

降本能转成多少降价，取决于容量宽松且可替代、容量紧张或服务差异化等市场情景，以及合同能否调价，见[微观生产函数篇](大模型推理的微观生产函数与架构经济学.md)。固定采购价、联动合同与按量采购又会把收益和风险分给不同主体。因此，Token 单价下降与卡租上涨可以同时出现，却不足以识别技术变化的因果效应；供给冲击、质量和合同变化仍需控制。

收益最终在消费者、模型研发者、托管商和上游间怎样分配，取决于需求、供给弹性、市场力量及合同权利。可检验的命题是：**同样的工程降本，在不同替代条件与调价安排下，会产生不同的净价、利润和投资反应**，而不是“大部分必然流向上游”。

## 6. 信用与资产重估风险

技术替代可能同时压低未来租赁收入和设备残值，加剧高杠杆企业压力。这是需要压力测试的不利相关性，相关系数并非必然为 1，也不是房地产或航运不具有的特殊现象。

可执行的测试至少包括：租金和利用率下降、客户延期/取消、接电推迟、利率上升、维修和迁移支出、二手回收价下降。分别查看现金流、债务契约与抵押物，而不是仅用会计亏损预测违约。

公司毛利、营业利润、EBITDA、净利润和现金流并非同一指标。利息通常位于营业利润以下；自由现金流为负可能来自扩张投资，并不单独证明无法偿债。国资或政策支持可以改变预算约束，也不能据此宣称相关主体永不违约。

公司级判断需要报表、附注和融资文件共同支持；待核财务数据集中登记在[数据附录第 6 节](算力与_token_经济：数据附录（2026-11-15—16_快照）.md)，不作为这里的机制证据。压力测试得到的现金约束，再进入投资、等待、迁移或退出的选择，而不是把亏损指标直接变成违约结论。

## 7. 制度与商业策略的可行方向

标准规格、可靠计量、价格评估、履约保障和业务责任都可能产生商业价值。基准机构也承担数据成本、治理、竞争和被替代风险，不是天然拥有永久收租权。企业集成与自动化同样可以创造持续价值，不能因为它节约流通费用就判定该业务必败。

价格发现与撮合可以相互促进，也可以分别服务于估值、采购和风险管理。衡量调度效果应同时记录实际卡时、可调容量、任务质量和履约结果：一次调度可能包含大集群和长时段，目录卡数也不等于实时可调用容量。新增平台、指数或衍生品须证明相对于现有询价、直接长约与本地调度的收益，不能由某个交易次数直接推出制度演进顺序。

短缺期买方希望防范涨价，卖方也可能希望满足融资收入要求，双方都有潜在套保动机。金融化不必等危机之后；是否采用取决于基差、成本、监管、信用和实际需求。

## 8. 可检验命题与分析小结

| 待检验问题 | 合格证据 | 不足以证明它的材料 |
|---|---|---|
| 规模是否降低成本 | 同权重、同质量/SLO 的完整单位成本与规模样本 | 不同服务包的公开价格 |
| 技术是否驱动租金下降 | 机型、期限、地域一致的价格与替代供给数据 | 一个型号的历史高点与另一个型号低点 |
| 信用风险是否兑现 | 报表、契约、违约/重组公告及现金流 | 毛利与净利不同、FCF 一次转负 |
| 基准能否支持套保 | 实际采购价与结算价的基差、覆盖率和流动性 | 交易所计划公告或假设结算价 |
| 开源是否压低利润 | 可比质量的发布事件与净价、成本、需求 | 排行榜接近或模型数量增加 |

具体产品公告、监管节点和财务材料按来源日期保留在[数据附录](算力与_token_经济：数据附录（2026-11-15—16_快照）.md)，历史公告不代替当前状态确认。

这套分析给出三条正面命题：可复制供给增加且切换可行时，买方替代选择改善；稀缺要素与可信履约权利可以支持收益，但收益取决于合同与竞争；不利现金流和抵押物变化若同时出现，会收紧融资与再投资空间。它们分别需要成本与净价、合同与替代选择、现金流与债务数据检验，并与[约束与风险面板](token_工厂的约束与风险面板：供给、需求与投资反馈.md)中的项目状态相衔接。
