# 毛选带读方案完整设计

---

## 第一部分：方案总体设计

### 一、首先明确：带读给谁？

不同人群的方案完全不同，我设计**三个版本**，你根据实际情况选用或混搭：

```
版本A：职场/创业人群（25-40岁）
  → 核心诉求：学思维方法、战略分析、管理方法论
  → 语言：商业语言翻译，大量现代案例对照
  → 调性：实用主义导向，"能用"是第一标准

版本B：大学生/考研/理论学习者
  → 核心诉求：理解马克思主义哲学、建立理论素养
  → 语言：学术语言 + 通俗解释
  → 调性：理论深度 + 思辨训练

版本C：通识读者/读书会爱好者
  → 核心诉求：拓宽视野、提升思维能力、文化素养
  → 语言：尽量通俗，少用术语
  → 调性：轻松但有深度，重在启发
```

> **以下方案以版本A（职场/创业人群）为主体设计，同时在关键节点标注B/C版本的调整方式。** 因为这个版本最具普适性，且你之前的提问方向也偏向"联系实际运用"。

---

### 二、整体架构

```
总周期：12周（3个月）
频率：每周1次
每次时长：2小时（线下）/ 1.5小时（线上）
总共：12次正式带读 + 1次开营 + 1次结营 = 14次

结构分为四个阶段：
  Phase 1：入门与心法（第1-3周）——解决"怎么读"的问题
  Phase 2：方法论工具箱（第4-7周）——掌握核心思维模型
  Phase 3：战略思维进阶（第8-10周）——系统性分析能力
  Phase 4：哲学内核与融会贯通（第11-12周）——底层操作系统
```

---

### 三、整体节奏设计

```
周一：发布本周阅读篇目 + 背景材料 + 阅读指引（预习）
周二-周五：学员自主阅读（每天约30-40分钟）
周六/周日：集中带读（2小时）
周日-周一：完成本周"应用作业"
```

---

## 第二部分：开营设计

### 开营课（第0周）：《为什么今天要读毛选》

**时长：** 1.5小时

**目标：**
1. 破除心理障碍（"政治课本""过时了""太深奥"）
2. 建立正确的阅读预期
3. 介绍阅读方法
4. 形成学习共同体

**流程设计：**

```
【开场破冰】15分钟
  "你对毛选的第一印象是什么？用三个词形容。"
  → 收集关键词，投屏/白板展示
  → 大概率会出现：政治、过时、深奥、革命、红色、教条……
  → 带读者回应："这些印象，有些对，有些是误解。
     今天结束时我们重新选三个词。"

【认知刷新】25分钟
  带读者做一个简短的"颠覆认知"展示：

  第一层颠覆：毛选不是政治读物，是方法论读物
    → 展示毛选核心思想与现代商业理论的对照表
    → （用我之前给你的那张对照表）
    → 让学员惊讶："原来这些我熟悉的概念，毛泽东早就说过了？"

  第二层颠覆：毛泽东面对的问题和你面对的问题，结构上是相似的
    → 案例：
      毛泽东1927年——资源极少、团队不专业、强敌环伺、方向不明
      创业者2024年——资源有限、团队待建、巨头压制、赛道不清
    → "他用什么方法在那种极端条件下赢了？这就是我们要学的。"

  第三层颠覆：毛选的语言其实非常通俗
    → 现场朗读几段（选《反对党八股》《反对自由主义》中的金句）
    → 让学员感受到：这不是枯燥的教科书

【阅读方法介绍】20分钟
  介绍"三层阅读法"：
    第一层：还原语境（他在说什么）
    第二层：提取结构（他在怎么想）
    第三层：迁移应用（我能怎么用）

  介绍"每篇四问"：
    ① 什么时间写的？→ 什么历史阶段
    ② 写给谁的？→ 写作对象
    ③ 要解决什么问题？→ 核心问题
    ④ 在反对什么错误？→ 靶子是谁

  介绍笔记模板（发给学员）

【分组 + 规则】15分钟
  → 4-6人一组
  → 每周每组轮流出一个"带读助教"负责整理本组讨论
  → 建立微信群/飞书群
  → 每周有"应用作业"——不长，但必须写

【结尾预告】10分钟
  → 预告第一周的阅读篇目
  → 发放背景材料
  → "下周我们从最容易的几篇开始，建立信心。"
```

## 第三部分：每周带读详细设计

---

### Phase 1：入门与心法（第1-3周）

#### 第1周：感受毛泽东的风格

**本周篇目：**
- 《为人民服务》
- 《纪念白求恩》
- 《反对自由主义》
- 《愚公移山》

（四篇都短，总阅读量不到5000字，无压力）

**预习材料：**
- 四篇原文
- 每篇100字的背景说明（带读者提前写好）

**带读流程（2小时）：**

```
【环节一：快速通读分享】20分钟
  → 每人选一篇中印象最深的一段话，读出来，说为什么
  → 目的：让每个人都开口，打破沉默

【环节二：带读者逐篇点评】30分钟

  《反对自由主义》重点带读：
    → 逐条念11种表现
    → 每条念完后问："在座有谁中过这一条？"（举手/弹幕）
    → 引发笑声和共鸣
    → 点明：这篇写于1937年，但描述的是人性的弱点，跨越时代

  《为人民服务》+《纪念白求恩》快速带读：
    → 核心提取：什么是"纯粹"？什么是"彻底"？
    → 联系现代：在一个浮躁的时代，"纯粹"的稀缺价值

  《愚公移山》快速带读：
    → 表面是鸡汤，其实是组织动员逻辑
    → 核心问题：如何让人相信一个看似不可能的目标？

【环节三：小组讨论】25分钟
  讨论题：
  "《反对自由主义》的11条中，选你自己最容易犯的3条，
   说说在什么场景下犯的，以及为什么明知不对还犯。"
  → 每组讨论后，派代表分享1-2条

【环节四：带读者总结】15分钟
  → 第一周的核心收获：
    ① 毛选的语言比想象中通俗
    ② 毛泽东关注的不是宏大叙事，而是具体的人、具体的行为
    ③ 他描述的问题跨越时代——因为人性没变

【环节五：布置本周作业】10分钟
  作业：
  "这一周在工作/生活中，用《反对自由主义》的11条做一次自查。
   记录下你观察到（自己或他人身上的）至少2个'自由主义'的具体场景，
   写200字。"
```

#### 第2周：学习如何调查和思考

**本周篇目：**
- 《反对本本主义》
- 《反对党八股》

**预习材料：**
- 两篇原文
- 一页纸的背景说明（1930年红军内部教条主义问题 / 1942年延安整风）

**带读流程（2小时）：**

```
【环节一：作业分享】15分钟
  → 2-3人分享上周的"自由主义自查"
  → 带读者点评，建立"学以致用"的习惯

【环节二：《反对本本主义》深度带读】40分钟

  第一层：还原语境
    → 1930年，红军在赣南闽西打游击
    → 很多干部从苏联/上海来，带着"本本"（书本理论）指挥
    → 不了解当地实际情况，瞎指挥
    → 毛泽东的愤怒："你对那个问题没有调查，就停止你的发言权！"

  第二层：提取结构
    → 画出文章的论证逻辑链（带学员一起画）：
    没有调查就没有发言权
        ↓
    调查就是解决问题
        ↓
    一切从实际出发，反对本本主义
        ↓
    怎么调查？（调查会的具体方法）
        ↓
    中国的问题需要中国人自己了解中国情况来解决

  第三层：迁移应用
    → "本本主义"的现代形态：
      照搬行业报告 → 不自己做用户调研
      迷信"最佳实践" → 不分析自己的具体情况
      听了一个理论就直接套用 → 不验证是否适合自己
      
    → 互动提问：
      "你在工作中见过哪些'本本主义'的行为？"

【环节三：《反对党八股》互动带读】30分钟

  → 方式：不逐段讲解，改为"对号入座游戏"
  → 带读者把八大罪状写在卡片上
  → 每读一条，让学员举例：
    "你见过最典型的这类表达/报告/会议是什么？"
  → 现场改写练习：
    拿一段典型的"党八股式"表达（可以用公司常见的空话模板）
    让学员用毛泽东教的方式改写：
    "要具体、要有针对性、要说人话"

【环节四：小组讨论】20分钟
  讨论题：
  "如果你这周要做一个'调查'——关于你工作中的某个问题——
   你打算调查谁？问什么问题？怎么确保不是'本本主义'？"
  → 每人列一个简单的调查计划

【环节五：总结 + 作业】15分钟
  本周核心：
    ① 没有调查就没有发言权
    ② 理论必须联系实际
    ③ 表达必须具体、有针对性

  作业（二选一）：
  A："这周真的做一次小型调查——找3个人聊一个你一直想弄清楚
      但没有调查过的问题。写300字调查笔记。"
  B："找一份你最近写的报告/方案/邮件，用'反对党八股'的标准
      审查一遍，改写其中最'八股'的一段。"
```

#### 第3周：学习如何学习

**本周篇目：**
- 《改造我们的学习》
- 《关心群众生活，注意工作方法》

**带读流程（2小时）：**

```
【环节一：作业分享 + 回顾】15分钟
  → 分享调查笔记或改写练习
  → 带读者用前两周学到的框架点评

【环节二：《改造我们的学习》带读】40分钟

  核心对比——两种学习态度：

  画一个对比表（现场板书或PPT）：
  ┌────────────────────┬────────────────────┐
  │    主观主义         │    实事求是          │
  ├────────────────────┼────────────────────┤
  │ 从书本出发         │ 从实际出发          │
  │ 理论脱离实际       │ 理论联系实际        │
  │ 学了一堆概念不会用  │ 带着问题去学习      │
  │ 言必称希腊         │ 具体问题具体分析    │
  │ 只会背诵不会应用   │ 学一个用一个        │
  │ 现代版：收藏了      │ 现代版：每学一个概念│
  │ 1000篇文章从不看   │ 就尝试应用一次      │
  └────────────────────┴────────────────────┘

  互动讨论：
    "你的学习方式更接近左边还是右边？举具体例子。"

  带读者总结：
    "毛选带读本身就要避免变成'主观主义'的学习——
     如果你每周来听我讲两小时，回去什么都不做，
     那就是毛泽东批评的那种学习方式。"

【环节三：《关心群众生活》快速带读】20分钟
  核心命题：想让人跟你走？先解决他们的具体问题。
  
  现代应用讨论：
  → 管理者版本：你知道你团队成员最大的痛点是什么吗？
  → 创业者版本：你知道用户最具体的困难是什么吗？
  → 不是抽象的"痛点"，而是柴米油盐级别的具体问题

【环节四：Phase 1 回顾与总结】30分钟

  带读者做一个三周回顾：
  "这三周我们学了什么？"

  引导学员总结出Phase 1的核心方法论：
  ┌─────────────────────────────────────────────┐
  │  ① 反对自由主义 → 对自己要有原则性           │
  │  ② 没有调查就没有发言权 → 一切从实际出发      │
  │  ③ 反对党八股 → 表达要具体、有针对性          │
  │  ④ 改造学习 → 带着问题学，学了就用            │
  │  ⑤ 关心群众生活 → 解决具体问题而非喊口号      │
  │                                               │
  │  一句话总结：实事求是，知行合一。               │
  └─────────────────────────────────────────────┘

  预告Phase 2：
  "从下周开始，我们要进入方法论的核心——
   学习毛泽东如何分析问题、如何做战略判断。
   难度会上升，但也会更有意思。"

【作业】
  Phase 1 总结作业：
  "回顾这三周，写一段300-500字的反思：
   你原来对毛选的认知是什么？现在有什么变化？
   这三周学到的东西中，哪一个已经在你生活中产生了影响？"
```

### Phase 2：方法论工具箱（第4-7周）

#### 第4周：利益分析法

**本周篇目：**
- 《中国社会各阶级的分析》

**预习材料：**
- 原文
- **一页纸"1925年中国社会结构简图"**（带读者提前制作，画清楚各阶级的经济关系）
- 马克思阶级分析法的基本概念（500字速览）

**带读流程：**

```
【环节一】15分钟 — 背景速览
  → 用10分钟讲清楚1925年的中国：
    帝国主义压迫 + 封建地主统治 + 民族资产阶级夹缝求生 + 农民赤贫
  → 提出核心问题：
    "如果你是1925年的毛泽东，手上资源极少，
     你怎么决定把有限的精力投向谁？"

【环节二】35分钟 — 逐层带读
  → 跟着毛泽东的分析链条走：
    经济地位 → 政治态度 → 对革命的立场
  → 每分析一个阶级，同步画"利益相关方地图"
  → 重点点明马克思主义的底层逻辑：
    "物质利益决定政治立场——这不是阴谋论，而是结构性分析"

【环节三】30分钟 — 现代迁移练习（核心环节）
  
  现场练习：
  "假设你要在公司推动一个重大变革（比如引入新系统/调整组织架构），
   请用毛泽东的方法画一张'利益相关方地图'：
   ① 列出所有相关方
   ② 分析每个人的'经济地位'（利益会增还是减？）
   ③ 推导他们的'政治态度'（会支持还是反对？）
   ④ 分类：核心支持者 / 可争取的中间力量 / 反对者
   ⑤ 制定对策"

  → 小组讨论，每组用一个真实案例做分析
  → 各组分享

【环节四】15分钟 — 带读者点评和理论提升
  → 把学员的练习跟毛泽东的分析做对照
  → 提炼方法论：
    "任何时候做决策，先画利益地图——这是毛泽东教给我们的第一个工具"

【环节五】10分钟 — 作业
  "选一个你当前面临的真实决策场景，做一个完整的利益相关方分析。
   用表格呈现，下周分享。"
```

#### 第5周：调查研究法

**本周篇目：**
- 《湖南农民运动考察报告》

**预习材料：**
- 原文（这篇较长，提前强调要通读）
- 大革命时期的背景说明
- 重点标注：毛泽东的调查方法和论证方式

**带读流程：**

```
【环节一】15分钟 — 背景 + "好得很vs糟得很"的矛盾设置
  → 场景还原：
    "你是一个中层干部，总部有人说基层的行动'太过激了'，
     也有人说'非常好'——你怎么判断？"
  → 引出毛泽东的选择：不参与争论，亲自去调查

【环节二】35分钟 — 带读
  重点不是逐段念原文，而是拆解三个维度：

  维度一：调查方法
    → 32天，5个县，找不同立场的人谈
    → 跟今天的用户调研方法做对比
    → 提炼"毛泽东调查法"的要点：
      a. 亲临一线（不要二手信息）
      b. 多元样本（不同利益方都要听）
      c. 具体事实（不要抽象感受）
      d. 结构化整理（14件大事的分类归纳）

  维度二：从事实到判断
    → 他怎么用14件大事回应"糟得很"论？
    → 本质上是用"事实的完整性"击败"观点的片面性"

  维度三："矫枉过正"的辩证法
    → 这是后面《矛盾论》的预演
    → 在变革中，"过分"可能是必要的——但有前提和边界

【环节三】30分钟 — 练习
  "模拟调查设计"：
  → 每组选一个真实问题（团队效率低、用户留存差、项目推进慢...）
  → 用"毛泽东调查法"设计一个调查方案：
    a. 调查谁？（列出不同立场的受访者）
    b. 问什么？（设计5个关键问题）
    c. 怎么判断信息可靠性？
    d. 怎么从调查结果得出结论？

【环节四】20分钟 — 分享 + 点评

【作业】
  "这周真的去做一次调查（哪怕只跟3个人聊），
   写一份500字的'考察报告'，模仿毛泽东的结构：
```

#### 第6周：如何在困境中看到希望

**本周篇目：**

**带读核心：**

```

【现代迁移讨论】

```

### Phase 3：战略思维进阶（第8-10周）

#### 第8周：战略分析的完整展示

**本周篇目：**
- 《论持久战》（选读核心章节）

**特别说明：** 全文约5万字，不可能一周读完。选读策略：

```
必读章节：
  → "问题的提起"（全文纲领）
  → "亡国论和速胜论的批驳"（辩证分析的范例）
  → "持久战的三个阶段"（战略规划的范例）

选读章节：
  → "能动性在战争中"
  → "战争和政治"

跳过章节（首轮可不读）：
  → 具体军事战术的部分
```

**带读核心：**

```
【核心环节：还原分析过程】40分钟

  不讲结论（"持久战三个阶段"大家都知道），
  重点拆解"他是怎么得出这个结论的"：

  Step 1：明确问题
    → 不是"我们会不会赢"而是"这场战争的性质和规律是什么"

  Step 2：全面对比分析
    → 中日双方的四对矛盾：
      军力：日强中弱
      经济：日小中大（资源总量）
      人心：日失道中得道
      国际：日寡助中多助
    → 每一对都做辩证分析（强中有弱，弱中有强）

  Step 3：动态推演
    → 随着时间推移，每一对矛盾如何变化？
    → 日本的优势（军力强）会因为战线拉长、资源消耗而递减
    → 中国的优势（地大人多、人心向背）会随着持久战而递增

  Step 4：得出结论
    → 短期敌强我弱 → 不可能速胜
    → 长期我方优势积累 → 不可能亡国
    → 因此：持久战，分三个阶段

  带读者板书出完整的分析框架图

【现代迁移练习】30分钟

  "用《论持久战》的分析框架，分析一个你面临的'持久战'：
   ① 你和你的竞争对手/困难各有什么优劣势？
   ② 这些优劣势随着时间会如何变化？
   ③ 时间站在谁那边？
   ④ 你的战略应该分几个阶段？每个阶段的重点是什么？"
```

#### 第9周：弱者的策略

**本周篇目：**
- 《抗日游击战争的战略问题》
- 《中国革命战争的战略问题》（选读第五章"战略防御"）

**带读核心：**

```
提炼"弱者博弈"的核心原则：
  ① 不在对手强的地方跟他拼（避实击虚）
  ② 集中优势兵力打歼灭战（在局部形成压倒性优势）
  ③ 打得赢就打，打不赢就走（保存有生力量）
  ④ 在运动中寻找战机（不被动等待）
  ⑤ 把对手的战略优势变成战术劣势（如利用对手战线长的弱点）

现代对应讨论：
  → 初创公司vs巨头：不做全面竞争，找一个巨头顾不到的缝隙市场
  → 个人vs强手：不全面比拼，在一个细分领域做到极致
  → 新人vs老手：不拼经验和资源，拼学习速度和适应力
```

**本周篇目：**

### Phase 4：哲学内核与融会贯通（第11-12周）

#### 第11周：《实践论》

**带读核心：**

```
【关键策略：不要抽象讲哲学，用前10周的例子来讲】

  "大家回忆一下——
   第5周我们学的'调查研究法'，本质上就是《实践论》说的
   '从实践中获得感性认识'；
   第4周的'阶级分析法'，就是《实践论》说的
   '从感性认识上升到理性认识'；
   第2周的作业——真的去做调查，就是'再回到实践中验证'。

   你们其实已经在用《实践论》了，只是不知道它的哲学名字。"

  这样讲，学员就不会觉得哲学是抽象的空中楼阁，
  而是"原来这就是我们前10周一直在做的事的理论总结"。

【核心概念讲解】用例子驱动
  感性认识 → "你第一次见到某个用户的时候的直觉印象"
  理性认识 → "你访谈了50个用户后总结出的规律"
  实践检验 → "你根据这个规律做了产品改进，看数据有没有变好"
  再认识 → "数据反馈不如预期，你修正了之前的判断"
```

#### 第12周：《矛盾论》+ 总复盘

**带读核心：**

```
【上半场：矛盾论核心概念】60分钟

  同样用前面的例子来讲——

  主要矛盾 vs 次要矛盾：
    → 回顾《论持久战》——中日战争中的主要矛盾是什么？
    → 回顾第6周——你在困境中，最关键的一个矛盾是什么？

  矛盾的普遍性 vs 特殊性：
    → 回顾《反对本本主义》——普遍理论不能代替具体分析
    → 马克思主义是普遍性，中国国情是特殊性
    → 你学的管理方法论是普遍性，你团队的具体情况是特殊性

  矛盾的转化：
    → 回顾《论持久战》——敌强我弱会逐渐转化为敌弱我强
    → 回顾《星星之火》——劣势可以转化为优势

  → 最终提炼：矛盾论提供了一个通用的分析操作系统
     面对任何复杂问题：
     ① 找出所有矛盾
     ② 判断主要矛盾
     ③ 判断矛盾的主要方面
     ④ 分析矛盾转化的条件
     ⑤ 集中力量于关键点

【下半场：12周总复盘】60分钟

  带学员一起梳理完整的方法论体系：

  ┌─────────── 毛泽东方法论体系 ───────────┐
  │                                          │
  │  认识论基础：                             │
  │    实践论 → 从实际出发，在实践中认识      │
  │    矛盾论 → 抓主要矛盾，具体问题具体分析  │
  │                                          │
  │  调查方法：                               │
  │    反对本本主义 → 没有调查就没有发言权     │
  │    农民运动考察 → 调查的具体方法           │
  │                                          │
  │  分析工具：                               │
  │    阶级分析 → 利益相关方分析              │
  │    矛盾分析 → 找主要矛盾和关键方面       │
  │    形势判断 → 辩证看优劣，动态看趋势      │
  │                                          │
  │  战略方法：                               │
  │    持久战 → 长期主义 + 阶段划分           │
  │    统一战线 → 团结一切可以团结的力量       │

  │    群众路线 → 从一线来，到一线去          │

  │                                          │
  │  自我修养：                               │
  │    反对自由主义 → 对自己有原则性           │

  │    反对党八股 → 表达要具体有效             │
  │                                          │
  └──────────────────────────────────────────┘

  最后互动：
  "12周前你用三个词形容毛选，现在再选三个词。"
```

## 第六部分：带读者自身准备清单

### 你在开始带读之前需要做的

```
□ 自己至少通读毛选一到三卷一遍
□ 对每篇选读文章做过完整的笔记
□ 准备好每篇的背景材料（可以参考注释 + 党史资料）
□ 每篇准备3个以上现代应用案例
□ 每篇准备2-3个讨论题
□ 做一次完整的试讲（至少试讲前3周的内容）
□ 建立社群、确定时间、准备工具
□ 准备好"学员手册"的前3周内容（后面可以边做边出）
```

### 带读过程中的核心原则

```
① 永远"翻译"——不能只读原文不做现代转化
② 永远"互动"——不能变成你一个人的独角戏
③ 永远"落地"——每周必须有应用作业，不能只读不做
④ 永远"诚实"——遇到你也不确定的问题，坦诚说"我也还在学习"
⑤ 永远"回扣"——后面的内容要不断回扣前面的，形成体系感
⑥ 控制节奏——宁可少读几篇但读透，也不要赶进度
```
