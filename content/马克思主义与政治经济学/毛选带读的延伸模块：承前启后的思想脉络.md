# 毛选带读的延伸模块：承前启后的思想脉络

---

## 核心设计思路

在原有12周方案中，不单独加"当代政治"专题课（容易变成时政讨论课，偏离方法论学习的主线），而是采用**"双线并行"**的方式——

```
主线：毛选原文（不变）
副线：在每周带读中嵌入一个"承前启后"的连接点

效果：学员不仅理解毛泽东当时在说什么，
      还能看到这些思想如何演化到今天，
      形成一条从1925年到2024年的完整思维脉络。
```

**操作方式：每周带读中增加一个15-20分钟的"延伸环节"——"这个思想今天怎么样了？"**

---

## 第一条脉络：主要矛盾的三次转化

### 这是最核心的一条线——贯穿百年

**毛选中的起点：**
《中国社会各阶级的分析》《矛盾论》

**完整脉络：**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  1925-1949 毛泽东时代                                    │
│  主要矛盾：帝国主义/封建主义 vs 中国人民                  │
│  → 任务：民族独立、人民解放                               │
│  → 路线：新民主主义革命                                   │
│                                                         │
│  1956 八大                                               │
│  主要矛盾重新判断：                                      │
│  人民对于经济文化迅速发展的需要                            │
│      vs 当前经济文化不能满足人民需要的状况                  │
│  → 任务：发展生产力                                      │
│  （后来这个判断被阶级斗争路线中断）                        │
│                                                         │
│  1981 十一届六中全会                                     │
│  重新定义主要矛盾：                                      │
│  人民日益增长的物质文化需要                                │
│      vs 落后的社会生产                                    │
│  → 任务：以经济建设为中心，改革开放                       │
│  → 这是邓小平路线的理论基础                               │
│                                                         │
│  2017 十九大                                             │
│  再次重新定义主要矛盾：                                   │
│  人民日益增长的美好生活需要                                │
│      vs 不平衡不充分的发展                                │
│  → 任务：高质量发展、共同富裕、解决结构性问题              │
│  → 这是当前阶段的理论基础                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**带读中怎么用：**

在**第4周（阶级分析）**或**第12周（矛盾论）**时展示这条脉络，然后引导讨论：

> "注意看——每一次主要矛盾的重新判断，都导致了整个国家战略的根本转向。这不是文字游戏，而是：**你对主要矛盾的判断，决定了你所有资源的配置方向。**"

> "从'落后的社会生产'到'不平衡不充分的发展'——这两个表述有什么区别？"

```
"落后的社会生产"：
  → 核心问题是"总量不够"
  → 解法：拼命做大蛋糕（GDP增长优先）
  → 对应策略：改革开放、招商引资、出口导向

"不平衡不充分的发展"：
  → 核心问题不再是"总量不够"，而是"结构不对"
  → 城乡不平衡、区域不平衡、收入不平衡
  → 有些领域发展过剩，有些领域发展不足
  → 解法：优化结构、补短板、共同富裕
  → 对应策略：乡村振兴、区域协调、科技自主、双循环
```

**引导学员思考：**

> "同样的方法论——抓主要矛盾——在不同时代得出不同的具体结论。这正是毛泽东在《矛盾论》中说的'矛盾的特殊性'和'不同阶段主要矛盾会转化'。"

> **"你自己的人生/事业，在不同阶段的主要矛盾是不是也在变？你有没有及时更新你的判断？"**

## 第二条脉络：实事求是——从延安到改革开放到今天

### 同一个方法论原则的三次重大应用

**毛选中的起点：**
《反对本本主义》《改造我们的学习》《实践论》

**完整脉络：**

```
第一次：毛泽东——反对教条主义
  背景：党内有人照搬苏联经验指挥中国革命
  毛泽东的回应："中国革命斗争的胜利要靠中国同志了解中国情况"
  核心命题：马克思主义必须中国化，不能当教条

          ↓ 承前启后 ↓

第二次：邓小平——"实践是检验真理的唯一标准"
  背景：文革结束后，"两个凡是"（凡是毛主席做出的决策都要维护，
        凡是毛主席的指示都要遵照执行）束缚思想
  1978年《实践是检验真理的唯一标准》一文引发大讨论
  邓小平的回应：重新确立"实事求是"的思想路线
  → 直接导向了改革开放
  → 邓小平的名言："不管黑猫白猫，抓住老鼠就是好猫"
  → 本质上就是《实践论》的应用：
    理论对不对，要在实践中检验

          ↓ 承前启后 ↓

第三次：当代——"大兴调查研究"
  2023年，中办印发《关于在全党大兴调查研究的工作方案》
  要求各级领导干部深入基层调查研究
  → 直接呼应毛泽东"没有调查就没有发言权"
  → 背景：经济下行压力、基层治理复杂化、
    上层决策与基层实际之间出现信息差
  → 本质问题没变：决策者容易脱离实际
```

**带读中怎么用：**

在**第2周（反对本本主义）**或**第5周（湖南农民运动考察）**时展开：

> "毛泽东在1930年说'没有调查就没有发言权'——93年过去了，2023年中央还要发文件强调这件事。这说明什么？说明**脱离实际是人的本能倾向，任何时代、任何组织都会反复犯这个错误。**这不是某个时代的问题，是人性的问题。"

**展示具体的呼应关系：**

```
┌─────────────────────┬──────────────────────────────┐
│ 毛泽东（1930年代）    │ 当代（2023年）                │
├─────────────────────┼──────────────────────────────┤
│ 到群众中去调查       │ 领导干部要"四不两直"          │
│                     │ （不发通知、不打招呼、          │
│                     │  不听汇报、不用陪同接待，       │
│                     │  直奔基层、直插现场）           │
├─────────────────────┼──────────────────────────────┤
│ 反对"本本主义"      │ 反对"指尖上的形式主义"         │
│ （只信书本不看实际）  │ （只看报表数据不看真实情况）    │
├─────────────────────┼──────────────────────────────┤
│ 开调查会要找各阶层   │ 要求调研要听"真话""实话"      │
│ 的人分别谈          │ 不能只听层层汇报的"好话"       │
├─────────────────────┼──────────────────────────────┤
│ 调查是为了解决问题   │ 调研要"奔着问题去"            │
│                     │ 不能为调研而调研               │
└─────────────────────┴──────────────────────────────┘
```

> **"你看，问题的本质没变，解决的方法也没变——只是换了表达方式。这就是为什么毛选不过时。"**

## 第三条脉络：群众路线——从革命到治理

**毛选中的起点：**
《关于领导方法的若干问题》《关心群众生活，注意工作方法》

**完整脉络：**

```
毛泽东时代：群众路线是革命方法
  → 从群众中来，到群众中去
  → 核心场景：发动农民、组织根据地、打游击
  → 群众是"革命的动力"

          ↓

改革开放时代：群众路线是改革方法
  → "摸着石头过河"本身就是群众路线——
    不是中央设计好方案推下去，
    而是让基层先试，试出经验后再总结推广
  → 典型案例：
    小岗村的家庭联产承包 → 农民自发创造 → 中央总结推广
    深圳特区的制度创新 → 地方先行先试 → 全国复制
  → "从群众中来，到群众中去"的改革版本：
    从基层实践中来 → 总结成政策 → 到全国推广 → 收集反馈 → 再修正

          ↓

当代：群众路线面临新挑战
  2013-2014年"党的群众路线教育实践活动"
  → 针对的问题：形式主义、官僚主义、享乐主义、奢靡之风
  → 本质上是：一些干部脱离了群众
  
  新的环境：
  → 互联网时代，"群众"的表达方式变了（网络舆论、社交媒体）
  → "从群众中来"怎么在数字时代实现？
  → 基层治理的复杂性增加（流动人口、新业态、社会分化）
  → "到群众中去"怎么在新条件下落地？

  新的实践：
  → "接诉即办"（北京）——12345热线直接收集群众诉求
  → "网格化管理"——把"到群众中去"制度化
  → "新时代枫桥经验"——基层矛盾基层解决
```

**带读中怎么用：**

在**第7周（领导方法）**时展开：

```
讨论题设计：

"毛泽东的'从群众中来，到群众中去'——
 在你的工作场景中，'群众'是谁？
 你有没有制度化的渠道在收集他们的声音？
 收集到之后，你有没有'集中起来'形成系统方案？
 形成方案后，有没有'到群众中去'验证和执行？

 参考北京'接诉即办'的案例——
 它本质上就是把群众路线做成了一个数字化系统：
 市民打12345（从群众中来）
 → 派单到相关部门（集中处理）
 → 解决后回访市民（到群众中去验证）
 → 数据分析高频问题，推动政策改进（再从群众中来）

 你的团队/公司有没有类似的闭环？"
```

## 第四条脉络：自我革命——从整风到全面从严治党

**毛选中的起点：**
《整顿党的作风》《反对自由主义》《改造我们的学习》

**完整脉络：**

```
毛泽东：延安整风（1942-1945）
  → 问题：党内存在主观主义、宗派主义、党八股
  → 方法：学习 → 对照检查 → 批评与自我批评 → 整改
  → 原则："惩前毖后、治病救人"
  → 效果：统一了全党思想，为夺取全国胜利奠定基础
  → 本质：组织的自我纠错机制

          ↓

邓小平时代：制度化建设
  → 认识到：不能只靠运动式整风
  → 开始强调制度建设、党内法规
  → "制度问题更带有根本性、全局性、稳定性和长期性"

          ↓

当代："自我革命"的系统化
  核心命题："党的自我革命"
  → "全面从严治党"
  → 八项规定（改作风）
  → 反腐败（"打虎拍蝇猎狐"）
  → 巡视制度（制度化的"调查研究"）
  → 主题教育（学习教育常态化）

  理论表述：
  "勇于自我革命是中国共产党区别于其他政党的显著标志"
  "跳出治乱兴衰的历史周期率的第二个答案就是自我革命"
  （第一个答案是毛泽东在延安与黄炎培对话时提出的"民主监督"）
```

**带读中怎么用：**

在**第3周（改造我们的学习/整顿作风）**时展开：

> "毛泽东搞延安整风，是组织的一次'自我纠错'。今天的话叫'自我革命'。问题是一样的：**任何组织运行久了，都会产生官僚化、形式主义、脱离一线的问题。**"

```
展示一个有趣的对比：

延安整风反对的"三股歪风"     →    今天反对的"四风"
──────────────────────────────────────────────
主观主义（脱离实际）          →    形式主义（重形式轻实效）
宗派主义（搞小圈子）          →    官僚主义（脱离群众）
党八股（空洞表达）            →    享乐主义 + 奢靡之风

核心问题没变：
  组织病 = 脱离实际 + 脱离群众 + 脱离目标
```

**引导学员联系自身：**

> "你的团队/公司有没有类似的'组织病'？
>  有没有制度化的'自我纠错'机制？
>  还是等到出了大问题才'运动式整改'？"

## 第五条脉络：统一战线——从革命联盟到新时代

**毛选中的起点：**
《中国社会各阶级的分析》《论联合政府》

**完整脉络：**

```
革命时代的统一战线：
  → 团结一切可以团结的力量反对主要敌人
  → 工农联盟为基础
  → 团结民族资产阶级、小资产阶级、开明士绅等

建设时代的统一战线：
  → 团结对象变了：民主党派、知识分子、非公经济人士
  → "长期共存、互相监督、肝胆相照、荣辱与共"

当代的统一战线（新变化）：
  → 新的社会阶层出现：
    互联网企业家、自由职业者、新媒体从业者
    网络意见领袖、留学归国人员等
  → 统一战线的对象和方式都在更新
  → 国际层面："人类命运共同体"——某种意义上是统一战线思维的国际化延伸
  
  核心逻辑不变：
  → 明确主要矛盾/主要目标
  → 围绕目标，最大范围团结同盟
  → 对不同群体采取不同策略
  → 保持核心领导权
```

**带读中怎么用：**

在**第10周（统一战线）**时简要展开：

> "统一战线的'道'没变——团结最多数人、孤立最少数人。变的是'术'——团结的对象、方式和场景都不同了。"

## 第六条脉络：马克思主义中国化——从第一次到最新篇章

### 这是所有脉络的总线

**毛选中的起点：**
几乎所有文章的底层方法论

**完整脉络：**

```
第一个阶段：毛泽东——"马克思主义中国化"的开创
  → 把马克思主义的普遍原理与中国革命的具体实践相结合
  → 成果：农村包围城市、新民主主义论、人民民主专政
  → 形成"毛泽东思想"

第二个阶段：邓小平——"中国特色社会主义"
  → 把马克思主义与中国改革开放的实践结合
  → 核心突破：社会主义也可以搞市场经济
  → 这在经典马克思主义中是没有的——但邓小平用"实事求是"破题
  → "发展才是硬道理"

第三个阶段（过渡）：
  → "三个代表"（江泽民时期）
  → "科学发展观"（胡锦涛时期）
  → 各自回应了不同阶段的新问题

第四个阶段：新时代——"马克思主义中国化时代化"
  → 在"中国化"基础上加了"时代化"
  → 强调两个结合：
    a. 马克思主义基本原理与中国具体实际相结合
    b. 马克思主义基本原理与中华优秀传统文化相结合
  → "第二个结合"是新提出的——
    意味着不仅要从马克思主义出发，
    还要从中国自身的文化传统中汲取资源
```

**带读中怎么用：**

在**第12周（矛盾论 + 总复盘）**时，作为最终总结的一部分：

```
展示这条线的内在逻辑：

毛泽东的核心方法：
  普遍原理 + 具体实际 = 正确的理论和路线
  （不是照搬，也不是抛弃，而是"结合"）

这个方法本身被一代一代地"应用"了：
  毛泽东用这个方法 → 解决了革命问题
  邓小平用这个方法 → 解决了发展问题
  当代用这个方法 → 试图解决新时代的问题

而你学毛选，也应该用同样的方法：
  毛泽东的思想是"普遍原理"
  你的具体处境是"具体实际"
  结合起来 → 形成你自己的判断和行动方案
```

> **"这就是毛选最根本的教诲——不是让你记住他的结论，而是让你学会他的方法，然后自己去分析、自己去判断、自己去实践。这个方法，共产党自己也在一直用。"**

## 第七条脉络：具体政策中的思想回响

这一部分可以作为**每周带读的小彩蛋**——用1-2分钟展示一个当代政策/概念与毛选的呼应：

```
┌────────────────────┬──────────────────┬──────────────────────┐
│ 毛选概念            │ 当代回响          │ 内在联系              │
├────────────────────┼──────────────────┼──────────────────────┤
│ 农村包围城市        │ 乡村振兴战略      │ 重视农村的战略传统     │
│                    │ 县域经济          │                      │
├────────────────────┼──────────────────┼──────────────────────┤
│ 自力更生为主        │ 科技自立自强      │ 核心能力不能依赖外部   │
│                    │ "卡脖子"问题攻关  │                      │
├────────────────────┼──────────────────┼──────────────────────┤
│ 矛盾的对立统一      │ "两山论"         │ 绿水青山与金山银山     │
│                    │                  │ 不是非此即彼，        │
│                    │                  │ 而是辩证统一          │
├────────────────────┼──────────────────┼──────────────────────┤
│ 持久战思维          │ "长期主义"       │ 大国竞争中的战略耐心   │
│                    │ "底线思维"       │                      │
├────────────────────┼──────────────────┼──────────────────────┤
│ 集中力量办大事      │ 新型举国体制      │ 集中优势资源攻关键领域  │
│ 集中优势兵力        │                  │                      │
├────────────────────┼──────────────────┼──────────────────────┤
│ 批评与自我批评      │ 民主生活会制度    │ 制度化的自我纠错       │
```

## 带读时的注意事项

### 1. 定位要清晰

```
我们做的是：
  ✓ 思想脉络的梳理——看一个方法论如何被传承和发展
  ✓ 方法论的对照——同样的分析工具在不同时代的应用
  ✓ 启发学员思考——这些方法你自己怎么用

我们不做的是：
  ✗ 政策解读课——那是党校的事
  ✗ 政治评论课——不做主观评价
  ✗ 时政讨论课——不跑题到具体新闻事件
```

### 2. 始终回扣方法论

每次延伸都要回到方法论层面：

```
不要说："这个政策好/不好"
而要说："这个政策背后用了什么分析方法？
        这个分析方法跟毛泽东当年用的是不是同一个？
        你自己能不能用这个方法？"
```

### 3. 保持客观呈现的态度

```
呈现事实：
  "毛泽东提出了X → 后来发展为Y → 现在的表述是Z"

引导思考：
  "你怎么理解这个演变？"
  "不变的是什么？变的是什么？为什么变？"

避免灌输结论：
  让学员自己通过对比得出认识
```

### 4. 最终落脚点永远是学员自身

```
每次延伸的最后一句话都应该是：
  "那么——这个思想/方法，对你的实际工作和生活，
   有什么启发？你打算怎么用？"
```
