# 毛选带读的延伸模块：承前启后的思想脉络

---

## 核心设计思路

本模块配合[《毛选带读方案完整设计》](毛选带读方案完整设计.md)使用。下文第2、5、7、12周等均指该教案的周次。主课仍读原文；延伸环节只做两件事：看后来文件实际怎样说，或用不同年代的材料比较同一道问题。

```
主线：毛选原文（不变）
副线：在每周带读中嵌入一个"承前启后"的连接点

学员要分得出：哪一句在文件中找得到，哪一句是带读者提出的比较。
```

**操作方式：每周带读中增加一个15-20分钟的"延伸环节"——"这个思想今天怎么样了？"**

## 第一条脉络：主要矛盾的三次转化

### 这是最核心的一条线——贯穿百年

**毛选中的起点：**
《中国社会各阶级的分析》《矛盾论》

**先对读有时间标记的材料：** 1956年中共八大、1981年十一届六中全会和2017年十九大对主要矛盾的表述，是三处不同的阅读落点。下表为带读者归纳，不是三份文件的连续引文。能看到表述变化，不等于能从一句话推出此后全部政策。

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  1925-1949 毛泽东时代                                    │
│  主要矛盾：帝国主义/封建主义 vs 中国人民                  │
│  → 任务：民族独立、人民解放                               │
│  → 路线：新民主主义革命                                   │
│                                                         │
│  1956 八大                                               │
│  主要矛盾重新判断：                                      │
│  人民对于经济文化迅速发展的需要                            │
│      vs 当前经济文化不能满足人民需要的状况                  │
│  → 任务：发展生产力                                      │
│  （后来这个判断被阶级斗争路线中断）                        │
│                                                         │
│  1981 十一届六中全会                                     │
│  重新定义主要矛盾：                                      │
│  人民日益增长的物质文化需要                                │
│      vs 落后的社会生产                                    │
│  → 任务：以经济建设为中心，改革开放                       │
│  → 这是邓小平路线的理论基础                               │
│                                                         │
│  2017 十九大                                             │
│  再次重新定义主要矛盾：                                   │
│  人民日益增长的美好生活需要                                │
│      vs 不平衡不充分的发展                                │
│  → 任务：高质量发展、共同富裕、解决结构性问题              │
│  → 这是当前阶段的理论基础                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**带读中怎么用：**

在**第4周（阶级分析）**或**第12周（矛盾论）**时展示这条脉络，然后引导讨论：

> “把几次判断中的‘需要’和跟它相对的那一端分别圈出来。两端各换了什么词？如果只盯着产量，后来那个问题还有哪些部分看不见？”

> "从'落后的社会生产'到'不平衡不充分的发展'——这两个表述有什么区别？"

```
"落后的社会生产"：
  → 核心问题是"总量不够"
  → 解法：拼命做大蛋糕（GDP增长优先）
  → 对应策略：改革开放、招商引资、出口导向

"不平衡不充分的发展"：
  → 核心问题不再是"总量不够"，而是"结构不对"
  → 城乡不平衡、区域不平衡、收入不平衡
  → 有些领域发展过剩，有些领域发展不足
  → 解法：优化结构、补短板、共同富裕
  → 对应策略：乡村振兴、区域协调、科技自主、双循环
```

**引导学员思考：**

> "同样的方法论——抓主要矛盾——在不同时代得出不同的具体结论。这正是毛泽东在《矛盾论》中说的'矛盾的特殊性'和'不同阶段主要矛盾会转化'。"

> **"你自己的人生/事业，在不同阶段的主要矛盾是不是也在变？你有没有及时更新你的判断？"**

## 第二条脉络：实事求是——从延安到改革开放到今天

### 同一个方法论原则的三次重大应用

**毛选中的起点：**
《反对本本主义》《改造我们的学习》《实践论》

**完整脉络：**

```
第一次：毛泽东——反对教条主义
  背景：党内有人照搬苏联经验指挥中国革命
  毛泽东的回应："中国革命斗争的胜利要靠中国同志了解中国情况"
  核心命题：马克思主义必须中国化，不能当教条

第二份材料：1978年文章《实践是检验真理的唯一标准》引发讨论。
  课堂问题：当时争论的是怎样判断一种主张是否站得住？
  文章、围绕文章的讨论与后来作出的政策决定，不是同一件事。


第三次：当代——"大兴调查研究"
  2023年，中办印发《关于在全党大兴调查研究的工作方案》
  要求各级领导干部深入基层调查研究
  把文件对调研的要求与《反对本本主义》对读，找相近的提问，也找实施条件的不同。
```

**带读中怎么用：**

在**第2周（反对本本主义）**或**第5周（湖南农民运动考察）**时展开：

> “两处材料都谈调查，是否针对同一种脱离实际？先说各自要解决什么，再说今天能借哪一步。”

**主持人用于讨论的转述（不是逐项引文）：**

```
┌─────────────────────┬──────────────────────────────┐
│ 毛泽东（1930年代）    │ 当代（2023年）                │
├─────────────────────┼──────────────────────────────┤
│ 到群众中去调查       │ 领导干部要"四不两直"          │
│                     │ （不发通知、不打招呼、          │
│                     │  不听汇报、不用陪同接待，       │
│                     │  直奔基层、直插现场）           │
├─────────────────────┼──────────────────────────────┤
│ 反对"本本主义"      │ 反对"指尖上的形式主义"         │
│ （只信书本不看实际）  │ （只看报表数据不看真实情况）    │
├─────────────────────┼──────────────────────────────┤
│ 开调查会要找各阶层   │ 要求调研要听"真话""实话"      │
│ 的人分别谈          │ 不能只听层层汇报的"好话"       │
├─────────────────────┼──────────────────────────────┤
│ 调查是为了解决问题   │ 调研要"奔着问题去"            │
│                     │ 不能为调研而调研               │
└─────────────────────┴──────────────────────────────┘
```

> **“流程看起来相像，怎样判断它确实让不同意见进入了决策？”**

## 第三条脉络：群众路线——从革命到治理

**毛选中的起点：**
《关于领导方法的若干问题》《关心群众生活，注意工作方法》

**完整脉络：**

```
毛泽东时代：群众路线是革命方法
  → 从群众中来，到群众中去
  → 核心场景：发动农民、组织根据地、打游击
  → 群众是"革命的动力"

          ↓

改革时期可以并读的现象：基层试验、地方经验的总结和推广。
  比较问题：一次试验成功与大范围推广之间，还要经过哪些判断？
  方法上都重视反馈，不意味着每项改革都是某一种读法的直接产物。

          ↓

当代：群众路线面临新挑战
  2013-2014年"党的群众路线教育实践活动"
  → 针对的问题：形式主义、官僚主义、享乐主义、奢靡之风
  → 本质上是：一些干部脱离了群众
  
  新的环境：
  → 互联网时代，"群众"的表达方式变了（网络舆论、社交媒体）
  → "从群众中来"怎么在数字时代实现？
  → 基层治理的复杂性增加（流动人口、新业态、社会分化）
  → "到群众中去"怎么在新条件下落地？

  北京“接诉即办”可作为课堂比较：意见怎样进来、交给谁、办完怎么知道当事人的看法？
```

**带读中怎么用：**

在**第7周（领导方法）**时展开：

```
讨论题设计：

"毛泽东的'从群众中来，到群众中去'——
 在你的工作场景中，'群众'是谁？
 你有没有制度化的渠道在收集他们的声音？
 收集到之后，你有没有'集中起来'形成系统方案？
 形成方案后，有没有'到群众中去'验证和执行？

 参考北京“接诉即办”的流程，找出相似的反馈环节，也找出没有对应的环节：
 市民打12345（从群众中来）
 → 派单到相关部门（集中处理）
 → 解决后回访市民（到群众中去验证）
 → 数据分析高频问题，推动政策改进（再从群众中来）

 你的团队/公司有没有类似的闭环？"
```

## 第四条脉络：自我革命——从整风到全面从严治党

**毛选中的起点：**
《整顿党的作风》《反对自由主义》《改造我们的学习》

**完整脉络：**

```
毛泽东：延安整风（1942-1945）
  → 问题：党内存在主观主义、宗派主义、党八股
  → 方法：学习 → 对照检查 → 批评与自我批评 → 整改
  → 原则："惩前毖后、治病救人"
  → 效果：统一了全党思想，为夺取全国胜利奠定基础
  → 本质：组织的自我纠错机制

          ↓

邓小平时代：制度化建设
  → 认识到：不能只靠运动式整风
  → 开始强调制度建设、党内法规
  → "制度问题更带有根本性、全局性、稳定性和长期性"

          ↓

当代："自我革命"的系统化
  核心命题："党的自我革命"
  → "全面从严治党"
  → 八项规定（改作风）
  → 反腐败（"打虎拍蝇猎狐"）
  → 巡视制度（制度化的"调查研究"）
  → 主题教育（学习教育常态化）

  理论表述：
  "勇于自我革命是中国共产党区别于其他政党的显著标志"
  "跳出治乱兴衰的历史周期率的第二个答案就是自我革命"
  （第一个答案是毛泽东在延安与黄炎培对话时提出的"民主监督"）
```

**带读中怎么用：**

在**第3周（《改造我们的学习》）**或**第7周（选读《整顿党的作风》）**时展开：

> "毛泽东搞延安整风，是组织的一次'自我纠错'。今天的话叫'自我革命'。问题是一样的：**任何组织运行久了，都会产生官僚化、形式主义、脱离一线的问题。**"

```
分成两组词，不画箭头：
  延安整风材料：主观主义、宗派主义、党八股。
  2013—2014年群众路线教育实践活动讨论的问题：形式主义、官僚主义、享乐主义、奢靡之风。

  请学员挑一段空泛表达，问它在什么条件下属于形式主义。
  再举一个享乐或奢靡的例子：它未必包含任何空话。
  名目、针对的行为和历史处境都不同，不能把“党八股”画成后两者的前身。
```

**引导学员联系自身：**

> "你的团队/公司有没有类似的'组织病'？
>  有没有制度化的'自我纠错'机制？
>  还是等到出了大问题才'运动式整改'？"

## 第五条脉络：统一战线——从革命联盟到新时代

**毛选中的起点：**
《中国社会各阶级的分析》《论联合政府》

**完整脉络：**

```
革命时代的统一战线：
  → 团结一切可以团结的力量反对主要敌人
  → 工农联盟为基础
  → 团结民族资产阶级、小资产阶级、开明士绅等

建设时代的统一战线：
  → 团结对象变了：民主党派、知识分子、非公经济人士
  → "长期共存、互相监督、肝胆相照、荣辱与共"

当代的统一战线（新变化）：
  → 新的社会阶层出现：
    互联网企业家、自由职业者、新媒体从业者
    网络意见领袖、留学归国人员等
  → 统一战线的对象和方式都在更新
  国际合作中的“共同目标”可拿来讨论，不能仅凭都讲团结就断定概念来自统一战线。
  
  核心逻辑不变：
  → 明确主要矛盾/主要目标
  → 围绕目标，最大范围团结同盟
  → 对不同群体采取不同策略
  → 保持核心领导权
```

**带读中怎么用：**

在**第10周（统一战线）**时简要展开：

> "统一战线的'道'没变——团结最多数人、孤立最少数人。变的是'术'——团结的对象、方式和场景都不同了。"

## 第六条脉络：马克思主义中国化——从第一次到最新篇章

### 这是所有脉络的总线

**毛选中的起点：**
几乎所有文章的底层方法论

**完整脉络：**

```
第一个阶段：毛泽东——"马克思主义中国化"的开创
  → 把马克思主义的普遍原理与中国革命的具体实践相结合
  → 成果：农村包围城市、新民主主义论、人民民主专政
  → 形成"毛泽东思想"

第二个阶段：邓小平——"中国特色社会主义"
  → 把马克思主义与中国改革开放的实践结合
  → 核心突破：社会主义也可以搞市场经济
  → 这在经典马克思主义中是没有的——但邓小平用"实事求是"破题
  → "发展才是硬道理"

第三个阶段（过渡）：
  → "三个代表"（江泽民时期）
  → "科学发展观"（胡锦涛时期）
  → 各自回应了不同阶段的新问题

第四个阶段：新时代——"马克思主义中国化时代化"
  → 在"中国化"基础上加了"时代化"
  → 强调两个结合：
    a. 马克思主义基本原理与中国具体实际相结合
    b. 马克思主义基本原理与中华优秀传统文化相结合
  → "第二个结合"是新提出的——
    意味着不仅要从马克思主义出发，
    还要从中国自身的文化传统中汲取资源
```

**带读中怎么用：**

在**第12周（矛盾论 + 总复盘）**时，作为最终总结的一部分：

```
展示这条线的内在逻辑：

毛泽东的核心方法：
  普遍原理 + 具体实际 = 正确的理论和路线
  （不是照搬，也不是抛弃，而是"结合"）

这个方法本身被一代一代地"应用"了：
  毛泽东用这个方法 → 解决了革命问题
  邓小平用这个方法 → 解决了发展问题
  当代用这个方法 → 试图解决新时代的问题

而你学毛选，也应该用同样的方法：
  毛泽东的思想是"普遍原理"
  你的具体处境是"具体实际"
  结合起来 → 形成你自己的判断和行动方案
```

> **"这就是毛选最根本的教诲——不是让你记住他的结论，而是让你学会他的方法，然后自己去分析、自己去判断、自己去实践。这个方法，共产党自己也在一直用。"**

## 第七组材料：一张出处卡，几道比较题

**有文本可定位，先做出处卡。** 1978年《实践是检验真理的唯一标准》是一篇引起讨论的文章；2023年中共中央办公厅印发的《关于在全党大兴调查研究的工作方案》是一份工作文件。主持人课前备其中一份原文，连同题名、年份、发布或发表场合交给学员。要说它明确承接某篇文章，还得指出原文提到哪篇、哪句话；题材相近不能算引证。

**没有直接承接证据，就做比较题。** 可在每周带读末尾选一道：

| 两个阅读对象 | 问题，而不是结论 |
|---|---|
| 革命时期的农村战略／乡村振兴 | 都说“农村”，前者关心什么历史处境，后者关心什么发展问题？仅凭同一个地名，能推出政策谱系吗？ |
| 自力更生／科技自立自强 | 两个语境里，哪些能力需要自己掌握，哪些仍有赖合作？ |
| 为人民服务／接诉后的回访 | 从一句价值判断走到具体制度，居民的意见在哪一步可能改变处理结果？ |
| 批评与自我批评／组织生活 | 哪些程序给人开口的机会？又怎样知道意见有没有得到回应？ |

## 实操方案：如何嵌入原有12周课程

### 方案一：每周加一个"今日回响"环节（轻量版）

```
在每周带读的最后15分钟，加一个环节：
"今日回响——这个思想今天怎么样了？"

示例：
第2周（反对本本主义）→ 展示2023年"大兴调查研究"的文件
第4周（阶级分析）→ 展示十九大"主要矛盾"的新判断
第5周（调查研究）→ 展示"四不两直"的调研方式
第7周（领导方法）→ 比较“接诉即办”的反馈回路，不作制度起源判断
第8周（论持久战）→ 联系当前大国博弈中的"持久战思维"
第10周（统一战线）→ 展示新社会阶层统战工作的新发展
第12周（矛盾论）→ 展示"两山论"作为辩证法应用的案例
```

### 方案二：增加2次专题延伸课（标准版）

在原有12周基础上，增加两次延伸课：

```
延伸课A（第7周和第8周之间）：
```

## 带读时的注意事项

### 1. 定位要清晰

```
我们做的是：
  ✓ 思想脉络的梳理——看一个方法论如何被传承和发展
  ✓ 方法论的对照——同样的分析工具在不同时代的应用
  ✓ 启发学员思考——这些方法你自己怎么用

我们不做的是：
  ✗ 政策解读课——那是党校的事
  ✗ 政治评论课——不做主观评价
  ✗ 时政讨论课——不跑题到具体新闻事件
```

### 2. 始终回扣方法论

每次延伸都要回到方法论层面：

```
不要说："这个政策好/不好"
而要说："这个政策背后用了什么分析方法？
        这个分析方法跟毛泽东当年用的是不是同一个？
        你自己能不能用这个方法？"
```

### 3. 保持客观呈现的态度

```
呈现事实：分别说清原文的题名、日期和问题。有明确引用再谈承接；没有，就请把箭头擦掉。

引导思考：
  "你怎么理解这个演变？"
  "不变的是什么？变的是什么？为什么变？"

避免灌输结论：
  让学员自己通过对比得出认识
```

### 4. 最终落脚点永远是学员自身

```
每次延伸的最后一句话都应该是：
  "那么——这个思想/方法，对你的实际工作和生活，
   有什么启发？你打算怎么用？"
```

## 最后：让学员自己决定能不能画线

结营时，每组拿三张卡：一张写早期篇目的问题，一张写后来文本的题名、年份和措辞，一张写今天的具体场景。能从材料中指出承接的，用实线并在旁边写证据；仅供比较的，平排两张卡，写出一个相似处和一个不能互换的地方。

第7周那一组可以从电话接诉一路追到回访：如果有人接、有人派，却没人问市民问题是否解决，这个回路就没有走完。说清这一处断点，比画出一条横跨百年的漂亮箭头有用。
