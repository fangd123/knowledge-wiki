# 《资本论》核心术语表

这份术语表收录三卷中反复出现、容易混淆或容易被日常语感带偏的核心概念，每条给一个简短定义，并链接到详细展开的章节。想快速回忆某个词是什么意思时查这里；想看完整论证，点链接去对应章节。

## 第一卷：生产过程中的核心概念

**使用价值**：商品的有用性，回答"它能干什么"。它是具体的、感性的，和人的某种需要相关，但本身不能解释商品为什么能相互交换。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**交换价值**：商品在市场上与其他商品交换时表现出来的比例关系，比如"20 码布 = 1 件衣服"。它是价值的表现形式，不是价值本身。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**价值**：凝结在商品中的抽象人类劳动，是不同商品能够放到同一尺度下比较、交换的共同内容。价值不是道德意义上的"值得"，而是商品交换体系中的社会劳动关系。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**具体劳动**：有具体形态、具体工具、具体目的的劳动，比如写代码、做咖啡、组装手机。具体劳动创造使用价值。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**抽象劳动**：撇开劳动的具体形式，只看作人类体力和脑力耗费的那一面。不同的具体劳动，作为抽象劳动可以相互比较，从而形成价值。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**社会必要劳动时间**：在当时社会正常生产条件下，以平均熟练程度和平均劳动强度，生产某种商品通常需要的劳动时间。它决定商品价值量，个人多花的时间不会自动变成更高价值。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**价值形式 / 一般等价物**：价值本身看不见，只能借助另一个商品表现出来，这个表现过程从简单价值形式一路发展到一般价值形式，最终固定为货币。充当这个共同表现材料的商品，就是一般等价物。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**货币**：固定下来的一般等价物，是商品世界共同承认的价值表达器，不是人为约定的符号，而是商品交换发展到一定阶段的必然产物。见 [第一卷第二章：交换过程](《资本论》辅助阅读/02-《资本论》第一卷第二章：交换过程.md)、[第一卷第三章：货币，或商品流通](《资本论》辅助阅读/03-《资本论》第一卷第三章：货币，或商品流通.md)。

**商品拜物教**：在商品社会中，人与人之间的社会关系表现为物与物之间的关系。人们看到的是价格、账单、算法结果，而不是背后真实的劳动和社会关系。见 [第一卷第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md)。

**劳动力**：人的体力和脑力的总和，是劳动能力本身，不同于劳动力被实际使用的过程（劳动）。劳动力成为商品，是资本主义生产的历史前提。见 [第一卷第四章：货币转化为资本](《资本论》辅助阅读/04-《资本论》第一卷第四章：货币转化为资本.md)。

**剩余价值**：劳动力在使用过程中创造出的、超过自身价值的那部分新价值，被资本无偿占有。它是资本增殖的秘密所在。见 [第一卷第四章：货币转化为资本](《资本论》辅助阅读/04-《资本论》第一卷第四章：货币转化为资本.md)、[第一卷第五章：劳动过程和价值增殖过程](《资本论》辅助阅读/05-《资本论》第一卷第五章：劳动过程和价值增殖过程.md)。

**不变资本**：用于购买生产资料的那部分资本，在生产过程中只把自身已有价值转移到新产品中，不创造新价值。见 [第一卷第六章：不变资本和可变资本](《资本论》辅助阅读/06-《资本论》第一卷第六章：不变资本和可变资本.md)。

**可变资本**：用于购买劳动力的那部分资本，在生产过程中通过劳动力的使用，创造出超过自身价值的新价值。见 [第一卷第六章：不变资本和可变资本](《资本论》辅助阅读/06-《资本论》第一卷第六章：不变资本和可变资本.md)。

**剩余价值率**：`m / v`，剩余价值与可变资本之比，等价于剩余劳动与必要劳动之比，用来衡量资本对劳动力的剥削程度，不同于利润率。见 [第一卷第七章：剩余价值率](《资本论》辅助阅读/07-《资本论》第一卷第七章：剩余价值率.md)。

**绝对剩余价值**：在必要劳动时间不变的前提下，通过延长工作日来增加剩余劳动时间，从而增加的剩余价值。见 [第一卷第八章：工作日](《资本论》辅助阅读/08-《资本论》第一卷第八章：工作日.md)、[第一卷第十四章：绝对剩余价值和相对剩余价值](《资本论》辅助阅读/14-《资本论》第一卷第十四章：绝对剩余价值和相对剩余价值.md)。

**相对剩余价值**：在工作日长度不变的前提下，通过提高劳动生产力、压缩必要劳动时间，相对延长剩余劳动时间而增加的剩余价值。见 [第一卷第十章：相对剩余价值的概念](《资本论》辅助阅读/10-《资本论》第一卷第十章：相对剩余价值的概念.md)。

**协作**：许多人在同一生产过程中共同劳动，产生单个劳动者不具备的集体生产力；在资本主义条件下，这种集体生产力表现为资本的组织和支配能力。见 [第一卷第十一章：协作](《资本论》辅助阅读/11-《资本论》第一卷第十一章：协作.md)。

**工资**：劳动力价值或价格的转化形式，看起来像是"劳动的价格"，实际上掩盖了必要劳动和剩余劳动的区分，让全部劳动看起来都得到了报酬。见 [第一卷第十七章：劳动力的价值或价格转化为工资](《资本论》辅助阅读/17-《资本论》第一卷第十七章：劳动力的价值或价格转化为工资.md)。

**简单再生产**：资本家把剩余价值全部消费掉、不扩大生产规模的再生产状态。即便如此，生产过程也会不断再生产出资本关系本身。见 [第一卷第二十一章：简单再生产](《资本论》辅助阅读/21-《资本论》第一卷第二十一章：简单再生产.md)。

**资本积累**：把剩余价值的一部分重新投入生产，转化为追加资本，使过去无偿占有的剩余劳动变成支配更多活劳动的能力。见 [第一卷第二十二章：剩余价值转化为资本](《资本论》辅助阅读/22-《资本论》第一卷第二十二章：剩余价值转化为资本.md)。

**相对过剩人口（产业后备军）**：资本积累过程中，随技术进步和资本有机构成提高而被相对排斥出生产过程的劳动人口，压低劳动者议价能力。见 [第一卷第二十三章：资本主义积累的一般规律](《资本论》辅助阅读/23-《资本论》第一卷第二十三章：资本主义积累的一般规律.md)。

**原始积累**：资本主义的历史起点不是勤俭神话，而是生产者与生产资料相分离的历史过程，形成一边占有资本、一边只能出卖劳动力的两个阶级。见 [第一卷第二十四章：所谓原始积累](《资本论》辅助阅读/24-《资本论》第一卷第二十四章：所谓原始积累.md)。

## 第二卷：流通与再生产中的核心概念

**资本循环**：资本依次采取货币资本、生产资本、商品资本三种形态并回到起点的运动，典型公式是 `G - W ... P ... W' - G'`。见 [第二卷第一章：货币资本的循环](《资本论》辅助阅读/27-《资本论》第二卷第一章：货币资本的循环.md)。

**资本周转**：资本循环反复进行的过程，周转时间等于生产时间加流通时间，周转次数决定同一笔预付资本一年内能完成多少次完整回流。见 [第二卷第七章：周转时间和周转次数](《资本论》辅助阅读/33-《资本论》第二卷第七章：周转时间和周转次数.md)。

**固定资本和流动资本**：固定资本的价值分多次转移和回收（如机器、厂房），流动资本的价值在一次周转中整体进入产品并回流（如原料、工资）；这一区分不同于不变资本／可变资本的区分。见 [第二卷第八章：固定资本和流动资本](《资本论》辅助阅读/34-《资本论》第二卷第八章：固定资本和流动资本.md)。

**社会总资本再生产 / 两大部类**：把社会生产分为生产资料部类（I）和消费资料部类（II），分析社会总产品的价值构成和实物构成能否相互补偿。简单再生产的核心条件是 `I(v+s) = IIc`。见 [第二卷第十八章：导言](《资本论》辅助阅读/44-《资本论》第二卷第十八章：导言.md)、[第二卷第二十章：简单再生产](《资本论》辅助阅读/46-《资本论》第二卷第二十章：简单再生产.md)。

## 第三卷：分配与竞争表象中的核心概念

**成本价格**：商品价值 `c + v + s` 在资本家账本上表现为 `k + p`，其中 `k = c + v`，把不变资本和可变资本合并为总成本，从而遮蔽了剩余价值来自劳动力这一点。见 [第三卷第一章：成本价格和利润](《资本论》辅助阅读/49-《资本论》第三卷第一章：成本价格和利润.md)。

**利润率**：`s / (c + v)`，剩余价值对全部预付资本（而不只是可变资本）的比率，让利润看起来像是全部资本共同产生的结果。见 [第三卷第二章：利润率](《资本论》辅助阅读/50-《资本论》第三卷第二章：利润率.md)。

**平均利润与生产价格**：资本竞争推动利润率平均化，各部门不再按自己直接生产的剩余价值取得利润，而是按资本比例分享社会总剩余价值；商品价值由此转化为成本价格加平均利润的生产价格。见 [第三卷第九章：一般利润率的形成和商品价值转化为生产价格](《资本论》辅助阅读/57-《资本论》第三卷第九章：一般利润率的形成和商品价值转化为生产价格.md)。

**利润率趋向下降的规律**：资本有机构成提高（不变资本相对增加、可变资本相对减少），而剩余价值只来自活劳动，因此平均利润率存在下降趋势；这一趋势会被多种反作用因素抵消或延缓。学术界对这条规律的解释力至今仍有争议，见 [第三卷第十三章：规律本身](《资本论》辅助阅读/61-《资本论》第三卷第十三章：规律本身.md) 的"存在争议"提示。

**商业资本／商业利润**：从产业资本的销售职能中分离出来、专门承担商品实现的资本；它不创造剩余价值，商业利润来自产业资本让渡的社会总剩余价值的一部分。见 [第三卷第十六章：商品经营资本](《资本论》辅助阅读/64-《资本论》第三卷第十六章：商品经营资本.md)、[第三卷第十七章：商业利润](《资本论》辅助阅读/65-《资本论》第三卷第十七章：商业利润.md)。

**生息资本**：货币作为资本被借出，表现为 `G - G'`，利息是利润的一部分，但在这个形式中，生产和劳动过程被全部遮蔽，货币看起来天然能生出更多货币。见 [第三卷第二十一章：生息资本](《资本论》辅助阅读/69-《资本论》第三卷第二十一章：生息资本.md)。

**虚拟资本**：把未来收入权资本化为可交易资产（股票、债券等），要注意区分现实生产资本与这类未来收益权的市场价格，二者可能大幅错位。见 [第三卷第二十五章：信用和虚拟资本](《资本论》辅助阅读/73-《资本论》第三卷第二十五章：信用和虚拟资本.md)。

**级差地租**：来自土地肥力、位置或追加投资生产率差异的地租：较差条件决定市场价格，较好条件获得超额利润，土地所有权把这部分超额利润转化为地租。见 [第三卷第三十八章：级差地租。总论](《资本论》辅助阅读/86-《资本论》第三卷第三十八章：级差地租。总论.md)。

**绝对地租**：不来自土地之间的差异，而来自土地私有权本身对资本自由进入土地的阻碍，使最差土地也可能收取地租。见 [第三卷第四十五章：绝对地租](《资本论》辅助阅读/93-《资本论》第三卷第四十五章：绝对地租.md)。

**三位一体公式**：资本产生利润、土地产生地租、劳动产生工资这一流行表象。马克思批判它把资本主义收入形式自然化，掩盖了利润、利息、地租其实都来自剩余价值的分割。见 [第三卷第四十八章：三位一体的公式](《资本论》辅助阅读/96-《资本论》第三卷第四十八章：三位一体的公式.md)。

**转形问题**：价值如何转化为生产价格，是《资本论》中争论最久的理论难题之一，学术界至今对马克思的转形方法是否自洽存在不同意见。见 [第三卷第九章：一般利润率的形成和商品价值转化为生产价格](《资本论》辅助阅读/57-《资本论》第三卷第九章：一般利润率的形成和商品价值转化为生产价格.md) 的"存在争议"提示。

**阶级**：资本主义基本阶级关系不是按收入高低划分，而是按人们同生产资料、土地、劳动力的关系划分；工资、利润、地租分别对应雇佣工人、资本家、土地所有者，但现实中存在大量混合和中间形式。见 [第三卷第五十二章：阶级](《资本论》辅助阅读/100-《资本论》第三卷第五十二章：阶级.md)。
