## 总逻辑

第三卷五十二章可以连成八段逻辑：

```text
c + v + s -> 成本价格 k + 利润 p
-> 利润率 p' = s / (c + v)
-> 利润率和剩余价值率的关系
-> 周转速度影响年利润率
-> 不变资本节约和价格变动影响利润率

不同部门资本构成不同 -> 直接利润率不同
-> 竞争形成一般利润率
-> 剩余价值转化为平均利润
-> 商品价值转化为生产价格
-> 部门内部竞争形成市场价值和超额利润

资本有机构成提高
-> 平均利润率趋向下降
-> 提高剥削、压低工资、降低不变资本价格、对外贸易等因素抵消下降趋势
-> 利润率下降规律的内部矛盾
-> 资本过剩、人口过剩、信用扩张和危机

商品经营资本 -> 商业利润
-> 商业资本周转和价格
-> 货币经营资本
-> 商人资本的历史地位

生息资本 -> 利润分为利息和企业主收入
-> 利息率
-> 资本关系在 G - G' 中外在化

信用和虚拟资本
-> 货币资本积累和利息率
-> 信用推动生产又放大投机和危机
-> 流通手段和资本的区分
-> 银行资本中真实资本与虚拟资本交织
-> 货币资本和现实资本在周期中错位
-> 信用制度下的流通手段
-> 批判通货原理
-> 贵金属、汇兑率和世界货币
-> 高利贷资本的历史收束

土地所有权
-> 级差地租第一形式和第二形式
-> 生产价格不变、下降、上涨时的地租变化

-> 建筑地段、矿山地租和土地价格
-> 资本主义地租的发生

-> 竞争的假象
-> 分配关系和生产关系
-> 阶级
```

第一章讲成本价格和利润。商品价值原本是 `c + v + s`，但在资本家账本上表现为 `k + p`，其中 `k = c + v`。成本价格把不变资本和可变资本合并为总成本，利润则把剩余价值表现为超过成本的余额，从而遮蔽剩余价值来自劳动力的关系。

第二章讲利润率。剩余价值率是 `s / v`，揭示剥削程度；利润率是 `s / (c + v)`，表现全部预付资本的增殖程度。利润率让利润看起来像全部资本共同产生的结果，而不是可变资本所购买的劳动力创造的剩余价值。

第三章分析利润率和剩余价值率的关系。利润率可以理解为 `p' = m' × v/(c+v)`，因此它不仅取决于剩余价值率，还取决于资本构成。剩余价值率相同，利润率可能不同；利润率相同，剥削程度也可能不同。

第四章把第二卷的周转理论接回利润率。周转越快，同一笔预付资本一年中能够反复生产和实现剩余价值，年利润率就越高；周转越慢，资本被生产时间、流通时间、账期和固定资本占用得越久，年利润率越受压。

第五章讲不变资本使用上的节约。不变资本不创造剩余价值，但节约机器、原料、能源、云资源、GPU、模型 API 和管理费用，可以降低成本价格和预付资本量，从而提高利润率。这种节约常来自社会化劳动和规模协作，却表现为资本自己的效率。

第六章讲价格变动的影响。生产资料价格上涨会增加成本和追加资本需求，压低利润率；生产资料价格下降会释放资本，提高利润率。存货、固定资本、GPU、云资源和数据资产还可能因市场价格变化发生价值增减。

第七章补充说明第一篇。利润率不是剩余价值率的直接外观，而是受到资本构成、周转、固定资本、流通费用、节约、价格波动和风险共同影响的复杂表现，因此利润来源在利润率形式中被进一步遮蔽。

第八章进入第二篇。不同生产部门资本构成不同，如果商品都按价值出售，剩余价值率相同的情况下，高可变资本部门直接利润率高，高不变资本部门直接利润率低。

第九章讲一般利润率和生产价格。资本竞争会推动利润率平均化，等量资本要求获得等量利润。于是各部门不再按自己直接生产的剩余价值取得利润，而是按资本比例分享社会总剩余价值；商品价值转化为成本价格加平均利润的生产价格。

第十章讲竞争机制。部门内部竞争形成市场价值和市场价格，部门之间竞争推动利润率平均化。个别生产条件优于社会平均的资本可以获得超额利润，但竞争会不断把先进条件扩散为新的平均条件。

第十一章讲工资变动对生产价格的影响。工资上涨会减少剩余价值并降低平均利润率，但由于不同部门资本构成不同，生产价格变化并不一致。劳动密集部门受工资成本影响更大，资本密集部门受平均利润率变化影响更明显。

第十二章补充说明第二篇。生产价格不是价值规律的否定，而是价值在平均利润率和资本竞争条件下的转化形式。社会总价格仍等于社会总价值，社会总利润仍等于社会总剩余价值。

第十三章进入第三篇，提出利润率趋向下降规律。资本主义发展推动劳动生产率提高和资本有机构成上升，不变资本相对增加、可变资本相对减少；由于剩余价值只来自活劳动，平均利润率因此存在下降趋势。

第十四章讲反作用因素。提高劳动剥削程度、压低工资、降低不变资本要素价格、制造相对过剩人口、对外贸易和股份资本等因素，会抵消、延缓或暂时逆转利润率下降趋势。现实利润率是在趋势和反趋势的拉扯中运动。

第十五章展开利润率下降规律的内部矛盾。利润率下降不等于利润量下降，资本可以通过扩大规模继续增长；但资本过剩、人口过剩、信用扩张和危机会周期性暴露资本增殖的限制。

第十六章进入商业资本。商品经营资本从产业资本的销售职能中分离出来，专门承担商品价值实现。它不创造剩余价值，却通过缩短流通时间、节约流通费用和控制销售渠道，参与社会总剩余价值分配。

第十七章讲商业利润。商业资本不生产剩余价值，商业利润来自产业资本生产的社会总剩余价值的一部分让渡。现代应用商店、云市场、渠道商和平台抽成，都可以从这一角度理解。

第十八章讲商业资本的周转。商业资本周转越快，同一笔商业资本一年中完成的买卖越多，较低单次差价也能形成可观年利润；平台结算周期、库存、渠道佣金和信用安排都会影响商业资本周转。

第十九章讲货币经营资本。支付、结算、保管、汇兑、账务等货币技术职能从产业资本和商业资本中分离出来，形成专门资本。它不创造价值，但通过组织货币流通和节约流通费用取得收入。

第二十章从历史上考察商人资本。商人资本早于资本主义产业资本存在，可以通过地区差价、垄断和信息不对称获利；在资本主义中，它被纳入产业资本主导的总运动，但仍能通过控制市场入口支配生产者。

第二十一章进入生息资本。货币作为资本被借出，表现为 `G - G'`：钱借出去，回来更多钱。利息是利润的一部分，利润来自剩余价值，但在生息资本形式中，生产和劳动过程被全部遮蔽。

第二十二章讲利润分割和利息率。总利润分为利息和企业主收入。利息归资本所有者，企业主收入归资本使用者；利息率没有固定的自然水平，而由货币资本供求、信用条件、风险和经济周期决定。

第二十三章讲利息和企业主收入的表象。利息看起来来自资本所有权，企业主收入看起来来自经营管理，但二者本质上都是利润的分割，最终都来自剩余价值。

第二十四章讲资本关系在生息资本形式上的外在化。产业资本还有 `G - W ... P ... W' - G'` 的过程，商业资本还有 `G - W - G'`，而生息资本只剩 `G - G'`，使货币看起来天然能够生出更多货币。这是资本拜物教最浓缩的形式之一。

第二十五章讲信用和虚拟资本。信用把未来支付能力提前带入现在，虚拟资本把未来收入权资本化为可交易资产。股票、债券、收益权和高估值都要区分现实生产资本与未来收益权的市场价格。

第二十六章讲货币资本积累及其对利息率的影响。可贷货币资本增加可能压低利息率，但货币资本积累不等于现实资本积累；资金充裕可能只是资产价格膨胀，并不代表生产能力真实扩大。

第二十七章讲信用在资本主义生产中的作用。信用可以加速资本周转、集中社会资本、推动股份公司和大规模生产；但它也会扩大投机、虚拟资本和危机传染。

第二十八章区分流通手段和资本。同一笔货币可能只是支付手段，也可能作为资本增殖，还可能作为可贷资本取得利息。把货币流通和资本流通混为一谈，会误解信用和危机。

第二十九章讲银行资本组成。银行资本不是一堆现金，而由现金准备、存款负债、贷款债权、票据、证券和自有资本构成，其中大量是债权和虚拟资本，因此银行资本账面规模不能等同于现实生产资本。

第三十章到第三十二章连续分析货币资本和现实资本。货币资本、可贷资本和虚拟资本的增加，不一定意味着机器、劳动力、商品和生产组织等现实资本同步增加。繁荣期信用和估值膨胀会掩盖错配，危机期则表现为现金饥渴、资本贬值和虚拟资本价格暴跌。

第三十三章讲信用制度下的流通手段。票据、存款、转账、清算和平台内部 credits 等信用化支付形式可以节约现金流通、提高周转效率，但也让支付体系依赖信任和清偿能力。

第三十四章批判通货原理和 1844 年英国银行立法。把危机归结为银行券数量是片面的；资本主义危机根源在信用、支付、资本周转、价值实现和现实资本错配中，机械限制通货可能加剧支付困难。

第三十五章讲贵金属和汇兑率。国内信用可以节约货币，但国际支付最终需要被世界市场承认的支付手段；汇兑率反映国际债权债务、贸易、资本流动和信用状况。

第三十六章讲资本主义以前的状态，尤其是高利贷资本。高利贷资本早于资本主义存在，能通过债务压迫小生产者，却不必然建立资本主义生产；现代高息消费贷、平台现金贷和高成本融资仍有类似影子。

第三十七章进入地租篇导言。地租不是土地自然生出价值，而是超额利润在土地所有权作用下转化出的收入形式。

第三十八章到第四十四章分析级差地租。级差地租来自土地肥力、位置或追加投资生产率差异。较差条件决定市场价格，较好条件获得超额利润，土地所有权把超额利润转化为地租。生产价格不变、下降、上涨时，地租规模和分布会不同；甚至最坏耕地内部也可能因追加投资差异形成级差地租。

第四十五章讲绝对地租。绝对地租不是来自土地差异，而是来自土地私有权本身对资本进入土地的阻碍。地主凭所有权阻止资本无偿使用土地，使最差土地也可能支付地租。

第四十六章讲建筑地段地租、矿山地租和土地价格。建筑地段地租主要来自位置，矿山地租来自资源品位和开采条件，土地价格则是未来地租收入的资本化。

第四十七章讲资本主义地租的发生。旧地租形式包括劳役、实物和货币地租；资本主义地租建立在地主、农业资本家和雇佣工人分离的基础上。

第四十八章讲三位一体公式：资本产生利润，土地产生地租，劳动产生工资。马克思批判这种表象，因为它把资本主义收入形式自然化，掩盖利润、利息和地租都来自剩余价值分割。

第四十九章回到生产过程，重新说明商品价值是 `c + v + s`。`c` 补偿生产资料，`v` 表现为工资，`s` 是剩余价值并分割为利润、利息、地租等收入形式。

第五十章讲竞争的假象。竞争实现价值规律，但不创造价值规律；供求解释价格偏离，不解释价值中心。市场竞争会遮蔽深层生产关系。

第五十一章讲分配关系和生产关系。工资、利润、利息、地租不是生产完成后的任意分配，而是劳动力商品化、资本所有权、土地所有权和货币资本所有权这些生产关系的表现。

第五十二章讲阶级。资本主义基本阶级关系不是按收入高低划分，而是按人们同生产资料、土地和劳动力的关系划分。工资、利润和地租分别对应雇佣工人、资本家和土地所有者，但现代社会有大量混合和中间形式，需要回到收入来源和生产条件控制权来分析。

## 版本与手稿背景

第三卷的手稿背景比第二卷更极端。马克思实际写作第三卷主体内容的时间是 1864 到 1865 年——比第一卷 1867 年正式出版还要早，此后他没有再回头系统修订这份手稿，而是转去打磨第一卷、参与第一国际事务、应对健康问题。也就是说，我们读到的第三卷，本质上是一份未经作者本人二次打磨的早期草稿，而不是像第一卷那样反复推敲过的定稿。

恩格斯在马克思去世后用了近十年（1885 到 1894 年）整理这份手稿，才编成现在的 52 章本子。整理难度并不均匀：前几篇（利润、平均利润、利润率下降）相对成型，恩格斯改动较少；但第五篇（利息和生息资本，第二十一到三十六章）和第七篇（各种收入及其源泉，第四十八到五十二章）留下的手稿明显更零散，有的段落只是提纲式的笔记，恩格斯必须自己补写连接文字、编排顺序。这也是为什么这些部分——尤其是第四十八章"三位一体的公式"——原文本身论述就比第一卷同等重要的章节要单薄，不是后人整理和讲解时省略了什么。

了解这段背景，读这些章节时可以多一分耐心：论证跳跃、例证稀少，很多时候是手稿本身的性质，不是理解出了问题。
