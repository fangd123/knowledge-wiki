# 《资本论》第一卷第六章：不变资本和可变资本

第五章讲清楚了资本主义生产过程的两面：一面是劳动过程，生产使用价值；另一面是价值增殖过程，生产剩余价值。

第六章紧接着解决一个更精确的问题：

> 在资本家预付的资本中，哪些部分只是把已有价值转移到产品中，哪些部分会在生产过程中发生价值增殖？

这就引出两个概念：

- **不变资本**；
- **可变资本**。

这两个词看起来像会计分类，但在马克思这里，它们不是简单的“固定资产”和“流动资金”，也不是“固定成本”和“变动成本”。它们讲的是不同资本部分在价值增殖中的作用。

一句话概括本章：

> 生产资料的价值只会转移，不会自行增殖，所以是不变资本；劳动力的价值在使用过程中能创造出超过自身的新价值，所以是可变资本。

## 资本家预付的两类东西

资本家要开始生产，首先要买两大类商品。

第一类是生产资料。

传统工业里包括厂房、机器、原料、燃料、工具。

AI 应用行业里可以包括：

- 电脑和服务器；
- GPU 算力；
- 云数据库；
- 模型 API；
- 向量数据库；
- 软件许可；
- 办公设备；
- 代码仓库和 CI/CD 系统；
- 数据集或数据服务；
- 广告账户和分发工具。

第二类是劳动力。

比如：

- Python 开发者；
- 算法工程师；
- 产品经理；
- UI 设计师；
- 测试工程师；
- 运维工程师；
- 数据标注员；
- 销售和客户成功；
- 内容运营和审核人员。

资本家把货币分成两部分，一部分买生产资料，一部分买劳动力。两者在生产中都不可缺少，但它们对价值的作用不同。

这就是第六章要精确区分的地方。

## 生产资料只是转移价值

先看生产资料。

比如一家 AI 公司花 10 万元购买服务器和工具服务。服务器被使用，工具被消耗，API 调用额度被消耗，云资源被计费。

这些东西当然重要。没有它们，产品做不出来。

但从价值形成角度看，它们不会创造超过自身的价值。它们只是把自己已有的价值，逐步转移到新产品中。

一台机器磨损多少，就把相应价值转移到产品中。

一批原料消耗多少，就把自身价值转移到产品中。

一个模型 API 调用花了多少成本，就进入产品成本。

一个 GPU 小时被消耗了，就把那部分算力成本转移到服务中。

生产资料的具体形态改变了。原料变成产品，机器被磨损，服务器资源被消耗，API credits 被扣减。

但它们的价值量并不会因为自己被使用而自动增加。

这就是“不变”的意思。

不变资本不是说它的物质形态不变。机器会磨损，原料会消失，云服务会用完。所谓“不变”，是说它在价值量上不发生增殖，只是把已有价值转移出去。

## 劳动力会创造新价值

再看劳动力。

资本家支付工资，购买一定时间内使用劳动力的权利。

比如月薪 3 万雇一个开发者。这个 3 万，是劳动力价值的货币表现。它大体对应于维持这个开发者生活、技能、恢复和再生产所需的社会成本。

但开发者在一个月里实际创造的价值，可能超过 3 万。

他可能完成一个功能，使公司多卖出几十万合同。

他可能优化推理成本，每月节省大量 API 开支。

他可能写出一个自动化流程，让公司用更少人服务更多客户。

他可能开发一个核心模块，让产品可以重复销售给很多企业。

资本家买的是劳动力这个商品，得到的是劳动力的使用价值。而这个使用价值很特殊：它能创造价值。

更关键的是，它能创造超过自身价值的价值。

所以，用来购买劳动力的资本部分，在生产过程中不是简单保持原值，而是发生了量的变化。它从工资这部分价值出发，通过劳动过程创造出更大的新价值。

这就是“可变资本”的意思。

可变资本不是说工资总额每天都在变，也不是说员工流动性大，而是说这部分资本在生产过程中能够变成更大的价值。

## 不变资本和可变资本的定义

现在可以给出更清晰的定义。

**不变资本**：资本家用来购买生产资料的那部分资本。它在生产过程中只把自身价值转移到新产品中，不创造新价值。

**可变资本**：资本家用来购买劳动力的那部分资本。它在生产过程中通过劳动力的使用，创造出超过自身价值的新价值。

用公式表示：

```text
C = c + v
```

其中：

```text
c = 不变资本
v = 可变资本
```

生产结束后，产品价值可以表示为：

```text
商品价值 = c + v + m
```

其中：

```text
m = 剩余价值
```

这三个符号非常重要：

- `c`：转移过来的旧价值；
- `v`：劳动力价值，也就是工资部分；
- `m`：劳动力创造出的超过自身价值的剩余价值。

这不是普通财务报表，而是马克思分析资本主义价值生产的基础结构。

## 一个 AI 应用公司的例子

假设一家 AI 应用公司开发一个企业知识库问答产品。

一个月投入如下：

- 云服务器、数据库、模型 API、软件工具：10 万
- 员工工资：20 万

这里，10 万用于生产资料，是不变资本 `c`。

20 万用于购买劳动力，是可变资本 `v`。

如果这个月产品和服务卖出 30 万，只够覆盖 `c + v`，那么没有剩余价值。

如果卖出 50 万，那么可以简化看作：

```text
c = 10 万
v = 20 万
m = 20 万
商品价值 = 50 万
```

这 20 万剩余价值，不是服务器自己多长出来的，也不是 API 自己创造的，而是员工劳动在生产和服务过程中创造的新价值超过了工资部分。

当然，现实商业会更复杂：价格会偏离价值，有融资补贴，有折旧，有税费，有管理层薪酬，有垄断收益，有品牌溢价，有金融收益。

但马克思在这里先抽象出最基本的关系：生产资料转移旧价值，劳动力创造新价值。

## 为什么机器不是可变资本

现代读者很容易卡在这里：机器、AI、自动化这么强，为什么它们不是创造价值的主体？

从日常语言看，我们会说“机器创造了产出”“AI 生成了内容”“算法带来了收入”。这些说法在技术生产层面没有问题。

但马克思讲的是价值关系。

机器本身是过去劳动的产物。它的价值来自生产它所需要的社会劳动。进入新的生产过程后，它通过磨损、折旧、消耗，把自身价值转移到新产品中。

比如 GPU 很强，能同时服务很多用户。它提高了生产效率，也让同一时间内能生产更多使用价值。

但 GPU 的价值会通过折旧、能耗、租赁费、维护费等形式进入产品成本。它不能凭空创造超过自身价值的价值。

AI 模型也是类似。模型能力可以极大提高生产力，但模型训练、数据、算力、工程维护本身是大量过去劳动的结果。当它作为生产资料被调用时，其成本被分摊到服务中。

真正让价值增殖发生的，不是机器单独存在，而是资本把机器和劳动力结合起来，并让活劳动创造超过劳动力价值的新价值。

这不意味着马克思低估技术。恰恰相反，后面章节会不断分析机器和技术如何改变劳动生产率、改变剩余价值生产方式。只是第六章要明确：技术提高生产力，不等于机器本身成为剩余价值的源泉。

## 不变资本也很重要，但作用不同

说生产资料“不创造新价值”，不是说它不重要。

没有服务器、没有模型 API、没有框架、没有机器、没有原料，劳动无法顺利进行。

生产资料会极大影响劳动生产率。

同样一个开发者：

- 用低效工具，可能一周只能做一个小功能；
- 用成熟框架和 AI 编程助手，可能一天完成；
- 有高质量数据和稳定 API，产品效果更好；
- 有完整 DevOps，交付速度更快；
- 有自动化测试和监控，维护成本更低。

这些都会改变单位时间内创造的使用价值数量。

但从价值增殖的来源看，生产资料只是条件，不是剩余价值本身的源泉。

它像放大器、通道、基础设施、生产条件；活劳动才是新价值的来源。

## 不变资本的价值转移方式

生产资料转移价值的方式也不完全一样。

有些生产资料一次性全部进入产品。

比如原料、燃料、一次性 API 调用、云服务用量。它们被消耗掉，就把全部价值转移到产品中。

有些生产资料则分多次转移。

比如机器、服务器、办公设备、长期软件系统。它们可以服务多个生产周期，只把折旧部分逐步转移到每批产品中。

AI 行业里也有类似区分：

- 当月用掉的 token 和 GPU 小时，接近一次性消耗；
- 自建模型、内部平台、代码框架、数据管道，则可能在多个产品周期中分摊；
- 购买的硬件服务器，会通过折旧逐步进入成本；
- 长期沉淀的数据资产和工作流，也可能反复参与生产。

但无论一次转移还是逐步转移，它们仍然属于不变资本，因为它们没有在价值量上自我增殖。

## 可变资本为什么是资本主义分析的关键

第六章之所以重要，是因为它把剩余价值的来源精确定位到可变资本。

如果不区分不变资本和可变资本，就容易把利润理解成各种投入共同“自然产生”的结果。

比如一个企业家可能说：

> 我投入了钱、设备、办公室、技术、管理、品牌，所以利润是这些要素共同贡献的。

从经营经验看，这些要素确实都重要。但马克思要追问：新价值到底从哪里来？剩余价值到底是哪一部分资本带来的？

他的回答是：只有购买劳动力的资本部分，才会通过劳动过程产生超过自身价值的新价值。

这个区分让资本关系变得清楚：

- 不变资本越大，生产规模可能越大，生产力可能越高。
- 但剩余价值的直接来源仍是可变资本所购买的劳动力。
- 资本家追求利润，最终要组织和支配活劳动。

这也是为什么资本主义不是单纯的“物的堆积”，而是人与人之间围绕生产资料和劳动力形成的社会关系。

## 对平台经济的理解

平台经济里，不变资本和可变资本的边界有时会被包装得很模糊。

平台会说自己只是技术中介，只提供系统、算法、规则和撮合。劳动者似乎是“自由接单者”，不是传统雇员。

但你仍然可以用第六章的框架去看：

- 平台的服务器、算法系统、App、支付系统、数据中心，是生产资料。
- 骑手、司机、主播、内容审核员、众包标注员、开发者生态，是活劳动来源。
- 平台通过规则和算法组织这些劳动，使其服务于平台收入和估值增长。

有些劳动力不以工资形式出现，而以佣金、分成、任务单价、补贴、流量收益表现出来。

但只要平台能通过组织他人的劳动获得超过成本的价值增殖，资本关系就仍然存在。

AI 平台也一样。

模型平台的收入看似来自 API、算力和软件产品，但背后有工程师、研究员、数据标注、内容审核、客户支持、开源贡献、用户反馈等活劳动。平台把这些劳动和巨大不变资本结合起来，形成可规模化的商品和服务。

## 对 AI 开发者的启发

这章能帮助你避免几个误解。

第一，不要把工具能力误认为价值源泉。

AI 编程助手、模型 API、GPU、框架确实能让你做得更快，但它们是生产资料。真正把它们组织成有用产品并创造新价值的，是人的劳动和社会协作。

第二，要区分“成本结构”和“价值增殖结构”。

公司财务上会看云成本、工资、销售费用、研发费用、毛利率。但马克思在问的是：哪些部分只是转移旧价值，哪些部分能创造新价值。

第三，软件的规模化会强化资本对活劳动的利用。

一个团队一次开发出的系统可以卖给成千上万客户，这会让劳动创造的价值通过规模化销售被放大。资本正是要把这种可复制性纳入增殖逻辑。

第四，开源和用户贡献也要放进社会劳动视野。

很多 AI 产品依赖开源库、社区经验、用户反馈和公共数据。它们可能不直接体现在工资账单上，却参与了产品价值形成。资本常常会把这些外部劳动吸收进自己的商业闭环。

## 用国学视角辅助理解

可以借“器”和“人”的关系来理解。

生产资料像“器”。器很重要，器利则事半功倍。没有工具，劳动难以展开。

但器不能自用，必须有人使用。古人讲“工欲善其事，必先利其器”，并不是说器自己会成事，而是人借器以成事。

在马克思这里，不变资本像被资本占有的“器”，可变资本对应资本购买的活劳动能力。

区别在于，传统讲器用，多关注如何成事；马克思进一步问：成事之后，价值归谁？增殖从何而来？谁控制器，谁使用器，谁占有结果？

这就从技术问题转向社会关系问题。

## 原文对照

> **转述**（第一卷第六章）：马克思在本章把预付资本区分为不变资本和可变资本——用于购买生产资料的部分只是把自身价值转移到产品中，不会自行增殖；只有用于购买劳动力的部分，才会在生产过程中创造出超过自身价值的新价值。

## 本章的核心结论

第六章可以浓缩成一句话：

> 资本分为不变资本和可变资本，是因为生产资料只转移已有价值，而劳动力能够创造超过自身价值的新价值。

更具体地说：

- 不变资本用于购买生产资料；
- 生产资料在生产中改变形态，但只转移自身价值；
- 可变资本用于购买劳动力；
- 劳动力在使用中创造新价值；
- 当新价值超过劳动力价值时，剩余价值产生；
- 商品价值可以表示为 `c + v + m`；
- 剩余价值的直接来源不是机器、原料或工具，而是被资本组织起来的活劳动。

理解这一章之后，再看一个 AI 公司成本表，你会有两层视野：

- 普通经营视角：云成本、工资、营销、收入、利润
- 马克思视角：不变资本 c、可变资本 v、剩余价值 m

这不是为了否认技术、机器和管理的重要性，而是为了看清资本增殖的核心关系：生产资料作为条件进入生产，劳动力作为特殊商品创造新价值，而资本占有这个增殖结果。
