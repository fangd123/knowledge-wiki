# 《资本论》第三卷第四十五章：绝对地租

第四十四章结束级差地租的补充。

第四十五章进入绝对地租。

级差地租来自土地差异。

绝对地租问的是另一个问题：即使最差的土地没有级差优势，地主也能拒绝把它无偿交给资本使用。那么，如果租地资本家还要保住平均利润，付给地主的那一份究竟从哪里来？

一句话概括本章：

> 在本章设定的条件下，农产品价值高于生产价格。土地所有权不是这个差额的来源；它是拦住资本自由进入的门槛，使差额的一部分或全部能作为绝对地租留下，最差土地也不例外。

## 级差地租和绝对地租的区别

级差地租：

> 土地之间有差异；
> 较好土地获得超额利润；
> 超额利润转化为地租。

绝对地租：

> 即使最差土地没有差异优势；
> 土地所有者也可以凭所有权要求租金；
> 资本必须支付才能使用土地。

所以级差地租来自差异。

绝对地租不要求这块地比别处好。地主对土地使用权的垄断解释的是谁有权把门；它还没有解释门里面有什么收入可分。

## 为什么土地私有权能阻碍资本

资本想进入农业或土地相关生产，必须使用土地。

但土地归地主所有。

地主可以说：

> 不给租金，就不能使用。

即使某块土地只是最差土地，资本家也不能免费使用。

如果农产品市场价格只等于生产价格，没有空间支付租金，地主可能不出租。

于是土地私有权阻止资本自由进入。

只有市场确实需要这块地的产品，又肯出一个让租地者既得平均利润又付得起地租的价，这块地才会出租。地主可以不租，不等于他报什么价就有人付。

## 绝对地租和价值

马克思认为，绝对地租与农业资本构成较低有关。

设剩余价值率相同，而农业资本有机构成低于社会平均水平。同样一笔资本，农业用于雇用劳动力的份额较大，生产的剩余价值就会多于按一般利润率分给这笔资本的平均利润。这时农产品的价值才有高于生产价格的差额。

土地所有权阻止这部分超额剩余价值完全进入平均利润分配。

于是它以绝对地租形式留在农业产品价格中。

这里细节复杂，但核心可以简化为：

> 土地私有权阻止资本自由平均化；
> 使农产品价格可以高于生产价格；
> 差额成为绝对地租。

## 现代资源垄断类比

绝对地租可以帮助理解某些资源控制。

比如：

- 城市土地所有权；
- 频谱牌照；
- 稀缺电力接入；
- 数据中心许可；
- 平台 API 入口；
- 应用商店准入；
- 关键数据授权。

这些资源即使没有明显质量差异，只要所有者能阻止使用，就能收费。

例如平台要求所有开发者支付固定抽成。

无论你排名高低，都必须缴纳。

这不是级差收益，而更接近准入垄断。

当然平台不是土地，不能直接等同，但结构上都涉及“没有许可不得使用”。

## 绝对地租和房租

创业公司在普通地段租一间办公室，每月也要交房租。能不能据此说它在交绝对地租？先把办公室和它脚下那块地分开。

租一幢房子，付的不只是地皮的使用费。建筑会折旧，需要维修，租金里还可能包含投入建筑的资本的利息。哪怕两块地位置一样，带房屋和出租空地也不是一回事。

再看位置：两间办公室建筑条件相同，靠近客户的那间可能贵一些。这才给了我们辨认位置级差的线索。至于另一间也不免费，只说明空间使用有价格；既没剥离建筑资本的部分，也没说明农业例子中价值超过生产价格的差额，不能把这张房租单当作绝对地租的证明。

## 对 AI 开发者的理解抓手

绝对地租提醒你关注准入成本：

- 使用平台是否必须抽成？
- 调用关键 API 是否必须付费？
- 获取数据是否必须买授权？
- 上架应用是否必须遵守平台税？
- 使用某云区域是否受资源所有者定价？
- 进入企业客户采购体系是否要渠道费用？

这些费用不一定来自对方帮你创造更多价值，而可能来自准入权。

## 类比的边界

平台抽成、API 准入费、数据授权费能借来说明一点：不管你排名高低，控制入口的人都可以拒绝你使用。这类比的是地主把门的权力，不是收费的价值来源。

土地是资本无法生产出来的自然要素。在土地已经被占有的地方，想租地耕作，就得和地主打交道。

平台、API、数据授权不完全是这样。

原则上，只要有足够资本和时间，竞争者可以自建平台、自建数据中心、自己采集或谈判获得数据授权，这在技术上是可行的，只是成本高、周期长。土地则不同，无论多少资本，都不能凭空造出更多地球表面。

```text
土地私有权壁垒：资本无法生产替代品，绕不开
平台/数据准入壁垒：原则上可被资本复制（自建平台、自采数据），只是成本高
```

另外，马克思讲绝对地租，还有一个具体机制：农业资本有机构成偏低，生产的剩余价值本来就可能高于按平均利润率分配后的水平，土地私有权只是拦住了这部分剩余价值被拉平的过程。这个机制是农业特有的，不能直接套到平台抽成上——平台抽成的定价逻辑更多来自网络效应和议价权，而不是资本有机构成差异。

所以"平台抽成等于绝对地租"这个类比，抓住了"所有权本身构成壁垒"这一点，但壁垒的成因不一样：自然资源不可再生产，商业设施原则上可复制。套用时要把这一点说清楚。

## 本章的核心结论

第四十五章讲绝对地租。

核心是：

> 级差地租要比较生产条件，绝对地租不要求最差土地另有优势。
> 在农业资本有机构成较低等假设下，农产品价值超过生产价格，才有本章讨论的可分差额。
> 土地所有权阻碍资本自由进入，使这部分差额不必全部参加利润率的平均化，地主因而可能在最差土地上也收到地租。拒绝别人使用的权利，本身不创造价值。

对现代数字经济来说，这章帮助理解：

- 平台准入费和固定抽成；
- 数据授权和 API 准入；
- 房租和机房资源；
- 牌照、频谱、云资源等稀缺使用权；
- 所有权不生产价值却能参与分配。
