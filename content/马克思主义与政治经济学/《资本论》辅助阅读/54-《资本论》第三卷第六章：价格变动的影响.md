# 《资本论》第三卷第六章：价格变动的影响

第五章讲不变资本使用上的节约。

第六章继续围绕利润率展开，但主题换成价格变动。

资本家生产商品，要购买生产资料和劳动力。

这些要素的价格会变化。

价格一变，成本价格、资本价值和利润率都会变。

一句话概括本章：

> 原料、能源、机器、云资源、模型 API 等生产资料价格变动，会改变成本价格、预付资本价值和利润率；资本家可能因为价格上涨而追加资本，也可能因为价格下跌而释放资本，甚至在存货重估中获得或遭受意外收益和损失。

## 为什么价格变动重要

利润率公式是：

```text
p' = s / (c + v)
```

如果 `c` 的价格变化，分母会变。

如果原料价格上涨，资本家需要更多资本维持同样生产规模。

如果原料价格下降，同样生产规模需要的资本减少。

这会影响利润率。

现代 AI 公司也非常熟悉：

- GPU 租金上涨；
- 云厂商降价；
- 模型 API 降价；
- 数据采购变贵；
- 电力成本上涨；
- 存储和带宽降价；
- 开源模型降低某些成本；
- 合规成本上升。

这些都不是外围因素，而是直接改变资本运动。

## 原料价格上涨

传统工业中，原料价格上涨会提高商品成本。

比如棉花涨价，纺织品成本上升。

煤炭涨价，工业生产成本上升。

现代 AI 中，类似的是：

- token 成本上涨；
- GPU 供应紧张；
- 云计算涨价；
- 高质量数据授权变贵；
- 电力价格上涨；
- 芯片价格上涨。

如果产品售价不能同步提高，利润率会下降。

比如一个 AI 应用每月收入 100 万。

原来成本：

- 云/API：30 万
- 工资：40 万
- 其他：10 万
- 利润：20 万

如果云/API 成本涨到 50 万：

- 总成本变成 100 万
- 利润变成 0

技术没有变，客户没有变，但上游价格变化就能吞掉利润。

这说明资本利润率深受生产资料市场影响。

## 原料价格下降

对正要采购生产资料的企业，若售价和其他条件不变，降价可以提高利润率。

AI 行业中，模型 API 降价是典型例子。

如果上游大模型调用成本下降 70%，下游应用有几种选择：

- 保持售价不变，提高利润率；
- 降价竞争，扩大市场；
- 增加功能，提高用户体验；
- 把节省资金投入销售和研发。

从资本角度看，生产资料降价会释放资本。

原来维持某个服务需要每月 30 万 API 成本，现在只要 10 万。

同样业务规模释放出 20 万货币资本。

这部分资本可以用于扩张、偿债、利润分配或金融投资。

第二卷第十五章已经讲过资本释放和资本束缚，第六章在利润率层面继续展开。

## 存货价格变动

价格变动不仅影响未来生产，也影响已有存货。

假设资本家已经买入一批原料。

如果买入后市场价格上涨，他手里的存货升值。

如果买入后市场价格下跌，他手里的存货贬值。

这会带来账面收益或损失。

现代公司中，类似情况包括：

- 囤积 GPU 后价格上涨或下跌；
- 预购云资源后市场降价；
- 买入数据版权后同类数据变便宜；
- 采购模型服务长约后现货价格下降；
- 大量库存硬件被新芯片淘汰。

这种收益或损失不一定来自生产过程。

它可能来自市场价格变动。

资本家会把它算进利润或亏损，但马克思要区分：这不是剩余价值生产本身，而是资本价值重估。

## 资本价值增减

马克思讨论价格变动时，经常讲资本价值的增减。

如果生产资料价格上涨，已经拥有这些生产资料的资本家可能获益。

因为他的存货或设备按新价格看更值钱。

但需要重新购买生产资料的资本家会受损。

如果价格下降，情况反过来。

已经持有高价存货的人受损。

新进入者或需要补充原料的人受益。

比如 AI 公司在 GPU 高价时大量购买。

如果后来 GPU 租赁价格暴跌，旧投资会承压。

如果公司没有购买，而是按需租用，就可能享受降价好处。

这就是固定资本和流动资本在价格变化中的不同风险。

## 固定资本的重估风险

固定资本特别容易受技术和价格变化影响。

一台 GPU 还没坏，但新一代芯片出现后，旧 GPU 的市场价值可能下降。

这就是无形磨损。

第六章关注价格变动，和前面固定资本折旧问题紧密相连。

假设设备原拟用 5 年逐步收回购价，第 2 年就因新设备出现而落后了。尚未收回的是当初垫付的设备价值；旧设备贬值，意味着余下的购价可能无法按原计划收回，不是说这两年工人少创造了剩余价值。

AI 行业技术迭代快，因此固定资本重估风险很高。

这解释了为什么很多公司选择云服务而不是自建算力：

它们宁愿支付较高的流动成本，也不愿承担固定资本快速贬值风险。

## 原料价格波动和危机

原料价格剧烈波动会造成危机。

价格上涨时：

- 成本上升；
- 资金需求增加；
- 利润率下降；
- 小资本被挤出；
- 企业提高售价；
- 下游需求受压。

价格下跌时：

- 存货贬值；
- 高价采购者亏损；
- 债务压力暴露；
- 新资本进入；
- 价格战加剧。

在 AI 行业中，如果算力价格剧烈波动，也会产生类似效果。

比如一轮 GPU 短缺导致训练和推理成本暴涨，许多应用公司模型无法成立。

随后供给增加和模型效率提升导致价格下降，早期高价投入者面临资产贬值，新进入者成本更低。

价格波动改变竞争格局。

## 生产资料价格和社会劳动生产率

生产资料价格下降，常常来自劳动生产率提高。

比如芯片制造更先进，单位算力成本下降。

模型推理优化，让单位 token 成本下降。

云基础设施规模扩大，让存储和计算降价。

这会降低不变资本价值。

资本家可能因此提高利润率。

但如果这种技术进步普及到全行业，商品价格也可能下降，超额利润消失。

单个资本家先采用低成本技术时，可以暂时获得优势。

全行业采用后，新的社会必要劳动时间形成，利润率结构重新调整。

这说明技术降本既是竞争优势，也是竞争压力。

## 工资价格变化

虽然本章重点是生产资料价格，但工资变化也影响利润率。

工资上涨，在其他条件不变时，会减少剩余价值。

工资下降，则可能增加剩余价值。

但工资不是普通价格。

工资关系到劳动力再生产。

如果工资长期低于劳动力价值，劳动者健康、技能、家庭和社会再生产都会受损。

现代平台劳动中，低价接单、无保障外包、算法压价，短期可能降低资本成本，长期会造成劳动者耗竭和质量下降。

资本账本上看到的是成本下降。

社会再生产层面看到的是劳动力损耗。

## 汇率和全球供应链

现代价格变动还包括汇率和全球供应链。

AI 公司可能：

- 用美元支付云服务；
- 从海外买 GPU；
- 面向全球客户收费；
- 雇佣跨国团队；
- 使用海外 API；
- 受国际制裁和出口管制影响。

汇率变化会改变成本和收入。

供应链限制会改变生产资料可得性。

这扩展了马克思所说的价格变动问题。

资本不是在本地封闭环境中运动，而是在世界市场中不断重估。

## 对 AI 开发者的理解抓手

你可以把第六章转化为商业风险检查表：

- 上游模型 API 会不会涨价？
- 云资源是否被单一供应商控制？
- GPU 是买还是租？
- 数据授权价格是否稳定？
- 是否有缓存和模型替代方案？
- 合同能否把成本变化传导给客户？
- 是否有长期资源合约？
- 是否会因技术迭代造成资产贬值？
- 是否有供应商锁定风险？

这些问题决定利润率稳定性。

技术上能跑通，不等于资本上能持续。

如果成本价格随上游波动剧烈，产品商业模式就很脆弱。

## 本章的核心结论

第六章的核心是：价格变动会改变成本价格、资本价值和利润率。

可以总结为：

```text
生产资料涨价 -> 成本上升、追加资本需求、利润率受压；
生产资料降价 -> 成本下降、资本释放、利润率可能上升；
存货和固定资本会因价格变化发生价值增减；
这些收益或损失不一定来自剩余价值生产，而可能来自资本重估。
```

对 AI 和软件行业来说，这章解释了：

- 为什么上游 API 和云成本决定应用公司利润率；
- 为什么 GPU 自建有重估和无形磨损风险；
- 为什么模型降价会重塑竞争格局；
- 为什么技术进步既带来降本，也带来价格战；
- 为什么商业模式必须考虑成本波动，而不只是功能可行。
