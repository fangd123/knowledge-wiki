# 阅读路径建议

《资本论》三卷加起来近百章，不是每个人都需要、也不是每次都适合从头读到尾。这里给三条路径：完整路径适合系统学习，快速路径适合第一次读、想先抓住主线，专题路径适合带着具体问题来查。

在开始之前，建议先读 [读《资本论》总觉得别扭？真不是你的水平问题](读《资本论》总觉得别扭？真不是你的水平问题.md) 和 [剥洋葱读句法](剥洋葱读句法.md)——它们不讲内容，只讲怎么啃长难句，对后面所有路径都有用。

## 完整路径

按原书顺序，三卷各自的目录页里已经按"篇"分组：

1. [第一卷：资本的生产过程](《资本论》辅助阅读/26-《资本论》第一卷通俗讲解阅读目录.md)（25 章）
2. [第二卷：资本的流通过程](《资本论》辅助阅读/48-《资本论》第二卷通俗讲解阅读目录.md)（21 章）
3. [第三卷：资本主义生产的总过程](《资本论》辅助阅读/101-《资本论》第三卷通俗讲解阅读目录.md)（52 章）

三卷的论证是递进的：第一卷说明剩余价值怎样在生产中产生，第二卷说明资本怎样循环、周转并在社会总资本层面再生产，第三卷说明剩余价值怎样在现实竞争中表现为利润、平均利润、利息、地租，把生产过程中的真实关系一层层"遮蔽"成市场表象。按顺序读，这条从本质到表象的线索最完整。

## 快速路径：第一次读怎么跳

如果是第一次接触，建议先抓主线，跳过历史考证和公式演算较密的章节，读完主线后再回头补细节。

**第一卷主线**（13 章）：
[第一章：商品](《资本论》辅助阅读/01-《资本论》第一卷第一章：商品.md) → [第四章：货币转化为资本](《资本论》辅助阅读/04-《资本论》第一卷第四章：货币转化为资本.md) → [第五章：劳动过程和价值增殖过程](《资本论》辅助阅读/05-《资本论》第一卷第五章：劳动过程和价值增殖过程.md) → [第六章：不变资本和可变资本](《资本论》辅助阅读/06-《资本论》第一卷第六章：不变资本和可变资本.md) → [第七章：剩余价值率](《资本论》辅助阅读/07-《资本论》第一卷第七章：剩余价值率.md) → [第八章：工作日](《资本论》辅助阅读/08-《资本论》第一卷第八章：工作日.md) → [第十章：相对剩余价值的概念](《资本论》辅助阅读/10-《资本论》第一卷第十章：相对剩余价值的概念.md) → [第十三章：机器和大工业](《资本论》辅助阅读/13-《资本论》第一卷第十三章：机器和大工业.md) → [第十七章：劳动力的价值或价格转化为工资](《资本论》辅助阅读/17-《资本论》第一卷第十七章：劳动力的价值或价格转化为工资.md) → [第二十一章：简单再生产](《资本论》辅助阅读/21-《资本论》第一卷第二十一章：简单再生产.md) → [第二十二章：剩余价值转化为资本](《资本论》辅助阅读/22-《资本论》第一卷第二十二章：剩余价值转化为资本.md) → [第二十三章：资本主义积累的一般规律](《资本论》辅助阅读/23-《资本论》第一卷第二十三章：资本主义积累的一般规律.md) → [第二十四章：所谓原始积累](《资本论》辅助阅读/24-《资本论》第一卷第二十四章：所谓原始积累.md)

跳过的部分：第二、三章（交换过程、货币职能细节）、第九章（剩余价值率和量的公式重复）、第十一、十二章（协作与工场手工业的历史细节）、第十四至十六章（公式整理）、第十八至二十章（工资形式细节）、第二十五章（殖民理论）——这些补充和深化主线，但不影响先把主线读完。

**第二卷主线**（4 章）：
[第一章：货币资本的循环](《资本论》辅助阅读/27-《资本论》第二卷第一章：货币资本的循环.md) → [第四章：循环过程的三个公式](《资本论》辅助阅读/30-《资本论》第二卷第四章：循环过程的三个公式.md) → [第八章：固定资本和流动资本](《资本论》辅助阅读/34-《资本论》第二卷第八章：固定资本和流动资本.md) → [第二十章：简单再生产](《资本论》辅助阅读/46-《资本论》第二卷第二十章：简单再生产.md)

**第三卷主线**（10 章）：
[第一章：成本价格和利润](《资本论》辅助阅读/49-《资本论》第三卷第一章：成本价格和利润.md) → [第二章：利润率](《资本论》辅助阅读/50-《资本论》第三卷第二章：利润率.md) → [第九章：一般利润率的形成和商品价值转化为生产价格](《资本论》辅助阅读/57-《资本论》第三卷第九章：一般利润率的形成和商品价值转化为生产价格.md) → [第十三章：规律本身](《资本论》辅助阅读/61-《资本论》第三卷第十三章：规律本身.md) → [第二十一章：生息资本](《资本论》辅助阅读/69-《资本论》第三卷第二十一章：生息资本.md) → [第二十五章：信用和虚拟资本](《资本论》辅助阅读/73-《资本论》第三卷第二十五章：信用和虚拟资本.md) → [第三十八章：级差地租。总论](《资本论》辅助阅读/86-《资本论》第三卷第三十八章：级差地租。总论.md) → [第四十五章：绝对地租](《资本论》辅助阅读/93-《资本论》第三卷第四十五章：绝对地租.md) → [第四十八章：三位一体的公式](《资本论》辅助阅读/96-《资本论》第三卷第四十八章：三位一体的公式.md) → [第五十二章：阶级](《资本论》辅助阅读/100-《资本论》第三卷第五十二章：阶级.md)

读完这 27 章的主线，再回头按目录页补第一卷的工资细节、第二卷的周转理论史、第三卷的地租各形式和信用制度部分，会更有耐心，因为已经知道这些细节服务于哪条主线。

## 专题路径：带着问题来查

**只关心金融、信用与危机**：[第三卷第二十一章：生息资本](《资本论》辅助阅读/69-《资本论》第三卷第二十一章：生息资本.md) 到 [第三十六章：资本主义以前的状态](《资本论》辅助阅读/84-《资本论》第三卷第三十六章：资本主义以前的状态.md)，即第三卷第五篇整篇。核心是生息资本、利息、信用、虚拟资本、银行资本、货币资本和现实资本的错位，以及危机怎样在这套信用结构里酝酿和爆发。

**只关心平台经济与劳动关系**：[第一卷第四章：货币转化为资本](《资本论》辅助阅读/04-《资本论》第一卷第四章：货币转化为资本.md) 到 [第一卷第十三章：机器和大工业](《资本论》辅助阅读/13-《资本论》第一卷第十三章：机器和大工业.md)（剩余价值怎样在生产中产生），加上 [第一卷第二十三章：资本主义积累的一般规律](《资本论》辅助阅读/23-《资本论》第一卷第二十三章：资本主义积累的一般规律.md)（相对过剩人口），再加上 [第三卷第十六章：商品经营资本](《资本论》辅助阅读/64-《资本论》第三卷第十六章：商品经营资本.md) 到 [第二十章：关于商人资本的历史考察](《资本论》辅助阅读/68-《资本论》第三卷第二十章：关于商人资本的历史考察.md)（商业资本怎样通过渠道和入口分享剩余价值，可以类比平台抽成）。

**只关心地租、房产与资源类资产**：[第三卷第三十七章：导言](《资本论》辅助阅读/85-《资本论》第三卷第三十七章：导言.md) 到 [第四十七章：资本主义地租的发生](《资本论》辅助阅读/95-《资本论》第三卷第四十七章：资本主义地租的发生.md)，即第三卷第六篇整篇。读的时候注意查对应章节里"类比的边界"提示——级差地租、绝对地租的机制和平台、云资源、数据中心的类比容易过度延伸，边界要看清楚。

**只关心分配问题、收入正义**：[第三卷第四十八章：三位一体的公式](《资本论》辅助阅读/96-《资本论》第三卷第四十八章：三位一体的公式.md) 到 [第五十二章：阶级](《资本论》辅助阅读/100-《资本论》第三卷第五十二章：阶级.md)，即第三卷第七篇整篇。这是全书对"利润、利息、地租、工资从哪里来"的总收束。

**只想学会怎么读懂长难句**：[读《资本论》总觉得别扭？真不是你的水平问题](读《资本论》总觉得别扭？真不是你的水平问题.md) 和 [剥洋葱读句法](剥洋葱读句法.md)，外加 [术语表](《资本论》核心术语表.md) 备查。
