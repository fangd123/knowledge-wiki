# Qwen 独立复核：处理结果与统一决策

日期：2026 年 11 月 17 日。把这篇与[原始评审](48-FormFill_研究包独立评审（qwen4-max-preview）.md)并排读，能看见两种不同的修改：一种是采纳建议，另一种是找到更好的证据后保留原事实。两者都不是用户访谈、交易或验证产品效果。

## 当日达成的六项决策

1. 通用首页保留“把已有资料，填进网页表单”。合作伙伴登记是候选；它和同页多记录要分别核实任务频率、替代与预算。
2. 合成技术试验和真实业务试用分开。真实资料试用之前先有可信的获取与数据说明、填前预览、原值保护与有限撤销。多记录先验主体隔离。
3. 保存结构对应不要求先实现完整的 Word 来源追踪；前者需可靠的源列、目标字段和变更时停用，后者要有实际核对收益。
4. 699 元只是假设的限定适配报价，多记录不通过防串填验收就不收款。199 元年费撤回。旧研究按 MIT 讨论收费；[冻结时盘点](22-FormFill_产品收尾与交接报告.md)未见根许可证，具体版本授权和贡献者权属不能据此确定，既有授权如已成立不因新服务定价撤回。
5. 第 30／60／90 天只用来复盘；决定能否进入下一阶段的是验收，而非日历。
6. 中文试点要核实真实可达渠道及当日规则，英文社区只作为技术反馈的一条路，不替买家表态。

## F1–F10 怎么处理

| 发现 | 对照与处理 | 状态 |
|---|---|---|
| F1 首页定位冲突 | 对照 README/网站审计与产品/定价报告，确认通用版与合作伙伴版并存；后两份已改通用主句，候选文案保留实验身份。网站源码从未实施旧建议，不能称线上定位已变 | 采纳并修订 |
| F2 预览/撤销优先级冲突 | 确认网站审计旧 P2-01 写“先验证需求再做”；改为 P1-07，和功能 A2/A3、执行 F03/F04 对齐；有限 DOM 撤销不承诺撤回网站服务器自动保存 | 采纳并修订 |
| F3 ¥699 价值单元缺口 | 区分同页多记录与同资料多网页；多记录服务明确选记录/防串填为收款前置；相似记录纳入验收；每个约定表单的范围和工时上限书面化 | 采纳并修订 |
| F4 首月负担过大 | 确认阶段清单与复杂度缺乏可核算的工时关系；改阶段门槛与复盘点。未采纳“单人一定 30 天做不完”的定量断言：当前工时/可投入时间同样未知 | 采纳排期改法，限定判断强度 |
| F5 客群选择缺少替代对照 | 增加两类候选任务，首先检查原生导入/API/规则工具是否足够；原生或规则足够时不强推 AI。保留合成技术任务集，补早期同任务比较 | 采纳并修订 |
| F6 中文客群/英文渠道不对齐及仓库入口 | 计划加入 1–2 个中文候选渠道的当日规则核验；英文反馈不代替买家。当时一次匿名读取旧托管页 返回 403；只记录该次失败，不能断言所有用户不可访问。匿名浏览器/目标用户验收和必要 Release/镜像列 W02 前置 | 采纳；仅记录当次失败 |
| F7 ¥199 无成本依据 | 从 README/产品策略当前价格建议撤下；定价与计划标为待定，历史数字只解释已撤回的假设 | 采纳并修订 |
| F8 BYOK/Office 容易被当独有 | 原正文已明确已有同类；保留并在摘要突出“不是独家优势”，不把这条算成发现虚假产品事实 | 强化已有边界 |
| F9 HN 快照正文指向 | 确认 strategy 快照中失败条目不能作正文证据；原研究改引实际读到的指南正文，不再以失败元数据充数 | 采纳并补链 |
| F10 FillApp 500 credits 与 $14.99 的证据保存不足 | 接受证据可审计性问题，但不直接删正确事实。重新 GET 官方页并保存 HTML：Monthly/500 credits 两个按钮均 `aria-pressed="true"`，可见价格 $14.99/month，标明 Billed monthly。根据当时的选中状态保留展示价；未结账、未推其他档价 | 补证后保留事实 |

F6 与 F10 尤其值得区分。匿名请求返回 403，不能直接写成所有人都无法访问；2026 年 11 月 17 日复查的 [FillApp 官方定价页](https://fillapp.ai/pricing)同时选中 “Monthly” 和 “500 credits”，显示 “$14.99 / month”“Billed monthly”。据此只认当日展示，没结账、没核其他档价，也不能把每 credit 换成一次填表。原始整页 HTML 不随文附发。F9 涉及的是当时可读的[HN 指南](https://news.ycombinator.com/newsguidelines.html)，不是一次获取失败的记录。

## 计划一致，不能冒充已经做完

[执行计划](46-FormFill_网站、功能、宣传与_SEO_执行计划.md)把意见落实为网站、功能、市场、SEO 四组任务；[定向复核](49-执行计划定向一致性复核（qwen4-max-preview）.md)的十一项检查同意它可作为下一阶段基线。审查者接受了对单人工期判断的限缩，也在核读价页补证后撤回降格建议。

当时报告记录：63 份 JSON 可解析，19 篇 Markdown 中 83 条相对链接有效，40 行词表的缺失指标被保留，26 个任务编号未重复。它们是文档检查，不是新跑的扩展测试；没有改业务代码、部署、上架、访问客户或取得真实市场证据。项目后来的结果以冻结交接为准。
