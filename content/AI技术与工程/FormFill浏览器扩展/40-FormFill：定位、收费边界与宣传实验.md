# FormFill：定位、收费边界与宣传实验

2026 年 11 月 17 日讨论收费时，没有一个人在 FormFill 上付过款。这里保留的是一个问题：用户究竟是为软件本身付钱，还是为“有人把这个表配好，并在约定范围内管用”付钱？当时审阅的是[研究总报告](35-FormFill_全面评估：网站、竞品、市场表现、产品策略与_SEO.md)及其中的[竞品](36-FormFill_竞品与同名品牌核查.md)、[社区](47-FormFill_社区发布案例研究与英文草稿.md)与[搜索研究](44-FormFill_SEO、关键词与获客研究.md)，不是销售台账。次日[停止产品化](22-FormFill_产品收尾与交接报告.md)，没有成交、录制所拟广告或投放。

## 1. 对照两类工作流，再选择客群、渠道与收入

**候选 A：同一套公司资料，从 `.xlsx`/`.docx` 录入多个合作伙伴的登记网页。候选 B：同一业务网页反复录入多条结构化记录。** 每次由人核对并提交。先研究可用合成资料复现的任务；目标用户有可用模型 API 或团队配置能力。先检查原生 CSV 导入/API 与规则工具是否已经满足，再判断语义映射是否有增量价值。

两者都是假设，尚无访谈证明频率和预算。A 的资料入口匹配但单个网页可能只填一次；B 便于摊薄同站映射成本，但规则工具可能更好。分开记录同一资料的目标网页数量、同一网页的记录数量与发生时间，不用“经常填表”混合二者。试点使用范围按已验证能力确定，不承诺企业级能力。

| 环节 | 围绕候选工作流的验证 |
|---|---|
| 价值主张 | 已有公司资料 → 当前网页字段，减少逐字段复制；由用户选模型，填写后人工核对。节省幅度待实测 |
| 首批获客 | 经允许的中文运营/效率工具交流、Gitee 问题讨论，以及“Excel/Word 资料填网页”的实操搜索；招募确实做此任务的人。开发者社区用于安装和兼容反馈，不能代替买家需求 |
| 产品重心 | 先做到一份明确资料受控填入当前表单；多记录任务必须先选人/公司并防串填，再验证同站映射复用；完整来源追溯按检查收益决定，不先做全自动跨站提交 |
| 收入路径 | 免费自行使用；对反复遇到同类问题的客户，开发并交付指定资料模板 + 指定网页的适配和验收说明 |
| 暂不主攻 | 求职自动投递、家庭医疗资料、PDF/OCR 全能工具、联系人外联机器人；这些会引入不同竞争、风险和交付范围 |

优势应表述为**适合这一工作流的能力组合与可验证服务**，而不是已有技术壁垒。现在没有证据证明 FormFill 比所有同类更快、更准或更隐私。

## 2. 真正的竞争压力：免费的替代已经存在

以下均为 **2026-11-17 直接读取的一手公开页面**，功能是厂商宣称，未安装实测、结账或核验服务条款执行。官网标价不是实际收入，也不能直接比较成每次填表成本。

| 产品 / 官方来源 | 本轮可确认的价格与范围 | 对 FormFill 的商业含义 |
|---|---|---|
| [FillApp pricing](https://fillapp.ai/pricing) | 起始 20 免费 credits；按需 $0.10/credit、$5 起购；默认选中 500 credits/月、$14.99/月、按月计费。页面另有 1,000 credits 和年付选择，未操作切换取得对应价格。购买 credits 包含全部功能和模型 | 它卖包含模型的工具/任务消耗。FormFill 用户另付 API 费，不能把相同订阅标价说成更便宜。credit 不等于一次表单，不计算虚假单次价 |
| [Text Blaze plans](https://blaze.today/plans/) | Free 永久免费、有限 snippets；Pro $3.49/月，或 $2.99/月按年付（$35.88/年）；Business $8.39/用户/月，或 $6.99/用户/月按年付（$83.88/用户/年）；Enterprise 询价。年总额为月展示价×12 | 固定文字和规则重复使用有廉价成熟替代。FormFill 应验证异构网页与资料语义匹配的价值，不能把普通模板包装成昂贵 AI 独有功能 |
| [FastFiller 官网](https://fastfiller.aeigs.com/)、[GitHub](https://github.com/mauryaankur99/FastFiller)、[MIT LICENSE](https://github.com/mauryaankur99/FastFiller/blob/main/LICENSE) | 官网称无订阅、无填表次数限制；BYOK、浏览器会话、本地 Ollama；预填审核、撤销、多资料档案均有公开说明。仓库确有 MIT 许可；本轮未验证安装和兼容效果，也不采信“模型零成本”“任意网页”等绝对承诺 | **免费 + MIT + BYOK + 无自有中间服务器已是直接替代。** 预览/撤销也是免费竞品的基础能力，不适合作为主要收费墙 |
| [ExcelToForm 新入口](https://exceltoform.com/new/)、[Formly 中文页](https://www.exceltoform.com/zh/formly/) | Classic 手动匹配表头、全本地；Formly 宣传 PDF/Word/Excel/CSV/图片语义填表、多人表格选记录，每月 10 次免费，更多需付费。本轮两个指定页面未显示付费金额；Classic/Automation 的收费金额亦未知 | “Office 文档→网页”并非独有；多记录选择也不是无人做过。纯结构化、字段固定时，应承认本地规则工具可能更适合 |

相对浏览器地址 autofill，当前区别在于临时文字/文件到业务字段；相对 Text Blaze，区别在于不先为每种内容手工建立 snippet 才做语义映射。相对 FastFiller/Formly，**当前证据不足以断言功能更强**。可争取的选择理由是中文资料的具体演示、清楚的数据流、易排查的配置，以及经开发和验收的指定任务兼容性。中英 UI、GBK 回退、Office 解析是已实现事实，不等于中文场景准确率优势。

## 699 元买的是哪一次交付？（未报价）

当时的软件策略是免费自用，远程模型另由用户承担费用；本品不销售模型额度。基础预览、已有值保护、撤销和隐私控制属于正确录入的条件，不应拿来收费解锁。候选服务则限定一个资料模板、一个约定网页、最多 20 个普通字段与一种浏览器/扩展/模型组合，含合成验收样例、说明、一次不超过 60 分钟的配置指导、验收后 14 天内范围内的缺陷修正。不含新页面、改版、无限扩展或自动续费。后来[方向重估](54-FormFill_产品原点与场景方向重估.md)把字段计数和复用证据分得更细。

如果卖“同一页面、换不同记录”，选记录、防串填和重做时的检查就是验收；如果卖“一份资料去不同网页”，每个网页的配置都可能重新花钱。免费规则工具已能处理部分固定表格，不能只凭工资折算或一次模型成功就定价。曾拟向 3–5 名符合条件的买家报同范围价格，对实付、拒绝、复用及支持工时分别计数；没有执行。原 199 元年费因缺持续工时与需求依据撤回。一次适配有人买也不证明年费或软件订阅有人买。

旧研究沿用 MIT 说法；冻结盘点未见根许可证，需要核对具体版本的原有授权及贡献者权属。如有已成立的许可，服务报价不能追溯撤销它；新服务收的是实施、验收与有限支持，不是对原代码再分发权作裁决。

## 6. 经济约束：先测工时，再谈利润或 ROI

**下面是可填入真实数据的公式，不是已经测得的成本或收益。**

```text
用户单任务净收益 = (手工总分钟 − 工具操作/核对/纠错总分钟) ÷ 60 × 用户认可的时间价值
                 − API 实际费用 − 分摊的交付费用
单笔交付贡献 = 实收款 − 支付/退款/税费 − 实际开发与支持工时 × 内部小时成本 − 其他直接成本
维护周期贡献 = 维护收入 − Σ(网站变更次数 × 单次修复工时 × 小时成本) − 发布/支持成本
获客成本 = 同口径现金与可归属获客工时成本 ÷ 新增实付客户数
可用交付工时 = (报价 − 税费/支付/退款准备 − 其他直接成本 − 目标贡献) ÷ 内部小时成本
```

时间价值由用户提供，不能把工资换算一律当能兑现的现金节省。API 费用读供应商账单并记录模型、请求大小、重试，不用竞品 credit 作代替。收入周期与成本周期一致；没有付款客户时 CAC 无法计算，不能报零。没有持续收入与留存数据时不报 LTV 或回本周期。

## 文案与分镜：留下的是设计，不是样片

当时拟的中文主句是“把已有资料，填进网页表单”，英文是 *Fill web forms from the information you already have.* 这句话没有经过投放测试。60 秒分镜同样没有录成广告：前 8 秒让合成公司资料与登记表同框；8–18 秒交代预先配置和费用；18–35 秒展示实际等待（如加速须明示）；35–49 秒留给人逐项核对；末 11 秒问“你的下一张登记表，哪些字段仍需手改？”剪辑时长不是完成任意任务的耗时。只有用同一任务算上检查、纠错和模型费，才能谈净收益。

当时读取 [FillApp 官方价页](https://fillapp.ai/pricing)，月付与 500 credits 被选中，显示“$14.99 / month”；没有结账或切换其他档位。[HN 官方指南](https://news.ycombinator.com/newsguidelines.html)当日反对发布生成文本，因此不拿上面的英文主句当实际帖子。本站不分发两份整页 HTML；当时的展示不能证明交易，也不是再发布第三方页面的授权。试验如何被限定，见[处理记录](50-Qwen_独立复核：处理结果与统一决策.md)和[执行计划](46-FormFill_网站、功能、宣传与_SEO_执行计划.md)。
