# [历史] 0.2.0 发布前检查清单

> **冻结状态（2026-11-18）：FormFill 已停止产品化，本清单不再执行。** 项目未发布 0.2.0、未上架任何商店、未部署正式网站。以下复选框只用于区分冻结前的历史结果，不是待办。总决策见[产品收尾与交接报告](22-FormFill_产品收尾与交接报告.md)。

本清单汇总冻结前散落的发布准备事项，保留为审计记录。`[x]` 表示当时有本地证据；`[已取消]` 表示冻结时未完成且已停止，不表示失败或等待继续。

## 冻结时的版本与材料状态

- **既成事实：** `package.json` 与 WXT 构建保持 `0.1.0`；0.2.0 从未发布，版本号不再 bump。
- **既成事实：** Chrome Web Store 与 Microsoft Edge Add-ons 的材料未提交；原定主渠道及 A/B 语言介绍仅保留在历史草案中。
- **既成事实：** 商店权限理由与数据使用申报未提交；冻结前文档记录了 storage、activeTab、内容脚本和 BYOK 数据边界。
- **既成事实：** 未发布“更新后刷新网页”的商店版本说明；技术文档继续保留该兼容提示。

## 冻结时未完成的网站与 SEO 事项（历史）

- [x] 静态预渲染：四页直读 HTML 含主文案与链接，React 挂载整体替换且无重复（S02，docs/execution/s02-prerender-check.json）。
- [x] robots.txt 在本地构建中存在并允许抓取，未写入虚构 Sitemap 行。
- [已取消] canonical、真实 404、sitemap、OG、线上逐页和移动检查；无生产域名，冻结后不再执行。
- [已取消] GSC 验证、关键词 SERP/Ads 采样、线上搜索观测和内容迭代；冻结后不再执行。
- [x] 本地断点布局和可访问性检查有历史证据；它们从未被当作线上表现。

## 冻结时的真实环境覆盖

- [x] Playwright Chromium 加载构建扩展并完成真实弹窗 UI 全链路 E2E（配置/连接/导入/预览/应用/撤销）。（w05-browser-e2e.json）
- [x] 映射保存、换记录免模型复用和已有值保护通过同轮浏览器验证。（w05-mapping-probe.json）
- **冻结时未验证：** 真实工具栏 activeTab 授权时序与跨站点 origin 隔离；相关验证计划已取消。
- **冻结时未验证：** 品牌版 Chrome 137+ 手动加载路径；相关验证计划已取消。
- **冻结时未验证：** 单选/复选建议的真实业务浏览器覆盖和真实 SDK fetch 底层 abort 时序；相关验证计划已取消。

## 冻结前的已知打磨项（历史，不再处理）

- 取消竞态极窄窗口：handleFill 用递增 requestId 守卫旧响应（F02 D3，无功能损害；D2 迟到预览已修复）。
- 测试连接与 propose 错误文案结构略不同，可统一 describeError 复用（F02 D5）。
- radio 组撤销恢复仅对 checked 项派发事件；undo 时元素已被页面移除仍计 restored；radio 预览显示 value 而非 label（F03-F04 残留备注）。
- select 真实选项 value 本身为空的罕见情况会被占位启发式误判（W05 浏览器轮 D1，启发式固有局限）。

## 冻结前的发布决策门槛（历史，不再执行）

- 付费渠道实验（M05）：仅在获取→配置→首次价值可用、有明确付费口径与基线后评估；冻结后不再开展。
- 英文核心页（W07）：原计划明确海外试点后再建完整 `/en/`；冻结后不建。
- F07/F08：原计划需真实需求证据再扩范围；冻结后不立项。
- M01 访谈：原计划验证真实自愿用户、任务频率与付费；冻结后不招募用户，不把点赞或预约当作使用或支付证据。
