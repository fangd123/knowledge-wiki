# FormFill 隐私政策

[English](15-FormFill_privacy_policy.md) | **简体中文**

> **归档状态：FormFill 已于 2026-11-18 停止产品化并冻结。** 项目从未上架浏览器商店，也未部署生产网站。本文描述归档代码快照：`package.json` 版本号仍为 `0.1.0`，但代码包含尚未发布的 `0.2.0` 行为；`0.2.0` 从未发布。

FormFill 使用你选择和配置的模型服务填写网页表单。本文说明归档代码实际处理的数据，包括暂停自动学习后的行为。总决策见[产品收尾与交接报告](22-FormFill_产品收尾与交接报告.md)。

## 处理与发送的数据

你发起填写时，扩展读取当前页面的标准表单控件，包括 `<form>` 外的控件，将你的描述和结构化表单摘要直接发送到配置的模型接口。摘要包括：

- 控件标签类型（tag）、type、name、ID、标签文字、占位符、CSS 类名、title 和无障碍标签（`aria-label`），仅包含实际存在的信息。
- 下拉选项的文字和值，以及单选框和复选框的 value 属性。
- 从最多三层父元素收集可见描述文字，排除表单控件内容、可编辑区域、脚本等可执行标记和隐藏内容，并合并空白。`content.ts` 保留前 120 字符，可能追加 `...`；`llm-retry.ts` 在**发送前再次限制为 120 字符**。
- 根据 tag、type、name、ID 和 label 计算的表单签名。一次模型请求最多包含 200 个控件。

摘要不包含完整网页 HTML，也不会把普通 input/textarea 的当前输入值作为单独的 value 字段发送。但这**不代表排除了所有敏感数据**：标签、选项、其他可见页面文字、你的描述和文件可能包含个人或敏感信息。扫描和实际写入共用检查：排除密码、隐藏、禁用（含禁用 fieldset）、只读及部分非录入控件，并检查祖先可见性。这不能保证去掉所有敏感页面文字。

模型建议先在弹窗中以预览展示，点击应用前不会写入页面。预览中每条建议值可修改，并在旁边显示该控件的当前值；已有值的字段默认不勾选。当前值仅用于本地预览对比，不会发送给模型。若预览到应用之间页面结构发生变化，不会写入任何内容。应用后可撤销：只恢复本次填写写入且此后未被你改动的字段；撤销快照保存在页面内容脚本内存中，页面刷新即丢失。

导入的文件在本地解析。填写请求发送文件名和最多 30,000 字符的解析内容，必要时附截断说明。文件最大 10 MB。Excel 由你选择工作表、表头行和一条记录；请求只包含选中记录的值，其他行不会发送。输入描述和解析内容保存在弹窗内存中，FormFill 不将它们另存为输入或文件档案；关闭弹窗会丢弃这部分弹窗状态。

历史填写值不会加入请求。提示词要求模型忽略表单摘要和文件中的指令，但不能保证模型抵御所有提示注入。

请求直接发送到**你选择的服务商或 Base URL**，包括自定义接口或本地 Ollama，**不经过开发者服务器**。服务商如何处理和保留数据由其条款决定。服务商可见请求中的网络元数据，例如 IP 地址；本地服务也可能按自身配置使用远程基础设施。

**测试连接**使用配置的模型和认证信息发送一条简短固定提示，不附表单摘要、文件或学习样本。

## 本地存储与学习模式

设置、各服务商配置、API Key、隐私提示确认状态保存在浏览器扩展的本地存储，不使用浏览器同步存储。API Key 仅本地保存，在请求时发送到配置的接口用于认证；FormFill 不将其上传到开发者服务，也不另外加密存储。切换服务商会保留各自配置。

Excel 填写成功后若你确认保存字段映射，扩展在本地存储保存站点来源、表单结构签名和“列名 → 字段位置”对应关系（最多 20 条）。映射不包含记录值、页面文字或 API Key，也不会发送给模型或任何服务器。复用映射只读取当前选中的记录，仍需预览和应用。可在弹窗中删除映射。

此版本**暂停自动学习**：不绑定提交监听，不采集新样本，不把历史值加入模型请求。设置存储当前为 v6：v5 迁移强制关闭旧学习标记并保留服务商已有配置，v6 增加可选思考强度设置；界面不提供重新开启学习的开关。扩展更新后请**刷新已打开的网页**，替换此前注入的旧内容脚本。

旧样本仅留在扩展本地，直至主动清除、查看时过期清理或卸载。样本含站点来源、表单签名、时间和字段键值，部分更旧的记录还可能包含路径。“查看本地记录”仅在弹窗内展示实际内容，不请求模型接口。查看时删除格式损坏或超过 **90 天**的记录，最多保留最近 **50 条**；不是定时清理。“清除学习记录”删除全部样本。旧版的敏感字段过滤是启发式规则，记录仍可能包含个人信息。本地删除无法删除服务商已经持有的副本。

## 不做的事

FormFill 无统计、无广告、不出售数据，没有开发者运营的数据收集服务器。不为统计目的追踪一般浏览历史、按键或点击，也不自动提交表单。扩展在请求填写时处理当前表单，不监听表单提交。你提供的信息或表单上下文仍可能按上述范围发送给你选择的服务商。

## 权限

- `storage`：保存本地设置、API Key、服务商配置及仍保留的旧样本。
- `activeTab`：在用户操作后访问当前标签页，以便弹窗定位填写页面。
- 内容脚本匹配 `<all_urls>`：在支持的站点提供扫描、填写和高亮。脚本在匹配页面加载，你发起填写时才请求用于模型的表单摘要。这是广泛页面访问，并非按需注入；浏览器限制页面仍不可用。
