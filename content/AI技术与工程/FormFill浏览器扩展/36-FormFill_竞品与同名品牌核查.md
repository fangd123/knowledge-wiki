# FormFill 竞品与同名品牌核查

- 任务目录日期：2026-11-16；实际联网核验日期：**2026-11-17，Asia/Singapore**（按本次执行环境日期记录，未把实时结果回填为历史快照）。
- 范围：**8 个有一手产品页面的对标对象**，其中 3 个直接同类、5 个邻近替代；额外核查 2 个同名域名，其中一个只有营销页证据，另一个未完成正文核验，均不冒充已验证上架产品。
- 方法：先读取本仓库 README、网站 README 与 App.tsx，再通过公开 HTTPS 读取官网、隐私政策、定价页与 Chrome Web Store 正文；通过商店公开搜索页补齐产品身份。没有安装竞品、注册账户、输入真实个人信息、付费、发布或联系任何人。
- 证据等级：官网描述只能证明厂商如此宣传；商店条目可证明当时公开列出的产品身份、版本、评价和声明，不能证明实际填表成功率或隐私实现。下文“支持”默认指一手页面声明，不代表本次实测。
- 展示范围：首屏判断依据 HTML 正文、标题顺序、CTA 文字与链接、嵌入媒体结构，**未进行竞品页面的浏览器视觉截图核验**，不推断像素布局、动画质量或转化率。SEO 仅审阅页面与链接结构，不推断收录、排名、搜索量或流量。
- 所有原始 URL 均在对应产品段落列出。补充的 competitor-sources.json 保存成功读取页面的 HTTP 状态、最终 URL 和证据用途，便于父会话复核。没有把搜索摘要当全文证据。

父会话复核：已重读 FillApp、Text Blaze、formfill.cc、Filliny、Simplify 和同名 BYOK 网站的关键公开页面。另已通过合成数据复现本项目默认学习采集和附近文本问题，详见 `website-audit.md`。对比中“本地存储/无自有后端”只描述架构，不代表当前隐私行为已无缺陷。社区报告另有 FastFiller、Filler 等更接近早期产品的发布案例，不能因为它们不在本表就认为没有这类直接竞争。

后续市场调研更新：已补实 Bardeen 本体商店入口，并扩展为 13 个商店条目的同日指标快照，见 [插件分发与社区量化](42-插件分发、开源与社区量化：市场表现补充.md)。本文开头的“7 个条目”描述原研究阶段，不是后续核验总数；用户数、评分和市场指标以新报告所列来源时间为准。

## 1. 先确认本项目是什么

本项目是 **Chrome 网页表单自动填写扩展**：读取当前页面字段结构，将自然语言或资料文件与字段摘要交给用户配置的 HTTPS OpenAI 兼容接口，接收字段填写指令，再写入页面。定位不应扩张成 PDF 编辑器、表单生成器、简历平台或自动投递代理。

| 核实项 | 本次仓库证据 | 可以如何表述 |
|---|---|---|
| 产品身份 | `README.md`；`website/src/site-links.ts` | 源码仓库是 <项目归档仓库> 。本项目与下文任何同名官网、商店产品均未发现归属关系证据。 |
| 当前分发 | `website/README.md`；`website/src/site-links.ts` 的 `CWS_LISTING_URL = null` | 目前提供开发者模式构建与加载说明；不能把他人的 FormFill 商店链接填进安装按钮。 |
| 自然语言与文件 | `README.md`；`utils/file-parser.ts` | 真正可解析 `.xlsx`、`.docx`、`.txt`、`.md`；Excel 读取全部工作表；文本优先 UTF-8、失败回退 GBK。单文件上限 10MB，解析结果超 50,000 字符会截断。 |

| 兼容范围 | `README.md`；`entrypoints/content.ts` | 支持 open Shadow DOM 和脱离 form 标签的控件；不扫描 iframe，不能访问 closed Shadow DOM。不能承诺“任意网页都能填”。 |
| 网站 Demo | `website/README.md`；`website/src/App.tsx` | 默认是浏览器本地正则模拟器，并非真实模型推理或已安装扩展演示；可选后端接口尚不能当作默认生产能力。 |

本项目的可信切入点是：**把中文日常资料和 Office 文档搬进现有网页表单，让已有模型账户的用户选择服务商；同时把发送范围与本地历史说清楚。** 它目前的主要门槛是安装与模型配置，不是缺少“AI”字样。

## 3. 直接同类：产品与官网证据

### 3.1 formfill AI：formfill.cc，必须先解决的同名冲突

**身份与一手来源，均已读取正文：**

- 官网：https://www.formfill.cc/ — HTTP 200，标题为 formfill AI；首要卖点为识别字段、可复用模板、自定义说明与 AI 自动填写。
- 商店：https://chromewebstore.google.com/detail/formfill-ai/faepndggpldacododbleilmkbfedkkpo — HTTP 200；开发者为 `bajiaoshan621`，版本 0.1.1，更新日期 2025-12-28；说明要求登录 formfill.cc，可能受每日配额限制。
- 隐私：https://www.formfill.cc/extension/privacy-policy — HTTP 200；政策标注 2025-12-24，个人开发者联系人为 Ping Liang。

**定位与工作流。** 这是通用网页表单 AI 助手，使用侧边栏粘贴参考文本或套用模板，按当前页面字段生成映射，在用户确认后填写；商店说明明确触发 input/change，不自动提交。它与本项目在输入到字段匹配这一核心动作上高度重叠，但账户、后端和模板形态不同。

**门槛、文件、价格。** 需站点登录，商店明确配额可能存在；是否允许 BYOK、接受哪些文件、是否有付费计划和金额，已读页面没有证据。官网的免费安装 CTA 不能推导为免费无限调用。

**隐私。** 政策明确用户输入和页面字段数据发送到 `https://www.formfill.cc` 后端与模型提供方；还涉及当前页面 URL、配置和身份令牌。模板与配置保留到删除 / 卸载；默认不保留请求日志，但为安全 / 防滥用而保留时最长 12 个月。它与本项目“用户浏览器直接调用所选模型、不经自有后端”的路径有可描述的差别。

**首页、CTA、演示与证明。** HTML 是紧凑的价值主张 + 免费扩展按钮 + 三个功能块 + 隐私链接。安装按钮实际指向上述商店，不是占位。没有在已读首页发现交互 Demo、客户案例或可复核的成功率证据。商店当时显示 13 users 且无评分，这属于商店观察，不能解释为活跃用户或商业成效，更不是本项目数据。

**SEO 结构。** 已见首页、登录 / 注册、独立扩展隐私页；未在首页导航发现用途页、文件格式教程、比较页或知识库。不能据此断言站内不存在其他页面。

**借鉴。** 对比其真正可安装的入口、短上手步骤与字段映射工作流。本项目应在商店标题、网站 title、OG、仓库链接和支持联系中持续添加开发者身份或明确修饰词，避免只靠 FormFill 裸品牌词。

### 3.2 FillApp：最值得优先研究的直接产品与演示对象

**身份与一手来源，均已读取正文：**

- 官网：https://fillapp.ai/ — HTTP 200，定位涵盖网页填表、数据录入和浏览器任务。
- 商店：https://chromewebstore.google.com/detail/fillapp-ai-form-filler-da/mdoaagdccddnbjncalegjfemhnlijgbo — HTTP 200；版本 2.2.15，更新日期 2026-11-12，公开开发者为 FillApp。
- 价格：https://fillapp.ai/pricing — HTTP 200。
- 隐私：https://fillapp.ai/privacy-policy/ — HTTP 200，政策日期 2026-10-12。

**定位与场景。** Fill Mode 用短文本或 snippets 填网页 / 浏览器内 PDF；Assist Mode 从页面、PDF、图片取信息；Agent Mode 还可跨标签点击、输入、上传和提交。官网另列语音控制、定时任务、快捷操作、云端继续和 PDF 编辑。这些是其更宽的产品表面，不能移植成本项目现有能力。

**门槛、文件、价格。** 官网先引导加 Chrome，20 免费 credits、无需信用卡；价格页按 credits 购买或订阅，常规路径未要求自备模型 key。另有连接 ChatGPT / Claude 的方式，不等于接受任意 OpenAI 兼容 Base URL。官网明确可附文档填表；商店说明侧栏有文件附件并支持读取 PDF、图片；xlsx/docx 等具体格式没有在已读正文中得到完整白名单。价格页展示 $0.10/credit，购买从 $5 起；月订阅展示 $14.99/月，同时 DOM 包含 500 与 1,000 credits 选项，**未执行套餐切换，不把二者都归为该价格的确定权益**。

**隐私。** 商店简介强调在浏览器会话内操作，但完整政策明确账户、snippets 和聊天服务数据涉及其云服务；AI 上下文可送 OpenAI / Anthropic，连接外部助手时内容经 relay。普通聊天与恢复 checkpoint 通常在 14 天不活跃后过期，有效定时任务关联内容例外。手工 PDF 编辑可本地进行，但 AI 处理另有上传。不能照抄“浏览器里运行”成“全部数据不外传”。

**首页与 CTA。** 首屏直接告诉用户把表单填完、完成浏览器任务，并把 Chrome 安装与免费额度放在一起；随后具体展示“资料文档 → 联系人 / 活动字段”的产品过程。这比泛泛功能清单更接近本项目需要解释的核心动作。

**演示与真实证明。** 已读 DOM 含产品工作区演示和独立 iframe，分别承载语音、计划与快捷方式示意；本次没有实际操作这些 iframe，不能评价演示是否完整使用真实后端。商店条目可独立核对发布身份与评论入口。首页演示中的联系人、公司与任务内容是产品示例，不作为客户证明；商店简介也不能替代亲自安装测试。

**SEO 结构。** 页脚按产品、PDF 工具、具体表单、资源分组，有 W-9、W-4、1040、I-9、租房申请和提示词库等可见入口。已确认链接结构，未逐页验证正文。这说明它通过具体任务承接搜索需求；本项目应借鉴结构，不应以自己不支持的 PDF 编辑或税表能力建设页面。

### 3.3 Filliny：旧扩展与当前官网需要分开对待

- 商店：https://chromewebstore.google.com/detail/filliny-ai-form-filling-a/ijhjngflokdbhimpcjhgjkljlfjenjlg — HTTP 200；仍名为通用 AI 填表助手，关联 filliny.io；版本 1.5.0，更新日期 2026-03-18，开发者 GetMattered。
- 定价：https://filliny.io/pricing — HTTP 200，但可读内容只有 Loading 与公共页脚，**金额未知**。
- 隐私：https://filliny.io/legal/privacy — HTTP 200；标注 February 2026，运营者为 Ava Bagherzadeh，Vancouver。
- 安全：https://filliny.io/legal/security — HTTP 200。

**定位冲突。** 商店说明仍是注册 / 建资料、页面浮动按钮、一键理解各类网页表单；宣传多 profiles、逐站说明、mock-data Test Mode、字段高亮 Vision Mode 和语言风格控制。当前官网首屏已主推 ATS 评分、简历定制、找岗位、自动投递、面试准备与申请追踪。两个来源通过同一域名关联，但这不能证明旧扩展已经实现官网所有新功能。

**门槛、文件、价格。** 商店路径要求创建个人资料，当前官网入口是免费开始；没有要求用户 API key 的公开步骤。平台有上传简历、文档翻译与简历构建；旧扩展是否可导入 xlsx/docx/txt/md 未知。商店标记有应用内购买，无法由此推出具体费用。

**隐私。** 当前政策说明账户 / 职业资料和简历内容会存储，使用 Cloudflare D1；相关 AI 数据送 OpenRouter，PostHog 用于分析，Stripe 处理支付。与本项目无自有后端的路径不同。商店宣称跳过密码 / 信用卡字段、数据不用于训练等；本次未安装验证，不能把安全营销语视为独立审计结论。

**首页、CTA、演示、证明。** 当前首屏强调找工作的结果，免费开始 CTA 后是自动投递进度、简历分数、职业分析等模拟工作区。官网有姓名 / handle / 日期形式的用户评价，但本次未核验相应原帖或作者，不能当独立客户证据。商店存在评价入口，能验证扩展实体，不能验证官网的求职效果。

**SEO 结构。** 导航可见 Features、Pricing、Blog、FAQ；内容把产品分解为职位发现、ATS、简历、面试与跟踪等求职任务。对本项目最有价值的是“按任务讲清收益”，而不是跟进其完整求职平台范围。

**判断。** 可把旧扩展当字段理解与 profile 工作流的同类参考；当前平台作为“用户为什么可能选择更完整求职工具”的替代。不要简单写成一个仍只做通用填表的竞品。

## 4. 邻近替代：争夺同一份重复录入时间

### 4.1 Text Blaze：最值得借鉴的转化结构

**已读来源：** 官网 https://blaze.today/ ；价格 https://blaze.today/plans/ ；隐私 https://blaze.today/privacypolicy.html ；商店 https://chromewebstore.google.com/detail/text-blaze-templates-and/idgadaccgipmpannjkmfddolnnhmeklj 。四者均成功读取正文。

**产品与门槛。** 核心是保存 snippets、设置快捷键、在网页输入时展开，另有动态字段、公式、团队共享以及模拟点击 / 按键的 Autopilot。对稳定、频繁重复的内容，它是减少输入的可行替代；不应描述成默认用 LLM 将任意文档映射到整张表单。核心上手要求配置 snippets，已读流程不要求模型 key。未找到 Office 文件作为语义填表资料源的支持证据；Data Blaze 和表格内容功能不能等同 xlsx 文件导入。

**价格与隐私。** 免费档有限 snippets；Pro $2.99/月按年或 $3.49/月按月；Business $6.99/用户/月按年或 $8.39/月按月，Enterprise 询价。政策明确处理注册资料、snippets、购买与使用统计，并可能借服务商处理；不能称本地专用工具。

**首屏 / CTA。** 首要内容直说减少重复输入和错误，立即提供免费 Chrome 安装；另有 Dashboard 与预约演示入口。无需先理解底层自动化术语，即能判断是否值得试。

**演示 / 证明。** 页面按“安装 → 保存短语与快捷键 → 任意位置展开”解释工作流，并列动态模板、共享场景和评价。官网时间 / 金额节省是厂商的计算或营销，本研究不采用为独立事实；商店当时可读到 4.9 与约 1.9K ratings，是商店观察。官网声称的用户规模与节省时间未独立核验。

**SEO 结构。** 首页链接到文档、Marketplace、功能文档、行业 / 职能方案、博客、价格与隐私。适合借鉴“功能说明 + 具体职能用途 + 可复制示例”的层级。本项目可先做活动报名、供应商登记、客户资料录入等少量真实用途，避免堆砌空泛行业页。

### 4.2 RoboForm：结构化身份资料与密码管理替代

**已读来源：** 官网 https://www.roboform.com/ ；独立填表页 https://www.roboform.com/form-filler ；隐私 https://www.roboform.com/privacy-policy ；商店 https://chromewebstore.google.com/detail/roboform-password-manager/pnlccmojcmeohlpggmfnbbiapkmbliob 。均成功读取正文。

**产品与门槛。** 主定位是密码管理器，填表页讲支付 / 地址资料、一键填表以及给家人或客户填写；需要创建自己的安全资料库，而不需要模型 key。官网提到从浏览器、其他密码管理器或 CSV 导入密码；没有证据证明其支持把 Word / Excel 的非结构资料交给模型填复杂业务字段。

**价格与隐私。** 官网公开 Free、Premium、Family 等档。读取到的 Premium 标准价是 $2.49/月按年、续费 $29.88/年；首年促销部分仍是模板占位，金额未知，不采用。页面宣称零知识架构与设备端加解密；隐私政策区分不开同步时本地密码资料、开同步时本地 + 服务器存储，并另有账户、支付与许可验证数据。零知识不等于没有任何网络请求或服务器记录。

**首屏 / CTA / 演示 / 证明。** 主站先卖安全与密码管理，CTA 为 Premium / Business 试用；独立填表页再聚焦省去重复录入，并用与浏览器原生填表的表格对比说明用途。页面展示应用商店评分，商店条目可核对身份；官网的评分摘要与本次商店实时值有差异，不能混用。没有进行在线交互演示操作。

**SEO 结构。** 独立 `/form-filler` 页面、个人 / 企业价格、安全、帮助文档、比较页和多语言导航清晰。值得借鉴“一个确切任务拥有独立 URL”；但本项目不应借用其密码 / 银行卡安全承诺，因为本项目实际上提示用户不要在这类页面使用。

额外必查但暂不作为已验证安装标杆的是 **formfillai.cc**：它直接否定“BYOK + 本地存储 + 语义填表是无人做过”的假设，但 `#` 安装入口使真实分发状态未知。不能一边忽略卖点重叠，一边拿其营销承诺作为已证实产品标准。
