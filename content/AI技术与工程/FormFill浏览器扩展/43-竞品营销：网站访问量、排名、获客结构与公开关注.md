# 竞品营销：网站访问量、排名、获客结构与公开关注

核查日期：**2026-11-17，Asia/Singapore**。最近完整自然月为 **2026-10**；来源只提供更早月份时单列。已先读本目录 `competitors.md`、`feature-comparison.md`、`product-strategy.md`。本子任务不执行 Plane log、不再委派、不修改业务源码；没有注册、登录、付费、发帖、联系他人或读取凭据。插件商店人数及 Reddit/HN 原始计数由其他研究任务负责，本报告不重复统计。

**取得 4 个有明确数据月份的全站月 visits 观察，其中 2 个可按同一提供者、同一月份和设备范围横向比较。其余 7 个域名的当月月量仍为 NA。** 这里的访问量均为第三方估计，不是竞品后台实际统计。结果不构成“填表工具市场份额”：Simplify 包含招聘平台，RoboForm 包含密码产品，Magical 已转向医疗运营，Bardeen 包含获客和抓取工具。

机器可读数据与短原文见 marketing-web-evidence.json；公开 HTTPS 抓取日志与正文快照在 marketing-web-raw。搜索连接器缓存和直接 HTTPS 的差异另外保留，未把旧缓存数字改成当前月。

父会话复核：已读取本报告与原始材料，另复核 Simplify 的 Semrush 正文、RoboForm 的 Exploding Topics 页面、Bardeen 的 SeekTool/PH，以及 Simplify 官方 LinkedIn。LinkedIn 在父会话的另一份缓存中为 44,135 followers，而下文 worker 取到 44,080；综合报告用约 4.4 万并保留两次观察，不把差值当增长。完整市场判断见 [营销规模与启示](41-竞品市场表现：规模、流量、社区与_FormFill_的推广选择.md)。

## 1. 指标定义与比较边界

| 指标 | 本报告使用的口径 | 官方说明 |
|---|---|---|
| Semrush Total visits | 该网站或网页上个月总访问次数的估计；重复访问计入。不是 PV、UV、下载、活跃用户或付费人数 | [Website Traffic Checker](https://www.semrush.com/website/) 原文：`Total visits: an estimate of the total number of visits to the website or webpage over the last month.` |
| Semrush Traffic Analytics | 用 clickstream 估计所有渠道的流量；页面顶部 `Visits` 才作为全站访问量 | [Traffic Analytics 与 Domain Analytics 的区别](https://www.semrush.com/kb/858-traffic-numbers-in-semrush)：前者涵盖所有来源，后者基于关键词排名、搜索量和 CTR 估计搜索流量 |
| Semrush Global/Country traffic rank | 指定期、指定地域的流量排名；数字越小排名越靠前。本文原样记录顶部 Worldwide / United States 标签 | [官方 Traffic Rank 说明](https://developer.semrush.com/api/v3/trends/api-reference/)：`The Traffic Rank report provides a list of domains sorted by traffic in descending order.` 它不同于 SEO Toolkit 的 [Semrush Rank](https://www.semrush.com/kb/27-rank)，后者是自然搜索可见度排名 |
| Similarweb monthly visits | 每月所有非去重访问次数之和 | [Top Websites 官方定义](https://support.similarweb.com/hc/en-us/articles/213856729-Top-Websites)：`Monthly Visits: Sum of all visits (non-unique) per month.` |
| Similarweb rank | 桌面与移动网页的月 unique visitors 和 pageviews 的组合估计；不是仅按 visits 排序。Global 对所有域名，Country 对最大流量来源国家，Industry 对相同行业 | [Rank 官方定义](https://support.similarweb.com/hc/en-us/articles/213452305-Rank)。本轮没有从 Similarweb 原站取得域名报告，只取得注明来源为 Similarweb 的 SeekTool 转载 |
| Traffic Journey 的 `google.com` | 来访前站点/来源域，不自动等于 organic search；免费页明确标为 Desktop | [Sources & Destinations](https://www.semrush.com/kb/1522-traffic-and-market-traffic-distribution-sources-destinations) 将 source domain 和 acquisition channel 分开。Direct 定义为直接输入地址或用书签，Organic Search 定义为未付费搜索来源 |

不能用 Semrush 下方 `Organic Search Traffic` 除以上方 `Visits` 来拼全站渠道占比，两者可能来自不同数据集、地域和模型。也不能把桌面 Journey 百分比直接乘全部设备 visits 得出渠道访问次数。本报告保留百分比适用范围，未做这些换算。

## 6. 对 FormFill 推广顺序的影响

1. **先完成可试用与信任基础。** 接续既有 P0：隐私/学习修复、准确的四类文件说明、真实获取入口、API 配置和真实扩展演示。FastFiller 的 release 路径与各工具商店 CTA 已是可见竞争要求；流量不能弥补用户无法安装或无法完成首次任务。
2. **先找会复做资料录入的少量业务用户，同时服务能自行配 API 的技术用户。** 已有研究选定“企业资料→合作方登记网页”；本轮没有取得直接同类的可靠月量，不能用大平台数字推翻或证明这个细分假设。观察下次实际使用、核对与纠错时间、适配需求，比追逐粉丝存量更直接。
3. **首批 SEO 只做少量有输入、输出和边界的任务指南。** 优先 Word 资料填网页、Excel 选定记录（实现记录隔离后）、模型配置。参考 FillApp 的任务标题、Text Blaze 的可用模板、ExcelToForm 的产品分支，但每页需有本项目可下载合成资料与实际过程。现有数据只证明这些内容结构存在，不证明文章数量、发布日期频率或流量因果。
4. **源码/演示与社区发布作为反馈渠道，比较页在同任务证据齐全后做。** Bardeen 有 PH 关注存量不等于 FormFill 首发应照搬其发布节奏。先让读者能独立尝试，再由作者按平台规则决定发布；本任务没有撰写或发布帖子。插件及 Reddit/HN 另一研究应与这里的来源链整合，不能把平台计数相加。
5. **广告、广泛行业页及商业投放留到漏斗可测之后。** 没有证据支持“把预算都投 SEO”或“LinkedIn 是最有效渠道”。先记录任务页→获取→完成配置→首次正确填写→复用/适配咨询；有付款与支持成本记录后再评估既有 ¥699 有范围适配实验。本报告没有估算竞品收入、LTV、CAC 或投放预算。

## 7. 访问失败、缓存差异与尚未验证项

- **原站页面失败与访问控制分开：**直接 Semrush 除 Simplify/Magical 之外均为 404；Similarweb 11 个指定域名请求均为 202 空正文。连接器对 RoboForm Semrush 一次显示 429，直接 HTTPS 为 404，两个观察均保存。没有把 429 写成永久无数据。
- **动态报告：**Exploding Topics 的 blaze.today / bardeen.ai URL 直接跳到公开流量检查器，正文停在 `Loading Your Results`，未取得数值；没有继续调用需要 key 的 API。RoboForm 同站摘要可读。
- **缓存不等于当前：**Magical 的连接器正文是 2026-08、76.82K、global 389,653，而直接 HTTPS 是 2026-10、103.81K、global 293,884。二者数据期不同，后者进入当月表，前者仅作为旧缓存留证；不能称估值冲突或偷换月份。Simplify 搜索摘要中的有些页也更旧，采用已读正文与直接 HTTPS 的 10 月值。
- **索引副本筛选：**HypeStat 的 Blaze 页出现 SEMrush/Similarweb/HypeRank 多组值，图表还含 2024 年；缺少可靠字段日期，不作当前排名。Filliny 的 Toolify 旧比较页摘要与当前 `--` 分开。搜索中还出现 Vaneform、目录排名、SEO 估计等，未取得足以支持同口径当前横向比较的原始来源链，不纳入主表。没有将搜索结果条数、directory 镜像数量或官网客户数换算月量。
- **登录/付费边界：**Semrush 更详细的渠道、完整国家和某些字段指向账户/Unlock；本轮未创建账户。官方 Trends API 文档可公开读，但 API 需要订阅/key；只读文档，没有调用 API。LinkedIn/PH 的直接 HTTPS 403，仅使用连接器已公开可读正文，不绕过限制。
- **未验证：**没有 GA/GSC/服务端日志、真实用户去重、品牌/非品牌全站份额、安装转化、试用转化、留存、社交关注去重、收入或竞品真实填表效果。Bardeen 的二手 Similarweb 数字与来源百分比未从原站独立核实；不能把它与 Semrush 的两行组成市场排名。

本轮完成了指定 11 个域名的一轮公开来源与索引补查，核实了指标定义、4 条有月期的 visits、3 个官方归属关注信号及营销入口结构。父会话可复核 JSON 的原文片段、访问记录和快照，合并其他 worker 的插件/论坛数据；继续采样时应按同一提供者、同一数据月、同一域范围和设备范围重新取值。
