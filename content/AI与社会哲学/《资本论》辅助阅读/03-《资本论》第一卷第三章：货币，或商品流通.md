# 《资本论》第一卷第三章：货币，或商品流通

第三章讲的是：商品世界为什么必然会生出“货币”，货币在流通中怎样工作，又为什么它不只是一个方便交易的工具，而会逐步变成一种支配商品世界的社会力量。

这一章可以按三层读：

1. **货币作为价值尺度**：商品先要用货币来“标价”。
2. **货币作为流通手段**：商品通过“卖出再买入”完成流通。
3. **货币作为货币本身**：当货币能储藏、支付、跨国结算时，它就不只是中介，而成为财富的独立形态。

如果用程序员熟悉的语言说：货币像是商品社会的统一接口、计价协议和结算运行时。不同商品的内部复杂性被抽象成同一种可比较的数值：价格。但马克思要说明的是，这个“接口”不是天然中立的技术协议，它背后封装的是劳动、社会关系和权力结构。

一句话概括本章：

> 货币不是天然中立的支付工具，而是商品社会关系的统一表达：它依次承担价值尺度、流通手段、贮藏手段、支付手段和世界货币的职能，把具体的劳动关系抽象成价格、账期和信用。

## 货币作为价值尺度

商品有两个面：使用价值和价值。

一件羽绒服能保暖，这是使用价值；它能卖 800 元，这是价格形式。马克思关心的不是“为什么它有用”，而是：为什么各种完全不同的东西，比如羽绒服、咖啡、GPU 云算力、Python 开发外包服务，最后都能被写成一个共同格式：

```text
商品 X = 若干货币
```

这就是货币作为价值尺度的功能。

货币让商品的价值获得一个统一表达。就像 API 系统里，不同服务内部实现不同，但对外必须暴露统一协议。一个图像识别 API、一个向量数据库服务、一个支付网关，功能完全不同，但平台可以统一写成：

```json
{
  "price": 0.002,
  "currency": "USD",
  "unit": "request"
}
```

于是，它们进入了同一个比较空间。

马克思的关键意思是：价格不是商品随便贴上的标签，而是商品价值借助货币表现出来的形式。商品不能直接说“我凝结了多少社会劳动”，它只能说“我值多少钱”。

这有点像中国古代讲“名实”。“实”是物自身承担的内容，“名”是社会承认的表达。价格是商品价值的“名”，但名与实并不总是完全一致。价格可以高于价值，也可以低于价值。市场供求、垄断、投机、品牌、平台规则，都可能让价格偏离价值。

比如一个 AI 应用：

- 开发成本不高，但因为踩中热点，订阅价格很高；
- 一个开源模型本身免费，但部署、推理、售后和品牌包装让它变成收费产品；
- 某些平台抽成高，导致终端价格上升；
- 某些补贴大战中，价格低到不覆盖真实成本。

这些都说明：价格是价值的表现形式，但不是价值的镜像复制。

## 价值尺度和价格标准

马克思区分两个概念：一是**价值尺度**，二是**价格标准**。

价值尺度回答的是：商品为什么能用货币表现价值。

价格标准回答的是：货币自身如何被分割成固定单位，比如元、角、分，美元、美分，或者古代的两、钱、分。

用开发类比：

- 价值尺度像是系统采用一种统一的数据类型来表达价值；
- 价格标准像是这个数据类型的单位规范，比如 `CNY`、`USD`、`USDC`，以及精度到小数点后几位。

一个支付 API 里，经常会要求金额用最小货币单位表示：

```json
{
  "amount": 999,
  "currency": "CNY"
}
```

这里的 999 不是抽象价值本身，而是按照人民币价格标准编码后的金额。货币作为价值尺度，是更深层的社会功能；货币单位，只是它在制度和技术上的刻度。

古代“度量衡”也类似。量布要有尺，称粮要有斗，称金银要有两。尺度本身不是财富，但没有尺度，社会交换就难以稳定展开。

## 商品流通：卖了再买

直接物物交换可以写成：

```text
商品 A <-> 商品 B
```

比如我有米，你有布，我们正好互相需要，就能交换。但这种方式效率很低，因为它要求双方需求同时匹配。

商品流通则变成：

```text
商品 A -> 货币 -> 商品 B
```

马克思写作时常用形式是：

```text
W - G - W
```

也就是：商品 - 货币 - 商品。

一个人卖出自己的商品，得到货币；再用货币买入自己需要的商品。货币在中间起桥梁作用。

现代例子更明显。一个 Python 开发者接了一个 AI 应用外包项目：

```text
开发服务 -> 现金收入 -> 购买显卡 / 云服务 / 房租 / 课程
```

他真正想要的不是那张银行卡里的数字本身，而是通过这个数字获得生活资料、生产资料和未来机会。

所以在简单商品流通中，最终目的仍是使用价值。卖，是为了买。货币只是中介。

但这里已经埋下一个重要变化：卖和买被分开了。

在物物交换中，交换双方同时完成。但在货币流通中，一个人可以今天卖出，明天再买；可以卖给甲，再向乙买；可以卖出之后暂时不买。

这带来便利，也带来危机的可能。

## 买卖分离与危机的可能性

马克思在这一章已经指出一个很深的点：货币让商品流通更灵活，但也让流通链条可以断裂。

卖和买分开之后，就会出现：

- 有人卖了不买
- 有人想卖卖不出去
- 有人等收款才能付款
- 有人库存积压
- 有人现金流断裂

这不是现代金融才有的问题，而是商品流通形式本身就包含的可能性。

平台经济里很容易理解。

一个小商家在电商平台卖货：

1. 先垫资进货；
2. 投广告获取流量；
3. 等用户付款；
4. 平台延迟结算；
5. 再付供应商货款；
6. 再继续采购。

如果某一环断了，比如广告成本上升、平台冻结资金、退货率暴涨、供应商催款，整个链条就会紧张。

货币原本只是流通工具，但因为买卖可以分离，货币就变成了必须握在手里的“流动性”。很多企业不是没有资产，而是没有现金；不是没有订单，而是回款太慢。

这就是马克思从商品流通中看到的危机种子：问题不只是人心贪婪，也不只是管理失误，而是商品经济的形式本身让断裂成为可能。

## 货币的流通

在商品流通中，商品最终离开流通，进入消费。面包被吃掉，衣服被穿上，服务器算力被调用，咨询服务被交付。

但货币不同。货币不会因为一次交易就消失，它会继续转手。

```text
甲买乙的商品 -> 乙拿钱买丙的商品 -> 丙拿钱付丁的服务
```

商品不断退出流通，货币却不断在流通中运动。

因此，一定时期内社会需要多少流通货币，不只取决于商品总价格，还取决于货币流通速度。

简化说：

```text
所需货币量 ~= 待实现商品价格总额 / 货币流通次数
```

现代支付系统也是这样。一个平台上，用户支付、商家收款、平台抽佣、骑手结算、广告充值、供应商提现，账面金额不断流动。真正需要的“基础货币”或可结算余额，不一定等于所有交易额之和，因为同一笔钱可以多次周转。

在数据库视角里，货币像一条不断被更新所有权的状态记录。重点不是它静态在哪里，而是它在交易网络中以多快速度完成状态迁移。

## 铸币、纸币和符号

马克思接着讲铸币和纸币。

当货币只是作为流通手段时，人们关心的不是它本身有多少金属价值，而是它能不能完成购买。于是，金属货币在长期流通中会磨损，实际重量减少，但仍按面额使用。进一步，国家发行的纸币也可以代替金属货币流通。

这里的关键是：在流通中，货币可以变成自己的符号。

现代人更容易理解这一点。

今天大多数支付根本不需要实物现金：

- 微信支付、支付宝；
- 银行卡清算；
- Stripe、PayPal；
- 平台余额；
- 预付卡；
- 稳定币；
- 游戏点券；
- 云服务账户 credits。

它们都在不同范围内承担“支付符号”的功能。

但马克思也提醒：纸币作为流通符号，不能任意发行。它能代表多少价值，受实际流通需要约束。如果符号发行超过商品流通所需，它的购买力就会下降。

用现代话说，支付系统里的 token 可以轻，但不能脱离清算约束。平台积分可以记账，但如果平台无限发券、无限补贴、无限制造余额，而背后没有对应商品、服务和信用支撑，最终会表现为贬值、挤兑或规则重写。

这和 API token 也有一点可类比：token 本身只是一串字符，但它之所以有效，是因为背后有认证系统、权限系统和资源承诺。离开这些，token 就只是字符串。

## 货币贮藏

当货币不再马上用于购买，而是被保存起来，它就成为贮藏手段。

在简单商品流通中，卖是为了买。但一旦货币成为财富的一般形式，人们就会产生另一种冲动：

```text
卖出商品 -> 得到货币 -> 保存货币
```

这时，货币不再只是桥，而像目的本身。

为什么？

因为货币是一般等价物。拿着具体商品，你只能满足特定需要；拿着货币，你似乎握有一切商品的可能性。

一台服务器只能跑服务；一件衣服只能穿；一批库存要看市场是否接收。但现金、存款、可流通资产，具有更高的选择权。

这就是货币的诱惑：它把具体财富变成抽象权力。

国学里讲“藏器于身，待时而动”，原意不必硬套到货币，但有一点相通：货币贮藏给予持有者等待时机的能力。不同的是，在商品社会中，这种“待时而动”不只是修身策略，而是市场权力。

对创业者来说也很现实。很多 AI 应用公司并不是死于没有技术，而是死于现金流撑不到下一轮产品迭代。于是“账上现金还能烧几个月”就成了生死线。

货币作为贮藏手段，使人能够延迟购买、抵御风险、等待机会；但从社会整体看，过度贮藏也会让流通收缩，买卖链条更容易断裂。

## 支付手段

货币还有一个更复杂的功能：支付手段。

这发生在买和付款分离的时候。

比如：

> 今天交货，30 天后付款。

在这里，买卖已经发生，但货币没有立即出现。货币先作为计价单位出现在合同里，之后才作为支付手段真正到场。

现代商业几乎离不开这种结构：

- SaaS 企业按月结算；
- 云厂商先用后付；
- 广告平台预充值或后结算；
- 外包项目分阶段付款；
- 电商平台 T+N 结算；
- 企业采购有账期；
- 信用卡先消费后还款；
- BNPL 先买后付。

这时，货币不只是流通媒介，而是债务关系的最终结算者。

问题也随之变尖锐：如果所有人都等别人付款再付款，链条就会非常脆弱。

比如：

> A 欠 B，B 欠 C，C 欠 D。

平时大家都相信到期能付，系统看起来正常。一旦 A 不能付款，B 就可能无法付 C，C 又无法付 D。于是局部违约扩散成连锁危机。

这就是马克思讲支付手段时特别重要的地方：货币在信用体系中平时好像被“节省”了，但危机时大家突然都需要真正的货币来清偿债务。

开发者可以把它理解成异步系统里的依赖链。正常情况下，promise 都能 resolve，系统吞吐量很高；一旦关键节点 reject，又缺乏隔离和补偿机制，失败就会沿调用链传播。

信用能提高流通效率，也能放大崩溃。

## 世界货币

最后，马克思谈世界货币。

在一国之内，国家铸币、纸币、法定货币可以流通，是因为有国家权力、税收系统和法律制度支撑。但到了国际市场，货币要面对不同国家、不同制度、不同信用体系。

在马克思的时代，金银在世界市场上承担最终货币角色。它们不再只是某国铸币，而是作为普遍财富形式出现。

今天情况复杂得多：美元、欧元、黄金、外汇储备、跨境清算系统、稳定币、央行数字货币试验，都在不同层面承担国际支付和储备功能。

但基本逻辑仍可理解：当交易跨越平台、国家和法律边界时，大家会追问最终结算资产是什么，谁承认它，谁能冻结它，谁能创造它，谁承担信用风险。

这和平台经济也类似。

在一个封闭平台内，平台积分、余额、优惠券都能流通；但离开平台，它们未必被承认。你在某云平台的 credits 可以买算力，却不能直接付房租。平台内的“货币”一旦走向平台外，就要兑换成更一般的支付形式。

世界货币就是更大范围内的一般等价物问题。

## 货币不是东西，而是一种社会关系的形式

第三章最容易误读的地方，是把它看成货币功能分类：价值尺度、流通手段、贮藏手段、支付手段、世界货币。

这些分类当然重要，但更深的线索是：商品社会中的人与人关系，越来越通过货币表现出来。

开发者给客户写代码，表面上是技术服务；进入市场后，它表现为报价、合同、发票、回款、税务和利润。用户对产品的需要，表现为订阅转化率。平台对商家的支配，表现为抽成比例、结算周期、流量价格。投资人对未来的判断，表现为估值。

很多具体关系被抽象成货币关系。

这就是马克思厉害的地方：他不是只问“钱怎么用”，而是问“为什么社会关系必须通过钱来显现”。

货币让交换更自由，也让人受制于抽象力量。你可以自由选择卖给谁、买什么、存多少、投哪里；但你也必须先把自己的劳动、产品或资源转化为货币，否则就难以参与社会生活。

## 给 AI 应用开发者的理解入口

如果你是做 AI 应用的 Python 开发者，可以这样把本章装进脑子里：

- 商品世界需要一种统一抽象，货币就是这个抽象层。
- 价格像序列化格式，把不同商品编码成可比较的数值。
- 支付像运行时协议，让商品所有权和服务使用权完成转移。
- 账期和信用像异步调用，提高吞吐，也制造链式失败风险。
- 平台余额、credits、token、积分都像局部货币，但它们的有效性取决于平台边界和背后信用。
- 现金流不是财务细节，而是商品流通的生命线。
- 货币看似是工具，实际上是社会关系的集中表达。

## 原文对照

> **原文**（第一卷第三章）："金银天然不是货币，但货币天然是金银。"

> **转述**（第一卷第三章）：马克思在本章区分了货币作为价值尺度、流通手段、贮藏手段、支付手段和世界货币的不同职能，并指出一旦买和卖在时间上分离，商品流通本身就潜藏着危机的可能性。

## 本章的核心结论

第三章可以浓缩成一句话：

> 货币是商品交换发展的必然产物，它先作为价值尺度让商品可以标价比较，再作为流通手段让买卖分离并展开，最终在贮藏、支付和世界市场中显出自己作为独立财富形态的力量。

更具体地说：

- 价值尺度让不同商品的价值可以用同一种货币单位表达；
- 流通手段让商品经过“卖出再买入”完成流通，但也让买和卖分离，埋下危机的可能性；
- 贮藏手段让货币从单纯的桥变成被追逐的目的本身；
- 支付手段让货币进入信用和债务链条，平时被信用节省，危机时又被集中追讨；
- 世界货币让一般等价物的问题从一国之内扩展到跨国、跨平台的结算和承认。

## 结语

第三章从“商品怎样标价”讲到“货币怎样流通”，再讲到“货币怎样成为财富和权力的独立形态”。它表面上是在分析钱，实际上是在分析商品社会的运行协议。

在这个协议中，任何具体劳动、具体产品、具体需要，都必须经过货币形式才能普遍流通。货币让陌生人之间可以协作，让商品世界高速运转；但它也让社会关系变得抽象、分离、可断裂，并把危机的可能性嵌入日常交易之中。

所以读这一章，不要只记“货币有五种职能”。更重要的是看见：当万物都要通过价格、支付、账期和结算来获得社会承认时，货币就不只是钱包里的东西，而是商品社会的底层协议。
