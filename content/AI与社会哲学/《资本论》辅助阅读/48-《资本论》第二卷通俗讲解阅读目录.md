## 总逻辑

第二卷二十一章可以连成一条线：

```text
货币资本循环 -> 生产资本循环 -> 商品资本循环
-> 三个循环公式的统一 -> 流通时间 -> 流通费用
-> 周转时间和周转次数 -> 固定资本和流动资本
-> 预付资本的总周转 -> 固定/流动资本理论史
-> 工作期间 -> 生产时间 -> 流通时间
-> 周转时间怎样改变预付资本量
-> 可变资本周转 -> 剩余价值的流通
-> 社会总资本再生产 -> 简单再生产
-> 积累和扩大再生产
```

第一章从货币资本出发，公式是 `G - W ... P ... W' - G'`。它说明资本从货币出发，购买生产资料和劳动力，经过生产过程形成包含剩余价值的商品，再销售回到更多货币。

第二章从生产资本出发，公式是 `P ... W' - G' - W ... P`。它强调生产过程不是一次性事件，而是必须通过销售、回款和重新购买生产要素，持续回到生产过程。

第三章从商品资本出发，公式是 `W' - G' - W ... P ... W'`。它强调商品资本必须卖出去，价值和剩余价值才能实现，并揭示单个资本循环和社会总流通之间的联系。

第四章把三个公式放在一起，说明货币资本、生产资本和商品资本不是三种孤立资本，而是同一产业资本在循环中依次采取的三种形态。资本必须不断完成购买、生产、实现这三个职能，才能持续运动。

第五章分析流通时间。资本不仅需要生产时间，还需要购买、销售、验收、结算、回款等流通时间；流通不创造价值，却会占用资本、延缓周转，并影响资本增殖速度。

第六章分析流通费用。买卖、记账、支付、销售等纯粹流通费用不创造新价值，但会从已经创造的价值中扣除；保管费用和运输费用则要具体区分，有些是生产过程在流通领域中的延续，有些是滞销和形式转换带来的负担。

第七章正式进入资本周转。资本不只是循环一次，而是在一定时期内反复循环；周转时间等于生产时间加流通时间，周转次数则取决于一年中资本能完成多少次完整回流。

第八章区分固定资本和流动资本。固定资本不是因为物理上不能移动，而是价值分多次转移和回收；流动资本不是因为物理上流动，而是价值在一次周转中整体进入产品并回流。这里必须同第一卷的不变资本、可变资本区分开。

第九章讨论预付资本的总周转。一个现实企业总是由多种周转速度不同的资本组成：机器、厂房、GPU、服务器等固定资本慢慢回收，工资、原料、API 调用、云资源等流动资本快速回收；总周转是这些不同节奏的综合。

第十章和第十一章清理固定资本与流动资本的理论史。重农学派看到了预付和年度再生产，亚当·斯密推进了固定/流动区分，但仍混淆生产资本和流通资本；李嘉图又常把流动资本同工资或维持劳动的资本混在一起，没有分清流动的不变资本和流动的可变资本。

第十二章分析工作期间。工作期间不是工作日长度，而是从开工到完成一个可出售产品所需的连续劳动过程。工作期间越长，资本越久凝结在未完成产品中，维持连续生产所需预付资本越多。

第十三章分析生产时间。工作时间一定是生产时间，但生产时间不一定都是工作时间。发酵、成熟、干燥、模型训练、自动化测试、等待技术过程完成等，都可能让资本停留在生产领域中，从而延缓周转。

第十四章再次分析流通时间，但重点转为周转角度。销售时间让资本停留在商品资本形态，购买时间让资本停留在货币资本形态；二者都不创造价值，却会延长周转时间并增加资本垫付。

第十五章把时间关系转化为预付资本量。为了维持连续生产，资本家需要覆盖整个周转时间内的投入；周转时间缩短会释放货币资本，周转时间延长或生产资料涨价则会追加资本需求。这也是现代企业现金流、账期、预付款、阶段付款和信用制度的理论基础。

第十六章讨论可变资本的周转。周转不创造剩余价值，剩余价值仍来自劳动力；但可变资本周转越快，同一笔预付工资资本一年中就能反复购买劳动力、反复生产剩余价值，从而提高年剩余价值率。

第十七章讨论剩余价值的流通。剩余价值实现为货币后，可以作为资本家收入被消费，也可以转化为追加资本。简单再生产中剩余价值被消费，扩大再生产中一部分剩余价值要先以货币形式积累，再转化为追加生产资料和追加劳动力。

第十八章进入社会总资本再生产。视角从单个资本扩大到全社会，问题不再只是某个资本能否卖出商品，而是社会总产品的价值构成和实物构成能否相互补偿。

第十九章回顾前人的社会再生产理论。重农学派有社会总流通视角，但局限在农业；亚当·斯密把商品价值最终化为工资、利润和地租，遗漏不变资本补偿，因此无法正确说明社会总资本怎样持续再生产。

第二十章分析简单再生产。社会分成生产资料部类 I 和消费资料部类 II。简单再生产的关键条件是 `I(v+s)=IIc`：I 部类的工人和资本家需要消费资料，II 部类需要补偿生产资料，二者必须按比例交换。

第二十一章分析积累和扩大再生产。资本家不再把全部剩余价值消费掉，而是把一部分转化为追加不变资本和追加可变资本。扩大再生产要求生产资料、消费资料、劳动力和货币流通形成新的比例协调。至此，第二卷从资本循环、资本周转推进到社会总资本再生产，完整说明了资本怎样在时间和社会结构中持续运动。

## 版本与手稿背景

第二卷不是马克思生前定稿出版的。马克思 1883 年去世时，只留下了跨越 1865 年到 1881 年间陆续写成的多份手稿（后世通常编号为手稿 I 到 VIII），详略很不均衡，有的部分反复修改，有的部分只是草稿提纲。恩格斯花了数年时间整理这些手稿，选择、拼接、补写过渡文字，才在 1885 年编成我们今天读到的这个 21 章本子。

知道这一点，读起来会更从容：第二卷的论证密度和例证丰富程度不如第一卷（第一卷是马克思本人在 1867 年亲自定稿、后来又参与修订法文版的），不是因为主题不重要，而是因为它本来就是编辑整理稿，不是最终打磨稿。读到偶尔跳跃或重复的地方，可以理解为手稿拼接留下的痕迹，而不是自己没读懂。
