# 《资本论》第三卷第四十五章：绝对地租

第四十四章结束级差地租的补充。

第四十五章进入绝对地租。

级差地租来自土地差异。

绝对地租则来自土地私有权本身。

即使最差土地没有级差优势，只要土地所有者能阻止资本无偿使用土地，就可能要求地租。

一句话概括本章：

> 绝对地租不是来自土地肥力差异，而是来自土地私有权对资本进入土地的垄断；土地所有者凭所有权阻止农产品价格完全降到生产价格，从而使最差土地也能支付地租。

## 级差地租和绝对地租的区别

级差地租：

> 土地之间有差异；
> 较好土地获得超额利润；
> 超额利润转化为地租。

绝对地租：

> 即使最差土地没有差异优势；
> 土地所有者也可以凭所有权要求租金；
> 资本必须支付才能使用土地。

所以级差地租来自差异。

绝对地租来自垄断。

这个垄断不是普通企业垄断，而是土地私有权对自然条件的垄断。

## 为什么土地私有权能阻碍资本

资本想进入农业或土地相关生产，必须使用土地。

但土地归地主所有。

地主可以说：

> 不给租金，就不能使用。

即使某块土地只是最差土地，资本家也不能免费使用。

如果农产品市场价格只等于生产价格，没有空间支付租金，地主可能不出租。

于是土地私有权阻止资本自由进入。

价格必须高到能支付地租。

这就是绝对地租的基础。

## 绝对地租和价值

马克思认为，绝对地租与农业资本构成较低有关。

如果农业中可变资本比例较高，它生产的剩余价值可能高于按平均利润率分配后应得的平均利润。

土地所有权阻止这部分超额剩余价值完全进入平均利润分配。

于是它以绝对地租形式留在农业产品价格中。

这里细节复杂，但核心可以简化为：

> 土地私有权阻止资本自由平均化；
> 使农产品价格可以高于生产价格；
> 差额成为绝对地租。

## 现代资源垄断类比

绝对地租可以帮助理解某些资源控制。

比如：

- 城市土地所有权；
- 频谱牌照；
- 稀缺电力接入；
- 数据中心许可；
- 平台 API 入口；
- 应用商店准入；
- 关键数据授权。

这些资源即使没有明显质量差异，只要所有者能阻止使用，就能收费。

例如平台要求所有开发者支付固定抽成。

无论你排名高低，都必须缴纳。

这不是级差收益，而更接近准入垄断。

当然平台不是土地，不能直接等同，但结构上都涉及“没有许可不得使用”。

## 绝对地租和房租

城市住房和办公租金中，有一部分来自位置差异。

这是级差地租。

但还有一部分来自土地和房产所有权本身。

只要你需要空间，就必须支付租金。

即使位置一般，也不是免费。

这接近绝对地租逻辑。

创业公司租办公室、机房、仓库，都面对这种支出。

房东不参与你的生产，却凭所有权取得收入。

## 对 AI 开发者的理解抓手

绝对地租提醒你关注准入成本：

- 使用平台是否必须抽成？
- 调用关键 API 是否必须付费？
- 获取数据是否必须买授权？
- 上架应用是否必须遵守平台税？
- 使用某云区域是否受资源所有者定价？
- 进入企业客户采购体系是否要渠道费用？

这些费用不一定来自对方帮你创造更多价值，而可能来自准入权。

## 类比的边界

本章把平台抽成、API 准入费、数据授权费类比绝对地租，这个类比有一点站得住：不管你排名高低、效率高低，只要用，就要交钱——这和绝对地租"不看差异、只看所有权"的逻辑是一致的。

但绝对地租能成立，靠的是一个很具体的条件：土地是资本无法生产出来的自然要素，所有资本要从事农业，都绕不开地主，因为你不能自己"造一块地"出来绕开他。

平台、API、数据授权不完全是这样。

原则上，只要有足够资本和时间，竞争者可以自建平台、自建数据中心、自己采集或谈判获得数据授权，这在技术上是可行的，只是成本高、周期长。土地则不同，无论多少资本，都不能凭空造出更多地球表面。

```text
土地私有权壁垒：资本无法生产替代品，绕不开
平台/数据准入壁垒：原则上可被资本复制（自建平台、自采数据），只是成本高
```

另外，马克思讲绝对地租，还有一个具体机制：农业资本有机构成偏低，生产的剩余价值本来就可能高于按平均利润率分配后的水平，土地私有权只是拦住了这部分剩余价值被拉平的过程。这个机制是农业特有的，不能直接套到平台抽成上——平台抽成的定价逻辑更多来自网络效应和议价权，而不是资本有机构成差异。

所以"平台抽成等于绝对地租"这个类比，抓住了"所有权本身构成壁垒"这一点，但壁垒的成因不一样：自然资源不可再生产，商业设施原则上可复制。套用时要把这一点说清楚。

## 本章的核心结论

第四十五章讲绝对地租。

核心是：

> 级差地租来自土地差异；
> 绝对地租来自土地私有权本身；
> 地主凭所有权阻止资本无偿使用土地；
> 最差土地也可能因准入垄断而支付地租。

对现代数字经济来说，这章帮助理解：

- 平台准入费和固定抽成；
- 数据授权和 API 准入；
- 房租和机房资源；
- 牌照、频谱、云资源等稀缺使用权；
- 所有权不生产价值却能参与分配。
