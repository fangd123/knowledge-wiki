# 《资本论》第三卷第三章：利润率和剩余价值率的关系

第二章建立了利润率：

```text
p' = s / (c + v)
```

第一卷中的剩余价值率是：

```text
m' = s / v
```

第三章要系统说明二者之间的关系。

一句话概括本章：

> 利润率由剩余价值率、资本构成和资本周转等因素共同决定；剩余价值率相同，利润率可以不同，利润率相同，剩余价值率也可能不同，因此利润率是剩余价值率被总资本结构折射后的表现形式。

## 从公式开始

设剩余价值率为：

```text
m' = s / v
```

那么：

```text
s = m' × v
```

利润率为：

```text
p' = s / (c + v)
```

把 `s = m' × v` 代入：

```text
p' = (m' × v) / (c + v)
```

这个公式说明，利润率取决于两个核心因素：

```text
剩余价值率 m'
可变资本在总资本中的比例 v/(c+v)
```

也可以写成：

```text
p' = m' × v/(c+v)
```

所以利润率不是单独由剥削程度决定。

它还取决于资本中有多少部分投在劳动力上。

## 可变资本比例越低，利润率越受压

假设剩余价值率都是 100%。

资本 A：

```text
c = 50
v = 50
s = 50
p' = 50 / 100 = 50%
```

资本 B：

```text
c = 80
v = 20
s = 20
p' = 20 / 100 = 20%
```

资本 C：

```text
c = 90
v = 10
s = 10
p' = 10 / 100 = 10%
```

剥削率一样，但利润率下降。

原因是可变资本占总资本的比例下降。

因为剩余价值只来自劳动力，而利润率却用全部资本做分母。

这条逻辑后来会发展为利润率趋向下降规律。

第三章先把数学关系讲清楚。

## 资本构成的重要性

资本构成可以粗略理解为：

`c 和 v 的比例`

不变资本越多，可变资本越少，资本构成越高。

现代 AI 基础模型公司往往资本构成很高。

它需要：

- GPU；
- 数据中心；
- 网络设备；
- 存储；
- 能源；
- 大规模训练基础设施；
- 长期研发系统。

这些都属于不变资本或固定资本占用。

应用外包团队可能资本构成较低。

它主要投入在工程师工资、项目交付和少量云资源上。

如果两者剩余价值率相同，高资本构成部门的利润率可能更低。

当然现实中基础模型公司可能依靠垄断、知识产权、规模、金融支持获得高利润。

但从基本价值关系看，高不变资本占比会改变利润率表现。

## 剩余价值率提高能抵消吗

如果可变资本比例下降，资本家可以通过提高剩余价值率来抵消利润率下降。

比如：

资本 B：

```text
c = 80
v = 20
```

如果剩余价值率是 100%：

```text
s = 20
p' = 20 / 100 = 20%
```

如果剩余价值率提高到 200%：

```text
s = 40
p' = 40 / 100 = 40%
```

利润率上升了。

资本可以通过：

- 延长工作日；
- 提高劳动强度；
- 压低工资；
- 提高劳动生产率；
- 缩短必要劳动时间；
- 外包和平台化；
- 全球劳动力套利；

来提高剩余价值率。

但这不是无限的。

劳动者身体、生活、组织抵抗、技术条件和社会制度都会构成限制。

## 利润率相同不代表剥削率相同

反过来，两个资本利润率相同，剩余价值率可能完全不同。

资本 A：

```text
c = 50
v = 50
m' = 50%
s = 25
p' = 25 / 100 = 25%
```

资本 B：

```text
c = 80
v = 20
m' = 125%
s = 25
p' = 25 / 100 = 25%
```

两个资本利润率都是 25%。

但 A 的剩余价值率是 50%，B 是 125%。

这说明利润率不能直接显示剥削程度。

资本家和投资人看到同样的回报率，但背后的劳动关系可能差异很大。

这对现代行业分析很重要。

同样 20% 利润率，有的公司靠技术垄断，有的靠压低工资，有的靠平台抽成，有的靠高周转，有的靠外包成本差。

利润率是表面结果，不是完整原因。

## 周转的影响

第三章也会牵涉周转。

如果可变资本一年周转多次，一年中生产的剩余价值总量会增加。

所以年利润率要考虑周转次数。

假设总资本 100，其中可变资本 20。

单次剩余价值率 100%，每次产生剩余价值 20。

如果一年周转 1 次：

```text
年剩余价值 = 20
年利润率 = 20 / 100 = 20%
```

如果一年周转 4 次：

```text
年剩余价值 = 80
年利润率 = 80 / 100 = 80%
```

这就是为什么第二卷的资本周转会在第三卷重新出现。

利润率不是静态结构，还受时间速度影响。

## 价格变化的影响

利润率还受不变资本价格变化影响。

如果生产资料变便宜，`c` 下降，在 `s` 不变时，利润率上升。

比如：

```text
c = 80, v = 20, s = 20
p' = 20%
```

如果云成本、GPU 成本、API 成本下降，使 `c` 降到 60：

```text
c = 60, v = 20, s = 20
p' = 20 / 80 = 25%
```

利润率提高。

反过来，如果模型 API 涨价、GPU 租金上涨、能源变贵，`c` 上升，利润率会被压低。

现代 AI 应用公司对此非常敏感。

上游模型降价会直接改善下游利润率。

上游涨价则可能让原本可行的商业模式失效。

## 工资变化的影响

工资变化会影响 `v` 和 `s` 的关系。

如果工作日和劳动生产率不变，工资上涨通常会减少剩余价值。

比如新增价值为 100。

原来：

```text
v = 50
s = 50
m' = 100%
```

工资上涨后：

```text
v = 60
s = 40
m' = 66.7%
```

如果 `c` 不变，利润率下降。

资本会试图通过提高劳动生产率、提高价格、裁员、自动化或转移生产来应对。

这也是为什么工资斗争会直接触动利润率。

利润率看似投资指标，背后有阶级关系。

## AI 自动化怎样影响关系

AI 自动化可能减少 `v`，增加 `c`。

比如公司用自动化客服替代一部分人工客服。

变化可能是：

> 工资支出下降；
> 软件、模型 API、算力支出上升；
> 单位服务成本下降；
> 剩余价值率和利润率变化取决于具体结果。

如果节省的工资超过新增不变资本成本，利润率可能上升。

但如果自动化成本高、维护复杂、客户体验下降、返工增加，利润率可能未必改善。

更深层的问题是：当整个行业普遍采用自动化，商品价值和价格也会变化。

单个资本家先采用技术可能获得超额利润。

全行业普及时，超额利润消失，新的平均条件形成。

这将在第三卷后面竞争和平均利润部分更充分展开。

## 利润率公式的几个变量

可以把利润率拆成几个变量：

```text
p' = m' × v/(c+v) × 周转因素
```

简化理解：

- `m'`：剩余价值率，受工资、工作日、劳动强度、生产率影响；
- `v/(c+v)`：可变资本占比，受技术和资本构成影响；
- 周转因素：受生产时间、流通时间、回款周期影响；
- 价格因素：影响 `c`、`v` 和商品售价；
- 流通费用：会扣减可实现利润。

这个拆法不是马克思原文的机械公式，而是帮助现代读者理解变量。

资本家的利润率不是由单一因素决定，而是多个关系叠加。

## 对 AI 开发者的理解抓手

如果分析一个 AI 产品利润率，可以问：

> 1. 人力投入占多大？
> 2. 云和 API 成本占多大？
> 3. 固定资本投入多大？
> 4. 工资和劳动强度如何？
> 5. 产品回款周期多长？
> 6. 上游价格是否稳定？
> 7. 是否有技术垄断或平台抽成？
> 8. 是否依赖一次性项目还是订阅复购？

比如一个 AI 客服产品：

- 如果大量依赖人工标注和人工兜底，`v` 高；
- 如果大量依赖模型 API，`c` 高；
- 如果客户按年预付，周转快；
- 如果客户半年验收，周转慢；
- 如果上游 API 降价，利润率改善；
- 如果行业价格战，利润率下降。

这些都能放进第三章的框架。

## 利润率和表象世界

第三章进一步说明，利润率是一个更表面的范畴。

它不是假的。

资本家确实按利润率投资。

银行、基金、股东、管理层也按利润率评价企业。

但利润率把许多不同关系压缩成一个数字。

这个数字越有用，越容易遮蔽。

它有点像一个复杂系统的单一 KPI。

KPI 能帮助决策，但也会隐藏系统内部结构。

马克思要做的，就是从这个 KPI 反推背后的生产关系和资本构成。

## 本章的核心结论

第三章说明利润率和剩余价值率之间的关系。

核心公式可以理解为：

```text
p' = m' × v/(c+v)
```

在考虑年利润率时，还要加入周转速度。

因此：

- 剩余价值率相同，利润率可能不同；
- 利润率相同，剩余价值率可能不同；
- 资本构成越高，在其他条件不变时利润率越低；
- 提高剩余价值率、降低不变资本成本、加快周转，都可能提高利润率；
- 利润率不能直接显示剥削程度。

对 AI 和软件行业来说，这章提供了一个分析利润率的框架：

不要只看最终利润率数字，要拆开人力、算力、API、固定资本、工资、周转、价格和平台权力。

第四章将专门讲周转对利润率的影响，把第二卷的资本周转理论接入第三卷利润率分析。
