## 总逻辑

全卷二十五章可以连成一条线：

```text
商品 -> 交换过程 -> 货币和商品流通 -> 货币转化为资本
-> 劳动过程和价值增殖过程 -> 不变资本和可变资本
-> 剩余价值率 -> 工作日 -> 剩余价值量
-> 相对剩余价值 -> 协作 -> 分工和工场手工业
-> 机器和大工业 -> 绝对剩余价值和相对剩余价值
-> 劳动力价格和剩余价值变化 -> 剩余价值率公式
-> 工资形式 -> 计时工资 -> 计件工资
-> 工资的国民差异 -> 简单再生产 -> 剩余价值转化为资本
-> 资本主义积累的一般规律 -> 所谓原始积累 -> 现代殖民理论
```

第一章先分析商品这个资本主义社会的基础单位：商品有使用价值和价值，劳动有具体劳动和抽象劳动，价值通过货币形式表现，并由此产生商品拜物教。

第二章说明商品不会自己交换，交换必须通过商品所有者的社会关系完成。随着交换关系扩大，一般等价物会被推出并固定下来，形成货币。

第三章展开货币的职能：价值尺度、流通手段、贮藏手段、支付手段和世界货币。货币让商品世界高速运转，也让买卖分离、债务链条和危机可能性出现。

第四章追问钱为什么会变成资本。普通交换是“商品 - 货币 - 商品”，资本运动则是“货币 - 商品 - 更多货币”。多出来的价值不能靠单纯流通解释，关键在于劳动力成为商品，并在生产中创造剩余价值。

第五章进入生产过程，说明同一个生产过程有两面：从劳动过程看，人用工具和对象生产使用价值；从价值增殖过程看，资本家购买生产资料和劳动力，让活劳动创造超过劳动力价值的新价值。

第六章区分不变资本和可变资本。不变资本用于购买生产资料，只把已有价值转移到产品中；可变资本用于购买劳动力，能在生产中创造超过自身价值的剩余价值。

第七章提出剩余价值率，即 `m / v`，它在劳动时间上等于剩余劳动与必要劳动的比例。这个概念用来衡量资本对劳动力的剥削程度，而不是普通利润率。

第八章讨论工作日。由于剩余价值来自剩余劳动，资本有延长工作日的内在冲动；劳动者则必须保留休息、恢复和生活时间。工作日长度不是自然事实，而是资本与劳动斗争的结果。

第九章把剩余价值率扩展为剩余价值量。剩余价值总量取决于可变资本总量和剩余价值率：资本既要提高单个劳动者的剩余劳动比例，也要扩大被自己支配的劳动规模。

第十章提出相对剩余价值。资本不只通过延长工作日增加剩余价值，也会通过提高生产力、降低劳动力再生产所需生活资料价值、压缩必要劳动时间，让同样工作日中的剩余劳动比例提高。

第十一章分析协作。许多人共同劳动会产生单个劳动者没有的集体生产力，但在资本主义条件下，这种集体生产力表现为资本的组织能力和支配力量。

第十二章分析分工和工场手工业。资本把完整劳动拆成局部工序，提高效率，也把完整劳动者变成局部劳动者，使劳动者更依赖资本掌握的整体生产过程。

第十三章分析机器和大工业。机器体系极大提高生产力，但在资本主义条件下，它被用来生产相对剩余价值、控制劳动节奏、替代或重组劳动者，并让人服从资本占有的机器系统。

第十四章综合绝对剩余价值和相对剩余价值。前者以延长工作日为核心，后者以提高生产力、缩短必要劳动时间为核心；二者共同构成资本主义生产剩余价值的基本机制。

第十五章分析劳动力价格和剩余价值的量的变化。工作日长度、劳动强度和劳动生产力共同影响工资、必要劳动和剩余价值；工资上涨、技术提效和剩余价值增加可以同时发生。

第十六章整理剩余价值率的各种公式。`m / v`、剩余劳动与必要劳动之比、剩余产品与必要产品之比，是从价值、时间和产品三个角度揭示同一个剩余价值关系。

第十七章说明工资形式的核心遮蔽。工资看起来像劳动的价格，实际上是劳动力价值或价格的转化形式；它把必要劳动和剩余劳动混在一起，使全部劳动看起来都得到了报酬。

第十八章分析计时工资。时薪、日薪、月薪把劳动力价格分摊到时间单位上，但真实工资水平必须结合实际工时、加班、待命、劳动强度和未支付准备时间来理解。

第十九章分析计件工资。计件工资把工资表现为每件产品或任务的报酬，制造“多劳多得”的表象，同时便于资本提高劳动强度、转嫁风险、组织竞争和进行平台化管理。

第二十章分析工资的国民差异。比较不同国家工资不能只看名义数字，而要看购买力、生活资料价值、劳动生产率、劳动强度、全球分工和价值链位置。

第二十一章进入简单再生产。即使资本家把剩余价值全部消费掉、不扩大生产规模，生产过程也会不断再生产资本、劳动力，以及资本家和雇佣劳动者之间的关系。

第二十二章分析剩余价值转化为资本。资本积累就是把剩余价值的一部分重新投入生产，使过去无偿占有的剩余劳动转化为支配更多活劳动的追加资本。

第二十三章分析资本主义积累的一般规律。资本积累扩大财富和生产力，同时也通过技术进步、资本构成变化和资本集中，生产相对过剩人口和产业后备军。

第二十四章分析所谓原始积累。资本主义的起点不是勤俭神话，而是生产者同生产资料相分离的历史过程；它形成了一边拥有资本和生产资料的人，另一边只能出卖劳动力的自由劳动者。

第二十五章分析现代殖民理论。殖民地场景说明，只要劳动者还能获得土地和生产资料，他就不愿稳定出卖劳动力；资本主义工资劳动必须以劳动者失去独立生产条件为前提。
