# 《资本论》第二卷第十四章：流通时间

第五章已经讲过流通时间。

为什么第十四章又讲一次？

区别在于：第五章更侧重资本循环中的价值关系，说明流通不创造价值却是价值实现的必要环节；第十四章则放在“资本周转”这一篇里，重点说明流通时间怎样影响周转时间和预付资本量。

一句话概括本章：

> 流通时间由销售时间和购买时间构成，它不创造价值，却会延长资本周转，使资本停留在商品资本或货币资本形态中，不能立即回到生产过程。

## 周转时间的另一半

资本的周转时间是：

```text
周转时间 = 生产时间 + 流通时间
```

前两章讲了生产方面的时间：

- 工作期间
- 生产时间

现在要看流通方面。

产品生产完成后，资本还没有完成周转。

商品必须卖出去。

货币必须收回来。

货币还要重新变成生产资料和劳动力。

所以流通时间包括两部分：

```text
销售时间：W' - G'
购买时间：G - W
```

销售时间通常更关键，因为商品卖不出去，价值和剩余价值就不能实现。

购买时间也重要，因为买不到生产资料和劳动力，下一轮生产就不能开始。

## 销售时间

销售时间，就是资本以商品资本形式等待变成货币的时间。

商品已经生产出来，但还没有卖出。

在这段时间里，资本停留在：

```text
W'
```

它不能作为生产资本发挥作用。

它也不能作为货币资本重新购买生产要素。

它只是等待实现。

传统行业中，销售时间受很多因素影响：

- 市场距离；
- 运输；
- 需求强弱；
- 竞争；
- 季节；
- 商品保质期；
- 商业信用；
- 支付习惯；
- 价格波动。

现代 AI 行业中，销售时间也很典型：

- 线索获取；
- demo；
- POC；
- 预算申请；
- 安全审查；
- 法务谈判；
- 采购流程；
- 领导审批；
- 合同盖章；
- 验收；
- 开票；
- 账期。

产品技术上已经能用，但资本还没有回到货币形态。

这就是流通时间。

## 商品资本的停滞

销售时间越长，商品资本停滞越久。

这会带来几种后果。

第一，占用资本。

已经投入的价值不能回收。

第二，产生额外费用。

商品要储存、维护、展示、推广。

数字产品也要维护试用环境、售前支持、客户成功和安全材料。

第三，产生贬值风险。

商品可能过时、降价、被竞品替代。

AI 产品尤其明显。

一个功能如果迟迟卖不出去，三个月后上游模型可能已经免费提供类似能力。

这时原来产品的市场价值会下降。

销售时间不是单纯等待，而是资本暴露在市场风险中的时间。

## 购买时间

购买时间，就是资本从货币形态重新转化为生产要素的时间。

公式是：

```text
G - W
```

资本家需要买到：

- 原材料；
- 机器；
- 燃料；
- 劳动力；
- 云服务；
- 数据；
- 模型 API；
- 办公工具；
- 合规服务。

如果购买顺利，生产可以快速开始。

如果购买受阻，货币资本会闲置。

比如：

- GPU 采购排队；
- 云资源开通慢；
- 数据授权谈不下来；
- 关键工程师招不到；
- 模型 API 额度受限；
- 企业客户环境迟迟不给权限；
- 跨境支付或合规审批拖延。

这时公司账上有钱，但钱不能立刻变成生产能力。

货币资本停留在货币形态，也不能增殖。

## 货币资本的停滞

很多人以为有现金就安全。

现金当然重要，但从资本角度看，现金如果不能转化为生产资本，也不会自动增殖。

货币资本停滞可能来自：

- 找不到合适投资项目；
- 供应链断裂；
- 生产资料涨价；
- 政策审批；
- 招聘困难；
- 市场不确定；
- 风险太高不敢扩张。

这解释了为什么经济低迷时，有些公司账上有钱却不投资。

货币资本并不是因为有钱就自然进入生产。

它需要可预期的销售、可获得的生产要素和足够利润前景。

如果这些条件不具备，货币会停在资本循环之外或转向金融市场。

## 空间距离和流通时间

马克思特别重视空间距离。

商品从生产地点到市场，需要时间。

生产资料从供应地到工厂，也需要时间。

交通和通信越落后，流通时间越长。

资本会不断发展交通、通信和物流系统，以压缩空间带来的时间障碍。

现代数字经济看似取消了距离，但并没有完全取消。

它把距离变成新的形式：

- 网络延迟；
- 数据跨境；
- CDN 节点；
- 云区域；
- 合规边界；
- 本地化部署；
- 支付通道；
- 语言和市场差异；
- 时区协作。

一个 AI 服务从美国云区调用亚洲用户的数据，可能遇到延迟和合规问题。

一个 SaaS 产品进入欧洲市场，可能需要 GDPR、数据驻留和本地支付。

这些都是现代流通时间的一部分。

## 信用对流通时间的影响

信用制度可以改变流通时间对资本家的压力。

如果商品卖出但客户暂时不付款，资本家可以：

- 给客户账期；
- 用应收账款融资；
- 找银行贴现；
- 通过平台提前结算；
- 用供应商账期对冲。

信用可以让资本在货币真正回流前继续运转。

但信用不能取消价值实现问题。

如果最终客户不付款，风险仍然爆发。

现代 ToB 公司很熟悉这一点。

合同额很漂亮，ARR 看起来增长，但如果回款慢、坏账高、客户续费差，公司现金流仍然会恶化。

信用只是把时间差包装起来，不是让时间差消失。

## 流通时间会反过来影响生产

流通时间不是生产之外的被动因素。

它会反过来塑造生产。

如果销售时间长，公司可能会：

- 做预售；
- 做定制化；
- 增加售前；
- 缩短产品线；
- 改变定价；
- 提高合同金额；
- 要求预付款；
- 选择更近市场；
- 放弃某些客户。

如果购买时间长，公司可能会：

- 建库存；
- 签长期供应合同；
- 自建算力；
- 多供应商策略；
- 提前招聘；
- 建数据资产；
- 标准化技术栈。

所以流通条件会反作用于生产组织。

资本不是先生产、后流通这么简单，而是在生产前就预判流通。

## 平台为什么能压缩流通时间

平台经济的一个重要作用，是压缩某些流通时间。

比如电商平台帮助商家：

- 找客户；
- 展示商品；
- 支付结算；
- 信用评价；
- 物流配送；
- 售后处理。

开发者平台也类似：

- 应用市场分发；
- API 市场；
- 插件市场；
- 自动支付；
- 订阅管理；
- 用户评价；
- 文档和示例。

这些机制可以让生产者更快卖出商品。

但平台也因此控制了价值实现通道。

它可以抽成、排序、限流、封禁、改变规则。

这说明流通时间的压缩往往伴随流通权力的集中。

对独立开发者来说，平台既是加速器，也是依赖来源。

## 自助订阅为什么重要

AI SaaS 和开发者工具常追求自助订阅。

用户从注册到付费的流程越短，流通时间越短。

理想路径是：

```text
看到产品 -> 注册 -> 试用 -> 绑定支付 -> 开始使用 -> 自动续费
```

相比之下，传统 ToB 路径是：

```text
线索 -> 销售 -> POC -> 合同 -> 审批 -> 验收 -> 回款
```

前者单价可能低，但周转快。

后者单价高，但流通时间长。

两种模式没有绝对优劣，但资本结构完全不同。

小团队如果现金有限，长销售周期会非常危险。

这就是为什么很多 AI 创业者努力寻找 PLG、开源获客、自助付费和标准化交付。

## 对 AI 开发者的理解抓手

第十四章可以转化成一个实际检查表。

对于一个产品或项目，你要问：

- 产品完成后多久能卖出？
- 客户从试用到付款要多久？
- 合同和审批要多久？
- 账期多久？
- 款项能否自动收取？
- 生产资料采购是否稳定？
- 上游 API 和云服务是否随时可得？
- 招聘是否会拖慢生产？
- 是否需要平台分发？
- 平台抽成和结算周期多久？

这些问题都属于流通时间。

很多技术人只看产品开发速度，却低估销售和采购时间。

结果产品做出来，钱回不来；或者钱有了，关键资源买不到。

资本周转就在这些地方被卡住。

## 本章的核心结论

第十四章的核心是把流通时间放进周转分析。

可以总结为：

```text
流通时间 = 销售时间 + 购买时间
```

销售时间让资本停留在商品资本形态。

购买时间让资本停留在货币资本形态。

二者都不创造价值，但都会延长周转时间，增加预付资本需求。

对现代 AI 应用来说：

- ToB 销售周期是典型流通时间；
- 账期和验收会推迟价值实现；
- GPU、数据、模型 API 的采购会影响下一轮生产；
- 平台可以缩短流通时间，也可能抽取和控制价值实现；
- 自助订阅和预付费是缩短流通时间的重要形式。

第十五章会把这些时间差进一步量化：周转时间长短会怎样改变维持连续生产所需的预付资本量。
