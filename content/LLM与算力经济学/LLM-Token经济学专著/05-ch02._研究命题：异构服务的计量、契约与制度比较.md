# ch02. 研究命题：异构服务的计量、契约与制度比较

> 本章把“交付什么、如何交易、为何采用新制度”连接起来。货币化是其中可检验的特殊分支；它不成立，不妨碍普通计算服务交易成立，也不自动证明路由、积分或创业项目有价值。

**本章衔接：**先读 [ch04 的四项坐标](07-ch04._概念坐标系：异构服务的四项交易坐标.md)与 [ch16 核心方法](19-ch16._跨模型任务成本：完整账单、验收与迁移条件.md#16.0%20核心方法阅读入口)。本章确定要检验的制度问题，再由 [ch06](09-ch06._服务契约的四组约束：计量、权利、漂移与归责.md)展开可执行性约束。

## 2.1 从业务任务建立共同反事实

共同问题是：**在同等质量、履约和风险约束下，新安排能否比现行法币采购降低总成本，或带来足以覆盖新增成本的服务价值？** 生产交付成本与狭义交易费用应分列：前者包括推理、核验和返工，后者包括寻源、订约、对账、执行与争议处理；比较方案时再在不重复的边界内汇总。

在 [技术报告核验教学队列](03-ch00._入门预读.md#0.9%20贯穿案例与三项采购工具)中，先观察人工流程的成本与失误，再比较单模型或多模型加复核。若人工流程已经足够经济，继续使用它是有效结论；若新流程改善交付，还需分别问客户愿付多少、服务商能否持续覆盖成本。

这条主线把采购研究接向经营研究：采购侧的可测改善是候选价值来源，付费采用、收入留存和责任成本决定它能否成为业务。两者之间需要证据，不能由“技术有用”直接跳到“创业可行”。

## 2.2 三个相接但不可互相替代的研究环节

| 环节 | 需要明确的对象 | 能够支持的判断 |
|---|---|---|
| 可比较交付 | 任务、质量、时限、数据边界、完整处理政策 | 哪个候选流程在共同约束下改善成本或结果 |
| 可执行交换 | 交付责任、价格、付款、授权、退款与违约 | 谁可提供和采购服务，风险与费用落在谁身上 |
| 可持续制度 | 供给组织、激励、接受范围、跨期承诺 | 新安排是否比现有工具更值得采用并持续经营 |

计量改善可以服务普通采购，不要求出现可转让资产；可转让服务权益可以用于特定联盟，不要求成为通用货币；自动化支付也可使用已有账户，不要求另发代币。三个环节相互提供条件，但不是从词元到货币的演进阶梯。

## 2.3 制度比较如何接入产品与创业问题

| 候选安排 | 要解决的具体问题 | 必须比较的现有替代品 | 还需取得的证据 |
|---|---|---|---|
| AI 与专家核验 | 可控成本下交付可靠结果 | 人工流程、单模型加复核 | 全量成本、质量与独立客户付费 |
| 路由与支出治理 | 跨供应商选择、可靠性或授权困难 | 直连 API、现有网关、企业费控 | 净收益超过集成维护与迁移费用 |
| 预付或可转让服务券 | 付款、贡献激励或跨主体承兑摩擦 | 月结、现金报酬、普通预付余额 | 接受需求、可执行权利与履约资金 |
| 容量或价格合同 | 有明确期限与规格的采购风险 | 按量采购、备援、固定价或预留合同 | 风险改善超过基差、资金与执行成本 |

这不是完整产品分类，而是反事实比较的示范。[ch08](11-ch08._六组可组合方案：客户问题、交付责任与单位经济.md)将其组织成六组可组合方案，[ch09](12-ch09._价值链分布：利润池结构、议价权与演化迁移.md)区分客户支出与经营者收入，[ch13](16-ch13._决策框架：预先登记评价标准、采用与停止条件.md)及 [ch15](18-ch15._试验设计与证据记录：按预设标准采用、调整或停止.md)规定如何验证。市场规模只约束潜在经营上限，不替代上述证据。

## 2.4 五项需要落到记录与合同的子问题

1. **可比较计量**：定义输入语料、模型版本、质量门槛、延迟和成本边界；输出任务成本分布，而不是一个通用“智能汇率”。
2. **可执行权利**：核查数据使用、转售许可、余额归属、服务级别、退款与到期规则。第三方签名不能扩张上游合同权利。
3. **跨期风险**：区分单价、用量、容量、供应商违约和模型淘汰风险，分别比较合同或风险管理工具。
4. **履约验证**：预设验收、争议、替代交付及赔付上限，记录全部失败和人工兜底。
5. **采用与持续经营**：用付费复购、收入、交付成本及真实接受需求检验，而非用代币交易量代替服务市场。

## 2.5 特殊分支：服务权益何时具有货币功能

一个平台可以允许用户购买或贡献劳动获得凭证，再兑换服务。流转的是发行人承诺承兑的**服务请求权**，不是已经生成的词元。首先写清发行主体、面额、可兑付服务、期限、转让与退款规则；若没有额外流转需求，普通预付服务券已经足以描述该安排。

现代教材用记账单位、交换媒介和价值储藏分析货币；Jevons 在 1875 年书中另列延期支付标准，共四项功能。基础说明见[英格兰银行](https://www.bankofengland.co.uk/quarterly-bulletin/2014/q1/money-in-the-modern-economy-an-introduction)。这些功能可以分离，不能当作三个必然递进的行业阶段。

| 功能问题 | 需要观察什么 | 容易混淆的普通交易 |
|---|---|---|
| 是否成为记账单位？ | 商品价格、债务与退款是否真正以该权益表达 | “USD 3/百万 token”仍以美元记账 |
| 是否成为交换媒介？ | 第三方是否愿接受，用于购买其他商品或服务 | 发行方自己承兑服务券，或用户以稳定币买 API |
| 是否用于跨期储藏？ | 持有需求、未来兑换能力、价格及信用风险 | 为已知短期用量预付，不等于通用储蓄需求 |

局部网络也可能形成受限交换媒介，不要求全球无条件接受。即使一种功能出现，也应独立检验其余功能、制度成本和法律分类；不以达到“完整货币”作为所有服务方案的成功标准。

转移数据库记录不等于转移可执行的兑付权。实际交易须检查发行方承认、上游授权、接受方需求及违约处理；[OpenAI Service Credit Terms](https://openai.com/policies/service-credit-terms/)是条款核查入口之一，适用版本及读取状态见 [附录 C](02-附录_C._核心文献、行业规范与实证数据源汇编.md)，不能据一家条款概括所有供应商。

跨期判断还取决于持有的权益：

| 权益 | 服务降价时的可能变化 | 其他主要风险 |
|---|---|---|
| 固定数量、固定版本 token 配额 | 法币替代采购价值可能下降 | 下线、到期、不能转让 |
| 固定法币面额服务余额 | 同一余额可能买到更多服务 | 发行人信用、定价与使用限制 |
| 固定容量时段 | 特定高峰时段仍可能稀缺 | 空置、限流条款、履约 |
| 固定质量任务券 | 取决于验收及替代模型成本 | 验证争议、需求变化 |

运营备付、折扣或保供可以提供持有理由，但不保证成为通用储蓄工具。若凭证安排增加的账本、兑换、治理与履约费用超过其收益，应放弃凭证层，而不是据此否定底层服务需求。

## 2.6 与加密资产的关系

比特币没有对特定发行人的服务兑付请求权，其价值与网络使用、稀缺性、风险偏好及市场预期有关。服务券则依赖发行人的履约能力。二者的风险结构不同，但“消耗过算力”既不保证资产有价值，也不给服务券建立不可跌破的价格底线。

商品货币要求商品实际被用作交换媒介；可兑换商品的凭证更接近代表性或信用性权利。LLM 词元本身不满足这些定义。

## 2.7 商品制度提供比较工具，而非演进脚本

原油合同的“美元/桶基准价 + 升贴水”分别涉及货币单位、数量单位和价格参照；信用证、仓单与衍生品则分别处理付款承诺、货物权利与风险敞口。计算服务可以借鉴这种职责分离：

- 升贴水帮助比较有差异的交付品，但不是跨模型固定换算常数。
- 仓单代表可识别库存，未来推理是尚待生产的服务，需额外处理产能和信用风险。
- 买方担心采购价格上涨可锁定采购价；持有库存担心跌价与供应商担心售价下降，是不同套保方向。远期不自动消除用量或容量风险。
- 中央对手方和保证金能够分配违约损失，不能消除所有风险。
- 指数须证明相对现有报价与账单审计的增量用途；不需要公共指数时，可继续使用客户内部基准。

## 2.8 本章小结

本书不是从“token 有用”推导“token 应成为货币”，而是从可验收服务出发比较制度。计量和契约给出共同边界，客户采用与单位经济检验经营价值，货币功能仅在额外流转与持有需求下单独研究。
