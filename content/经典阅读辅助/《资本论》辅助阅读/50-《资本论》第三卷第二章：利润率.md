# 《资本论》第三卷第二章：利润率

第一章讲成本价格和利润。

商品价值从：

```text
c + v + s
```

表现为：

```text
k + p
```

其中成本价格 `k = c + v`，利润 `p` 是剩余价值 `s` 的转化形式。

第二章继续推进：

> 如果利润相对于全部预付资本来计算，会发生什么？

答案是利润率。

一句话概括本章：

> 利润率把剩余价值同全部预付资本相比，而不是同可变资本相比；因此它进一步遮蔽了剩余价值的来源，使资本家觉得全部资本都按比例产生利润。

## 剩余价值率和利润率

第一卷中的剩余价值率是：

```text
m' = s / v
```

它表示剩余价值同可变资本的比例。

也就是：

`工人创造的剩余价值 / 工资价值`

第三卷中的利润率是：

```text
p' = s / (c + v)
```

或者写成：

```text
p' = p / C
```

其中 `C` 是预付总资本。

它表示利润同全部预付资本的比例。

这两个公式差别很大。

剩余价值率揭示剥削程度。

利润率表现资本增殖程度。

资本家日常关心的是后者。

## 为什么资本家更关心利润率

资本家投资时，不会只问：

> 工资资本带来多少剩余价值？

他会问：

> 我总共投了多少钱？
> 一年赚多少钱？
> 回报率是多少？
> 和别的行业相比怎么样？

比如两个项目：

项目 A：

- 总投入 100 万
- 利润 20 万
- 利润率 20%

项目 B：

- 总投入 1000 万
- 利润 100 万
- 利润率 10%

资本家可能更喜欢 A，因为资本回报率更高。

这就是利润率的现实意义。

资本不是为了抽象地生产剩余价值，而是为了让预付资本增殖。

## 利润率怎样遮蔽剩余价值来源

剩余价值率公式是：

```text
s / v
```

它把剩余价值同工资资本联系起来。

利润率公式是：

```text
s / (c + v)
```

它把剩余价值同全部资本联系起来。

这样一来，生产资料和劳动力的区别进一步消失。

机器、原料、云服务、GPU、工资，都被放到分母里。

利润似乎来自它们共同作用。

比如一个 AI 公司：

```text
c = 800 万
v = 200 万
s = 200 万
```

剩余价值率：

```text
s / v = 200 / 200 = 100%
```

利润率：

```text
s / (c + v) = 200 / 1000 = 20%
```

资本家看到的是：

> 总资本 1000 万，利润 200 万，利润率 20%。

他不会从利润率中直接看到劳动力被剥削 100%。

这就是利润率形式的遮蔽作用。

## 同一剩余价值率，不同利润率

利润率受总资本构成影响。

假设两个行业剩余价值率都为 100%。

行业 A：

```text
c = 50
v = 50
s = 50
利润率 = 50 / 100 = 50%
```

行业 B：

```text
c = 90
v = 10
s = 10
利润率 = 10 / 100 = 10%
```

两个行业对工人的剥削率相同。

但利润率差别很大。

原因是 B 的不变资本占比高，可变资本占比低。

因为剩余价值只来自可变资本所购买的劳动力，而利润率却把全部资本都放进分母。

这为后面“平均利润率”和“利润率趋向下降”打下基础。

## AI 行业中的资本构成

AI 行业内部也有不同资本构成。

应用外包公司：

- c 较低：主要是云服务、工具、办公设备
- v 较高：工程师和交付人员工资

基础模型公司：

- c 很高：GPU、数据中心、训练数据、能源、基础设施
- v 也高：研究员和工程团队
- 但 c 的占比可能更高

纯平台分发公司：

- c 包含平台系统、数据、品牌和流量基础设施
- v 包含运营、研发、销售
- 还可能通过抽成参与剩余价值分配

如果剩余价值率相同，资本构成越偏向不变资本，利润率可能越低。

当然现实中还受垄断、知识产权、平台权力、融资成本、价格等因素影响。

但基本逻辑是：利润率不能只看劳动强度，还要看总资本结构。

## 预付资本和消耗资本

利润率计算中还要注意预付资本和实际消耗资本的区别。

有些资本一次生产中全部消耗。

比如原料、API 调用、云推理费用。

有些资本长期使用，只把一部分价值转移到商品中。

比如 GPU、服务器、办公设备。

资本家计算利润率时，会从全部预付资本角度考虑投资回报。

但商品成本中只包含固定资本当期转移的折旧部分。

这会让利润率计算比简单公式更复杂。

比如你花 1000 万买 GPU，预计用 5 年。

每年折旧 200 万进入成本。

但投资人会问：

> 这 1000 万总投资一年能赚多少？

所以固定资本规模会影响利润率，即使它的价值不是一次性进入商品。

这和第二卷的固定资本周转直接相连。

## 利润率和周转

虽然第二章主要建立利润率概念，但它已经为第四章埋下伏笔。

利润率不仅取决于：

```text
s / (c + v)
```

还会受资本周转速度影响。

同一笔资本一年周转多次，年利润率可能更高。

比如一个项目单次利润率 10%。

如果一年周转 1 次，年利润率大约是 10%。

如果一年周转 4 次，年利润率可能接近 40%。

当然现实还要考虑固定资本、闲置、流通费用和价格变化。

但基本方向是：资本家关心的是一定时期内总资本的增殖。

因此第三卷第四章会把第二卷周转理论接回利润率。

## 利润率和经营决策

利润率是资本配置的核心指标。

资本会流向利润率高的领域，离开利润率低的领域。

现代投资语言里，这表现为：

- ROI；
- ROIC；
- gross margin；
- operating margin；
- payback period；
- capital efficiency；
- burn multiple。

这些指标不等于马克思的利润率，但都在不同层面追问同一件事：

> 预付资本的回报如何？

AI 创业中，投资人会问：

- 每获得一美元 ARR 要烧多少钱；
- 毛利能否覆盖推理成本；
- 销售周期多长；
- 客户生命周期价值是否大于获客成本；
- 算力投入能否形成规模收益；
- 资本回收期多久。

这些都是利润率问题的现代形式。

## 利润率和剥削程度不是一回事

一个常见误解是：利润率越高，剥削率一定越高。

不一定。

利润率受多个因素影响：

- 剩余价值率；
- 资本有机构成；
- 周转速度；
- 原材料价格；
- 工资水平；
- 技术效率；
- 市场价格；
- 垄断能力；
- 流通费用。

剥削率高，但如果不变资本巨大、周转慢，利润率可能不高。

剥削率相同，但资本构成不同，利润率也不同。

这就是为什么第三卷要从剩余价值率转到利润率。

现实资本主义竞争不是直接围绕剩余价值率展开，而是围绕利润率展开。

但利润率背后仍然有剩余价值。

## 利润率为什么会成为表面规律

资本家之间比较的不是谁剥削率更高，而是谁投资回报更高。

这会产生一种表面规律：

> 资本按大小获得利润。

投入 1000 万，就应该按平均利润率获得利润。

投入 1 亿，就应该获得更大绝对利润。

这看起来很自然。

但从价值分析看，剩余价值来自活劳动。

如果一个资本拥有很多机器却雇很少工人，它直接生产的剩余价值可能不多。

后面平均利润率形成后，资本会通过竞争分享社会总剩余价值。

第二章还没展开这个问题，但利润率概念已经为它准备好了。

## 对 AI 开发者的理解抓手

你可以把利润率看成资本系统的“收益率指标”。

但要同时保留两层：

- 业务层：利润 / 总投入
- 价值层：剩余价值 / 可变资本

比如一个 AI 产品毛利率很高，但需要巨额前期研发和算力投入。

利润率未必高。

一个咨询项目毛利率一般，但几乎无固定资本、回款快，资本收益率可能不错。

一个开源基础设施项目用户很多，但商业化弱、维护成本高，利润率可能低。

所以判断商业模式时，不要只看收入或毛利。

要看：

- 总资本投入；
- 固定资本占用；
- 工资和劳动组织；
- 周转速度；
- 上游成本；
- 是否有定价权；
- 利润是否可持续。

## 国学类比：形上与形下

如果借一个类比，剩余价值率像在看关系的“里层”，利润率像在看市场表现的“外层”。

形下的账本当然要看。

但只看形下，就会把资本的表面运动当成本质。

这里不需要把马克思和传统哲学硬合并，只要借这个差别帮助记忆：

> 剩余价值率揭示生产关系；
> 利润率表现资本回报。

## 本章的核心结论

第二章建立了利润率公式：

```text
p' = s / (c + v)
```

它和剩余价值率不同：

```text
m' = s / v
```

剩余价值率揭示剥削程度。

利润率表现全部预付资本的增殖程度。

利润率进一步遮蔽剩余价值来源，因为它让利润看起来像全部资本共同产生的结果。

对 AI 和软件行业来说，这章提醒我们：

- 高收入不等于高利润率；
- 高毛利不等于高资本回报；
- 固定资本和周转速度会影响利润率；
- 工资、云、API、GPU 在财务上都是成本，但在价值分析中地位不同；
- 资本家真正比较的是总资本回报，而不是剩余价值来源。

第三章会进一步分析：利润率和剩余价值率之间到底由哪些因素连接，为什么同一个剩余价值率会表现为不同利润率。
