# 《资本论》第二卷第十一章：关于固定资本和流动资本的理论：李嘉图

第十章讲了重农学派和亚当·斯密。

马克思指出，前人虽然已经看到了固定资本和流动资本的区别，但往往把周转形式、物质形态、生产资本和流通资本混在一起。

第十一章继续讲李嘉图。

李嘉图比斯密更关注价值、工资、利润和价格之间的关系，所以他的讨论更接近古典政治经济学的核心问题。

但在固定资本和流动资本问题上，他仍然没有摆脱混乱。

一句话概括本章：

> 李嘉图把固定资本和流动资本主要当作说明价格变动的工具，却没有真正区分固定/流动与不变/可变，从而把劳动力、工资、原料和机器之间的本质差别压扁成周转快慢和耐久程度的差别。

## 为什么还要讲李嘉图

如果你只是想快速理解资本周转，理论史似乎可以跳过。

但马克思连续两章批判斯密和李嘉图，是因为这里牵涉到一个根本问题：

> 资本家的成本视角，会不会遮蔽剩余价值的来源？

资本家看账本时，会看到：

- 机器成本；
- 原料成本；
- 工资成本；
- 租金成本；
- 利息成本；
- 销售成本；
- 云服务成本；
- API 成本。

这些都表现为“成本”。

如果只从成本角度看，它们似乎只是：

> 有些用得久；
> 有些用得快；
> 有些一次性消耗；
> 有些多年折旧。

这就是固定资本和流动资本的表层差别。

但马克思认为，只停留在这里就不够。

因为工资购买的是劳动力，而劳动力在生产过程中能创造新价值和剩余价值。

机器、原料、燃料、API 调用这些生产资料，只是把自身已有价值转移到产品中。

所以必须同时保留两组区分：

> 固定资本 / 流动资本：价值怎样周转；
> 不变资本 / 可变资本：价值能否增殖。

李嘉图的问题，就是没有把这两组区分彻底分开。

## 李嘉图关心什么

李嘉图最关心的是价值和分配。

他要解释：

- 商品价值由什么决定；
- 工资变化怎样影响利润；
- 利润率变化怎样影响价格；
- 不同资本结构为什么会导致价格偏离劳动价值。

这已经比普通商业常识深入很多。

但在讨论固定资本和流动资本时，李嘉图常常是为了说明一种特殊问题：

> 当工资变化时，不同资本构成的行业，商品价格会怎样变化？

比如两个行业：

> 行业 A：大量使用机器，工资占比低；
> 行业 B：大量使用人工，工资占比高。

如果工资上涨、利润下降，两类行业的价格受影响可能不同。

李嘉图借固定资本和流动资本来说明这种差别。

这个问题并非没有意义。

但马克思认为，李嘉图因此把固定/流动概念主要服务于价格理论，却没有充分分析它们作为生产资本周转形式的意义。

## 李嘉图的混淆

李嘉图常把固定资本理解为：

`投在工具、机器、建筑等耐久生产资料上的资本`

把流动资本理解为：

`用于维持劳动的资本`

也就是工资或生活资料。

这就有问题。

从周转角度看，工资确实属于流动资本。

因为工资每个周期都要支付，它的价值通过商品销售回流后又要重新垫付。

但流动资本不只有工资。

原料、辅助材料、燃料、按量消耗的云资源、模型 API 调用费，也都是流动资本。

它们在一次生产中被消耗，价值一次性进入产品。

如果把流动资本主要等同于工资，就会漏掉大量生产资料中的流动部分。

更严重的是，工资和原料虽然都属于流动资本，但在价值增殖中的作用完全不同。

工资对应劳动力。

劳动力能创造新价值。

原料只是转移已有价值。

李嘉图没有把这个差别讲清楚。

## 一个现代例子

假设有两家 AI 公司。

公司 A 自建算力：

- GPU 集群：大量固定资本
- 工程师工资：流动资本中的可变资本
- 电力和维护：流动资本中的不变资本

公司 B 主要调用外部模型 API：

- 自有固定资产少
- 工程师工资：流动资本中的可变资本
- API 调用费：流动资本中的不变资本

如果我们只说：

`A 固定资本多，B 流动资本多`

这只是周转维度。

如果进一步说：

`B 的工资和 API 调用费都是流动资本，所以性质一样`

这就错了。

工资购买劳动力，劳动力在开发、运维、调试、客户交付中创造新价值。

API 调用费购买的是上游已经商品化的服务，它把已有价值转移到你的产品成本里。

二者在现金流上都要按期支付，但在剩余价值分析中不能合并。

李嘉图式混淆，在今天就表现为把一切都叫“成本项”。

## “维持劳动的资本”有什么问题

古典经济学中常有一种说法：资本家预付一笔资本，用来维持工人的生活。

这听起来好像工资是一种生活资料基金。

但马克思会追问：

资本家购买的到底是什么？

不是直接购买“劳动者的生活”，而是购买劳动力。

工人拿工资去买生活资料，是劳动力再生产的过程。

资本家支付工资，是为了获得劳动力在一定时间内的使用权。

在生产过程中，劳动力创造出的价值可以超过工资价值。

剩余价值正来自这个差额。

如果把工资只看成“维持劳动的资本”，就容易把劳动力的商品性质遮住。

这就像把开发者工资说成“维持程序员生活的费用”。

这句话不是完全没道理，但它没有说到资本关系的核心。

公司支付工资，不是为了慈善地维持你生活，而是为了购买你的开发能力、判断能力、调试能力、架构能力和交付能力。

这些能力在生产过程中创造产品价值。

## 李嘉图为什么会忽略原料

李嘉图讨论固定和流动时，经常把焦点放在机器和工资的对比上。

这和他关心工资、利润、价格关系有关。

但这样一来，原料、辅助材料等流动的不变资本就容易被边缘化。

在现实生产中，这部分非常重要。

传统制造业里有：

- 棉花；
- 铁；
- 煤；
- 燃料；
- 化学材料；
- 包装材料。

AI 行业里有：

- token 调用；
- 云计算；
- 向量数据库；
- 存储读写；
- 数据采购；
- 标注服务；
- 训练样本；
- 第三方 API。

这些投入不是工资，但也不是固定资本。

它们是流动的不变资本。

如果理论上没有这个位置，就会把资本结构讲歪。

## 固定资本的耐久性不是全部

李嘉图还常从耐久程度理解固定资本。

机器耐用，所以是固定资本。

工资和生活资料很快消耗，所以是流动资本。

这有一定现实基础，但仍然不够精确。

马克思的标准是价值周转方式。

有些东西物理上耐用，但如果是被商人买来转卖，它对商人来说不是固定资本，而是商品资本。

有些东西物理上不耐用，但如果作为长期生产条件的一部分被不断更新，它在资本周转中有特定位置。

比如软件系统没有像机器那样的物理磨损，但可能长期参与生产，并通过多期收入逐步回收开发投入。

数据集也可能长期用于模型训练、评估和产品迭代。

它们是否具有固定资本特征，要看它们在生产过程中的职能和价值回收方式。

这比单纯问“耐不耐用”更准确。

## 价格问题和周转问题不能混在一起

李嘉图关注价格变化，这是合理的。

不同资本结构会影响价格形成。

固定资本多、周转慢的行业，和工资占比高、周转快的行业，在利润率平均化时会表现出不同价格关系。

这个问题在《资本论》第三卷会更充分展开。

但第二卷这里的重点不是价格偏离价值，而是资本周转。

也就是说，我们现在问的不是：

> 这个商品最后价格如何形成？

而是：

> 预付资本各部分怎样进入生产、怎样转移价值、怎样回到资本家手里？

如果把价格问题提前压到周转概念里，周转分析就会变形。

这也是马克思批评李嘉图的原因之一。

## 对现代创业话语的提醒

现代创业圈有很多看似清楚、实际混乱的说法。

比如：

> 人力成本太高，所以要用 AI 替代人。

这句话从老板的成本视角很直观。

但从马克思的分析看，需要进一步分解：

- 被替代的是哪类劳动？
- AI 系统本身是固定资本还是流动成本？
- 上游模型 API 是不变资本的流动部分吗？
- 维护 AI 系统的新劳动是否增加？
- 剩余价值生产关系发生了什么变化？
- 周转速度是否真的提高？

再比如：

> 我们用 API，不买 GPU，所以资产很轻。

这也只说了一部分。

你减少了固定资本，但增加了流动的不变资本依赖。

如果上游 API 涨价、限流、封号或延迟，你的生产成本和交付能力都会受影响。

所以轻资产不是没有资本结构，而是资本结构换了形态。

## 对 AI 开发者的理解抓手

可以用四个维度给一个成本项做标注。

比如“工程师工资”：

- 所在领域：生产过程
- 周转方式：流动资本
- 价值作用：可变资本
- 风险特点：每期支付，依赖收入回流

“模型 API 调用费”：

- 所在领域：生产过程
- 周转方式：流动资本
- 价值作用：不变资本
- 风险特点：按量消耗，受上游价格控制

“自建 GPU”：

- 所在领域：生产过程
- 周转方式：固定资本
- 价值作用：不变资本
- 风险特点：折旧、闲置、技术淘汰

“广告投放”：

- 所在领域：流通过程
- 周转方式：不能简单归入生产资本内部的固定/流动
- 价值作用：主要帮助价值实现，不创造商品价值
- 风险特点：获客成本上升会吞掉剩余价值

这样标注，就能避免李嘉图式混淆。

## 国学类比：辨物居方

如果借国学里的说法，这一章可以用“辨物居方”来理解。

每个概念都要安放在它自己的位置。

固定资本、流动资本、不变资本、可变资本，不是互相替代的词，而是从不同角度观察同一资本运动。

一个东西可以同时具有多个规定。

比如 GPU 是：

> 生产资料；
> 不变资本；
> 固定资本；
> 可能还有无形磨损风险。

工程师工资对应的是：

> 劳动力；
> 可变资本；
> 流动资本；
> 每期需要垫付和回收。

概念位置一错，后面的推理就会错。

## 本章的核心结论

第十一章的核心是：李嘉图虽然深入讨论了价值、工资、利润和价格，但在固定资本和流动资本问题上仍然混淆了不同维度。

可以总结为：

> 李嘉图把固定资本主要看作机器等耐久生产资料；
> 把流动资本常常等同于维持劳动的资本；
> 因此没有充分区分流动的不变资本和流动的可变资本；
> 也没有把固定/流动与不变/可变彻底分开。

对现代 AI 和软件行业来说，这章的现实意义很强。

今天很多人习惯把所有东西都叫成本，或者只用 capex、opex、burn rate 这些财务词。

这些词有用，但不够。

马克思要求我们继续追问：

- 这个成本处在生产还是流通？
- 它是固定周转还是流动周转？
- 它转移旧价值还是创造新价值？
- 它帮助生产使用价值，还是帮助实现价值？
- 它怎样影响资本回流速度？

第十二章将离开理论史，回到资本周转本身，讨论一个非常现实的问题：工作期间。也就是从劳动过程开始，到一个可出售产品完成，中间到底要连续占用资本多久。
