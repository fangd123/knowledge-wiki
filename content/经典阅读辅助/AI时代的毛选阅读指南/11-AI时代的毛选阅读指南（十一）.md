# AI时代的毛选阅读指南（十一）

## 实践论：知行合一的认识论操作系统

> **本篇解决的问题：** 为什么你读了很多书、听了很多课、收藏了很多文章，生活却没有任何改变？为什么"知道"和"做到"之间有一条巨大的鸿沟？

---





### 一、你可能是毛泽东批评的那种"学者"

毛泽东在《实践论》中批评了一种人——

他们"读了很多书""知道很多道理"，但从来不去实践，也不用实践来检验自己学到的东西。

毛泽东给了这种人一个名字：**"书本上的马克思主义者"**。

翻译成2024年的话：

> 你是一个"收藏夹里的成功学者"——收藏了1000篇干货文章，学了20门在线课程，能说出OKR、MECE、第一性原理、飞轮效应、AARRR模型……但你的实际工作和生活没有发生任何变化。

**为什么？**

因为你只完成了认识过程的一半。

---

### 二、背景还原





**时间：** 1937年7月

**地点：** 延安

**背景：** 1937年，毛泽东在延安的抗日军政大学讲了两堂哲学课——《实践论》和《矛盾论》。

当时党内有两种错误倾向——

**教条主义者：** 把马克思主义当圣经，照搬书本上的理论指导革命，不管中国的实际情况。他们"知道"很多理论，但不"做"。

**经验主义者：** 只相信自己的局部经验，不学习理论，不做系统思考。他们一直在"做"，但不"知道"。

毛泽东写《实践论》，就是要同时批评这两种人，提出一个完整的认识论——

> **实践和认识的关系不是谁先谁后的问题，而是一个不断循环、螺旋上升的过程。**

---

### 三、《实践论》的核心逻辑——你需要记住的一张图





《实践论》的核心逻辑可以压缩为一个循环：

```
实践（做）
  ↓
感性认识（获得直觉和经验）
  ↓
理性认识（总结规律和模型）
  ↓
再实践（用规律指导行动）
  ↓
再认识（根据新的实践结果修正认识）
  ↓
再实践……
  ↓
（循环往复，螺旋上升）
```

**逐层解释：**

#### 感性认识：你看到了什么

> "你要知道梨子的滋味，你就得变革梨子，亲口吃一吃。"

你在工作中做了一段时间，积累了一些直觉和感受：
- "这个客户好像不太满意"
- "这个功能上线后数据不太好看"
- "团队最近的氛围好像变了"

这些是**感性认识**——你感受到了，但你不知道为什么。

**它的特点：** 表面的、片面的、零散的。你知道"是什么"，不知道"为什么"。

#### 理性认识：你理解了什么

当你积累了足够多的感性认识后，你开始总结规律：

- "客户不满意的原因是我们的交付周期太长——因为内部流程有三个冗余环节"
- "数据不好看是因为这个功能解决的不是用户最核心的痛点"
- "团队氛围变了是因为绩效考核方式改了，大家觉得不公平"

这就是从感性认识上升到了**理性认识**——你看到了表象背后的规律和因果关系。

**关键跳跃：** 从"知道发生了什么"到"理解为什么发生"。

#### 再实践：你验证了什么

有了理性认识之后，你根据这个认识去采取行动：

- 你砍掉了三个冗余环节 → 交付周期缩短了30% → 客户满意度提升了
- 你重新调研了用户核心痛点 → 调整了功能方向 → 数据开始好转
- 你跟团队沟通了考核方式 → 做了调整 → 氛围开始恢复

行动的结果进一步验证或修正了你的认识。

**如果结果符合预期 →** 你的认识是正确的，继续深化
**如果结果不符合预期 →** 你的认识有偏差，需要修正，然后再实践

#### 核心洞察：认识永远不会"完成"

> "实践、认识、再实践、再认识，这种形式，循环往复以至无穷。"

没有"一劳永逸的正确认识"这种东西。每一次实践都会带来新的信息，要求你更新认识。

### 四、用现代语言重新说一遍





如果你觉得"感性认识""理性认识"这些哲学术语有点抽象，我换一种方式说——

**《实践论》的认识循环 = 精益创业的Build-Measure-Learn循环 = PDCA循环 = 科学方法论**

```
精益创业版：
  Build（做一个最小可行产品）
  → Measure（测量用户反应）
  → Learn（总结什么有效什么无效）
  → 改进产品 → 再测量 → 再学习 → ……

PDCA版：
  Plan（基于认识制定计划）
  → Do（执行计划）
  → Check（检查结果是否符合预期）
  → Act（根据检查结果改进）
  → 再Plan → ……

实践论版：
  实践（在现实中行动）
  → 感性认识（获得直接经验）
  → 理性认识（总结规律）
  → 再实践（用规律指导行动）
  → 再认识（根据结果修正规律）
  → ……
```

**本质上是同一件事：在做中学，在学中做，不断循环，螺旋上升。**

毛泽东在1937年用哲学语言讲清楚的东西，精益创业在2011年用商业语言重新讲了一遍，PDCA在1950年代用质量管理语言讲了一遍。

### 五、为什么你"知道"了却"做不到"——实践论的诊断





用《实践论》的框架，我们可以精确诊断"知行脱节"的原因——

**病症一：只学不做（停在"理性认识"不去实践）**

```
你读了很多管理学的书
你能说出各种模型和框架
但你从来没有在你自己的团队中试过任何一个

→ 毛泽东的诊断：教条主义
→ 你的"认识"没有经过实践检验，所以它不是真正的认识
→ 它只是"信息"，不是"知识"

信息 = 你知道这个概念
知识 = 你用过这个概念、知道它在什么情况下有效、什么情况下失效
```

**病症二：只做不学（停在"感性认识"不上升到理性认识）**

```
你做了10年销售
你靠直觉和经验做判断
但你从来没有系统地总结过你的经验是什么规律

→ 毛泽东的诊断：经验主义
→ 你有大量的感性认识，但没有上升到理性认识
→ 你知道"怎么做"但不知道"为什么有效"
→ 当环境变化时（比如AI改变了销售流程），你的经验就失灵了
```

**病症三：学了→做了→但没有复盘（断在了"再认识"环节）**

```
你试了一个新方法，失败了
你的结论是"这个方法不行"
然后你就不再尝试了

→ 毛泽东的诊断：认识过程断裂
→ 你没有分析"为什么失败"——是方法本身有问题，还是你的执行有问题？
→ 一次失败不代表方法错误，可能是时机不对、条件不满足、执行有偏差
→ 你需要的是"再认识"——分析失败原因，修正方法，再试
```

**病症四：学了→做了→成功了→然后再也不改了（停在旧的"理性认识"上）**

```
你用一个方法取得了成功
你把这个方法固化为"永远正确"的信条
10年过去了，环境变了，你还在用同一套方法
结果越来越不灵

→ 毛泽东的诊断：认识僵化
→ 成功的方法是在特定条件下成功的
→ 条件变了，方法要跟着变
→ "实践论"的循环不会停止——环境永远在变，认识必须持续更新
```

### 六、"实践是检验真理的唯一标准"





《实践论》中最深刻也最有用的一句话：

> **"判定认识或理论之是否真理，不是依主观上觉得如何而定，而是依客观上社会实践的结果如何而定。真理的标准只能是社会实践。"**

翻译成职场语言：

> **一个方案好不好，不是你觉得好就好，也不是逻辑上说得通就好——而是做出来的结果说了算。**

这个原则的应用极其广泛：

**在产品决策中：**
- 不要在会议室里争论"用户喜不喜欢这个功能"
- 做一个最小版本，上线测试，看数据
- 数据是实践的结果，数据说了算

**在管理决策中：**
- 不要猜测"这个制度能不能推行"
- 先在一个团队试点，看效果
- 效果是实践的结果，效果说了算

**在个人成长中：**
- 不要猜测"这条路走不走得通"
- 用最小成本试一试，看反馈
- 反馈是实践的结果，反馈说了算

**在团队争论中：**
- 双方各执己见，谁也说服不了谁
- 不要继续争论，去做实验
- 让事实来回答

### 七、实践论给你的行动框架





把《实践论》转化为你每周可以使用的行动框架：

```
┌──────────────────────────────────────────────┐
│            实践论 · 个人行动循环                │
├──────────────────────────────────────────────┤
│                                              │
│  本周实践：我要尝试做什么？                     │
│  → 选一个你学到的概念/方法，                    │
│    本周在工作中至少用一次                       │
│                                              │
│  本周观察：做了之后发生了什么？                  │
│  → 记录具体事实：哪些有效？哪些无效？            │
│    哪些是你没预料到的？                         │
│                                              │
│  本周总结：我从中学到了什么？                    │
│  → 这个方法在什么条件下有效？                    │
│    需要什么前提？有什么局限？                    │
│                                              │
│  下周调整：我要怎么改进？                       │
│  → 基于本周的总结，下周调整什么？                │
│    或者换一个新的方法来试？                      │
│                                              │
│  → 循环                                       │
│                                              │
└──────────────────────────────────────────────┘
```

**记住：每一次循环，你的认识都会深一层。**

第一次用一个方法，你学到的是"这个方法大概是什么"。
第二次用，你学到的是"这个方法在什么条件下有效"。
第三次用，你学到的是"这个方法怎么跟其他方法配合使用"。

**这就是毛泽东说的"螺旋上升"——不是简单的重复，而是每次循环都在更高的层次上。**

### 本篇练习

**练习：完成一次"实践论循环"**

选一个你在本系列前面的文章中学到的思维工具（利益分析法、调查研究法、困境分析五步法、持久战三阶段、弱者兵法——随便哪个），本周在工作中用一次。

然后填写：

```
我用的工具是：____________________

我在什么场景中用了它：____________________

用了之后的结果：____________________

跟我预期相比，有什么不同：____________________

如果再用一次，我会怎么调整：____________________
```

**这就是你的第一次"实践论循环"。**

---

**本文要点回顾：**

1. 实践论的核心循环：实践→感性认识→理性认识→再实践→再认识
2. 这个循环等价于精益创业的Build-Measure-Learn、PDCA循环
3. "知行脱节"的四种病症：只学不做、只做不学、做了不复盘、成功后不更新
4. 实践是检验真理的唯一标准——不要在会议室里争论，去做实验
5. 每周完成一次"实践论循环"，你的认识就会螺旋上升
