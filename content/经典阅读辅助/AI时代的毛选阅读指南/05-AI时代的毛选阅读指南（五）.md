# AI时代的毛选阅读指南（五）

## 调查研究是第一生产力：《湖南农民运动考察报告》的方法论

> **本篇解决的问题：** 上一篇我们说"没有调查就没有发言权"。这一篇回答更关键的问题：**调查怎么做？做完之后怎么形成判断？**

---



### 一、一个关于"判断力"的故事

1927年初，中国正处于大革命时期。

国共合作还在维持，但农村正在发生一场剧烈的变革——农民运动如火如荼。全国舆论分成了两派：

**一派说"好得很"** ——农民终于翻身了，这是革命的根本力量。

**一派说"糟得很"** ——农民太激进了，打土豪、分田地，简直是暴民乱来。

注意，说"糟得很"的不只是国民党右派，**共产党内部也有大量同志持这个观点**。他们坐在城市里，看着报纸上的报道，得出了自己的判断。

面对这个争论，毛泽东做了一件当时大多数人不会做的事——

**他没有参与争论，而是亲自去调查。**

1927年1月4日至2月5日，32天，他走了5个县，跟各种人谈——农民协会的积极分子、普通农民、地主、商人、教师、地方官员。

调查结束后，他写出了《湖南农民运动考察报告》。

这篇文章不仅推翻了"糟得很"的论断，而且精确预判了中国革命的核心力量和方向——后来的历史证明，他的判断完全正确。

**关键问题来了：为什么他的判断是对的，而那些坐在城市里争论的人的判断是错的？**

不是因为他更聪明。**而是因为他去了现场，而别人没有。**

### 二、毛泽东的调查方法拆解



仔细读《湖南农民运动考察报告》，你可以从中提取出一套完整的调查方法论。这套方法论放在今天，比很多市场调研教科书都更实用。

#### 方法一：亲临一线

毛泽东没有让秘书去调查然后汇报给他。他自己走了32天，5个县。

> 原文："我这回到湖南，实地考察了湘潭、湘乡、衡山、醴陵、长沙五县的情况。"

**为什么一定要亲自去？**

因为二手信息一定会失真。信息每经过一个传递环节，就会被筛选、加工、扭曲一次。你的下属跟你汇报的，是他认为你想听的；你的客户经理跟你反馈的，是他能理解的；行业报告跟你呈现的，是它的方法论能捕捉的。

**只有亲自到一线，你才能接触到"原始信号"——那些没有被加工过的事实。**

**现代对应：**
- 产品经理应该定期去客服中心坐一天，亲耳听用户怎么骂你的产品
- 管理者应该偶尔跟一线员工一起工作半天，而不是只看周报
- 创业者应该自己去跑几次销售，而不是只看CRM里的数据

#### 方法二：多元样本

毛泽东不只是跟"自己人"聊。他找了各种人：

```
农民协会积极分子 → 了解运动的推动者怎么看
普通农民 → 了解沉默的大多数怎么看
地主 → 了解被革命对象怎么看（他们的恐惧和反应）
商人 → 了解利益受影响但立场中间的人怎么看
地方知识分子 → 了解有观察力但不直接参与的人怎么看
```

**为什么要找"跟你立场不同"的人？**

因为如果你只问支持你的人，你得到的只是"确认偏见"——你原来怎么想，调查完还怎么想。

**现代对应：**
- 用户调研不能只找活跃用户，还要找流失用户、从未转化的潜在用户
- 推行新制度前不能只问支持者，更要找反对者聊——**他们的反对理由往往比支持者的理由更有信息量**
- 做竞品分析不能只分析竞品的功能，要去找竞品的用户问："你为什么用它而不用我们的？"

#### 方法三：要事实，不要观点

毛泽东的考察报告里充满了这样的细节：

> "农民协会在醴陵普遍地成立了。醴陵共有一百零九个区，每区都有了农民协会。"
>
> "农民取得了结社、集会的自由，在从前是没有的。"

他记的是**具体的数字、具体的变化、具体的事件**——不是"农民运动搞得挺好"这种抽象评价。

**为什么要记事实而不是观点？**

因为观点可以争论，事实不容置疑。当你用事实说话时，你的论证力量是压倒性的。

这也是毛泽东回应"糟得很"论的方式——他没有用观点反驳观点（"你说糟得很，我说好得很"），而是**用大量具体事实让"糟得很"的论断不攻自破**。

**现代对应：**
- 汇报的时候说"用户反馈不太好"是没用的。说"上周收到47条投诉，其中32条集中在XX功能的XX步骤"才有用
- 跟老板提需求说"团队压力很大"是没用的。说"上季度团队加班总时长增加了40%，其中3个人的工作量超过了标准的1.5倍"才有用
- 面试时说"我的领导力很强"是没用的。说"我接手这个团队时离职率25%，6个月后降到了5%"才有用

#### 方法四：结构化分析

毛泽东不是把收集到的信息堆在一起。他做了一件关键的事——**分类和归纳**。

他把农民运动的成果归纳为"十四件大事"，每一件都有具体描述和分析：

```
第一件大事：将农民组织在农会里
第二件大事：政治上打击地主
第三件大事：经济上打击地主
第四件大事：推翻土豪劣绅的封建统治——打倒都团
第五件大事：推翻地主武装，建立农民武装
……
第十四件大事：普及政治宣传
```

**为什么要结构化？**

因为零散的事实不能形成判断。你需要把事实组织成一个有逻辑的框架，才能看清全貌，才能得出有力的结论。

**现代对应：**
- 用户调研做完后，不能只是"整理了一份访谈记录"。要分类：痛点可以分成几类？每类有多少用户提到？哪类最严重？
- 竞争分析不能只是"列了一堆竞品的功能"。要归纳：竞品在哪几个维度上做得好？在哪几个维度上有弱点？我们的差异化机会在哪里？

### 三、"好得很"还是"糟得很"——如何在争议中做判断



这篇文章给我们的最大启发，其实不只是"调查方法"，而是一个更深层的思维方式——

**面对争议，不要急于站队，先去调查。**

在工作中，你一定遇到过类似的场景：

- 产品部说"是运营的问题"，运营说"是产品的问题"
- 销售说"价格太高了"，产品说"不是价格问题是需求不匹配"
- 一部分人说"这个方向是对的"，另一部分人说"完全走偏了"

面对这种争论，大多数人会——

1. 根据自己的直觉站队
2. 根据谁的声音大站队
3. 根据谁是自己的"盟友"站队
4. 保持沉默，等领导做决定

**毛泽东的做法是第5种——不争论，去调查。**

然后用事实来回答。

这不是"和稀泥"——毛泽东的结论非常鲜明，他明确站在了"好得很"一边。但他的站队不是基于立场，而是基于调查。**这就是"站队"和"判断"的区别。**

```
站队：先有立场，再找支持立场的证据（确认偏见）
判断：先有调查，再根据事实形成立场（实事求是）
```

### 四、"矫枉必须过正"——一个你需要理解的辩证观点



在考察报告中，毛泽东提出了一个很重要但经常被误解的观点——

> "矫枉必须过正，不过正不能矫枉。"

很多人把这句话理解为"做什么事都要走极端"。**大错特错。**

毛泽东说的是一个辩证法的道理：

当一种力量长期被压制时，它爆发出来的时候一定会超过"恰到好处"的那个点。**这不是应该追求的目标，而是变革的客观规律。**

就像一根弯曲的铁丝，你要把它掰直，必须朝反方向掰过一点——你掰到刚好直的地方松手，它会弹回去。

**现代应用：**

**在组织变革中：**

如果一个团队长期习惯了"不开会不沟通"，你要推行"充分沟通"的文化，初期可能会出现"会开得太多"的问题。这不是你的方法错了，而是变革过程中的必然现象。你需要的不是立刻"纠正过度沟通"，而是容忍这个阶段，等新习惯建立后再找到平衡点。

如果一家公司长期忽视数据，突然开始"数据驱动"，初期可能出现"一切都要数据支持"的教条。这也是矫枉过程中的正常现象。

**关键认知：** 改革初期的"过"，往往是必要的推动力。如果你在这个阶段就急于"纠偏"，结果可能是改革无功而返，重新回到原来的状态。

当然，"过正"有边界。毛泽东在后面的论述中也说了，过正不等于无限制地过——你需要判断什么是变革的必经阶段，什么是真正的失控。

### 五、把毛泽东的调查法变成你的工具



基于毛泽东的调查方法，我给你一个可以直接使用的"现代调查模板"：

```
┌──────────────────────────────────────────────────────┐
│                毛泽东调查法 · 现代版                    │
├──────────────────────────────────────────────────────┤
│                                                      │
│  第一步：明确调查问题                                  │
│  "我要搞清楚什么？"                                    │
│  → 把问题写成一句话（不要模糊的"了解情况"，              │
│    要具体的"为什么XX用户在第三步流失了"）                │
│                                                      │
│  第二步：确定调查对象                                   │
│  "我应该找谁聊？"                                      │
│  → 至少覆盖三类人：                                    │
│    ① 直接利益相关方（受影响最大的人）                    │
│    ② 间接相关方（能提供不同视角的人）                    │
│    ③ 持反对意见的人（最不容易想到但最有信息量的人）       │
│                                                      │
│  第三步：设计调查问题                                   │
│  "问什么？"                                            │
│  → 5个关键问题：                                       │
│    Q1. 最近遇到的具体困难是什么？（要事实不要感受）       │
│    Q2. 这个困难是什么时候开始的？频率如何？               │
│    Q3. 你试过什么解决办法？效果如何？                    │
│    Q4. 在你看来，根本原因是什么？                       │
│    Q5. 如果只能改一件事，你最希望改什么？                │
│                                                      │
│  第四步：执行调查                                      │
│  → 记具体事实和案例，不记抽象评价                       │
│  → 不同人说法矛盾时，矛盾本身就是重要信息               │
│  → 保持倾听，不要在调查过程中推销你的观点                │
│                                                      │
│  第五步：结构化分析                                     │
│  → 把发现分类归纳                                      │
│  → 找出高频出现的共性问题                               │
│  → 区分"根因"和"症状"                                  │
│  → 形成你的判断                                        │
│                                                      │
│  第六步：写"调查报告"                                   │
│  → 调查背景和目的（为什么做这个调查）                    │
│  → 调查方法（找了谁、怎么找的）                         │
│  → 发现的事实（按分类呈现）                             │
│  → 你的分析和判断                                      │
│  → 下一步行动建议                                      │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 六、调查的反面：为什么你的"调研"经常没用



很多公司也做"调研"，但做完跟没做一样。问题出在哪里？

**常见的无效调研：**

**1. 确认式调研**
> 你已经有了结论，做调研只是找支持材料。
> "我觉得应该做A方案，去找几个用户聊聊看他们是不是也这么想。"
>
> → 毛泽东做调查是为了**发现事实**，不是为了**证明自己对**。

**2. 样本偏差**
> 你只找了"容易找到的人"，而不是"应该找的人"。
> 比如只调研了活跃用户，忽略了沉默的大多数和流失用户。
>
> → 毛泽东刻意找了不同立场的人，包括"对手"（地主）。

**3. 表面调研**
> 问了很多人，但问的都是"你觉得怎么样"这种大而化之的问题。
> 收集了一堆"还不错""一般般"的反馈，分析不出任何东西。
>
> → 毛泽东问的是具体事实："做了什么？结果怎样？为什么？"

**4. 调研变表演**
> 调研的目的不是了解情况，而是"做给领导看"——"我做过调研了"。
> 调研报告写得很漂亮，但结论完全没有影响决策。
>
> → 毛泽东说："调查就是解决问题。"调查不是为了完成流程，是为了做出正确判断。

**5. 信息堆积**
> 收集了大量信息但不做分析。厚厚一叠访谈记录，没有分类、归纳、提炼。
> "调研做完了"="记录做完了"，并不等于"判断形成了"。
>
> → 毛泽东把农民运动的成果归纳为"十四件大事"——这是分析，不是记录。

### 七、一个你可以立刻用的"迷你调查"

你不需要像毛泽东一样花32天走5个县。在现代职场中，一次有效的"迷你调查"可能只需要3-5次深度对话。

**示例：你觉得团队最近状态不好**

```
传统做法（本本主义）：
  → 上网搜"如何提升团队士气"
  → 读了3篇文章
  → 决定搞一次团建
  → 团建完了，该怎样还怎样

毛泽东式做法（调查研究）：
  → 这周找3个不同角色的人单独聊30分钟
    · 聊一个骨干成员（了解核心力量的状态）
    · 聊一个新人（了解新人视角下的团队）
    · 聊一个你感觉"有情绪"的人（了解问题所在）
  → 问具体问题：
    "上周工作中遇到什么具体的不顺利？"
    "你觉得最浪费你时间的事是什么？"
    "如果你能改变团队中的一件事，你想改什么？"
  → 分析：三个人都提到的共性问题是什么？
  → 针对共性问题制定解决方案
  → 一周后跟进效果
```

**你会惊讶地发现：真正的问题往往和你想的完全不同。**

也许你以为是"工作量太大"，调查后发现其实是"需求总变来变去，做了很多无用功"。

也许你以为是"薪资不满意"，调查后发现其实是"看不到成长空间"。

**不调查，你永远在猜。调查了，你才开始判断。**

### 本篇练习

**本周任务：做一次真正的调查**

选一个你一直困惑但从未深入了解的工作问题，做一次"毛泽东式"的迷你调查。

要求：
1. 找至少3个不同角色/立场的人聊
2. 每次对话至少20分钟
3. 记录具体事实和案例，不记抽象评价

然后写一份500字的"考察报告"，模仿毛泽东的结构：

```
① 调查背景和目的（我要搞清楚什么）
② 调查对象和方法（找了谁，怎么聊的）
③ 发现的事实（分类呈现，要具体）
④ 我的分析和判断
⑤ 下一步行动建议
```

**记住毛泽东的话：** "你对于某个问题没有调查，就停止你对于某个问题的发言权。"

反过来说：**你调查了，你就有了发言权——而且是有分量的发言权。**

---

**本文要点回顾：**

1. 面对争议，不要急于站队——先去调查，用事实形成判断
2. 毛泽东调查法四要素：亲临一线、多元样本、要事实不要观点、结构化分析
3. 无效调研的5种常见病：确认式调研、样本偏差、表面调研、调研变表演、信息堆积
4. "矫枉过正"是变革的客观规律，不要在改革初期急于纠偏
5. 一次有效的迷你调查只需要3-5次深度对话——关键是找对人、问对问题
