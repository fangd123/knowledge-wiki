# 风格指导 v2（出镜 + HTML 手动分拍）

> 这是出镜 + HTML 手动分拍版。拍一次订票：主持页问“上次说的转机条件还算数吗？”，下一拍人让到左边，右边并排亮出两张机票；再缩成小窗，指给观众看只改了出发时间。导演不必先装引擎就能用这三拍试讲。


## 0. 一句话定位

**真人讲解，旁边是一张会一步步长出来的纸上图解。** 人负责提问、表态和带观众走，图负责把界面、对照和数字摆清楚。纸色、墨线、硬投影的手账风格保留，但不再有卡通人物。

## 1. 从卡通 PPT 改到真人图解

| 旧选择 | 现行做法 | 为什么这样改 |
|---|---|---|
| 卡通角色提问 | 真人在主持页提问 | 同一问题不需要讲者和角色再问两遍 |
| 真人只在两端出现 | 按任务切全屏、侧边与小窗 | 讲态度让人看脸，读界面就让出画面 |
| PPT 或 PNG | 手动分拍录浏览器 | 讲错可以退一拍，画面与口播一起重录 |
| 插图包办 | 界面自绘；物件插图逐件判断 | 图要说清操作，不是冒充产品实机 |

## 2. 出镜方式（每一拍都要指定）

| `cam` | 叫法 | 什么时候用 | 例拍 | 每集预算占比 |
|---|---|---|---|---|
| `full` | 主持页 | 开场提问、亮观点、段落转折、结尾判断 | 直视镜头问转机条件 | 25–30% |
| `side-l` / `side-r` | 人 + 图 | 解释过程、两边对照、讲例子 | 讲者与两张机票同框 | 约 30% |
| `pip-bl` / `pip-br` | 小窗 + 全屏图 | 走读界面、连续讲数字、看一段对话 | 小窗让出日期栏 | 约 30% |
| `off` | 全屏图 | 极少数需要整屏细看的图，比如五代演进表 | 读完五代演进表 | ≤ 10% |

这些比例是分拍预算。界面的字和差异必须看得清；不为凑出镜时间把人脸盖在条件栏上。

**规则：**
- 页型按内容功能来定，不要随手切换。同一意思内部不换页型。
- 在左右两侧之间交替：上一段图在右，下一段就放到左。
- 小窗盖住的内容要换到另一个角，或者把小窗移开。
- 拍与拍之间的变化由引擎自动做动画，不要另外加转场。

## 3. 舞台与栅格

- 舞台为 1920×1080（16:9）。竖屏版另外重新排版，不直接裁切。
- **字幕安全区 y > 940**：只放背景和摄像头画面。字幕在后期由 ASR 生成后加上。
- 场景标题放在图解区的左上角。`full` 拍不显示场景标题，只能叠一张标题贴纸。
- 先摆图，再摆人：试着把小窗从左下移到右下，只保留不遮转机与总时长的一侧。

## 4. 文字

**画面上的字只是路标，解释靠口播。**

| 用途 | 字体 | 字号（舞台 px） |
|---|---|---|
| 标题贴纸 | 得意黑 | 64–80 |
| 场景标题（≤ 16 字） | 得意黑 | 52 |
| 卡片标题、标签（≤ 12 字） | 思源黑体 CN Medium | 32–40 |
| 界面里的文字 | 思源黑体 CN | 28–32 |
| 旁批、思考泡、便签 | 霞鹜文楷 | 28–36 |
| 署名 | 思源黑体 CN，灰色 | 16 |

- 除署名外，最小字号 28px。观众会用手机看。
- 每拍新增的上屏文字不超过 20 个字，整个画面同时出现的字不超过 50 个。
- 不用项目符号列表。
- 内联字体前，核对实际字体文件的版本、许可及子集化要求；随发布包保留所需许可和署名。

## 5. 颜色（含义全系列固定）

| 名称 | HEX | 含义 |
|---|---|---|
| 纸 | `#FFF8E7` | 背景 |
| 白卡 | `#FFFFFF` | 卡片、气泡、界面 |
| 墨 | `#25324B` | 描边、文字、硬投影 |
| 蓝 | `#4A7CFF` | **AI 一方**：模型、AI 回复 |
| 橙 | `#FF9B54` | **人一方**：用户的输入，以及痛点 |
| 绿 | `#49A88F` | **更好的做法** |
| 黄 | `#FFE27A` | 荧光笔 |
| 浅橙 / 浅绿 / 浅蓝底 | `#FFE9D6` / `#DFF3EC` / `#E3EBFF` | 对照卡底色、用户气泡、AI 气泡 |
| 灰 | `#8A93A6` | 次要信息 |

- 每个画面除墨色以外，最多用两种强调色。
- 对照固定为**左边旧做法（橙），右边新做法（绿）**。
- 出镜在 `side-l` 时，对照卡整体放到右侧，但卡片之间仍然是左橙右绿。

## 6. 形状与动效

- 墨线 4px，界面内部控件 2.5px。
- 硬投影：右下偏移 8px，不模糊。小元素用墨色，大卡片用 `#EADFC6`。
- 贴纸、便签旋转 ±2–4°；界面示意保持 0°，表示"这是正经的界面"。
- 每拍揭示一个意思。一拍通常 5–12 秒的口播，最长不超过 20 秒。
- 动画缓出，0.4–0.8 秒。可以用打字、描线、荧光笔刷出、错落入场。不用弹跳和旋转飞入。
- 涂鸦（问号、汗滴、星光、对勾、叉号）每个画面最多 2 个，不用 emoji。

## 7. 图从哪里来

1. **界面、气泡、面板、图表、箭头**：一律用代码画，按通用造型。不仿任何真实产品的界面，也不用它们的标识。
2. **物件插图**（门把手、吸管、黏土、方向盘）：若采用生成图，做成扁平贴纸、粗墨线、无渐变；先明确具体模型版本与权重来源。
   - 逐件记来源、版本、许可原文及拟用场景；模型代码许可不等于权重、输入素材或输出都可用于这次发布。
   - 不按厂牌一刀切。不能确认该版本的权利，就自己画门把手或直接拿实物出镜。
   - 标签由代码叠字，便于改词和统一字号，不把生成图里的字当正式标注。
3. **真实人物和产品照片**：只用可确认许可范围的照片；记录文件页、作者、许可及修改，画面保留署名。封面不用第三方照片。
4. **封面**：用本人画面加上大字问题，这是小Lin说的常见做法。封面上不放第三方真人照片。

## 8. 每集结构

| 段落 | 长度 | 要求 | 依据 |
|---|---|---|---|
| 钩子 | 25–40 秒 | `full`；第一句就提问，或者抛一个反常识的事实；0 秒就上画面；结尾说出本集要回答的问题 | 先试录一遍，看观众能否在半分钟内说出这个问题 |
| 正文 | 4–6 段，每段 2–3 分钟 | 段与段之间用一拍 `full` 的转折句，或者系列地图衔接；每段走完"观点 → 例子 → 证据 → 对你的意义"。合并集在前后两半之间加一拍 `full` 转折 | 跨段换问题时再切主持页 |
| 你可以这样做 | 约 60 秒 | 结尾前，给 2–3 条下次用 AI 时马上能用的做法；用 `side` 或 `pip` 配一张清单卡 | 例如让观众把去程日期改一天，再核对转机条件是否仍在 |
| 平衡 | 每集一处，2–3 句 | 讲清聊天什么时候好用；其他地方不再加"我不是说……" | 例如只改出发时间，直接说比逐项重填省力 |
| 结尾 | 10–20 秒 | `full`；回到自己的判断，再接上下一集要讲的具体问题；**不喊一键三连** | 让观众带走判断，不把结尾让给口号 |

## 9. 写稿规则

1. **语速与篇幅**：按[六集大纲](04-《聊天框之外：AI交互设计小课》系列大纲_v5（按_2026_版文章）.md)写，第 1 集 8–10 分钟，第 2–4 集 14–16 分钟，第 5–6 集 12–14 分钟。330–350 字/分是预算，不是讲者实测，按试录调整。
   - 加长靠**加深**，不靠注水。每段按"观点 → 日常例子 → 证据或历史 → 对你意味着什么"四步走。每集至少要有：1 个有人物、有年份的历史故事；1 个能上屏的研究数字；1 段面向普通人的机制解释（AI 为什么会这样）；1 个观众马上能试的小实验或用法。
2. **短句**：一句话说一个意思，用逗号切成每段 8–12 字的短句。不写长从句。
3. **对着观众说**："你"的次数多于"我"，约 2:1 可作试写提醒，不必凑数。"我认为""我的理解是"每集合计不超过 3 次。
4. **问句**：大约每 30 秒一个，问完马上自己回答。问句放在 `full` 拍；反问每集最多 1–2 次。
5. **数字和例子**：数字放在 `pip` 或"人 + 图"的拍上，一个数配一张卡或一个画面；大约每 90 秒一个具体例子。
6. **引导看图**：在 `side` 和 `pip` 拍里，用"看这里""右边这个框"之类的话把视线带到图上，说的位置要和画面一致。
7. **分寸**：别念免责声明。第 4 集就双指缩放交代“普及不是发明”；第 6 集收束时说“这六条是我的归纳”。旧八集 PPT 的集号不用在这里。
8. **"对话小剧场"改成气泡**：原来小问和点点之间的对白，改成画面上的聊天气泡，由本人用两种语气念出来，或者只放气泡不念。
9. 每拍的口播写进 `say`，来源和口径写进 `note`。口播稿、画面和备注都从同一份场景文件生成。

## 10. 录制规范

- **背景**：浅色，接近纸色 `#FFF8E7`，干净，最多一两件摆设，背景稍虚。不要白墙死光。
- **灯光**：一盏柔光灯正对或偏 30°，脸上不要有明显阴影；同一集里光线不变。
- **机位**：镜头和眼睛同高，胸部以上入画。眼睛大约在画面高度的 38% 处（用校准场景对位）。
- **服装**：纯色或细条纹，避开纯白（太亮）、绿色、细密格纹（会闪）；同一集里不换衣服。
- **提词**：用演讲者窗口，放在镜头旁边或者第二块屏幕上。每拍开口前先看一眼，说的时候看镜头。
- **讲错了**：按 ← 退回这一拍重讲，剪辑时照拍点 CSV 剪掉错的那段。
- **一集分几次录**：可以按段落分开录，但同一集里的光线和服装要一致，开录前在校准场景里核对一次机位。

## 11. 每拍自检

1. 这一拍的 `cam` 和内容功能对得上吗？
2. 图有没有压到摄像头框，有没有进入字幕安全区（y > 940）？
3. 不看文字，能看懂这个画面在说什么吗？
4. 有没有小于 28px 的字？上屏字数超没超？
5. 除墨色外，强调色有没有超过两种？对照是不是左橙右绿？
6. 一路前进、退回、跳转到达这一拍，画面都一样吗？
