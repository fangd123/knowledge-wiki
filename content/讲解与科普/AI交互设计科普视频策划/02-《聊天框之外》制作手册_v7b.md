## 本轮重建与检查

只重建EP03和EP07，不运行write_course或sync_visual，不重写口播与分镜，不重建其他集或样张。

```powershell
python -B EP03_摆开工作台/build.py
python -B EP07_直接捏输出/build.py
python -B _tools/validate.py --all
python -B _tools/check_v7b.py
python -B _tools/render_v7b.py
python -B _tools/pixel_compare_v7b.py
python -B _tools/verify_office_v7b.py
```

`validate.py`默认及`--all`均检查8集+kit共201页，当前0错误；输出`v7b_validate*.json`，v7历史报告保留两处旧错误，不覆盖。检查几何紧跟xfrm、空动画节点、目标和清单一致性。`check_v7b.py`核实仅EP03 P01/P02及EP07 P01 XML改变、备注和口播字节不变、逐页点击/效果/时长不变、EP03点击清单字节不变。

`render_v7b.py`使用同一Aspose版本渲染归档v7与当前交付，保留评估水印，并生成3改页的逐点击状态；辅助像素只有指定3页变化。`pixel_compare_v7b.py`分别报告辅助与真实Office比对，真实图缺失标待导出，不以辅助冒充真实。归档在`_review/v7b_source/`。

源码仍用kit公共入口，EP03场景scenes_v5.py，EP07场景scenes_v6.py。纸罩使用已修好的components_v5.straw_view；黏土新增可选show_hand，默认行为不变，仅EP07封面去掉独立示意手，改为小问自己的手接触软块。

先核实得意黑、思源黑体CN、霞鹜文楷实际字形；OFL字体在`_assets/fonts/`，未写系统字体或注册表，字体不嵌入PPTX。

```powershell
& .\_tools\export_png_v7b.ps1
```

脚本先全量预检，再只读打开EP03和EP07，输出`_review/office_v7b/ep03_v7b/`、`ep07_v7b/`，1920×1080；2封面另导1280×720。记录COM效果数和源PPT SHA256，调用verify_office_v7b.py合并XML，随后自动运行真实PNG像素比对。EP03使用v6真实PNG作为未改v7基准，EP07使用v7真实PNG。范围外像素变化会报错。

**MainSequence.Count为效果数，不是点击数。** EP03=33/39，EP04=41/44，EP05=37/43，EP06=37/39，EP07=33/41，EP08=45/48（点击/效果）。EP03 P07=4/8、EP07 P08=4/7、EP08 P22=2/3；旧态退出和新态进入同次单击。COM仅导出PNG及读效果数；点击读取XML clickEffect，不使用Timing.TriggerType。

先确认组件样张能正常打开，再F5逐页看初始隐藏、整组进入、同次退出进入、最后点击后翻页。本轮重点EP03 P01吸管不穿头、P02初始纸罩和第2次点击后的整墙，EP07封面手捏黏土且点点不挡道具。EP08最终画面预留10秒。Office若提示修复，记录并退回，不把自动修复视为正常验收。

`_review/v7b_aux/`为保留Aspose评估水印的辅助图，不用于成片；原生交付PPT未经过评估版保存，无评估文字。辅助静态副本移除已退出层，states子目录按XML清单模拟各单击状态，都不是Office真实放映。静态Office PNG也可能同时显示旧/新层，切换页仍须F5验证。

## 1. 录音前准备

关掉风扇、通知声与音乐，拉上窗帘或靠近软装，避开空旷墙角。麦克风先放在嘴前约15–20厘米，略偏一侧，避免直接对着气流；整个录制过程保持距离。耳机监听能帮助发现回声，别让扬声器返送进入麦克风。

先试录30秒，包含普通说话、重读一句和一次点击。戴耳机听，再用手机扬声器听：人声要清楚，不爆音、不忽远忽近，鼠标声不盖住说话。声音不理想先调位置和输入音量，不急着加降噪滤镜。

## 2. 在PowerPoint里录制

“录制→从头开始”或“幻灯片放映→录制幻灯片放映→从头开始”。选择实际使用的麦克风，摄像头可关闭；本样片按全屏图解设计，不需要每页露脸。如果希望出镜，另录开头或结尾的短镜头更容易避免挡住图解。

先在“视图→备注”检查提词稿。新版“录制”窗口通常有“备注/提词器”入口；若窗口没有这个功能，可用双屏“幻灯片放映→使用演讲者视图”，让自己一侧显示备注，观众一侧只有画面；单屏且无提词器时，把《口播稿.md》放在手机或纸上，不要把备注截图录进正片。不要假设旧版普通放映与新版录制工作室的界面相同。

每到 `[点击]`，先停半拍，再点一次；等图出现后继续下一句。不要一边连点一边追赶文字。每页口播先读完，停一拍，再翻页，等新页稳定后再开口。**翻页的那一下不要说话：PowerPoint不会录入换页过渡期间的音视频。** 微软官方也提示页首和页尾可能有短暂静音缓冲。

某页讲错：停止录制，选中该页，进入“录制→从当前幻灯片开始”，只重录这一页。若需清除，选择“清除→清除当前幻灯片的录制内容”，不要选清除全部。重新录制会替换该页原旁白和计时；重录后回放前后两页，确认动画点击、旁白、翻页停顿都接上。最后保存录制版。

## 3. 导出1080p MP4

“文件→导出→创建视频”，选“全高清/1080p”，选择“使用录制的计时和旁白”，输出MPEG-4。不要选统一每页几秒来代替你实际录下的点击节奏。等状态栏导出完成后再关PowerPoint。

完整播放一次：开头有没有被截字、每次图解是否跟着声音出现、页间有没有漏音、最后一页有没有足够时间读完。EP01约5分30秒、EP02约7分钟是分镜预算，实际以本人录音为准，不为凑秒数硬加静帧。

## 4. 在剪映里精修

创建16:9项目，导入刚导出的MP4，拖入时间线。先剪口误和过长空白，再“文本→智能字幕/识别字幕”，选择原视频人声，逐条校对。重点查：韦泽、示能、普适计算、直接操控、Calm Technology；人名和年份不要依赖自动识别。背景音乐可不加。

字幕建议思源黑体CN，一次1–2行，按意群断句，每行约14–20个汉字起步。放入底部空白区，文字与底色保证对比；别让字幕顶到进度条或盖住控件。用手机实际看一遍，再决定字号。剪映字幕权益依当前版本和账户，不保证无限免费。

需要片头时，把封面标识叠在最初1–2秒，让钩子照常开始；片尾沿用PPT最后一页，通常保留本集结论和下集问题约5–8秒，EP08不预告下集、最终驾驶画面预留10秒。修剪后可保存SRT字幕备份。导出建议1920×1080、H.264、25或30fps固定其一，音频AAC；若软件开放参数，可用约10–16Mbps作为起点，最终按平台上传提示调整。导出后实播检查，不只看时间线预览。

## 5. 发布前检查

确认人声、字幕、人名、年份、来源、概念示意标签都正确；无真实订单、隐私信息或未授权音乐。标题与封面使用本集问题，不宣传为唯一的终极答案。简介可直接写：

> 本集讨论AI交互的设计选择。界面与角色为概念示意；历史人物/物件照片按开放许可使用。参考资料请复制本集讲稿末的对应条目；照片署名、文件页和许可链接请复制《素材授权清单.md》中该集的条目。本人录音。


**AI标识沿用《总体规划.md》定案。** 本阶段使用原生形状和开放照片，拟由本人录音，没有AI生图或合成语音。仅使用原生形状加本人录音时不额外标识；以后加入AI生图或合成语音，就在平台主动声明。发布简介按实际素材保留照片署名与来源。

## 6. 备选：PNG + 剪映配音

COM实际导出的PNG按页序导入剪映；先录本人旁白，再按声音调整每张图的停留时长。**PNG没有页内动画**，只会显示所有元素都出现后的静态图；如果想保留分步揭示，要另导出多个状态图，或改用PowerPoint录制的MP4。`_review/v7b_aux/`的评估水印PNG只能看构图，不建议拿来直接充当正式视频画面。
