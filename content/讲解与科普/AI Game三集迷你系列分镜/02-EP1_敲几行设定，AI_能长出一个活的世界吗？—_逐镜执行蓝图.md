## 4. 逐镜执行蓝图

### Scene 01：一个活的世界长什么样？
- **时间窗**：`00:00 - 00:24`（24s）
- **人像调度**：`full_canvas`
- **路标**：左上 `01 — 小镇一日`；右上 `示意`。
- **空间运镜与转场**：单一世界，摄像机三段：①0–9s 近景停在住宅一侧（zoom 2.0）；②9–12.6s 随人潮横摇到工坊再摇回；③15.0–17.0s 拉远（zoom 2.0→0.6）同时"同一条街"被复制出六份落到下方，成为七行。24s 末硬切入 Scene 02 人像空档。
- **精修口播词**：
  > "这个小镇住着一百个 AI 居民。/ 每个人都有名字、有工作、有朋友，/ 都在认真过日子。/ 来，【我们看一整天】。/ ……【再看一个星期】。/ 它是活的，每一秒都是真的。/ 可你刚才，是不是已经想划走了？"
- **核心装置（唯一主角）**：**同一条街，被看了七遍**。一条中世纪小镇的街道侧立面（左：四间住宅；中：三个集市摊位；右：铁匠铺、面包房），线稿矢量，一百个青色小圆点是居民，在街前的路面上走。看一整天时它是一条大街；看一个星期时，这条街被原样复制成七行，七行里的小点在竖直方向上排成整齐的列、动作逐像素一致——观众不用听口播就能看出"每天都一样"。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底，极淡的 `--ink-muted` 点阵网格，随摄像机以 `-0.35×` 反向视差位移。
  - **核心装置层**：街道侧立面线稿（`--ink-secondary`，`--stroke-hairline` 到 `--stroke-regular`；建筑造型参考 `_assets/gen/s01_concepts/` 的街道图，**由程序画成矢量**）。居民为 `--sem-2` 实心圆，世界坐标半径 8。街道原始宽 1700、建筑高约 150、路面带高约 60，居民只在路面带内活动。七行态每行缩放 0.6，行距 120，水平居中。
  - **路标层（全部 ≥ 24px，屏幕坐标渲染）**：①0–9s 三个名字短标（`铁匠 · 莫恩`、`面包师 · 艾拉`、`学徒 · 吉姆`，贴在对应小点右上，裸排）；②数字钟 `--font-mono`，`--text-h2`，右对齐于 `x=1832`，顶在 `y=124`（右上角让给「示意」）；钟下一行 `第 N 天`；③七行态下每行左侧一个 `第 N 天`（裸排）。
- **因果动效编排**：
  1. `[0.0s - 9.0s 初始态]`：清晨 06:00，小点全在住宅前，静止。`[3.0s / 3.8s / 4.6s]` 三个名字依次浮出各停 0.8s。摄像机 1.00→1.04 缓推。
  2. `[口播"我们看一整天" 9.0s -> 响应]`：钟 6 秒走完 24 小时；摄像机 9.0–9.6s 横摇到工坊一侧，随小点上工；12:00 前后 30 个小点涌向集市摊位再回来；11.4–12.6s 摄像机摇回住宅，随小点下班；钟回到 06:00 停住。
  3. `[口播"再看一个星期" 15.0s -> 响应]`：15.0–17.0s 摄像机拉远，街被复制，六份副本自上而下依次落位（每份错开 0.15s，0.6s `easeOutCubic`）；七行各带一个 `第 N 天`。
  4. `[15.9s - 19.2s 七行依次重演]`：第 k 行在 `15.9 + (k-1)×0.3` 秒起走一遍当天日程（每行 1.5s，该行 `第 N 天` 提亮到 `--ink-primary`，走完回落）。七行动作完全一样，像同一小节乐谱印了七遍。
  5. `[落定停留 19.2s - 24.0s]`：七行静止，小点停在各自家门口，竖直成列，4.8s。

### Scene 03：那个小镇是怎么来的？
- **时间窗**：`00:50 - 01:10`（20s）
- **人像调度**：`full_canvas`
- **路标**：左上 `03 — 一个按钮`；右上 `示意`。
- **空间运镜与转场**：同一张无边界画布上两处"工位"：左边是设定文字，右边是街道。6.0s 按钮被按下后摄像机用 `easeInOutQuint` 横摇 1920px 过去，背景点阵 `-0.35×` 反向视差。20s 末与下一镜（样段里是 Scene 08）用同一个 0.8s 横移转场。
- **精修口播词**：
  > "刚才那个小镇，就是这么来的：/ 【四行设定】，/ 【一个按钮】。/ 它确实长出来了。/ 只是长出来的东西，像一座城市的监控录像——/ 全是真的，没人想看。"
- **核心装置（唯一主角）**：**一个按钮，通向一个镜头里的世界**。先是四行设定逐行打出，按钮被按下，摄像机横摇过去，看到的是 Scene 01 的那条街，只是现在透过监控取景框看它：四角细角标，一排滚动时间码，小点重复同一条路线。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底 + 视差点阵。
  - **左工位（世界坐标 x≈960）**：四行设定**裸排**在开放画布上（`--text-h2`，不套面板），每行下一条 `--stroke-hairline` 底线示意"可输入"；下方一枚琥珀描边的胶囊按钮"生成世界"（`--sem-1`，人的动作）。
  - **右工位（世界坐标 x≈2880）**：Scene 01 同款街道，zoom 1.6，居民从空街里成批冒出；四角 `--ink-secondary`、`--stroke-bold` 的 L 形取景角标；一排 `--font-mono` 时间码。
  - **路标层（≥ 24px）**：设定原文四行："世界观：中世纪奇幻""魔法：稀有，少数人掌握""种族：人类、精灵、矮人""时代：漫长和平的终结"；时间码 `录像 03:14:07` 逐秒滚动；落定后画面中下方 `--text-h1` "真实 ≠ 好玩"（`y ≤ 800`）。
- **因果动效编排**：
  1. `[初始态 0.0s]`：画布上只有第一行下划线，光标 0.5s 间隔闪（由 `t` 算，不用定时器）。
  2. `[口播"四行设定" 2.5s -> 响应]`：四行文字逐行打出，每行 0.7s。
  3. `[口播"一个按钮" 6.0s -> 响应]`：按钮在 6.0s 被按下，闪一下 `--sem-1`；动作先行，6.1s 摄像机起摇，7.2s 到位；居民从 7.3s 起成批冒出。
  4. `[口播"监控录像" 12.0s -> 响应]`：取景角标和时间码在 12.0s 淡入，小点开始重复同一条路线。
  5. `[落定停留 15.0s - 20.0s]`：街道压暗到 35% 亮度，"真实 ≠ 好玩"浮到前景，静止 5.0s。

### Scene 04：为什么活的也无聊？
- **时间窗**：`01:10 - 01:52`（42s）
- **人像调度**：`full_canvas`
- **路标**：左上 `04 — 经验压缩`；右上 `示意`。
- **空间运镜与转场**：摄像机沿时间带缓推 zoom 1.00→1.06（7.0–27.0s，随念到的那一类块推过去），27.0s 的"挤掉"动作时拉回 1.00；转场用画布横移。
- **精修口播词**：
  > "为什么？/ 先看我们自己的日子。/ 把普通的一段生活【摊开】：/ 大部分是通勤、干活、睡觉；/ 有一小段是小开心、小烦恼；/ 真正忘不掉的，只有那么一丁点。/ 这个比例是我的体感，不是统计。/ 而游戏做的事，就是【把灰的挤掉】，把亮的留下。/ 我管它叫经验压缩。"
- **注意力焦点**：一条很长的灰色时间带被挤短，只剩下亮的部分。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底，无坐标轴、无刻度。
  - **核心主体层**：一条横贯画面的时间带（宽约 1680px，高 96px，垂直居中偏上）。由三种块交错组成：大量 `--sem-3` 灰块；少量低亮度琥珀块（`--sem-1-tint` 填充加琥珀细描边）；极少几粒满亮 `--sem-1` 小块。三者面积粗略为"绝大部分 / 一小部分 / 一丁点"，不标数字。
  - **路标文字层**：三个短标随口播依次出现在对应块上方："平淡""小起伏""高光"（≥ 24px）。带子下方一行脚注（≥ 24px）："比例为作者体感，非统计数据"。压缩完成后带子上方出现"经验压缩"。
- **因果动效编排**：
  1. `[初始态 0.0s]`：只有一条细的空轨。
  2. `[口播"摊开" 4.5s -> 响应]`：时间带从左到右铺开，2s 铺满。
  3. `[口播三句依次 7.0s / 10.5s / 13.5s -> 响应]`：念到哪类，哪类块微微抬起 6px 并亮标签，其余压暗；念完落回。
  4. `[口播"体感，不是统计" 19.0s -> 响应]`：角注淡入。
  5. `[口播"把灰的挤掉" 27.0s -> 响应]`：所有灰块横向收窄到原宽的十分之一左右，琥珀块向中间聚拢，整条带子缩成约 560px 宽、以琥珀为主的一小段。动作 2.5s，干脆。
  6. `[落定停留 29.5s - 34.5s]`：短带居中，上方"经验压缩"，下方保留一条淡灰的原长虚影作对照，静止 5s。
  7. `[34.5s - 42.0s]`：**补动态**：在口播"我管它叫经验压缩"前后，摄像机沿虚影从短带缓推到虚影尽头（zoom 1.00→1.12），让观众看到被挤掉的那一大段灰；42.0s 落定前再静止 2.5s。

### Scene 06：那让 AI 一直给高光不就行了？
- **时间窗**：`02:18 - 02:58`（40s）
- **人像调度**：`full_canvas`
- **路标**：左上 `06 — 一条线`；右上 `示意`。
- **空间运镜与转场**：摄像机 1 倍；31.5s 带子变形为曲线时用同构变形（每个块的顶边连成曲线，不淡入淡出）；右下 EVID-04 小证据框出现时压暗周围到 0.35。
- **精修口播词**：
  > "那让 AI 一直给高光，不就行了？/ 试试。/ 【全换成亮的】。/ ……几秒钟之后，你就不觉得它亮了。/ 没有平静，就没有紧张；/ 没有日常，就没有惊喜。/ 高光是比出来的。/ 有的游戏甚至反过来，把平淡本身做成了卖点。/ 所以好玩不是事件多，/ 是【一条有起有伏的线】。"
- **注意力焦点**：整条带子全亮之后，亮色自己褪成了灰。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底。
  - **核心主体层**：Scene 04 的时间带（恢复长带）。后段在画面右下出现一个约 640×360 的小证据框播 `[EVID-04]`《动物森友会》。最后时间带变形为一条情感曲线。
  - **路标文字层**：全亮时带子上方"全是高光"；褪灰后改为"高光是比出来的"（≤ 8 字，≥ 24px）；曲线落定后峰旁标"紧"，谷旁标"松"。
- **因果动效编排**：
  1. `[初始态 0.0s]`：长带，灰多琥珀少。
  2. `[口播"全换成亮的" 5.5s -> 响应]`：所有灰块在 1s 内翻成满亮 `--sem-1`，整条带子刺眼地亮。
  3. `[时间流逝 7.5s - 11.5s -> 响应]`：没有任何别的动作，整条带子的琥珀在 4s 内均匀褪成 `--sem-3` 灰。这一拍只让"时间过去"作动因，画面其余部分完全不动。
  4. `[口播"没有平静，就没有紧张" 13.0s -> 响应]`：灰块按原位置插回，夹在其间的琥珀块重新亮起，比第 2 步更醒目。
  5. `[口播"反过来" 22.0s -> 响应]`：右下小证据框淡入播 EVID-04，6s 后淡出。
  6. `[口播"有起有伏的线" 31.5s -> 响应]`：时间带上每个块按"琥珀高、灰低"竖向错开，再连成一条平滑曲线，带子本身淡出。
  7. `[落定停留 35.0s - 40.0s]`：只剩曲线和"紧""松"两个标签，静止。

### Scene 08：涌现是什么？
- **时间窗**：`03:14 - 03:44`（30s）
- **人像调度**：`full_canvas`
- **路标**：左上 `08 — 涌现`；右上自 16.0s 起显示 `生命游戏 B3/S23 实跑`（不打「示意」）。
