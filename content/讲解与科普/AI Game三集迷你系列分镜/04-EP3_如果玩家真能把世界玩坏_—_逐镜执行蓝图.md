## 4. 逐镜执行蓝图

### Scene 01：你在游戏里做的事，算数吗？
- **时间窗**：`00:00 - 00:20`（20s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > “看这条街，刚才还一片狼藉。/ ……/ 【重新载入】。/ 同一机位，一切如新。/ 我刚才做的事，没有写进这一次载入的存档。”
- **注意力焦点**：同一条街、同一个机位，前一秒满目狼藉，后一秒完好如初。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底。
  - **核心主体层**：近乎满屏的证据框（约 1680×945，避开底部字幕区）播 `[EVID-08]`：先是破坏后的街道，再是重新载入后的同一条街。
  - **路标文字层**：证据框左上游戏名与厂商；切换瞬间画面中央极短地闪一行"重新载入"（`--text-h1`），0.8s 后消失。
- **因果动效编排**：
  1. `[初始态 0.0s]`：EVID-08 第一段，破坏后的街道，实机原速播放。
  2. `[口播"重新载入" 7.5s -> 响应]`：硬切到第二段，同一机位的完好街道；"重新载入"闪现后消失。不加任何转场特效，硬切本身就是论点。
  3. `[落定停留 12.0s - 20.0s]`：第二段继续原速播放，画面上没有任何自制元素。

### Scene 04：把安全网撤掉，会发生什么？
- **时间窗**：`01:12 - 01:58`（46s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "那我们把安全网撤掉。/ 我砍树。砍得很开心。/ 【森林没了】，雨就少了。/ 雨少了，【田荒了】。/ 田荒了，【粮仓见底】，人开始走。/ 后面每一环，都不是我亲手干的。/ 可每一环，都是我干的。/ 这条链上的数字是我编的示意，真要做得靠模拟去调。/ 重点只有一个：它没有在第二天重置。"
- **注意力焦点**：一个琥珀色光标砍树之后，四个环节一个接一个地倒下去，没人再碰它们。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底上的俯视沙盘网格（沿用细胞网格的格子尺寸）。
  - **核心主体层**：沙盘自左向右四块区域：森林（一片 `--sem-2` 格子）、降雨（区域上方一根横向量条）、农田（一片 `--sem-2` 格子）、粮仓与居民（一根量条加若干 `--sem-2` 小点）。相邻区域之间有细箭头。一个 `--sem-1` 十字光标只在森林区活动。画面右上稳定度读数。
  - **路标文字层**：四块区域标签"森林""降雨""农田""粮仓 · 居民"；稳定度读数从"100"起，三个阈值小刻度"70 预警""40 危机""10 崩溃"；读数下角注"阈值为作者示意"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：四块区域全满全亮，读数 100，光标停在森林边。
  2. `[口播"我砍树" 3.5s -> 响应]`：光标在森林区连点，每点一下灭掉一小片格子，节奏轻快。约 4s 后森林只剩三成，光标停手并从此不再动。
  3. `[口播"森林没了，雨就少了" 9.0s -> 响应]`：森林到降雨的箭头亮起，降雨量条缩短到三成；读数降到 70，"70 预警"刻度亮 `--sem-4`。
  4. `[口播"田荒了" 15.0s -> 响应]`：降雨到农田的箭头亮起，农田格子大片由青褪灰；读数降到 40。
  5. `[口播"粮仓见底，人开始走" 19.0s -> 响应]`：粮仓量条见底，居民小点一个个向画面右缘移出；读数降到 10，读数本身变朱红。
  6. `[口播"都不是我亲手干的" 24.0s -> 响应]`：停在森林边的琥珀光标轻闪一次，并拉出一条极细的琥珀虚线，沿三条箭头一路连到粮仓——把最后的结果连回最初的那只手。
  7. `[落定停留 36.0s - 46.0s]`：一片灰掉的沙盘、朱红的"10"、那条琥珀虚线，静止。没有任何重置动作。

### Scene 05：世界崩了，是不是就是烂游戏？
- **时间窗**：`01:58 - 02:42`（44s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "同一场崩溃，两种给法。/ 左边：玩了一百个小时，【啪】，一行字。/ 这是 bug。你只想退款。/ 右边：【它一年一年地垮给你看】。/ 大通胀。暴动。割据。最后一座图书馆被烧掉。/ 你知道是哪一步走错的。/ 这是一段历史。/ 而且是你写的。"
- **注意力焦点**：右栏那份逐年打出来的编年史；左栏那行冷冰冰的弹窗是它的对照。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底，中间一条竖直分隔线。
  - **核心主体层**：左栏（占 38%）：一个 `[示意]` 游戏弹窗，`--sem-4` 描边。右栏（占 62%）：一份编年史面板，`--bg-surface` 底，文字逐行打出，行首年份为 `--font-mono`。
  - **路标文字层**：左栏弹窗原文"由于经济崩溃，游戏结束。按 ESC 重新开始。"；左栏底部标签"崩溃 = bug"。右栏逐行："2087 大通胀开始，货币贬值 90%""2088 首都爆发食品暴动""2089 中央政府瓦解，三个军阀割据""2091 最后一座图书馆被焚毁""2095 文明数据已保存"；末行"这个文明存续了 108 年"为 `--sem-1-text`。右栏底部标签"崩溃 = 历史"。面板下角注"年份与数字为作者示意"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：只有分隔线，两栏皆空。
  2. `[口播"啪" 5.5s -> 响应]`：左栏弹窗无过渡地直接出现（0 帧淡入），这就是它的毛病。
  3. `[口播"你只想退款" 9.5s -> 响应]`：左栏底部标签出现，随后左栏整体压暗到 40%。
  4. `[口播"一年一年地垮给你看" 13.0s -> 响应]`：右栏面板展开，五行编年史按口播节奏逐行打出（约 14.5s / 17.0s / 19.0s / 21.5s / 25.0s），每行打完年份数字轻亮一下。
  5. `[口播"你知道是哪一步走错的" 28.0s -> 响应]`：第一行"2087 大通胀开始"左侧出现一个 `--sem-1` 小标记——那是玩家自己的决定所在的那一年。
  6. `[口播"而且是你写的" 35.0s -> 响应]`：末行"这个文明存续了 108 年"打出；右栏底部标签出现。
  7. `[落定停留 37.0s - 44.0s]`：左暗右亮，静止。
