## 4. 逐镜执行蓝图

### Scene 01：AI 管 AI，人能下班吗？
- **时间窗**：`00:00 - 00:16`（16s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "让一个 AI 当员工，【写内容】。/ 再让一个 AI 当经理，【审稿】。/ 再让一个 AI 当老板，【定方向】。/ 那人，是不是可以下班了？"
- **注意力焦点**：三层青色方框自下而上亮起，最顶上那个琥珀色的位置是空的。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底。画面中央是上一集结尾的母图轮廓，压到 20% 亮度作底。
  - **核心主体层**：母图框内自下而上三条横带：生成层、评估层、调控层，初始只有淡灰虚线轮廓。最上方、框的顶边之上，一个 `--sem-1` 虚线空框。
  - **路标文字层**：三条带左侧标签"员工：生成""经理：评估""老板：调控"；顶上空框内一个字"人？"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：只有压暗的母图和三条虚线轮廓。
  2. `[口播"写内容" 2.0s / "审稿" 5.5s / "定方向" 9.0s -> 响应]`：三条带依次由虚线变为 `--sem-2` 实线并出现标签，下层亮完上层才亮。
  3. `[口播"那人" 11.5s -> 响应]`：顶上的琥珀虚线空框出现，"人？"淡入。
  4. `[落定停留 13.0s - 16.0s]`：三层青、一个空的琥珀框，静止。

### Scene 03：一条事件怎么过第一道门？
- **时间窗**：`00:44 - 01:24`（40s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "我们跟着一批内容，从下往上走一遍。/ 最底下的 AI 只管多产，【天马行空】。/ 往上走，先过一道硬门槛。/ 世界的物理不能变——【这张，打回】。/ 角色的性格不能一夜翻脸——【这张，也打回】。/ 这道门槛不用 AI 判断好不好。/ 它是人写死的底线。"
- **注意力焦点**：五张事件卡往上走，两张撞在琥珀色的门槛上被弹回。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底。三条横带纵向展开占满画面高度的可用区：下 35% 为生成层，中 35% 为评估层，上 20% 为调控层（本镜压暗）。
  - **核心主体层**：生成层里五张 `--sem-2` 描边的事件卡（每张约 300×96px）。生成层与评估层之间一道横贯的 `--sem-1` 双线门槛，线上嵌两枚小牌。
  - **路标文字层**：五张卡的文字："铁匠铺夜里失火""河水倒流上山""两支商队为一口井吵起来""国王一夜之间变成懦夫""又一个送信任务"。门槛两枚小牌："物理不变""人设不崩"。门槛右端小字"硬约束，人定"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：三层带静止，生成层为空。
  2. `[口播"天马行空" 6.5s -> 响应]`：五张卡从生成层底边依次弹出，间隔 0.3s，排成一行。
  3. `[口播"硬门槛" 11.0s -> 响应]`：琥珀门槛从左到右画出，两枚小牌亮起；五张卡同时开始上升。
  4. `[口播"这张，打回" 16.0s -> 响应]`："河水倒流上山"撞到"物理不变"小牌，小牌闪亮，卡褪成 `--sem-3` 灰并落回生成层底部。
  5. `[口播"这张，也打回" 21.5s -> 响应]`："国王一夜之间变成懦夫"撞到"人设不崩"，同样褪灰落回。
  6. `[其余三张通过 23.0s]`：三张卡穿过门槛进入评估层，停在中带。
  7. `[落定停留 31.0s - 40.0s]`：评估层三张青卡，生成层底两张灰卡，门槛常亮，静止。

### Scene 04：谁来判断"够不够有趣"？
- **时间窗**：`01:24 - 02:06`（42s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "剩下三张，经理 AI 拿三把尺子量：/ 够不够新，/ 够不够动人，/ 合不合现在的节奏。/ 又一个送信任务，不新——【压下去】。/ 另外两张，【放进世界】。/ 注意这三把尺子怎么配重。/ 我在文章里写的是三成、四成、三成。/ 那是我拍脑袋的示意，不是测出来的。/ 配这个重，本身就是在定义什么叫好玩。"
- **注意力焦点**：三把尺子给每张卡量出的三段长度，以及那组可以拨动的配重。
- **视觉图层拆解**：
  - **背景/环境层**：同 Scene 03 的三层带，镜头略推近评估层。
  - **核心主体层**：评估层里三张卡竖向排开；每张卡右侧三条横向量条（长度即得分），量条为 `--sem-2`。量条上方三个表头，每个表头下有一个 `--sem-1` 的配重滑块。画面右缘一条竖直的"世界"入口。
  - **路标文字层**：表头"新颖""情感""节奏"；滑块旁数字"0.3""0.4""0.3"（`--font-mono`）；滑块下角注"配重为作者示意，非实测"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：评估层三张卡，无量条。
  2. `[口播三把尺子 3.5s / 5.5s / 7.5s -> 响应]`：三个表头依次出现，每出现一个，三张卡对应的那条量条同时伸出到各自长度。"又一个送信任务"的"新颖"条极短。
  3. `[口播"压下去" 14.0s -> 响应]`："又一个送信任务"褪灰，下沉回生成层底部，和之前两张灰卡排在一起。
  4. `[口播"放进世界" 17.0s -> 响应]`：另外两张卡向右滑进"世界"入口，入口亮一下青色。
  5. `[口播"怎么配重" 21.0s -> 响应]`：三个琥珀滑块和数字浮现并各自轻轻左右拨动一次再回原位——提示它们是人能拧的旋钮。
  6. `[口播"不是测出来的" 30.0s -> 响应]`：角注淡入。
  7. `[落定停留 34.0s - 42.0s]`：三个琥珀滑块是画面上唯一的琥珀元素，其余为青与灰，静止。

### Scene 05：整个世界跑偏了谁来管？
- **时间窗**：`02:06 - 02:44`（38s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "最上面那位不看单张卡。/ 它只看一条线：这个世界最近是紧是松。/ 平了太久，它往下发一句话：【多来点冲突】。/ 底层的口味立刻变了。/ 闹过头了，它再发一句：【稳一稳】。/ 上一集 RimWorld 的讲述者，也管事件什么时候来。/ 我借的是它调节奏的角色，不是说游戏里藏着这三层 AI。"
- **注意力焦点**：顶层那条情感曲线，以及它往下发的一句话如何改变底层吐出的卡。
- **视觉图层拆解**：
  - **背景/环境层**：三层带回到全景。
  - **核心主体层**：调控层亮起，内有一条从左向右延伸的情感曲线（EP1 Scene 06 的同款线）。一条细的 `--sem-2` 回路线从调控层右端向下绕回生成层左端——母图 L2 在此成形。生成层继续吐卡。末段右下角约 560×315 小证据框播 `[EVID-07]`。
  - **路标文字层**：调控层标签"紧 / 松"；两条下行指令气泡"多来点冲突""稳一稳"；生成层新卡的文字，冲突类如"边境哨所被袭""粮价一夜翻倍"，日常类如"集市来了个说书人""老猎户收了个徒弟"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：调控层从压暗变亮，曲线已有一段，近期一长段是平的。
  2. `[口播"平了太久" 9.0s -> 响应]`：平的那段曲线被一条虚线标出。
  3. `[口播"多来点冲突" 12.5s -> 响应]`：指令气泡沿回路线从调控层滑到生成层；到达后，生成层吐出两张冲突类新卡；这两张卡一路通过门槛和评估进入世界，曲线随之抬升出一个峰。
  4. `[口播"闹过头了" 20.0s -> 响应]`：曲线连出两个高峰，峰顶被虚线标出。
  5. `[口播"稳一稳" 22.5s -> 响应]`：第二个气泡沿同一回路下行；生成层吐出两张日常类卡；曲线回落成一个谷。
  6. `[口播"讲述者" 31.0s -> 响应]`：右下小证据框淡入播 EVID-07 讲述者界面 4s。
  7. `[落定停留 33.0s - 38.0s]`：一条有峰有谷的曲线、一圈闭合的青色回路，静止。

- **人像调度**：`full_canvas`
- **精修口播词**：

- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底，三层带收成画面上方一条窄的示意条（只留评估层高亮）。
  - **核心主体层**：画面中央大幅的情感曲线（宽约 1500px），沿用 Scene 05 落定的峰谷形状。曲线左下方三枚玩家行为信号小牌，各有一条细线连向上方的评估层。曲线右侧一个竖向旋钮"留存率"。
  - **路标文字层**：三枚小牌"跳过的对话""停留的时长""重玩的次数"；旋钮标签"留存率"；直线形成后上方"全是高潮"。右下「示意」。
- **因果动效编排**：

  2. `[口播"看他做了什么" 5.0s -> 响应]`：三枚行为小牌依次出现，细线上有青色小光点向评估层流动。
  3. `[口播"拿这些去教经理" 13.0s -> 响应]`：评估层的窄条亮一下；"留存率"旋钮出现并开始缓慢上旋。
  4. `[口播"低谷被一个一个填平" 26.0s -> 响应]`：曲线的谷从左到右逐个被抬起到峰的高度，每填一个谷旋钮再上旋一格。约 5s 填完，曲线成为高位直线。
  5. `[口播"上一集，我们见过它的下场" 37.0s -> 响应]`：整条直线在 3s 内由琥珀褪成 `--sem-3` 灰——与 EP1 Scene 06 第 3 步完全同款的褪色。
  6. `[落定停留 40.0s - 44.0s]`：一条灰色的高位直线，旋钮拧到顶，静止。

### Scene 08：让它直接从现实里学行不行？
- **时间窗**：`03:42 - 04:38`（56s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "第二条路更激进：/ 让 AI 去读整个互联网，自己总结人类喜欢什么。/ 它可能看见什么被转得多。/ 转发是不是喜欢，还得问。/ 可人的喜欢，是一层套一层的。/ 最外面：【我喜欢这个角色】。/ 往里：【因为他敢反抗】。/ 再往里：【因为我自己在生活里憋着】。/ 最里面：【人想自己做主】。/ 外面有行为线索。/ 越往里，越不能光靠次数断定动机。/ 而一部作品真正打动人的地方，偏偏在里面。"
- **注意力焦点**：一根青色的探针从外面扎进四层同心结构，只到第一层就停了。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底。
  - **核心主体层**：画面中央偏右一个四层同心圆剖面（直径约 760px），像切开的洋葱，层间用 `--ink-border` 细线分隔，越往里底色越接近 `--sem-1-tint`，核心是一个满亮 `--sem-1` 的小圆。左侧一片由许多 `--sem-2` 小点构成的数据云；一根 `--sem-2` 探针从数据云伸向同心圆。
  - **路标文字层**：四层各一行引出文字："我喜欢这个角色""因为他敢反抗""因为我在生活里憋着""人想自己做主"。数据云标签"流行什么"。探针停住处小字"行为线索"；内三层旁小字"动机未定"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：只有左侧数据云，小点缓慢聚成几簇（对应"什么在火"）。
  2. `[口播"一层套一层" 17.0s -> 响应]`：右侧同心圆从外向内逐层展开，此时不带文字。
  3. `[口播四层 20.5s / 24.0s / 27.5s / 32.0s -> 响应]`：四行文字由外向内逐层点亮，每点亮一层，该层底色加深一档；最后核心小圆亮到满琥珀。
  4. `[口播"外面有行为线索" 37.0s -> 响应]`：探针从数据云伸出，刺入最外层，层内泛起青色并出现"行为线索"。
  5. `[口播"越不能光靠次数断定动机" 41.0s -> 响应]`：探针继续向内，推进速度明显变慢并在第二层边界处停住、线条变虚；内三层旁出现"动机未定"。
  6. `[落定停留 47.0s - 56.0s]`：青色只染到最外一层，琥珀核心完好地亮在中间，静止。

### Scene 09：就算学得会，还差什么？
- **时间窗**：`04:38 - 05:10`（32s）
- **人像调度**：`full_canvas`
- **精修口播词**：
  > "还有一道更硬的坎。/ 数据能告诉你：比如这次把两种任务并排放，快反馈的那种被点得多。/ 先别急着猜人为什么点。/ 它告诉不了你：/ 那我们是顺着做，/ 还是做一款让人慢下来的游戏？/ 前一个是观察。/ 后一个是【选择】。"
- **注意力焦点**：左边的柱子可以一直长，但它伸向右边的箭头在中间断开了；右边要人来填。
- **视觉图层拆解**：
  - **背景/环境层**：墨蓝底，中间一条竖直的 `--ink-border` 分隔线。
  - **核心主体层**：左半：两根 `--sem-2` 横条示意点开次数，较长的一根标着"快反馈"。右半：一个 `--sem-1` 描边的空白卡，里面有一个闪动的光标。一条箭头从左半指向右半，在分隔线处断开。
  - **路标文字层**：左半标题"任务被点开几次"，两根条分标"快反馈""慢铺垫"；右半标题"我们该做什么"；左下"观察"，右下"选择"。右下「示意」。
- **因果动效编排**：
  1. `[初始态 0.0s]`：只有分隔线。
  2. `[口播"数据能告诉你" 3.0s -> 响应]`：左半标题与两根条依次长出，"快反馈"最长。
  3. `[口播"它告诉不了你" 10.0s -> 响应]`：箭头从左半出发向右延伸，到分隔线处断开并停住；右半标题与空白卡出现，光标开始闪。
