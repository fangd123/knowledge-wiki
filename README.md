# fangd123 的公开知识库

这是从个人 Obsidian 知识库中选编、脱敏后的公开版本。作者署名 **fangd123**。

## 这里有什么

- **AI 技术与工程**：本地大模型架构与推理框架、LLM 网关与生图生态调研、Agent 工具实战（含火山引擎对话机器人）、声音产品方法论、AI交互设计2026版、FormFill 浏览器扩展项目文档
- **算力与产业研究**：LLM-Token 经济学专著、算力经济学系列（总纲 + 产业链通识 / token 工厂 / 期限结构 / 指数与衍生品 / 计量与定价专题）、算力交易市场建模、实体产业 AI 应用调研、金属定价与标准竞争长文《标准出海》
- **马克思主义与政治经济学**：《资本论》辅助阅读（含术语表、词义陷阱、读法专题）、AI 时代的毛选阅读指南（含带读前置材料）、面包的寓言、关于费尔巴哈的提纲、AI 大收割、异化与商品化批判、范畴批判与历史唯物主义随笔
- **AI 与社会**：AI 教育与管理学、组织变革（组织根据地、AI 燎原路径）、软件工程的重生、算法权力评论、AI 替代劳动
- **讲解与科普**：AI 交互设计系列文章、科普视频导演阐述与分镜、PPT 策划
- **创作与人文**：小岛物语 Godot 开发日志、人生尽调故事集、生活方法随笔（如买房与租房的比较）、六个月摄影提升计划（方法论教程，不含家人照片）、AI 带娃方法手记（去标识化的通用育儿方法）
- **工具与效率**：利器系列、终端环境改造、Zellij 使用指南

## 这里没有什么

- **任何雇主相关信息（永久排除）**：公司名、产品名、团队、报价、会议、内部战略、招聘材料。
- 个人与家庭数据：简历、孩子信息、家庭日程、个人照片、私人 Agent 记忆。
- 第三方付费内容：播客音频/字幕、课程逐字稿、未授权新闻图片、论文或文档全文镜像。
- 未完成草稿、冲突副本、日志、数据库、工程中间产物。
